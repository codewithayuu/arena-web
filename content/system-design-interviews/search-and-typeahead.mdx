Many products have a search box. Behind it, the system has to find matching items among millions of records, order them so the best ones come first, and often suggest queries before the user finishes typing.

This lesson covers how search systems find matching results in large amounts of text in milliseconds, how they decide which results to show first, and how typeahead suggests queries while the user is still typing.

It also covers how to approach search and typeahead in a system design interview, since search is part of many common interview problems.
