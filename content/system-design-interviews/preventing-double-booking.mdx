Booking systems need to make sure that a seat, room, or time slot is assigned to only one person, even when many users try to book it at exactly the same time.

This lesson covers why double booking happens when many users try to reserve the same thing at the same time, the main techniques used to prevent it, and how to handle cases where thousands of users compete for a limited number of seats.

It also covers how to approach double booking in a system design interview, since it's a key part of most booking and reservation problems.
