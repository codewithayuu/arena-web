**Question 1: Which principle helps prevent a class from growing large and handling unrelated tasks, leading to maintenance issues?**

- [x] Single Responsibility Principle
- [ ] Open/Closed Principle

**Question 2: A payment processing module needs to support new payment methods without modifying its existing code. Which principle supports this?**

- [x] Open/Closed Principle
- [ ] Dependency Inversion Principle
- [ ] Single Responsibility Principle

**Question 3: If a subclass cannot be used reliably in place of its superclass without breaking the system, which principle is violated?**

- [x] Liskov Substitution Principle
- [ ] Open/Closed Principle
- [ ] Interface Segregation Principle

**Question 4: A class depends on lower-level modules and is tightly coupled to a specific implementation (e.g., a concrete email provider). Which SOLID principle is being violated?**

- [x] Dependency Inversion Principle
- [ ] Interface Segregation Principle
- [ ] Single Responsibility Principle

**Question 5: You notice an interface with many unrelated methods, leading to classes having unused or empty implementations. Which principle is being violated?**

- [x] Interface Segregation Principle
- [ ] Single Responsibility Principle
- [ ] Liskov Substitution Principle

**Question 6: Which concept describes the relationship where one class 'owns' an object and is responsible for its lifecycle?**

- [x] Composition
- [ ] Aggregation
- [ ] Association

**Question 7: What is a likely symptom of not following the Open/Closed Principle?**

- [x] Frequent modification of tested, stable code when requirements change
- [ ] Too many interfaces for simple classes
- [ ] Using abstractions instead of concrete classes

**Question 8: You find yourself adding empty method implementations just to satisfy an interface. Which design principle can help?**

- [x] Interface Segregation Principle
- [ ] Single Responsibility Principle
- [ ] Open/Closed Principle

**Question 9: Which design principle ensures that code changes in one class do NOT cause bugs or require changes in unrelated classes?**

- [x] Single Responsibility Principle
- [ ] Dependency Inversion Principle
- [ ] Liskov Substitution Principle

**Question 10: Which principle would be directly violated if a function that expects a general media player fails when given a specialized audio only player?**

- [x] Liskov Substitution Principle
- [ ] Open/Closed Principle
- [ ] Interface Segregation Principle
