**Question 1: Which design pattern is best for decoupling the sender of a request from the object that performs the request?**

- [x] Command
- [ ] Observer
- [ ] Mediator
- [ ] Visitor

**Question 2: A fitness app wants multiple modules to receive updates whenever new health data arrives. Which pattern is most suitable?**

- [x] Observer
- [ ] State
- [ ] Strategy
- [ ] Iterator

**Question 3: Which pattern should you use to allow a playlist to be traversed in multiple ways without exposing the internal song list?**

- [x] Iterator
- [ ] Chain of Responsibility
- [ ] Template Method
- [ ] Mediator

**Question 4: You need several algorithms for calculating shipping costs in your e-commerce app. Which pattern offers the best flexibility?**

- [x] Strategy
- [ ] Memento
- [ ] Visitor
- [ ] State

**Question 5: A vending machine changes its logic based on whether money has been inserted. What's the most appropriate pattern for this?**

- [x] State
- [ ] Mediator
- [ ] Iterator
- [ ] Command

**Question 6: If you want to compose a request-processing pipeline where each handler may process or pass the request along, which pattern fits?**

- [x] Chain of Responsibility
- [ ] Strategy
- [ ] Observer
- [ ] Visitor

**Question 7: Which pattern should be used in a drawing app to add new operations (like export formats) to shapes without modifying their classes?**

- [x] Visitor
- [ ] Template Method
- [ ] Memento
- [ ] Command

**Question 8: An application must support undo functionality for user actions while keeping object state encapsulated. Which pattern fits best?**

- [x] Memento
- [ ] Observer
- [ ] State
- [ ] Chain of Responsibility

**Question 9: Which pattern would you use to coordinate interactions between UI components (fields, buttons) to reduce their dependencies on each other?**

- [x] Mediator
- [ ] Strategy
- [ ] Template Method
- [ ] Visitor

**Question 10: If you want to ensure the structure of an algorithm remains the same across subclasses, but allow certain steps to be overridden, which pattern applies?**

- [x] Template Method
- [ ] Strategy
- [ ] Memento
- [ ] Iterator

**Question 11: What is the primary benefit of using the Iterator pattern with a tree or graph data structure?**

- [x] Enabling traversal without exposing internal structure
- [ ] Decoupling user input from UI elements
- [ ] Storing snapshots of state
- [ ] Notifying multiple observers

**Question 12: Which pattern prevents violating encapsulation when restoring a previous object state?**

- [x] Memento
- [ ] Mediator
- [ ] Strategy
- [ ] Command
