<h1 id="quiz-questions">Quiz Questions</h1>

**Question 1: Which concept means combining data and behavior into a single unit with restricted access?**

- [x] Encapsulation
- [ ] Inheritance
- [ ] Polymorphism
- [ ] Abstraction

**Question 2: What is the main advantage of using enums for state representation?**

- [x] Prevents invalid values in variables
- [ ] Reduces the number of classes
- [ ] Adds runtime flexibility
- [ ] Supports class inheritance

**Question 3: A subclass overrides a method from its superclass. This demonstrates which concept?**

- [x] Polymorphism
- [ ] Association
- [ ] Composition
- [ ] Aggregation

**Question 4: What distinguishes an interface from an abstract class in OOP design?**

- [x] It defines only behavior, no implementation
- [ ] It must provide concrete methods
- [ ] It cannot be used for polymorphism
- [ ] It enforces single inheritance

**Question 5: What is a primary benefit of designing with high abstraction?**

- [x] Simplifies use by hiding complexity
- [ ] Increases coupling between classes
- [ ] Forces all details to be exposed
- [ ] Prevents code reuse

**Question 6: A remote control works with various devices through the same set of commands. Which OOP concept does this illustrate?**

- [x] Polymorphism
- [ ] Enum
- [ ] Aggregation
- [ ] Association

**Question 7: An object can only take one of a limited set of predefined roles, such as ADMIN, CUSTOMER, or DRIVER. What feature best models this?**

- [x] Enum
- [ ] Abstract class
- [ ] Interface
- [ ] Composition
