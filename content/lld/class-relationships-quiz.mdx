<h1 id="quiz-questions">Quiz Questions</h1>

**Question 1: Which UML symbol best represents an aggregation relationship between two classes?**

- [x] Hollow diamond
- [ ] Filled diamond
- [ ] Arrowhead
- [ ] Dashed line

**Question 2: Which relationship should you use if the lifecycle of a part depends entirely on its whole?**

- [x] Composition
- [ ] Aggregation
- [ ] Association
- [ ] Dependency

**Question 3: A computer system prints a document but does not retain a reference after printing. What relationship does this describe?**

- [x] Dependency
- [ ] Association
- [ ] Aggregation
- [ ] Composition

**Question 4: Which option best defines Association in object-oriented design?**

- [x] A relationship where objects use or reference each other with independent lifecycles
- [ ] A relationship where the lifecycle of one object is tied to another's
- [ ] A relationship showing temporary reliance without persistent reference
- [ ] A relationship where one object completely owns another

**Question 5: In a UML class diagram, how is a dependency depicted?**

- [x] Dashed arrow
- [ ] Solid line
- [ ] Hollow diamond
- [ ] Filled diamond

**Question 6: Which scenario best illustrates an aggregation relationship?**

- [x] A library has books, but books can exist outside the library
- [ ] A car has an engine that cannot exist without the car
- [ ] A user interacts with a printer briefly to print
- [ ] A student logs into a portal

**Question 7: If destroying a parent object automatically destroys all its child objects, what relationship is being modeled?**

- [x] Composition
- [ ] Aggregation
- [ ] Association
- [ ] Dependency

**Question 8: Which is NOT a valid characteristic of aggregation?**

- [x] The whole controls the lifecycle of the part
- [ ] The part can exist independently
- [ ] The whole and part are logically connected
- [ ] The part can be shared among multiple wholes

**Question 9: Which relationship is typically represented by a solid line in UML?**

- [x] Association
- [ ] Dependency
- [ ] Aggregation
- [ ] Composition

**Question 10: Which design scenario indicates a 'has-a' but not a 'part-of' relationship?**

- [x] Association
- [ ] Composition
- [ ] Aggregation
- [ ] Dependency

**Question 11: Which kind of UML multiplicity conveys that an object may reference multiple instances of another class?**

- [x] -
- [ ] 1
- [ ] 0..1
- [ ] 1..1

**Question 12: A team consists of players, but players can also join other teams. Which relationship is best used in the design?**

- [x] Aggregation
- [ ] Composition
- [ ] Association
- [ ] Dependency
