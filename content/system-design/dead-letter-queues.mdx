<h1 id="1-what-is-a-dead-letter-queue">1. What Is a Dead Letter Queue?</h1>

A **dead letter queue**, or **DLQ**, is a separate queue where messages go after they fail processing too many times.

Instead of retrying the poison message forever, or deleting it, the system moves it into the DLQ. The main queue continues processing the rest of the messages normally.

The failed message sits in the DLQ, where engineers can inspect it, understand why it failed, fix the problem, and send it back for processing.

You can think of the DLQ as a **quarantine area**. It keeps one bad message from affecting everything else, while making sure nothing is lost.
