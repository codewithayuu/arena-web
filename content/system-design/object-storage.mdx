<LessonCard>

Modern applications need to store large amounts of data, from images, videos, and documents to backups, logs, and machine learning datasets. Much of this data is stored using object storage, the storage model behind services like Amazon S3, Google Cloud Storage, Azure Blob Storage, and MinIO.

In this chapter, we will look at what object storage is, how it stores and serves files at massive scale, and where it fits (and does not fit) in a system design.
