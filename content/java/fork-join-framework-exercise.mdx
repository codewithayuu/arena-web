Use a Fork/Join `RecursiveTask<Integer>` to sum the array containing the integers `1` through `16`. Use a threshold of `4` elements.

In `compute()`, sum the slice directly when its length is less than or equal to `4`. Otherwise split at the midpoint, fork the left task, compute the right task on the current thread, join the left task, and return the combined sum.
