Process the literal invoice string "invoice:A-17" through two layers while preserving the low-level parsing failure.

The readCustomerId method should wrap the caught NumberFormatException in a RepositoryException with the message "Could not read customer id from invoice:A-17". The processInvoice method should wrap the caught RepositoryException in a ProcessingException with the message "Could not process invoice invoice:A-17". The main method already walks the chain with getCause().
