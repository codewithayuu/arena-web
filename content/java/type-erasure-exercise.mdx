Demonstrate how a raw generic reference can bypass compile-time checks and make the compiler-inserted cast fail later. Start with a `Box<String>` containing "safe".

Assign `textBox` to the raw `Box` variable `rawBox`, then store `Integer.valueOf(99)` through `rawBox`. Reading from `textBox` as a `String` should throw `ClassCastException`, and the existing catch block should print the failure message.
