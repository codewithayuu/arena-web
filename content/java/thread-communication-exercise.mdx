A SignalBox starts with its boolean flag set to false. The waiter thread must block until the main thread sends a signal.

In awaitSignal, use the monitor methods on the SignalBox object: wait in a while loop while ready is false. In sendSignal, set ready to true and call notifyAll so the waiting thread can continue.
