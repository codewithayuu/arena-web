Build three overloaded methods named `tag` for a checkout label printer. For `tag("Pencils", 12)`, return the string `Pencils: 12 in stock`. For `tag("Notebook", 2.5)`, return the string `Notebook: $2.50`. For `tag("Backpack", "sold out")`, return the string `Backpack: sold out`.

Keep the same method name and let the different parameter lists choose the overload at compile time.
