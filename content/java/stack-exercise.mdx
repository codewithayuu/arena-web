Model a shelf stack that receives the strings "notebook", "pen", and "eraser" in that order. Because a stack is last-in-first-out, "eraser" is the top item immediately after the pushes.

Use `peek()` to read the top without removing it, `pop()` to remove the top, another `peek()` to read the new top, and `empty()` to check whether the stack still has items. The popped item is "eraser", the new top is "pen", and the empty check is `false`.
