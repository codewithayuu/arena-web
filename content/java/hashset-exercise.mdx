Track warehouse product codes in a `HashSet<String>`. Add the literal codes "P-1001", "P-1002", "P-1001" again, and "P-1003".

Store the return value from adding the first "P-1001" in `firstAdd`, the return value from adding the duplicate "P-1001" in `duplicateAdd`, and store whether the set contains "P-1002" in `hasP1002`. A new element added to a `HashSet` returns `true`; a duplicate returns `false`.
