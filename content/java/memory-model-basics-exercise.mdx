Classify three shared-state bugs using the exact strings "visibility", "atomicity", and "ordering".

A non-volatile boolean flag named storeOpen that one thread changes and another thread may never notice is "visibility". An orderCount++ update performed by multiple threads is "atomicity". A customerName write that should be seen before a ready flag but may be observed in the opposite order is "ordering".
