Inspect the nested `Product` class with reflection. It declares `public static final double TAX_RATE`, private fields `id`, `name`, and `price`, and package-private field `stockQty`.

Use `Product.class.getFields()` for public fields and `Product.class.getDeclaredFields()` for fields declared directly on `Product`. Sort field names alphabetically before joining them with `", "`.
