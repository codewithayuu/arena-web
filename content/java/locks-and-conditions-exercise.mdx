Use one `ReentrantLock` through the `Lock` interface to protect an integer stock count. In `addStock`, acquire the lock, add the given amount to `stockCount`, and release the lock in a `finally` block.

In `readStock`, acquire the same lock, return `stockCount`, and release the lock in a `finally` block. The program adds 10 units and then 7 units before printing the final count.
