Print sounds for three pets stored in a `Pet[]`: `new Dog("Rex")`, `new Cat("Misty")`, and `new Pet("Pebble")`. The loop calls `pet.sound()` for every element so Java chooses the method from the runtime object.

`Dog.sound()` returns `"woof"`, `Cat.sound()` returns `"meow"`, and the base `Pet.sound()` returns `"quiet"`.
