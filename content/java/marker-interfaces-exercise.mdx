Use Java's `Serializable` marker to let `ObjectOutputStream` accept a receipt and reject a session token. Mark only `Receipt` as `Serializable`, and declare `private static final long serialVersionUID = 1L;` inside `Receipt`.

The program tests a receipt with id "R-100" and total `42.50`, then tests a session token with value "TOKEN-XYZ".
