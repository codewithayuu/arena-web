Print two greetings using default methods in the `Greeter` interface. The `morningGreeting()` method uses the time string "morning" and the name "Mia"; the `eveningGreeting()` method uses the time string "evening" and the name "Leo".

Use the private interface instance method `formatGreeting(String time, String name)` to build exactly `"Good " + time + ", " + name + "!"` so both default methods share the same helper logic.
