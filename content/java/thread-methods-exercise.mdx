Start a Thread named "order-worker" so its lambda runs on that worker thread, not on "main". The main method should print its own thread name before starting the worker, wait for the worker to finish with join(), and then print its own thread name again.

Inside the worker, use Thread.currentThread().getName() in the existing print statement so the worker line contains "order-worker".
