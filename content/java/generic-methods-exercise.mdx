`firstNonNull` is a static generic method with one method type parameter, `T`. It must return `a` when `a` is not `null`; otherwise it must return `b`, using the conditional expression `(a != null) ? a : b`.

The program calls the method with `null` and `"WELCOME10"` to get a `String`, then with `null` and `25` to get an `Integer`.
