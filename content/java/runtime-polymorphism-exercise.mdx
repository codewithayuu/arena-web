A single `Animal[]` contains `new Dog("Rex")`, `new Cat("Misty")`, and `new Cow("Betsy")`. The loop calls `speak()` through an `Animal` reference, so each subclass must override `speak()` for runtime polymorphism to choose the real object's method.

Make `Dog.speak()` return `"woof"`, `Cat.speak()` return `"meow"`, and `Cow.speak()` return `"moo"`.
