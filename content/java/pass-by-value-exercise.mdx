Demonstrate that passing primitive `int` values copies the numbers into method parameters. The caller starts with `left` equal to `7` and `right` equal to `3`.

Inside `swapCopies`, swap only the local parameters `a` and `b` using a temporary `int` variable, then print them with the existing `System.out.println`. The caller's `left` and `right` variables must remain `7` and `3` after the method returns.
