Open a JDBC connection through `DriverManager` using the URL-only overload. Use the exact URL string `jdbc:demo:mem:shop;DB_CLOSE_DELAY=-1`; the registered demo driver accepts only that URL and reports the catalog `SHOP`.

Store the URL in the `url` variable before the guard so the program obtains a `Connection`, checks that it is open, and prints its catalog.
