Model exactly two ticket records: `BusTicket("B-100", "Central")` and `TrainTicket("T-200", "North Station")`. Make `Ticket` a sealed interface that permits only `BusTicket` and `TrainTicket`.

The program uses reflection to print whether `Ticket` is sealed, then prints the permitted type names and descriptions of the two ticket objects.
