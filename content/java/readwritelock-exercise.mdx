A price catalog stores "notebook" at 4.99 and "pen" at 1.49, then changes "notebook" to 5.49. Guard lookups with the read view and mutations with the write view of one ReentrantReadWriteLock.

Use the cached Lock fields named readLock and writeLock. In getPrice, lock and unlock readLock. In updatePrice, lock and unlock writeLock. Return -1.0 for a missing product.
