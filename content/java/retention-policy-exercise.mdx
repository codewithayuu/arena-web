Make the class-level annotation `@ValidateOrder` survive until runtime so reflection can see it on the nested `Order` class.

Use `@Retention(RetentionPolicy.RUNTIME)` and keep `@Target(ElementType.TYPE)` on `ValidateOrder`. The program should print whether `Order.class.isAnnotationPresent(ValidateOrder.class)` is `true`.
