Print only the cart item names that start with the letter "P" from the list `List.of("Notebook", "Pen", "Eraser", "Pencil")`.

Use `cart.stream()` as the source, `filter(name -> name.startsWith("P"))` as the intermediate operation, and `forEach(name -> System.out.println(name))` as the terminal operation.
