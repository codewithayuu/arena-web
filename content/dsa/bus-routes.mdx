<LessonCard>

You are given an array `routes` where `routes[i]` is a bus route that the `i`th bus repeats forever.

- For example, if `routes[0] = [1, 5, 7]`, this means that the `0`th bus travels in the sequence `1 -> 5 -> 7 -> 1 -> 5 -> 7 -> 1 -> ...` forever.

You will start at the bus stop `source` (You are not on any bus initially), and you want to go to the bus stop `target`. You can travel between bus stops by buses only.

Return the least number of buses you must take to travel from bus stop `source` to bus stop `target`. Return `-1` if it is not possible.

\***\*Example 1:\*\***

**Input:** `routes = [[1,2,7],[3,6,7]]`, `source = 1`, `target = 6`

**Output:** `2`

_The best strategy is take the first bus to the bus stop 7, then take the second bus to the bus stop 6._

\***\*Example 2:\*\***

**Input:** `routes = [[7,12],[4,5,15],[6],[15,19],[9,12,13]]`, `source = 15`, `target = 12`

**Output:** `-1`

\***\*Constraints:\*\***

- `1 <= routes.length <= 500`
- `1 <= routes[i].length <= 10^5`
- All the values of `routes[i]` are unique.
- `sum(routes[i].length) <= 10^5`
- `0 <= routes[i][j] < 10^6`
- `0 <= source, target < 10^6`

For each stop we dequeue, find all routes that serve it, then add every unvisited stop on those routes to the queue. Each BFS level corresponds to boarding one more bus.

<h1 id="understanding-the-problem">Understanding the Problem</h1>

We have a city with bus stops and bus routes. Each bus route is a loop that visits a specific set of stops. We start at a particular stop and want to reach another stop using as few buses as possible. The answer counts buses boarded, not stops passed through.

This is a shortest path problem where the cost is per bus, not per stop. Riding one bus for 20 stops costs 1, while boarding a second bus to travel a single stop raises the total to 2.

Once you board a bus, every stop on its route is reachable at no extra cost. The question then becomes: what is the minimum number of routes we need to chain together to get from source to target? Two routes can be chained if they share at least one stop, because that shared stop is where we transfer from one bus to the other.

<h3 id="key-constraints">Key Constraints:</h3>

- `1 <= routes.length <= 500` -> The number of routes is small. A BFS whose nodes are whole routes searches at most 500 nodes.
- `sum(routes[i].length) <= 10^5` -> The total number of stop entries across all routes is at most 100,000. This bounds the work of any approach that scans route contents.
- `0 <= routes[i][j] < 10^6` -> Stop IDs can be up to a million, so we map stops to routes with a hash map rather than an array indexed by stop ID.

<h1 id="approach-1-bfs-on-stops">Approach 1: BFS on Stops</h1>

<h3 id="intuition">Intuition</h3>

Treat each bus stop as a node and run a BFS from source to target. Two stops are connected if some bus route contains both, and riding that bus from one stop to the other costs 1 bus. A single BFS step should therefore expand from a stop to every stop on every route that serves it.

For each stop we dequeue, find all routes that serve it, then add every unvisited stop on those routes to the queue. Each BFS level corresponds to boarding one more bus.

One hazard remains. A route can hold up to 100,000 stops, and the same route can be reached from many different stops, so re-expanding it on every encounter repeats that work. Tracking visited routes ensures each route's stops are expanded once, which keeps the total expansion work bounded by the total number of stop entries.

<h3 id="algorithm">Algorithm</h3>

1. If source equals target, return 0 immediately.
2. Build a map from each stop to the list of route indices that serve it.
3. Initialize a BFS queue with the source stop. Set the initial bus count to 0.
4. Maintain a set of visited stops and a set of visited routes.
5. For each level of BFS (one level = one bus ride):
6. If the queue empties without reaching the target, return -1.

```java
class Solution {
    public int numBusesToDestination(int[][] routes, int source, int target) {
        if (source == target) return 0;

        // Map each stop to the routes that serve it
        Map<Integer, List<Integer>> stopToRoutes = new HashMap<>();
        for (int i = 0; i < routes.length; i++) {
            for (int stop : routes[i]) {
                stopToRoutes.computeIfAbsent(stop, k -> new ArrayList<>()).add(i);
            }
        }

        // BFS on stops
        Queue<Integer> queue = new LinkedList<>();
        Set<Integer> visitedStops = new HashSet<>();
        Set<Integer> visitedRoutes = new HashSet<>();
        queue.offer(source);
        visitedStops.add(source);
        int buses = 0;

        while (!queue.isEmpty()) {
            buses++;
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int stop = queue.poll();
                // Check all routes through this stop
                for (int route : stopToRoutes.getOrDefault(stop, new ArrayList<>())) {
                    if (visitedRoutes.contains(route)) continue;
                    visitedRoutes.add(route);
                    // Add all stops on this route
                    for (int nextStop : routes[route]) {
                        if (nextStop == target) return buses;
                        if (visitedStops.add(nextStop)) {
                            queue.offer(nextStop);
                        }
                    }
                }
            }
        }
        return -1;
    }
}
```

> - **Time Complexity:** O(S) where S is the total number of stop entries across all routes. Building the stop-to-routes map takes O(S). Each stop is dequeued at most once and its route list is scanned once; the sum of all those list lengths is S. Each route is expanded at most once, and the sum of all route lengths is also S.
> - **Space Complexity:** O(S + N) where N is the number of routes: O(S) for the stop-to-routes map, the visited-stops set, and the queue, plus O(N) for the visited-routes set.

This approach is correct and fast, but the queue holds individual stops (up to 100,000 entries) while the answer counts buses. The next approach makes routes the nodes of the BFS, so the search operates directly on the quantity being minimized.

<h1 id="approach-2-bfs-on-routes-optimal">
  Approach 2: BFS on Routes (Optimal)
</h1>

<h3 id="intuition">Intuition</h3>

Run the BFS over routes instead of stops. Every route that contains the source stop is reachable with 1 bus. If any of those routes contains the target, the answer is 1. Otherwise, every route that shares a stop with one of them is reachable with 2 buses, because the shared stop is a transfer point. Expanding level by level finds the first route that contains the target.

This is a standard BFS where the nodes are route indices and two routes are neighbors if they share at least one stop. The number of buses equals the BFS level at which a route containing the target first appears. The queue now holds route indices (at most 500) instead of stop IDs (up to a million), and one BFS level corresponds to one bus.

> BFS on an unweighted graph reaches every node at its minimum distance first, so the first route found to contain the target gives the minimum bus count. This is also why marking a route visited at enqueue time (rather than at dequeue time) is safe: any later path to that route uses at least as many buses. Enqueue-time marking also keeps each route in the queue at most once, so the queue never holds more than N entries.

<h3 id="algorithm">Algorithm</h3>

1. If source equals target, return 0 immediately.
2. Build a map from each stop to the list of route indices that serve it.
3. Create a set of "target routes" (routes that contain the target stop) for quick lookup.
4. Initialize the BFS queue with all route indices that serve the source stop. Mark them as visited. Set bus count to 1.
5. For each level of BFS:
6. If the queue empties, return -1.

```java
class Solution {
    public int numBusesToDestination(int[][] routes, int source, int target) {
        if (source == target) return 0;

        int n = routes.length;
        // Map each stop to the routes that serve it
        Map<Integer, List<Integer>> stopToRoutes = new HashMap<>();
        for (int i = 0; i < n; i++) {
            for (int stop : routes[i]) {
                stopToRoutes.computeIfAbsent(stop, k -> new ArrayList<>()).add(i);
            }
        }

        // Identify routes containing the target
        Set<Integer> targetRoutes = new HashSet<>();
        for (int route : stopToRoutes.getOrDefault(target, new ArrayList<>())) {
            targetRoutes.add(route);
        }

        // BFS on routes, starting from all routes that serve the source
        Queue<Integer> queue = new LinkedList<>();
        boolean[] visitedRoutes = new boolean[n];
        for (int route : stopToRoutes.getOrDefault(source, new ArrayList<>())) {
            queue.offer(route);
            visitedRoutes[route] = true;
        }

        int buses = 1;
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int route = queue.poll();
                // Check if this route reaches the target
                if (targetRoutes.contains(route)) return buses;
                // Find neighbor routes via shared stops
                for (int stop : routes[route]) {
                    for (int neighbor : stopToRoutes.get(stop)) {
                        if (!visitedRoutes[neighbor]) {
                            visitedRoutes[neighbor] = true;
                            queue.offer(neighbor);
                        }
                    }
                }
            }
            buses++;
        }
        return -1;
    }
}
```

```rust
use std::collections::{HashMap, HashSet, VecDeque};

struct Solution;

impl Solution {
    pub fn num_buses_to_destination(routes: Vec<Vec<i32>>, source: i32, target: i32) -> i32 {
        if source == target {
            return 0;
        }

        let n = routes.len();
        // Map each stop to the routes that serve it
        let mut stop_to_routes: HashMap<i32, Vec<usize>> = HashMap::new();
        for i in 0..n {
            for &stop in &routes[i] {
                stop_to_routes.entry(stop).or_default().push(i);
            }
        }

        // Identify routes containing the target
        let target_routes: HashSet<usize> = stop_to_routes
            .get(&target)
            .cloned()
            .unwrap_or_default()
            .into_iter()
            .collect();

        // BFS on routes, starting from all routes that serve the source
        let mut queue: VecDeque<usize> = VecDeque::new();
        let mut visited_routes = vec![false; n];
        if let Some(routes_at_source) = stop_to_routes.get(&source) {
            for &route in routes_at_source {
                queue.push_back(route);
                visited_routes[route] = true;
            }
        }

        let mut buses = 1;
        while !queue.is_empty() {
            let size = queue.len();
            for _ in 0..size {
                let route = queue.pop_front().unwrap();
                // Check if this route reaches the target
                if target_routes.contains(&route) {
                    return buses;
                }
                // Find neighbor routes via shared stops
```

```javascript
var numBusesToDestination = function (routes, source, target) {
  if (source === target) return 0;

  const n = routes.length;
  // Map each stop to the routes that serve it
  const stopToRoutes = new Map();
  for (let i = 0; i < n; i++) {
    for (const stop of routes[i]) {
      if (!stopToRoutes.has(stop)) stopToRoutes.set(stop, []);
      stopToRoutes.get(stop).push(i);
    }
  }

  // Identify routes containing the target
  const targetRoutes = new Set(stopToRoutes.get(target) || []);

  // BFS on routes
  let queue = [];
  const visitedRoutes = new Array(n).fill(false);
  for (const route of stopToRoutes.get(source) || []) {
    queue.push(route);
    visitedRoutes[route] = true;
  }

  let buses = 1;
  while (queue.length > 0) {
    const nextQueue = [];
    for (const route of queue) {
      if (targetRoutes.has(route)) return buses;
      for (const stop of routes[route]) {
        for (const neighbor of stopToRoutes.get(stop) || []) {
          if (!visitedRoutes[neighbor]) {
            visitedRoutes[neighbor] = true;
            nextQueue.push(neighbor);
          }
        }
      }
    }
    queue = nextQueue;
    buses++;
  }
  return -1;
};
```

```typescript
function numBusesToDestination(
  routes: number[][],
  source: number,
  target: number,
): number {
  if (source === target) return 0;

  const n = routes.length;
  // Map each stop to the routes that serve it
  const stopToRoutes = new Map<number, number[]>();
  for (let i = 0; i < n; i++) {
    for (const stop of routes[i]) {
      if (!stopToRoutes.has(stop)) stopToRoutes.set(stop, []);
      stopToRoutes.get(stop)!.push(i);
    }
  }

  // Identify routes containing the target
  const targetRoutes = new Set<number>(stopToRoutes.get(target) || []);

  // BFS on routes
  let queue: number[] = [];
  const visitedRoutes = new Array(n).fill(false);
  for (const route of stopToRoutes.get(source) || []) {
    queue.push(route);
    visitedRoutes[route] = true;
  }

  let buses = 1;
  while (queue.length > 0) {
    const nextQueue: number[] = [];
    for (const route of queue) {
      if (targetRoutes.has(route)) return buses;
      for (const stop of routes[route]) {
        for (const neighbor of stopToRoutes.get(stop) || []) {
          if (!visitedRoutes[neighbor]) {
            visitedRoutes[neighbor] = true;
            nextQueue.push(neighbor);
          }
        }
      }
    }
    queue = nextQueue;
    buses++;
  }
  return -1;
}
```

> - **Time Complexity:** O(N _ S) in the worst case, where N is the number of routes and S is the total number of stop entries across all routes. Building the stop-to-routes map is O(S). The BFS processes each route at most once, and processing a route scans the route list of every stop on it. A stop shared by many routes is rescanned once per route that contains it, which bounds the total at N _ S. With N &lt;= 500 and S &lt;= 10^5, this stays within roughly 5 \* 10^7 operations.
> - **Space Complexity:** O(N + S) for the stop-to-routes map (S entries), the visited array (N entries), and the BFS queue (at most N route indices).
