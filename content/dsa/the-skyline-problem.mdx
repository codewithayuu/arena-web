<LessonCard>

A city's **skyline** is the outer contour of the silhouette formed by all the buildings in that city when viewed from a distance. Given the locations and heights of all the buildings, return the skyline formed by these buildings collectively.

The geometric information of each building is given in the array `buildings` where `buildings[i] = [left_i, right_i, height_i]`:

- `left_i` is the x coordinate of the left edge of the `i-th` building.
- `right_i` is the x coordinate of the right edge of the `i-th` building.
- `height_i` is the height of the `i-th` building.

You may assume all buildings are perfect rectangles grounded on an absolutely flat surface at height 0.

The **skyline** should be represented as a list of "key points" **sorted by their x-coordinate** in the form `[[x1, y1], [x2, y2], ...]`. Each key point is the left endpoint of some horizontal segment in the skyline except the last point in the list, which always has a y-coordinate 0 and is used to mark the skyline's termination where the rightmost building ends. Any ground between two adjacent buildings should be part of the skyline's contour as well.

**Note:** There must be no consecutive horizontal lines of equal height in the output skyline. For instance, `[..., [2, 3], [4, 5], [7, 5], [11, 5], [12, 7], ...]` is not acceptable; the three lines of height 5 should be merged into one in the final output as such: `[..., [2, 3], [4, 5], [12, 7], ...]`.

\***\*Example 1:\*\***

- **Input:** `buildings = [[2,9,10],[3,7,15],[5,12,12],[15,20,10],[19,24,8]]`

- **Output:** `[[2,10],[3,15],[7,12],[12,0],[15,10],[20,8],[24,0]]`

\***\*Example 2:\*\***

- **Input:** `buildings = [[0,2,3],[2,5,3]]`

- **Output:** `[[0,3],[5,0]]`

\***\*Constraints:\*\***

- `1 <= buildings.length <= 10^4`
- `0 <= left_i < right_i <= 2^31 - 1`
- `1 <= height_i <= 2^31 - 1`
- `buildings` is sorted by `left_i` in non-decreasing order.

A city skyline viewed from far away is a silhouette: the outline traced by the tallest visible building at every horizontal position. That outline is what we compute.

Each building is a rectangle defined by its left x-coordinate, right x-coordinate, and height. The skyline consists of "key points" where the height of the silhouette changes. We record a new point only when the maximum height at that x-coordinate differs from the previous maximum height.

The complication is overlapping buildings. When buildings overlap, only the tallest one is visible. When a tall building ends but a shorter one behind it is still standing, the height drops to the shorter building's height, not to zero. So the core question reduces to: at every x-coordinate where a building starts or ends, what is the current maximum height among all buildings covering that point?

- `1 <= buildings.length <= 10^4` -- Each building generates two events (start and end), so up to 20,000 events. An O(n^2) scan over events is on the order of hundreds of millions of operations, so O(n log n) is the target.
- `0 <= left_i < right_i <= 2^31 - 1` -- Coordinates range up to roughly 2 billion, so a coordinate-indexed array is impossible. Processing has to be event-based, driven by the building edges rather than by every integer position.
- `1 <= height_i <= 2^31 - 1` -- Heights fit in a 32-bit signed integer. We never add or multiply heights, only compare them, so there is no overflow risk here.
- `buildings is sorted by left_i` -- The input is pre-sorted by left edge. That does not remove the need to sort events, because right edges interleave with the left edges of later buildings.

<h1 id="approach-1-brute-force-scan-all-critical-points">
  Approach 1: Brute Force (Scan All Critical Points)
</h1>

<h3 id="intuition">Intuition</h3>

The skyline height can only change at x-coordinates where a building starts or ends. Between two consecutive edges the set of covering buildings is fixed, so the height is constant there. That means we only ever have to evaluate the height at these "critical" x-coordinates.

The brute-force version collects all critical x-coordinates, sorts them, and at each one scans every building to find the maximum height of any building covering that point. It does redundant work (re-scanning all buildings at every point) but it captures the core logic directly.

<h3 id="algorithm">Algorithm</h3>

1. Collect all left and right x-coordinates from all buildings into a set (to deduplicate).
2. Sort these critical x-coordinates.
3. For each critical x-coordinate, scan all buildings. A building covers this x if `left <= x < right`. Track the maximum height among all covering buildings.
4. If this maximum height differs from the previous height, add `[x, maxHeight]` to the result.

```java
class Solution {
    public List<List<Integer>> getSkyline(int[][] buildings) {
        // Collect all critical x-coordinates
        TreeSet<Integer> xSet = new TreeSet<>();
        for (int[] b : buildings) {
            xSet.add(b[0]);
            xSet.add(b[1]);
        }

        List<List<Integer>> result = new ArrayList<>();
        int prevHeight = 0;

        // At each critical x, find the max height
        for (int x : xSet) {
            int maxHeight = 0;
            for (int[] b : buildings) {
                // Building covers x if left <= x < right
                if (b[0] <= x && x < b[1]) {
                    maxHeight = Math.max(maxHeight, b[2]);
                }
            }
            if (maxHeight != prevHeight) {
                result.add(List.of(x, maxHeight));
                prevHeight = maxHeight;
            }
        }

        return result;
    }
}
```

> - **Time Complexity:** O(n^2). We have at most 2n critical x-coordinates. For each one, we scan all n buildings. That gives O(n \* n) = O(n^2).
> - **Space Complexity:** O(n). The set of critical x-coordinates takes O(n) space. The result list is at most O(n) as well.

The waste is clear: at each critical x-coordinate we rescan all `n` buildings, even though only one building changes state from one critical point to the next. The next approach keeps a running collection of the currently active buildings and queries its maximum in O(log n) per event instead of O(n).

<h1 id="approach-2-sweep-line-with-max-heap">
  Approach 2: Sweep Line with Max-Heap
</h1>

<h3 id="intuition">Intuition</h3>

Instead of re-scanning all buildings at every critical point, we process events in order along the x-axis. Each building creates two events: a "start" event at its left edge, where the building becomes active, and an "end" event at its right edge, where it becomes inactive.

Sort the events by x-coordinate and maintain an active set of building heights that supports fast maximum queries (a max-heap or an ordered multiset). Walking the events left to right, each start adds a height to the active set and each end removes one. After processing every event at a given x, the maximum of the active set is the skyline height there. Whenever that maximum differs from the previous one, we record a key point.

Ties at the same x need a defined order. To represent start events we store the height as negative and end events as positive. Sorting then breaks ties by this signed value, so at a shared x all starts (negative) come before all ends (positive).

> Consider two buildings of height 3 that touch, one spanning `[0, 2]` and the next `[2, 5]`. At x = 2 the first building ends and the second starts. If we processed the end first, the active set would briefly drop to height 0, and we would emit a spurious key point `[2, 0]` followed by `[2, 3]`, splitting one flat roofline into a false dip. Processing the start first keeps the maximum at 3 throughout x = 2, so no key point is emitted and the two roofs merge into one segment, which is the correct skyline.
>
> The same ordering matters when a taller building starts exactly where a shorter one ends: handling the start first lets the new, taller height win immediately rather than recording a transient lower value.

<h3 id="algorithm">Algorithm</h3>

1. Create events: for each building `[left, right, height]`, add `(left, -height)` for start and `(right, height)` for end.
2. Sort events by x-coordinate, then by height value (negative heights sort first at same x).
3. Maintain a height-count map (acting as a multiset) initialized with `{0: 1}` for the ground level.
4. For each event:

```java
class Solution {
    public List<List<Integer>> getSkyline(int[][] buildings) {
        // Create events: [x, height] where negative height = start
        List<int[]> events = new ArrayList<>();
        for (int[] b : buildings) {
            events.add(new int[]{b[0], -b[2]}); // start: negative height
            events.add(new int[]{b[1], b[2]});   // end: positive height
        }

        // Sort by x, then by height (starts before ends at same x)
        events.sort((a, b) -> a[0] != b[0] ? Integer.compare(a[0], b[0]) : Integer.compare(a[1], b[1]));

        // TreeMap as a multiset for O(log n) max queries and removal
        TreeMap<Integer, Integer> heightMap = new TreeMap<>();
        heightMap.put(0, 1); // ground level

        List<List<Integer>> result = new ArrayList<>();
        int prevMax = 0;

        for (int[] event : events) {
            int x = event[0];
            int h = event[1];

            if (h < 0) {
                // Start event: add height
                heightMap.merge(-h, 1, Integer::sum);
            } else {
                // End event: remove height
                int count = heightMap.get(h);
                if (count == 1) {
                    heightMap.remove(h);
                } else {
                    heightMap.put(h, count - 1);
                }
            }

            int currentMax = heightMap.lastKey();
            if (currentMax != prevMax) {
                result.add(List.of(x, currentMax));
                prevMax = currentMax;
            }
        }

        return result;
    }
}
```

```python
class Solution:
    def getSkyline(self, buildings: list[list[int]]) -> list[list[int]]:
        # Create events: (x, height) where negative height = start
        events = []
        for left, right, height in buildings:
            events.append((left, -height, right))  # start
            events.append((right, 0, 0))            # end sentinel

        # Sort: by x, then starts (negative) before ends
        events.sort()

        # Max-heap (negate for Python min-heap): (neg_height, right_edge)
        # Ground level that never expires
        heap = [(0, float('inf'))]
        result = []
        prev_max = 0

        i = 0
        while i < len(events):
            curr_x = events[i][0]

            # Process all events at the same x
            while i < len(events) and events[i][0] == curr_x:
                x, neg_h, right = events[i]
                if neg_h < 0:
                    # Start event: push height with its expiration
                    heapq.heappush(heap, (neg_h, right))
                i += 1

            # Lazy deletion: remove expired buildings from top
            while heap[0][1] <= curr_x:
                heapq.heappop(heap)

            current_max = -heap[0][0]
            if current_max != prev_max:
                result.append([curr_x, current_max])
                prev_max = current_max

        return result
```

```cpp
    vector<vector<int>> getSkyline(vector<vector<int>>& buildings) {

        vector<pair<int, int>> events;
        for (auto& b : buildings) {

            events.push_back({b[1], b[2]});   // end
        }

        // Sort by x, then by height
        sort(events.begin(), events.end());

        // Multiset acts as a max-accessible collection
        multiset<int> heights;
        heights.insert(0); // ground level

        vector<vector<int>> result;
        int prevMax = 0;

        for (auto& [x, h] : events) {
            if (h < 0) {
                heights.insert(-h); // start: add height
            } else {
                heights.erase(heights.find(h)); // end: remove one instance
            }

            int currentMax = *heights.rbegin();
            if (currentMax != prevMax) {
                result.push_back({x, currentMax});
                prevMax = currentMax;
            }
        }

        return result;
    }
```

```csharp
public class Solution {
    public IList<IList<int>> GetSkyline(int[][] buildings) {
        // Create events: (x, height) where negative height = start
        var events = new List<int[]>();
        foreach (var b in buildings) {
            events.Add(new int[]{b[0], -b[2]}); // start
            events.Add(new int[]{b[1], b[2]});   // end
        }

        events.Sort((a, b) => a[0] != b[0] ? a[0].CompareTo(b[0]) : a[1].CompareTo(b[1]));

        // SortedDictionary as a multiset for heights
        var heightMap = new SortedDictionary<int, int>();
        heightMap[0] = 1; // ground level

        IList<IList<int>> result = new List<IList<int>>();
        int prevMax = 0;

        foreach (var e in events) {
            int x = e[0], h = e[1];

            if (h < 0) {
                // Start: add height
                int key = -h;
                if (heightMap.ContainsKey(key)) heightMap[key]++;
                else heightMap[key] = 1;
            } else {
                // End: remove height
                if (heightMap[h] == 1) heightMap.Remove(h);
                else heightMap[h]--;
            }

            int currentMax = heightMap.Keys.Max();
            if (currentMax != prevMax) {
                result.Add(new List<int> { x, currentMax });
                prevMax = currentMax;
            }
        }

        return result;
    }
```

```go
// maxHeap of active building heights (largest on top).
type maxHeap []int

func (h maxHeap) Len() int            { return len(h) }
func (h maxHeap) Less(i, j int) bool  { return h[i] > h[j] }
func (h maxHeap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *maxHeap) Push(x interface{}) { *h = append(*h, x.(int)) }
func (h *maxHeap) Pop() interface{} {
    old := *h
    n := len(old)
    v := old[n-1]
    *h = old[:n-1]
    return v
}

func getSkyline(buildings [][]int) [][]int {
    // Create events: [x, height] negative height = start
    type event struct{ x, h int }
    events := make([]event, 0, len(buildings)*2)
    for _, b := range buildings {
        events = append(events, event{b[0], -b[2]}) // start
        events = append(events, event{b[1], b[2]})  // end
    }

    sort.Slice(events, func(i, j int) bool {
        if events[i].x != events[j].x {
            return events[i].x < events[j].x
        }
        return events[i].h < events[j].h
    })

    // Heap of live heights plus a count of how many copies are still active.
    h := &maxHeap{0} // ground level
    active := map[int]int{0: 1}
    prevMax := 0
    result := [][]int{}

    for _, e := range events {
        if e.h < 0 {
            heightVal := -e.h
            active[heightVal]++
            heap.Push(h, heightVal)
        } else {
            active[e.h]-- // lazily remove: leave the value in the heap
        }

        // Lazy deletion: discard the top while its count has dropped to 0.
        for (*h).Len() > 0 && active[(*h)[0]] == 0 {
            heap.Pop(h)
        }

        currentMax := (*h)[0]
        if currentMax != prevMax {
            result = append(result, []int{e.x, currentMax})
            prevMax = currentMax
        }
    }

    return result
}
```

```rust
use std::collections::BTreeMap;

pub struct Solution;

impl Solution {
    pub fn get_skyline(buildings: Vec<Vec<i32>>) -> Vec<Vec<i32>> {
        // Create events: (x, height) where negative height = start
        let mut events: Vec<(i32, i32)> = Vec::new();
        for b in buildings.iter() {
            events.push((b[0], -b[2])); // start: negative height
            events.push((b[1], b[2])); // end: positive height
        }

        // Sort by x, then by height (starts before ends at same x)
        events.sort_unstable_by(|a, b| {
            if a.0 != b.0 {
                a.0.cmp(&b.0)
            } else {
                a.1.cmp(&b.1)
            }
        });

        // BTreeMap as a multiset for O(log n) max queries and removal
        let mut height_map: BTreeMap<i32, i32> = BTreeMap::new();
        height_map.insert(0, 1); // ground level

        let mut result: Vec<Vec<i32>> = Vec::new();
        let mut prev_max = 0;

        for (x, h) in events {
            if h < 0 {
                // Start event: add height
                *height_map.entry(-h).or_insert(0) += 1;
            } else {
                // End event: remove height
                if let Some(count) = height_map.get_mut(&h) {
                    if *count == 1 {
                        height_map.remove(&h);
                    } else {
                        *count -= 1;
                    }
                }
            }

            let current_max = *height_map.keys().next_back().unwrap();
            if current_max != prev_max {
                result.push(vec![x, current_max]);
                prev_max = current_max;
            }
        }

        result
    }
}
```

```javascript
// Binary max-heap of building heights.
class MaxHeap {
  constructor() {
    this.data = [];
  }
  size() {
    return this.data.length;
  }
  peek() {
    return this.data[0];
  }
  push(v) {
    const d = this.data;
    d.push(v);
    let i = d.length - 1;
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (d[p] >= d[i]) break;
      [d[p], d[i]] = [d[i], d[p]];
      i = p;
    }
  }
  pop() {
    const d = this.data;
    const top = d[0];
    const last = d.pop();
    if (d.length > 0) {
      d[0] = last;
      let i = 0;
      while (true) {
        let largest = i;
        const l = 2 * i + 1,
          r = 2 * i + 2;
        if (l < d.length && d[l] > d[largest]) largest = l;
        if (r < d.length && d[r] > d[largest]) largest = r;
        if (largest === i) break;
        [d[largest], d[i]] = [d[i], d[largest]];
        i = largest;
      }
    }
    return top;
  }
}

var getSkyline = function (buildings) {
  // Create events: [x, height] negative height = start
  var events = [];
  for (var b of buildings) {
    events.push([b[0], -b[2]]); // start
    events.push([b[1], b[2]]); // end
  }

  events.sort(function (a, b) {
    return a[0] !== b[0] ? a[0] - b[0] : a[1] - b[1];
  });

  var heap = new MaxHeap();
  heap.push(0); // ground level
  var active = new Map(); // height -> live count
  active.set(0, 1);

  var result = [];
  var prevMax = 0;

  for (var e of events) {
    var x = e[0],
      h = e[1];

    if (h < 0) {
      var key = -h;
      active.set(key, (active.get(key) || 0) + 1);
      heap.push(key);
    } else {
      active.set(h, active.get(h) - 1); // lazy remove
    }

    // Lazy deletion: drop heap-top entries whose live count is 0.
    while (heap.size() > 0 && active.get(heap.peek()) === 0) {
      heap.pop();
    }

    var currentMax = heap.peek();
    if (currentMax !== prevMax) {
      result.push([x, currentMax]);
      prevMax = currentMax;
    }
```

```typescript
// Binary max-heap of building heights.
class MaxHeap {
  private data: number[] = [];
  size(): number {
    return this.data.length;
  }
  peek(): number {
    return this.data[0];
  }
  push(v: number): void {
    const d = this.data;
    d.push(v);
    let i = d.length - 1;
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (d[p] >= d[i]) break;
      [d[p], d[i]] = [d[i], d[p]];
      i = p;
    }
  }
  pop(): number {
    const d = this.data;
    const top = d[0];
    const last = d.pop()!;
    if (d.length > 0) {
      d[0] = last;
      let i = 0;
      while (true) {
        let largest = i;
        const l = 2 * i + 1,
          r = 2 * i + 2;
        if (l < d.length && d[l] > d[largest]) largest = l;
        if (r < d.length && d[r] > d[largest]) largest = r;
        if (largest === i) break;
        [d[largest], d[i]] = [d[i], d[largest]];
        i = largest;
      }
    }
    return top;
  }
}

function getSkyline(buildings: number[][]): number[][] {
  // Create events: [x, height] negative height = start
  const events: number[][] = [];
  for (const b of buildings) {
    events.push([b[0], -b[2]]); // start
    events.push([b[1], b[2]]); // end
  }

  events.sort((a, b) => (a[0] !== b[0] ? a[0] - b[0] : a[1] - b[1]));

  const heap = new MaxHeap();
  heap.push(0); // ground level
  const active = new Map<number, number>(); // height -> live count
  active.set(0, 1);

  const result: number[][] = [];
  let prevMax = 0;

  for (const e of events) {
    const x = e[0],
      h = e[1];

    if (h < 0) {
      const key = -h;
      active.set(key, (active.get(key) || 0) + 1);
      heap.push(key);
    } else {
      active.set(h, active.get(h)! - 1); // lazy remove
    }

    // Lazy deletion: drop heap-top entries whose live count is 0.
    while (heap.size() > 0 && active.get(heap.peek()) === 0) {
      heap.pop();
    }

    const currentMax = heap.peek();
    if (currentMax !== prevMax) {
      result.push([x, currentMax]);
      prevMax = currentMax;
    }
  }

  return result;
}
```

> - **Time Complexity:** O(n log n). Creating and sorting the 2n events is O(n log n). Each event does an O(log n) ordered-map or heap operation. The lazy-deletion versions (Python, Go, JavaScript, TypeScript) may leave stale entries in the heap, but every value is pushed and popped at most once, so the total heap work is still O(n log n).
> - **Space Complexity:** O(n). The events list is O(n), and the ordered map or heap holds at most O(n) heights at a time.

The sweep line with a TreeMap already runs in O(n log n). An alternative is divide and conquer: split the buildings in half, solve each half recursively, and merge the two skylines like merge sort.

<h1 id="approach-3-divide-and-conquer">Approach 3: Divide and Conquer</h1>

<h3 id="intuition">Intuition</h3>

This approach follows the structure of merge sort. Split the buildings into two halves, recursively compute the skyline for each half, then merge the two skylines into one.

The merge step is where the two contours combine. We walk through both skylines at once with two pointers. As we advance, we keep `leftH` and `rightH`, the current height contributed by each side. At each new x-coordinate, the merged height is `max(leftH, rightH)`. If that differs from the previously recorded height, we add a key point.

This is correct because each half's skyline already captures every height change for its own buildings, and the final skyline at any x is the maximum over all buildings, which equals the maximum of the two partial skylines at that x. Merging by taking the pointwise maximum (the upper envelope of the two contours) therefore produces the combined skyline.

<h3 id="algorithm">Algorithm</h3>

1. Base case: if there's only one building `[left, right, height]`, the skyline is `[[left, height], [right, 0]]`.
2. Split buildings into left and right halves.
3. Recursively compute the skyline for each half.
4. Merge the two skylines:

```java
class Solution {
    public List<List<Integer>> getSkyline(int[][] buildings) {
        return divideAndConquer(buildings, 0, buildings.length - 1);
    }

    private List<List<Integer>> divideAndConquer(int[][] buildings, int lo, int hi) {
        // Base case: single building
        if (lo == hi) {
            List<List<Integer>> skyline = new ArrayList<>();
            skyline.add(List.of(buildings[lo][0], buildings[lo][2]));
            skyline.add(List.of(buildings[lo][1], 0));
            return skyline;
        }

        int mid = lo + (hi - lo) / 2;
        List<List<Integer>> left = divideAndConquer(buildings, lo, mid);
        List<List<Integer>> right = divideAndConquer(buildings, mid + 1, hi);
        return merge(left, right);
    }

    private List<List<Integer>> merge(List<List<Integer>> left, List<List<Integer>> right) {
        List<List<Integer>> result = new ArrayList<>();
        int i = 0, j = 0;
        int leftH = 0, rightH = 0, prevMax = 0;

        while (i < left.size() && j < right.size()) {
            int x;
            if (left.get(i).get(0) < right.get(j).get(0)) {
                x = left.get(i).get(0);
                leftH = left.get(i).get(1);
                i++;
            } else if (left.get(i).get(0) > right.get(j).get(0)) {
                x = right.get(j).get(0);
                rightH = right.get(j).get(1);
                j++;
            } else {
                x = left.get(i).get(0);
                leftH = left.get(i).get(1);
                rightH = right.get(j).get(1);
                i++;
                j++;
            }

            int maxH = Math.max(leftH, rightH);
            if (maxH != prevMax) {
                result.add(List.of(x, maxH));
                prevMax = maxH;
            }
        }

        // Append remaining from left
        while (i < left.size()) {
            List<Integer> point = left.get(i);
            if (point.get(1) != prevMax) {
                result.add(point);
                prevMax = point.get(1);
            }
            i++;
        }

        // Append remaining from right
        while (j < right.size()) {
            List<Integer> point = right.get(j);
            if (point.get(1) != prevMax) {
                result.add(point);
                prevMax = point.get(1);
            }
            j++;
        }

        return result;
    }
```
