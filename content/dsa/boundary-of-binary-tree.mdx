<LessonCard>

The boundary of a binary tree is the concatenation of the root, the left boundary, the leaves ordered from left-to-right, and the reverse order of the right boundary.

The **left boundary** is the set of nodes defined by the following:

- The root node's left child is in the left boundary. If the root does not have a left child, then the left boundary is empty.
- If a node in the left boundary and has a left child, then the left child is in the left boundary.
- If a node is in the left boundary, has no left child, but has a right child, then the right child is in the left boundary.
- The leftmost leaf is not in the left boundary.

The **right boundary** is similar to the left boundary, except it is the right side of the root's right subtree. Again, the rightmost leaf is not in the right boundary, and the right boundary is empty if the root does not have a right child.

The **leaves** are nodes that do not have any children. For the given tree, the leaves are ordered from left to right.

Return the values of the boundary in an anti-clockwise direction starting from the root.

\***\*Example 1:\*\***

- **Input:** `root = [1,null,2,3,4]`

- **Output:** `[1,3,4,2]`

The left boundary is empty because the root does not have a left child. The leaves are [3,4]. The right boundary is [2]. Concatenating in anti-clockwise order: [1] + [] + [3,4] + [2] = [1,3,4,2].

\***\*Example 2:\*\***

- **Input:** `root = [1,2,3,4,5,6,null,null,null,7,8,9,10]`

- **Output:** `[1,2,4,7,8,9,10,6,3]`

The left boundary is [2]. The leaves are [4,7,8,9,10]. The right boundary is [3,6] reversed to [6,3]. Result: [1] + [2] + [4,7,8,9,10] + [6,3] = [1,2,4,7,8,9,10,6,3].

\***\*Constraints:\*\***

- The number of nodes in the tree is in the range `[1, 10^4]`.
- `-1000 <= Node.val <= 1000`

The boundary is the outline of the tree traced anti-clockwise: start at the root, go down the left side, sweep across the bottom (the leaves), and come back up the right side.

The boundary has three distinct parts:

1. **Left boundary:** Start from the root's left child and keep going down, preferring the left child at each step. If there's no left child, take the right child instead. Stop before you reach a leaf.
2. **Leaves:** All leaf nodes collected from left to right across the entire tree.
3. **Right boundary:** Start from the root's right child and keep going down, preferring the right child at each step. If there's no right child, take the left child instead. Stop before you reach a leaf. This list gets reversed because we're tracing anti-clockwise (bottom-up).

The root is always included first (unless the tree is empty). The main complication is double-counting: a leaf at the end of the left or right boundary path must not appear twice, so the boundary definitions explicitly exclude the leftmost leaf from the left boundary and the rightmost leaf from the right boundary. Those two nodes belong to the leaves section only.

- `1 <= number of nodes <= 10^4` → A linear traversal handles this size comfortably, and every reasonable solution here is O(n).
- `-1000 <= Node.val <= 1000` → Node values can be negative and can repeat. We collect values, not node references, so equal values at different positions both appear in the output.

<h1 id="approach-1-three-separate-traversals">
  Approach 1: Three Separate Traversals
</h1>

<h3 id="intuition">Intuition</h3>

Break the problem into the three parts the statement describes, collect each separately, and concatenate them.

The left boundary is a single walk down from `root.left`: at each node take the left child if it exists, otherwise the right child, and stop before reaching a leaf. The right boundary is the mirror image starting from `root.right`, except its values are needed bottom-up, so collect them top-down into a temporary list and reverse it.

For the leaves, a DFS that recurses into the left subtree before the right one encounters childless nodes in left-to-right order, so appending each leaf as it is found produces the middle section directly.

Excluding leaves from both boundary walks is what prevents double-counting: the leftmost and rightmost leaves are picked up once, by the leaf pass, even though the boundary walks end right above them.

<h3 id="algorithm">Algorithm</h3>

1. If the root is null, return an empty list.
2. Add the root's value to the result.
3. If the root is a leaf (no children), return the result containing only the root.
4. Collect the left boundary: start from `root.left`, walk down preferring left children, stop before any leaf. Add each node's value to the result.
5. Collect all leaves: do a DFS traversal of the entire tree. Add every leaf's value to the result.
6. Collect the right boundary: start from `root.right`, walk down preferring right children, stop before any leaf. Store values in a temporary list, then reverse it and append to the result.
7. Return the result.

<h3 id="visualization-and-code">Visualization and Code</h3>

<InteractiveAnimation />

> - **Time Complexity:** O(n). The leaf collection visits every node once via DFS and dominates. The two boundary walks each visit at most h nodes, where h is the tree height.
> - **Space Complexity:** O(n). The result list holds up to n values. The leaf-collection recursion stack and the temporary right-boundary list each add O(h), which is O(n) worst case for a skewed tree.

This approach makes three separate passes over different parts of the tree. The next approach visits each node once and classifies it on the spot, using a flag passed down from its parent.

<h1 id="approach-2-single-preorder-traversal-with-flags">
  Approach 2: Single Preorder Traversal with Flags
</h1>

<h3 id="intuition">Intuition</h3>

A single preorder traversal can classify every node if each recursive call knows which role the node plays: left boundary, right boundary, or neither. The parent passes this role down as a flag. Whether a node is on a boundary is fully determined by its parent's flag and its position, so no second pass is needed.

The flag propagation mirrors the problem's definition. A left boundary node's left child inherits the LEFT flag; its right child inherits it only when there is no left child, because the boundary follows the leftmost available path. The right boundary is symmetric. Every other child gets the NONE flag.

Preorder visits left boundary nodes before any leaf and visits leaves in left-to-right order, so two of the three sections come out already ordered. The right boundary is the one piece preorder produces top-down when the output needs it bottom-up, so it goes into a separate list that is reversed during the final assembly.

> Classification checks for a leaf before checking the flag. A leaf goes to the leaves list even when it carries a boundary flag, so the node at the bottom of each boundary path (the leftmost or rightmost leaf) is recorded once, among the leaves. This single ordering rule replaces the "stop before a leaf" logic from Approach 1.

<h3 id="algorithm">Algorithm</h3>

1. If the root is null, return an empty list.
2. Initialize three lists: `leftBoundary`, `leaves`, `rightBoundary`.
3. Run a preorder DFS starting from the root. For each node, pass a flag indicating if it's a left boundary node, a right boundary node, or neither.
4. At each node, check for a leaf first: a leaf goes to `leaves` regardless of its flag. Otherwise a LEFT-flagged node goes to `leftBoundary` and a RIGHT-flagged node goes to `rightBoundary`.
5. Propagate flags to children: a LEFT flag goes to the left child, or to the right child when there is no left child. The RIGHT flag is symmetric. All other children get NONE.
6. Combine: [root.val] + leftBoundary + leaves + reverse(rightBoundary).

```java
class Solution {
    private static final int NONE = 0, LEFT = 1, RIGHT = 2;

    public List<Integer> boundaryOfBinaryTree(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;

        result.add(root.val);
        if (root.left == null && root.right == null) return result;

        List<Integer> leftBound = new ArrayList<>();
        List<Integer> leaves = new ArrayList<>();
        List<Integer> rightBound = new ArrayList<>();

        // Root's left child starts with LEFT flag, right child with RIGHT flag
        dfs(root.left, LEFT, leftBound, leaves, rightBound);
        dfs(root.right, RIGHT, leftBound, leaves, rightBound);

        result.addAll(leftBound);
        result.addAll(leaves);
        // Right boundary needs to be reversed (bottom-up order)
        for (int i = rightBound.size() - 1; i >= 0; i--) {
            result.add(rightBound.get(i));
        }

        return result;
    }

    private void dfs(TreeNode node, int flag,
                     List<Integer> leftBound, List<Integer> leaves, List<Integer> rightBound) {
        if (node == null) return;

        boolean isLeaf = (node.left == null && node.right == null);

        if (isLeaf) {
            leaves.add(node.val);
        } else if (flag == LEFT) {
            leftBound.add(node.val);
        } else if (flag == RIGHT) {
            rightBound.add(node.val);
        }

        // Propagate flags to children
        int leftChildFlag = NONE, rightChildFlag = NONE;
        if (flag == LEFT) {
            leftChildFlag = LEFT;
            rightChildFlag = (node.left == null) ? LEFT : NONE;
        } else if (flag == RIGHT) {
            rightChildFlag = RIGHT;
            leftChildFlag = (node.right == null) ? RIGHT : NONE;
        }

        dfs(node.left, leftChildFlag, leftBound, leaves, rightBound);
        dfs(node.right, rightChildFlag, leftBound, leaves, rightBound);
    }
}
```

```python
class Solution:
    def boundaryOfBinaryTree(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []

        result = [root.val]
        if not root.left and not root.right:
            return result

        NONE, LEFT, RIGHT = 0, 1, 2
        left_bound, leaves, right_bound = [], [], []

        def dfs(node: Optional[TreeNode], flag: int) -> None:
            if not node:
                return

            is_leaf = not node.left and not node.right

            if is_leaf:
                leaves.append(node.val)
            elif flag == LEFT:
                left_bound.append(node.val)
            elif flag == RIGHT:
                right_bound.append(node.val)

            # Propagate flags to children
            if flag == LEFT:
                left_flag = LEFT
                right_flag = LEFT if not node.left else NONE
            elif flag == RIGHT:
                right_flag = RIGHT
                left_flag = RIGHT if not node.right else NONE
            else:
                left_flag = NONE
                right_flag = NONE

            dfs(node.left, left_flag)
            dfs(node.right, right_flag)

        # Root's left child starts with LEFT flag, right with RIGHT
        dfs(root.left, LEFT)
        dfs(root.right, RIGHT)

        return result + left_bound + leaves + right_bound[::-1]
```

```rust
pub struct Solution;

// Flags must live at module level so both functions can use them
const NONE: i32 = 0;
const LEFT: i32 = 1;
const RIGHT: i32 = 2;

impl Solution {
    pub fn boundary_of_binary_tree(root: Option<Rc<RefCell<TreeNode>>>) -> Vec<i32> {
        if root.is_none() {
            return vec![];
        }

        let root = root.unwrap();
        let mut result = vec![root.borrow().val];
        if root.borrow().left.is_none() && root.borrow().right.is_none() {
            return result;
        }

        let mut left_bound = Vec::new();
        let mut leaves = Vec::new();
        let mut right_bound = Vec::new();

        // Root's left child starts with LEFT flag, right child with RIGHT flag
        Self::dfs(root.borrow().left.clone(), LEFT, &mut left_bound, &mut leaves, &mut right_bound);
        Self::dfs(root.borrow().right.clone(), RIGHT, &mut left_bound, &mut leaves, &mut right_bound);

        result.extend(left_bound);
        result.extend(leaves);
        // Right boundary needs to be reversed (bottom-up order)
        for i in (0..right_bound.len()).rev() {
            result.push(right_bound[i]);
        }

        result
    }

    fn dfs(
        node: Option<Rc<RefCell<TreeNode>>>,
        flag: i32,
        left_bound: &mut Vec<i32>,
        leaves: &mut Vec<i32>,
        right_bound: &mut Vec<i32>,
    ) {
        let Some(node_rc) = node else {
            return;
        };

        let node_ref = node_rc.borrow();
        let is_leaf = node_ref.left.is_none() && node_ref.right.is_none();

        if is_leaf {
            leaves.push(node_ref.val);
        } else if flag == LEFT {
            left_bound.push(node_ref.val);
        } else if flag == RIGHT {
            right_bound.push(node_ref.val);
        }

        // Propagate flags to children
        let mut left_child_flag = NONE;
        let mut right_child_flag = NONE;
        if flag == LEFT {
            left_child_flag = LEFT;
            right_child_flag = if node_ref.left.is_none() { LEFT } else { NONE };
        } else if flag == RIGHT {
            right_child_flag = RIGHT;
            left_child_flag = if node_ref.right.is_none() { RIGHT } else { NONE };
        }

        let left = node_ref.left.clone();
        let right = node_ref.right.clone();
        drop(node_ref);

        Self::dfs(left, left_child_flag, left_bound, leaves, right_bound);
        Self::dfs(right, right_child_flag, left_bound, leaves, right_bound);
    }
}
```

```javascript
var boundaryOfBinaryTree = function (root) {
  if (!root) return [];

  const result = [root.val];
  if (!root.left && !root.right) return result;

  const NONE = 0,
    LEFT = 1,
    RIGHT = 2;
  const leftBound = [],
    leaves = [],
    rightBound = [];

  function dfs(node, flag) {
    if (!node) return;

    const isLeaf = !node.left && !node.right;

    if (isLeaf) {
      leaves.push(node.val);
    } else if (flag === LEFT) {
      leftBound.push(node.val);
    } else if (flag === RIGHT) {
      rightBound.push(node.val);
    }

    let leftChildFlag = NONE,
      rightChildFlag = NONE;
    if (flag === LEFT) {
      leftChildFlag = LEFT;
      rightChildFlag = node.left ? NONE : LEFT;
    } else if (flag === RIGHT) {
      rightChildFlag = RIGHT;
      leftChildFlag = node.right ? NONE : RIGHT;
    }

    dfs(node.left, leftChildFlag);
    dfs(node.right, rightChildFlag);
  }

  dfs(root.left, LEFT);
  dfs(root.right, RIGHT);

  result.push(...leftBound, ...leaves);
  for (let i = rightBound.length - 1; i >= 0; i--) {
    result.push(rightBound[i]);
  }

  return result;
};
```

> - **Time Complexity:** O(n). The preorder DFS visits each node once and does O(1) work per node: check for a leaf, classify, and append to a list. The final concatenation and reversal take O(n) total.
> - **Space Complexity:** O(n). The result stores up to n values and the three auxiliary lists together hold at most n values. The recursion stack adds O(h), where h is the tree height (O(n) worst case for a skewed tree).
