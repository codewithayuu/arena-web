<LessonCard>

An **AVL tree** is the first historical answer to it. Invented in 1962 by Adelson-Velsky and Landis, it was the first self-balancing binary search tree. The idea is simple: after every insertion or deletion, check whether any node has become "too lopsided" and fix it with a local rotation. The shape of the tree stays close to a perfectly balanced one, and every operation stays at O(log n).

In this chapter, we'll cover:

- The exact balance condition that defines an AVL tree
- The four rotation cases and how to recognize each one
- Insertion and deletion with rebalancing
- A height proof that shows why O(log n) is guaranteed
- When to pick an AVL tree over a red-black tree
- A complete, working implementation

<h1 id="the-balance-condition">The Balance Condition</h1>

An AVL tree is a BST with one extra invariant:

That difference, `height(left) - height(right)`, is called the node's **balance factor**. An AVL tree allows only three values: `-1`, `0`, `+1`. Anything outside that range is a violation that must be fixed.

The height of a node is the number of edges on the longest path from that node down to a leaf. By convention the height of an empty subtree is `-1`, so a leaf has height `0`.

Look at the difference between a plain BST and an AVL tree after inserting `1, 2, 3, 4, 5`:

**Plain BST:**

Height is 4. Search for `5` walks every node.

**AVL tree (same keys, same order):**

Height is 2. Search for `5` walks 3 nodes. The AVL tree did extra work during the inserts (it performed rotations as the tree leaned), but every future query is fast.

<h1 id="why-the-balance-factor-matters">Why the Balance Factor Matters</h1>

Every node carries enough information to detect imbalance locally. To compute its own balance factor, a node only needs to look at the heights stored in its two children. So whenever a subtree's height changes, the parent can check itself in O(1) and decide whether action is needed.

The two operations that change subtree heights are insert and delete. Both follow the same pattern:

1. Do the BST operation as usual.
2. On the way back up the recursion, recompute the height of each ancestor.
3. If any ancestor's balance factor falls outside `{-1, 0, +1}`, fix it with a rotation.

The fix is always one of four cases, picked by looking at _where_ the imbalance came from.

<h1 id="the-four-rotation-cases">The Four Rotation Cases</h1>

When a node `N` ends up with balance factor `+2` (left-heavy) or `-2` (right-heavy), the trouble is in one of the four directions: Left-Left, Left-Right, Right-Right, or Right-Left. Each has a fixed rotation pattern.

The naming reads off the path from the offending ancestor: "the imbalance came from the Left child's Left subtree" gives Left-Left.

<h3 id="case-1-left-left-right-rotation">Case 1: Left-Left (Right Rotation)</h3>

`N` is left-heavy, and its left child `L` is also left-heavy (or balanced). The fix is a single right rotation around `N`.

Before rotation:

After right rotation around `N`:

`L` becomes the new root of the subtree. The middle subtree (formerly `L`'s right) becomes `N`'s left. The BST ordering is preserved: everything in `LL` is still less than `L`, everything between `L` and `N` is in the middle, and everything greater than `N` is on the right.

<h3 id="case-2-right-right-left-rotation">
  Case 2: Right-Right (Left Rotation)
</h3>

The mirror image of Case 1. `N` is right-heavy, and its right child is also right-heavy. The fix is a single left rotation around `N`. `R` becomes the new subtree root, `N` becomes `R`'s left child, and `R`'s old left subtree slides over to be `N`'s new right child.

<h3 id="case-3-left-right-left-rotation-on-child-then-right-rotation-on-n">
  Case 3: Left-Right (Left rotation on child, then Right rotation on N)
</h3>

`N` is left-heavy, but its left child `L` is **right-heavy**. A single right rotation would not balance the tree because the heavy subtree is in the wrong corner. The fix is two rotations:

1. Rotate left around `L`. This converts the Left-Right shape into a Left-Left shape.
2. Rotate right around `N`. This handles the now-standard Left-Left case.

Before:

After the double rotation, `LR` ends up at the top, with `L` and `N` as its children, and the four subtrees distributed left-to-right in BST order.

<h3 id="case-4-right-left-right-rotation-on-child-then-left-rotation-on-n">
  Case 4: Right-Left (Right rotation on child, then Left rotation on N)
</h3>

The mirror image of Case 3. Rotate right around the right child first, then rotate left around `N`.

<h3 id="choosing-the-right-case">Choosing the Right Case</h3>

Once a node's balance factor reaches `±2`, the case is determined by the sign of the _child's_ balance factor:

| Node balance | Child balance | Case        | Fix                                         |
| ------------ | ------------- | ----------- | ------------------------------------------- |
| +2           | +1 or 0       | Left-Left   | One right rotation                          |
| +2           | -1            | Left-Right  | Left rotation on child, then right rotation |
| -2           | -1 or 0       | Right-Right | One left rotation                           |
| -2           | +1            | Right-Left  | Right rotation on child, then left rotation |

The "or 0" rows happen only during deletion, never during insertion. After an insert, the child causing the imbalance can never be perfectly balanced.

<h1 id="insertion">Insertion</h1>

AVL insertion is exactly the same as BST insertion until the new node is in place. Then, as recursion unwinds, each ancestor:

1. Recomputes its own height as `1 + max(height(left), height(right))`.
2. Checks its balance factor.
3. If the factor is `±2`, performs the appropriate rotation.

A single insertion can change heights along the path from the new node to the root. But there is a useful property: **one rotation always suffices for insert**. The first time you fix an imbalance on the way up, the subtree's overall height returns to what it was before the insert, so no ancestor's balance factor changes after that point.

<h3 id="walkthrough-insert-10-20-30">Walkthrough: Insert 10, 20, 30</h3>

Start empty. Insert `10`, then `20`. The tree is still balanced:

Now insert `30`. After the BST insert:

Recursion unwinds:

- At `30`: height = 0, balance factor = 0. Fine.
- At `20`: height = 1, balance factor = `-1`. Fine.
- At `10`: height = 2, balance factor = `-2`. Imbalance.

The child `20` has balance factor `-1`, so this is Right-Right. One left rotation around `10`:

Balanced again. Future inserts of `25, 5, 15` will trigger a mix of single and double rotations following the same rule.

<h1 id="deletion">Deletion</h1>

Deletion follows the BST deletion algorithm (replace with successor, recurse), then rebalances ancestors on the way up just like insert. Two differences matter:

1. The case table includes child-balance `0`, which never occurs after insert.
2. **One rotation is not always enough.** After a deletion, the rotation can shorten the subtree, which can in turn cause the next ancestor up to become unbalanced. In the worst case, you rotate at every level from the deleted node to the root.

Each rotation is still O(1), and the path is O(log n), so delete remains O(log n) overall.

<h1 id="why-the-height-is-olog-n">Why the Height Is O(log n)</h1>

The AVL invariant guarantees a tight height bound. Let `N(h)` be the minimum number of nodes in any AVL tree of height `h`. The most lopsided AVL tree of height `h` has one subtree of height `h - 1` and one of height `h - 2` (any larger gap would break the invariant). So:

`N(h) = 1 + N(h - 1) + N(h - 2)`

with `N(0) = 1` and `N(1) = 2`. This is the Fibonacci recurrence plus 1. Solving it gives:

`N(h) ≈ φ^h / √5`, where `φ = (1 + √5) / 2 ≈ 1.618`.

Inverting, `h ≤ log_φ(n) ≈ 1.44 · log_2(n)`. The height is at most about 44% taller than a perfectly balanced binary tree. Every operation that walks one root-to-leaf path costs O(log n).

<h1 id="full-implementation">Full Implementation</h1>

The class stores `height` on each node so that balance-factor lookups are O(1). Insert and delete both return the new root of the subtree, so rotations and rebalancing can be expressed as pure substitutions rather than pointer surgery on the parent.

```java
class AVLTree {
    static class Node {
        int val, height;
        Node left, right;
        Node(int val) { this.val = val; this.height = 0; }
    }

    Node root;

    int height(Node n) { return n == null ? -1 : n.height; }

    int balanceFactor(Node n) {
        return height(n.left) - height(n.right);
    }

    void updateHeight(Node n) {
        n.height = 1 + Math.max(height(n.left), height(n.right));
    }

    Node rotateRight(Node y) {
        Node x = y.left;
        Node t = x.right;
        x.right = y;
        y.left = t;
        updateHeight(y);
        updateHeight(x);
        return x;
    }

    Node rotateLeft(Node x) {
        Node y = x.right;
        Node t = y.left;
        y.left = x;
        x.right = t;
        updateHeight(x);
        updateHeight(y);
        return y;
    }

    Node rebalance(Node n) {
        updateHeight(n);
        int bf = balanceFactor(n);

        // Left heavy
        if (bf > 1) {
            if (balanceFactor(n.left) < 0) {
                n.left = rotateLeft(n.left);   // Left-Right
            }
            return rotateRight(n);             // Left-Left
        }
        // Right heavy
        if (bf < -1) {
            if (balanceFactor(n.right) > 0) {
                n.right = rotateRight(n.right); // Right-Left
            }
            return rotateLeft(n);               // Right-Right
        }
        return n;
    }

    public void insert(int val) { root = insert(root, val); }

    Node insert(Node n, int val) {
        if (n == null) return new Node(val);
        if (val < n.val)      n.left  = insert(n.left, val);
        else if (val > n.val) n.right = insert(n.right, val);
        else                  return n;   // no duplicates
        return rebalance(n);
    }

    public void delete(int val) { root = delete(root, val); }

    Node delete(Node n, int val) {
        if (n == null) return null;
        if (val < n.val)      n.left  = delete(n.left, val);
        else if (val > n.val) n.right = delete(n.right, val);
        else {
            if (n.left == null)  return n.right;
            if (n.right == null) return n.left;
            Node succ = findMin(n.right);
            n.val = succ.val;
            n.right = delete(n.right, succ.val);
        }
        return rebalance(n);
    }

    Node findMin(Node n) {
        while (n.left != null) n = n.left;
        return n;
    }

    public boolean search(int val) { return search(root, val); }

    boolean search(Node n, int val) {
        if (n == null) return false;
        if (val == n.val) return true;
        return val < n.val ? search(n.left, val) : search(n.right, val);
    }
}
```

```python
class AVLTree:
    class Node:
        __slots__ = ("val", "height", "left", "right")
        def __init__(self, val):
            self.val = val
            self.height = 0
            self.left = None
            self.right = None

    def __init__(self):
        self.root = None

    @staticmethod
    def _h(n):
        return -1 if n is None else n.height

    def _bf(self, n):
        return self._h(n.left) - self._h(n.right)

    def _update_height(self, n):
        n.height = 1 + max(self._h(n.left), self._h(n.right))

    def _rotate_right(self, y):
        x = y.left
        t = x.right
        x.right = y
        y.left = t
        self._update_height(y)
        self._update_height(x)
        return x

    def _rotate_left(self, x):
        y = x.right
        t = y.left
        y.left = x
        x.right = t
        self._update_height(x)
        self._update_height(y)
        return y

    def _rebalance(self, n):
        self._update_height(n)
        bf = self._bf(n)
        if bf > 1:
            if self._bf(n.left) < 0:
                n.left = self._rotate_left(n.left)
            return self._rotate_right(n)
        if bf < -1:
            if self._bf(n.right) > 0:
                n.right = self._rotate_right(n.right)
            return self._rotate_left(n)
        return n

    def insert(self, val):
        self.root = self._insert(self.root, val)

    def _insert(self, n, val):
        if n is None:
            return AVLTree.Node(val)
        if val < n.val:
            n.left = self._insert(n.left, val)
        elif val > n.val:
            n.right = self._insert(n.right, val)
        else:
            return n
        return self._rebalance(n)

    def delete(self, val):
        self.root = self._delete(self.root, val)

    def _delete(self, n, val):
        if n is None:
            return None
        if val < n.val:
            n.left = self._delete(n.left, val)
        elif val > n.val:
            n.right = self._delete(n.right, val)
        else:
            if n.left is None:
                return n.right
            if n.right is None:
                return n.left
            succ = self._find_min(n.right)
            n.val = succ.val
            n.right = self._delete(n.right, succ.val)
        return self._rebalance(n)

    @staticmethod
    def _find_min(n):
        while n.left is not None:
            n = n.left
        return n

    def search(self, val):
        n = self.root
        while n is not None:
            if val == n.val:
                return True
            n = n.left if val < n.val else n.right
        return False
```

```cpp
class AVLTree {
    struct Node {
        int val, height;
        Node *left = nullptr, *right = nullptr;
        Node(int v) : val(v), height(0) {}
    };

    Node* root = nullptr;

    int height(Node* n) { return n ? n->height : -1; }
    int balanceFactor(Node* n) { return height(n->left) - height(n->right); }

    void updateHeight(Node* n) {
        n->height = 1 + std::max(height(n->left), height(n->right));
    }

    Node* rotateRight(Node* y) {
        Node* x = y->left;
        Node* t = x->right;
        x->right = y;
        y->left = t;
        updateHeight(y);
        updateHeight(x);
        return x;
    }

    Node* rotateLeft(Node* x) {
        Node* y = x->right;
        Node* t = y->left;
        y->left = x;
        x->right = t;
        updateHeight(x);
        updateHeight(y);
        return y;
    }

    Node* rebalance(Node* n) {
        updateHeight(n);
        int bf = balanceFactor(n);
        if (bf > 1) {
            if (balanceFactor(n->left) < 0)
                n->left = rotateLeft(n->left);
            return rotateRight(n);
        }
        if (bf < -1) {
            if (balanceFactor(n->right) > 0)
                n->right = rotateRight(n->right);
            return rotateLeft(n);
        }
        return n;
    }

    Node* insertNode(Node* n, int val) {
        if (!n) return new Node(val);
        if (val < n->val)      n->left  = insertNode(n->left, val);
        else if (val > n->val) n->right = insertNode(n->right, val);
        else return n;
        return rebalance(n);
    }

    Node* findMin(Node* n) {
        while (n->left) n = n->left;
        return n;
    }

    Node* deleteNode(Node* n, int val) {
        if (!n) return nullptr;
        if (val < n->val)      n->left  = deleteNode(n->left, val);
        else if (val > n->val) n->right = deleteNode(n->right, val);
        else {
            if (!n->left)  { Node* r = n->right; delete n; return r; }
            if (!n->right) { Node* l = n->left;  delete n; return l; }
            Node* succ = findMin(n->right);
            n->val = succ->val;
            n->right = deleteNode(n->right, succ->val);
        }
        return rebalance(n);
    }

public:
    void insert(int val) { root = insertNode(root, val); }
    void erase(int val)  { root = deleteNode(root, val); }

    bool search(int val) {
        Node* n = root;
        while (n) {
            if (val == n->val) return true;
            n = val < n->val ? n->left : n->right;
        }
        return false;
    }
};
```

```csharp
    private class Node {
        public int val, height;
        public Node left, right;
        public Node(int val) { this.val = val; this.height = 0; }
    }

    private Node root;

    private int Height(Node n) => n == null ? -1 : n.height;
    private int BalanceFactor(Node n) => Height(n.left) - Height(n.right);
    private void UpdateHeight(Node n) {
        n.height = 1 + Math.Max(Height(n.left), Height(n.right));
    }

    private Node RotateRight(Node y) {
        Node x = y.left;
        Node t = x.right;
        x.right = y;
        y.left = t;
        UpdateHeight(y);
        UpdateHeight(x);
        return x;
    }

    private Node RotateLeft(Node x) {
        Node y = x.right;
        Node t = y.left;
        y.left = x;
        x.right = t;
        UpdateHeight(x);
        UpdateHeight(y);
        return y;
    }

    private Node Rebalance(Node n) {
        UpdateHeight(n);
        int bf = BalanceFactor(n);
        if (bf > 1) {
            if (BalanceFactor(n.left) < 0) n.left = RotateLeft(n.left);
            return RotateRight(n);
        }
        if (bf < -1) {
            if (BalanceFactor(n.right) > 0) n.right = RotateRight(n.right);
            return RotateLeft(n);
        }
        return n;
    }

    public void Insert(int val) { root = InsertNode(root, val); }

    private Node InsertNode(Node n, int val) {
        if (n == null) return new Node(val);
        if (val < n.val)      n.left  = InsertNode(n.left, val);
        else if (val > n.val) n.right = InsertNode(n.right, val);
        else return n;
        return Rebalance(n);
    }

    public void Delete(int val) { root = DeleteNode(root, val); }

    private Node DeleteNode(Node n, int val) {
        if (n == null) return null;
        if (val < n.val)      n.left  = DeleteNode(n.left, val);
        else if (val > n.val) n.right = DeleteNode(n.right, val);
        else {
            if (n.left == null)  return n.right;
            if (n.right == null) return n.left;
            Node succ = FindMin(n.right);
            n.val = succ.val;
            n.right = DeleteNode(n.right, succ.val);
        }
        return Rebalance(n);
    }

    private Node FindMin(Node n) {
        while (n.left != null) n = n.left;
        return n;
    }

    public bool Search(int val) {
        Node n = root;
        while (n != null) {
            if (val == n.val) return true;
            n = val < n.val ? n.left : n.right;
        }
        return false;
    }
}
```

```go
type avlNode struct {
    val         int
    height      int
    left, right *avlNode
}

type AVLTree struct {
    root *avlNode
}

func avlHeight(n *avlNode) int {
    if n == nil {
        return -1
    }
    return n.height
}

func balanceFactor(n *avlNode) int {
    return avlHeight(n.left) - avlHeight(n.right)
}

func updateHeight(n *avlNode) {
    l, r := avlHeight(n.left), avlHeight(n.right)
    if l > r {
        n.height = 1 + l
    } else {
        n.height = 1 + r
    }
}

func rotateRight(y *avlNode) *avlNode {
    x := y.left
    t := x.right
    x.right = y
    y.left = t
    updateHeight(y)
    updateHeight(x)
    return x
}

func rotateLeft(x *avlNode) *avlNode {
    y := x.right
    t := y.left
    y.left = x
    x.right = t
    updateHeight(x)
    updateHeight(y)
    return y
}

func rebalance(n *avlNode) *avlNode {
    updateHeight(n)
    bf := balanceFactor(n)
    if bf > 1 {
        if balanceFactor(n.left) < 0 {
            n.left = rotateLeft(n.left)
        }
        return rotateRight(n)
    }
    if bf < -1 {
        if balanceFactor(n.right) > 0 {
            n.right = rotateRight(n.right)
        }
        return rotateLeft(n)
    }
    return n
}

func (t *AVLTree) Insert(val int) { t.root = insertNode(t.root, val) }

func insertNode(n *avlNode, val int) *avlNode {
    if n == nil {
        return &avlNode{val: val, height: 0}
    }
    switch {
    case val < n.val:
        n.left = insertNode(n.left, val)
    case val > n.val:
        n.right = insertNode(n.right, val)
    default:
        return n
    }
    return rebalance(n)
}

func (t *AVLTree) Delete(val int) { t.root = deleteNode(t.root, val) }

func deleteNode(n *avlNode, val int) *avlNode {
    if n == nil {
        return nil
    }
    switch {
    case val < n.val:
        n.left = deleteNode(n.left, val)
    case val > n.val:
        n.right = deleteNode(n.right, val)
    default:
        if n.left == nil {
            return n.right
        }
        if n.right == nil {
            return n.left
        }
        succ := findMin(n.right)
        n.val = succ.val
        n.right = deleteNode(n.right, succ.val)
    }
    return rebalance(n)
}

func findMin(n *avlNode) *avlNode {
    for n.left != nil {
        n = n.left
    }
    return n
}

func (t *AVLTree) Search(val int) bool {
    n := t.root
    for n != nil {
        if val == n.val {
            return true
        }
        if val < n.val {
            n = n.left
        } else {
            n = n.right
        }
    }
    return false
}
```

```rust
struct Node {
    val: i32,
    height: i32,
    left: Option<Box<Node>>,
    right: Option<Box<Node>>,
}

pub struct AVLTree {
    root: Option<Box<Node>>,
}

impl AVLTree {
    pub fn new() -> Self { AVLTree { root: None } }

    fn height(n: &Option<Box<Node>>) -> i32 {
        n.as_ref().map_or(-1, |node| node.height)
    }

    fn update_height(n: &mut Box<Node>) {
        n.height = 1 + std::cmp::max(Self::height(&n.left), Self::height(&n.right));
    }

    fn balance_factor(n: &Box<Node>) -> i32 {
        Self::height(&n.left) - Self::height(&n.right)
    }

    fn rotate_right(mut y: Box<Node>) -> Box<Node> {
        let mut x = y.left.take().unwrap();
        y.left = x.right.take();
        Self::update_height(&mut y);
        x.right = Some(y);
        Self::update_height(&mut x);
        x
    }

    fn rotate_left(mut x: Box<Node>) -> Box<Node> {
        let mut y = x.right.take().unwrap();
        x.right = y.left.take();
        Self::update_height(&mut x);
        y.left = Some(x);
        Self::update_height(&mut y);
        y
    }

    fn rebalance(mut n: Box<Node>) -> Box<Node> {
        Self::update_height(&mut n);
        let bf = Self::balance_factor(&n);
        if bf > 1 {
            if Self::balance_factor(n.left.as_ref().unwrap()) < 0 {
                let left = n.left.take().unwrap();
                n.left = Some(Self::rotate_left(left));
            }
            return Self::rotate_right(n);
        }
        if bf < -1 {
            if Self::balance_factor(n.right.as_ref().unwrap()) > 0 {
                let right = n.right.take().unwrap();
                n.right = Some(Self::rotate_right(right));
            }
            return Self::rotate_left(n);
        }
        n
    }

    pub fn insert(&mut self, val: i32) {
        self.root = Self::insert_node(self.root.take(), val);
    }

    fn insert_node(node: Option<Box<Node>>, val: i32) -> Option<Box<Node>> {
        match node {
            None => Some(Box::new(Node { val, height: 0, left: None, right: None })),
            Some(mut n) => {
                if val < n.val {
                    n.left = Self::insert_node(n.left.take(), val);
                } else if val > n.val {
                    n.right = Self::insert_node(n.right.take(), val);
                } else {
                    return Some(n);
                }
                Some(Self::rebalance(n))
            }
        }
    }

    pub fn delete(&mut self, val: i32) {
        self.root = Self::delete_node(self.root.take(), val);
    }

    fn delete_node(node: Option<Box<Node>>, val: i32) -> Option<Box<Node>> {
        let mut n = match node { None => return None, Some(n) => n };
        if val < n.val {
            n.left = Self::delete_node(n.left.take(), val);
        } else if val > n.val {
            n.right = Self::delete_node(n.right.take(), val);
        } else {
            if n.left.is_none()  { return n.right; }
            if n.right.is_none() { return n.left; }
            let succ_val = Self::find_min(n.right.as_ref().unwrap()).val;
            n.val = succ_val;
            n.right = Self::delete_node(n.right.take(), succ_val);
        }
        Some(Self::rebalance(n))
    }

    fn find_min(node: &Box<Node>) -> &Box<Node> {
        let mut cur = node;
        while let Some(ref left) = cur.left { cur = left; }
        cur
    }

    pub fn search(&self, val: i32) -> bool {
        let mut cur = self.root.as_ref();
        while let Some(node) = cur {
            if val == node.val { return true; }
            cur = if val < node.val { node.left.as_ref() } else { node.right.as_ref() };
        }
        false
    }
}
```

A few implementation notes that come up in production code:

- Storing the height on each node trades 4 bytes per node for O(1) balance-factor lookups. The alternative, recomputing heights with a recursive walk, makes every operation O(n log n).
- Rotations work because they reattach three subtrees, not because they "swap values." Always rotate node references, never copy values around to fake a rotation. Copying values breaks BST invariants when the tree stores complex objects with stable identity.
- The `rebalance` function is the single choke point that enforces the AVL invariant. Every operation that mutates the tree must end its recursion by routing through `rebalance`.

<h1 id="when-to-use-avl">When to Use AVL</h1>

AVL trees give the tightest height bound of any standard balanced BST. That makes them a good fit when reads dominate writes:

- **Read-heavy in-memory indexes** where every microsecond of search latency matters.
- **Database systems with mostly-static lookups** and infrequent updates.
- **Applications that frequently call predecessor / successor / range queries** where shorter trees translate directly to fewer pointer chases.
- **Educational settings** where the explicit balance factor makes the invariant easy to verify.

Their downside is rebalancing cost on writes. A delete can trigger O(log n) rotations, and the constant factors are higher than a red-black tree because the invariant is stricter.

<h1 id="avl-vs-red-black-quick-comparison">
  AVL vs Red-Black: Quick Comparison
</h1>

The two structures both guarantee O(log n) per operation but make different trade-offs.

| Property           | AVL                            | Red-Black                                             |
| ------------------ | ------------------------------ | ----------------------------------------------------- |
| Worst-case height  | `1.44 · log2(n)`               | `2 · log2(n)`                                         |
| Search performance | Slightly faster (shorter tree) | Slightly slower                                       |
| Insert rebalancing | At most 1 rotation             | At most 2 rotations                                   |
| Delete rebalancing | Up to O(log n) rotations       | At most 3 rotations                                   |
| Per-node overhead  | `height` (4 bytes)             | `color` (1 bit)                                       |
| Used in            | Some database indexes          | `java.util.TreeMap`, `std::map`, Linux kernel `epoll` |

The rule of thumb most production systems follow: **use red-black trees when writes are frequent, AVL when reads dominate.** Both end up at O(log n), but the constants and pause times differ.
