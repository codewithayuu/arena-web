<LessonCard>

You are given an `m x n` grid `rooms` initialized with these three possible values:

- `-1` - A wall or an obstacle.
- `0` - A gate.
- `INF` - Infinity means an empty room. We use the value `2^31 - 1 = 2147483647` to represent INF as you may assume that the distance to a gate is less than `2147483647`.

Fill each empty room with the distance to its nearest gate. If it is impossible to reach a gate, the room should remain filled with `INF`.

\***\*Example 1:\*\***

- **Input:** `rooms = [[2147483647,-1,0,2147483647],[2147483647,2147483647,2147483647,-1],[2147483647,-1,2147483647,-1],[0,-1,2147483647,2147483647]]`

- **Output:** `[[3,-1,0,1],[2,2,1,-1],[1,-1,2,-1],[0,-1,3,4]]`

\***\*Example 2:\*\***

- **Input:** `rooms = [[-1]]`

- **Output:** `[[-1]]`

\***\*Example 3:\*\***

- **Input:** `rooms = [[2147483647]]`

- **Output:** `[[2147483647]]`

\***\*Constraints:\*\***

- `m == rooms.length`
- `n == rooms[i].length`
- `1 <= m, n <= 250`
- `rooms[i][j]` is `-1`, `0`, or `2^31 - 1`

We have a 2D grid where some cells are walls (-1), some are gates (0), and the rest are empty rooms (INF). Our job is to update every empty room cell with the shortest distance to the nearest gate. Movement is only allowed in four directions (up, down, left, right), and we cannot pass through walls.

The word "nearest" is what drives the solution. Each empty room needs the minimum distance across all gates, not the distance to one specific gate. One option is to start from each empty room and search outward for the closest gate. The other is to start from the gates and search outward toward the rooms. Starting from the gates turns out to be far cheaper, because a single search from all gates at once fills the entire grid.

That single search is a multi-source BFS. We put all gates into the queue at the start and expand outward from all of them at the same time. Because BFS visits cells in increasing order of distance, the first time it reaches an empty room, the distance recorded is the shortest distance from any gate.

- `1 <= m, n <= 250` → The grid has up to 62,500 cells. A per-room search runs a separate BFS for each of those cells, which is O((m _ n)^2) in the worst case, around 4 billion operations. A single multi-source pass is O(m _ n) and stays well within limits.
- `rooms[i][j]` is `-1`, `0`, or `2147483647` → Walls, gates, and empty rooms are the only three values, so the empty-room marker (`INF`) can double as an "unvisited" flag during BFS.

<h1 id="approach-1-bfs-from-each-empty-room">
  Approach 1: BFS from Each Empty Room
</h1>

<h3 id="intuition">Intuition</h3>

Treat each empty room as an independent shortest-path problem. For every cell that contains INF, run a BFS outward until it hits a gate, and record the number of steps it took.

BFS on an unweighted grid expands one distance level at a time, so the first gate reached from a given room is the closest one to that room. That distance is the answer for that room.

<h3 id="algorithm">Algorithm</h3>

1. Iterate through every cell in the grid.
2. If the cell is an empty room (value is INF), run a BFS starting from that cell.
3. In the BFS, explore neighbors in all four directions (up, down, left, right).
4. Skip walls (-1) and already-visited cells.
5. The first time we encounter a gate (value 0), that BFS distance is the answer for this room.
6. Update the room's value with the distance found.

```java
class Solution {
    public void wallsAndGates(int[][] rooms) {
        int m = rooms.length, n = rooms[0].length;
        int INF = Integer.MAX_VALUE;
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (rooms[i][j] != INF) continue;

                // BFS from this empty room to find nearest gate
                Queue<int[]> queue = new LinkedList<>();
                boolean[][] visited = new boolean[m][n];
                queue.offer(new int[]{i, j});
                visited[i][j] = true;
                int dist = 0;
                boolean found = false;

                while (!queue.isEmpty() && !found) {
                    int size = queue.size();
                    dist++;
                    for (int k = 0; k < size && !found; k++) {
                        int[] cell = queue.poll();
                        for (int[] d : dirs) {
                            int r = cell[0] + d[0], c = cell[1] + d[1];
                            if (r < 0 || r >= m || c < 0 || c >= n) continue;
                            if (visited[r][c] || rooms[r][c] == -1) continue;
                            if (rooms[r][c] == 0) {
                                rooms[i][j] = dist;
                                found = true;
                                break;
                            }
                            visited[r][c] = true;
                            queue.offer(new int[]{r, c});
                        }
                    }
                }
            }
        }
    }
}
```

> - **Time Complexity:** O((m _ n)^2). In the worst case, every cell is an empty room, and each BFS visits the entire grid. That gives us O(m _ n) rooms, each taking O(m \* n) BFS work.
> - **Space Complexity:** O(m _ n). Each BFS uses a visited array and a queue, both of which can hold up to O(m _ n) cells.

This approach is correct but runs a full BFS for every empty room, and adjacent rooms re-explore almost the same cells each time. The next approach reverses the direction: it searches outward from the gates and fills the whole grid in one pass.

<h1 id="approach-2-multi-source-bfs-from-all-gates">
  Approach 2: Multi-Source BFS from All Gates
</h1>

<h3 id="intuition">Intuition</h3>

Instead of asking "for each room, what is the closest gate?", flip the question to "from all gates at once, how far is each room?" Adding every gate to the BFS queue at distance 0 and expanding outward fills the entire grid in a single pass.

A multi-source BFS is one BFS seeded with many starting cells. All gates begin at distance 0. The wavefront then advances one step at a time across the whole grid together. The first time the wavefront reaches a room, that room is recorded at the current distance and never touched again.

> Seeding the queue with all gates is equivalent to adding one virtual super-source connected to every gate by a zero-cost edge, then running ordinary BFS from that single source. Ordinary BFS labels each cell with its shortest distance from the source, so each room ends up labeled with its distance to the nearest gate. The first arrival is final: once a room is set, its value is no longer INF, and the `rooms[r][c] != INF` check blocks any later, longer path from overwriting it.
>
> No separate visited array is needed. A room still holding INF has not been reached; any other value (a wall at -1, a gate at 0, or an assigned distance) is skipped by the same check.

<h3 id="algorithm">Algorithm</h3>

1. Create a queue and add the position of every gate (cells with value 0) to it.
2. Run BFS. For each cell dequeued, explore its four neighbors.
3. For each neighbor that is an empty room (value is still INF), update its distance to `current cell's distance + 1` and add it to the queue.
4. Skip walls (-1) and cells that have already been updated (value is no longer INF).
5. When the queue is empty, every reachable empty room has been filled with its shortest distance to any gate.

```java
class Solution {
    public void wallsAndGates(int[][] rooms) {
        int m = rooms.length, n = rooms[0].length;
        int INF = Integer.MAX_VALUE;
        int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};
        Queue<int[]> queue = new LinkedList<>();

        // Add all gates to the queue as starting points
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (rooms[i][j] == 0) {
                    queue.offer(new int[]{i, j});
                }
            }
        }

        // BFS from all gates simultaneously
        while (!queue.isEmpty()) {
            int[] cell = queue.poll();
            int row = cell[0], col = cell[1];
            for (int[] d : dirs) {
                int r = row + d[0], c = col + d[1];
                // Only process unvisited empty rooms (still INF)
                if (r < 0 || r >= m || c < 0 || c >= n) continue;
                if (rooms[r][c] != INF) continue;
                rooms[r][c] = rooms[row][col] + 1;
                queue.offer(new int[]{r, c});
            }
        }
    }
}
```

```rust
    pub fn walls_and_gates(rooms: &mut Vec<Vec<i32>>) {

        if m == 0 {
            return;
        }
        let n = rooms[0].len();
        let inf = i32::MAX;
        let dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)];

                if rooms[r][c] != inf {
                    continue;
                }
```

```javascript
  while (head < queue.length) {
    const [row, col] = queue[head++];
    for (const [dr, dc] of dirs) {
      const r = row + dr,
        c = col + dc;
      // Only process unvisited empty rooms (still INF)
      if (r < 0 || r >= m || c < 0 || c >= n) continue;
      if (rooms[r][c] !== INF) continue;
      rooms[r][c] = rooms[row][col] + 1;
      queue.push([r, c]);
    }
  }
};
```

```typescript
function wallsAndGates(rooms: number[][]): void {
  const m = rooms.length,
    n = rooms[0].length;
  const INF = 2147483647;
  const dirs = [
    [0, 1],
    [0, -1],
    [1, 0],
    [-1, 0],
  ];
  const queue: number[][] = [];

  // Add all gates to the queue as starting points
  for (let i = 0; i < m; i++) {
    for (let j = 0; j < n; j++) {
      if (rooms[i][j] === 0) {
        queue.push([i, j]);
      }
    }
  }

  // BFS from all gates simultaneously
  let head = 0;
  while (head < queue.length) {
    const [row, col] = queue[head++];
    for (const [dr, dc] of dirs) {
      const r = row + dr,
        c = col + dc;
      // Only process unvisited empty rooms (still INF)
      if (r < 0 || r >= m || c < 0 || c >= n) continue;
      if (rooms[r][c] !== INF) continue;
      rooms[r][c] = rooms[row][col] + 1;
      queue.push([r, c]);
    }
  }
}
```

> - **Time Complexity:** O(m _ n). We scan the grid once to find all gates, then during BFS each cell is added to the queue at most once. Processing each cell takes O(1) work (checking 4 neighbors). Overall: O(m _ n).
> - **Space Complexity:** O(m _ n). The queue can hold at most O(m _ n) cells in the worst case. No separate visited array is needed since the grid itself tracks visited status.
