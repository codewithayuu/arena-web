<LessonCard>

There exists an infinite number line, on which you can place obstacles.

You are given a 0-indexed 2D integer array `queries`, where each `queries[i]` is either `[1, x]` (type 1) or `[2, x, sz]` (type 2).

There are two types of queries:

- For a query of type 1, you are given `queries[i] = [1, x]`. Set an obstacle at position `x`. It is guaranteed that there is no obstacle at position `x` when this query is made.
- For a query of type 2, you are given `queries[i] = [2, x, sz]`. Check if it is possible to place a block of size `sz` anywhere in the range `[0, x]` on the number line, so that the block lies entirely within `[0, x]` and does not intersect any obstacle. The block may touch an obstacle at either end.

Note that an obstacle at position 0 already exists.

Return a boolean array `results` where `results[i]` is the result of the `i`-th query of type 2. For each type 2 query, the result is `true` if you can place the block, and `false` otherwise.

\***\*Example 1:\*\***

- **Input:** `queries = [[1,2],[2,3,3],[2,3,1],[2,2,2]]`

- **Output:** `[false,true,true]`

\***\*Example 2:\*\***

- **Input:** `queries = [[1,7],[2,7,6],[1,2],[2,7,5],[2,7,6]]`

- **Output:** `[true,true,false]`

\***\*Constraints:\*\***

- `1 <= queries.length <= 15000`
- `2 <= queries[i].length <= 3`
- `1 <= queries[i][0] <= 2`
- `1 <= queries[i][1] <= min(5 * 10^4, 3 * queries.length)`
- For type 2 queries: `1 <= queries[i][2] <= min(5 * 10^4, 3 * queries.length)`

<h1 id="approach-1-brute-force-sorted-set-linear-scan">
  Approach 1: Brute Force (Sorted Set + Linear Scan)
</h1>

<h3 id="intuition">Intuition</h3>

Maintain a sorted set of all obstacle positions. For a type 2 query, walk through the obstacles in [0, x] in increasing order, compute the gap between each consecutive pair, and check whether any gap reaches sz.

One gap does not lie between two obstacles: the stretch from the last obstacle at or before x up to x itself. A block can end exactly at x, so this trailing gap counts too and gets checked separately.

<h3 id="algorithm">Algorithm</h3>

1. Initialize a sorted set containing position 0.
2. For each query:
3. Collect results for all type 2 queries.

```java
class Solution {
    public List<Boolean> getResults(int[][] queries) {
        TreeSet<Integer> obstacles = new TreeSet<>();
        obstacles.add(0);
        List<Boolean> results = new ArrayList<>();

        for (int[] query : queries) {
            if (query[0] == 1) {
                // Type 1: place obstacle at query[1]
                obstacles.add(query[1]);
            } else {
                // Type 2: check if block of size query[2] fits in [0, query[1]]
                int x = query[1];
                int sz = query[2];
                boolean canPlace = false;
                int prev = 0;
                for (int obs : obstacles) {
                    if (obs > x) break;
                    if (obs - prev >= sz) {
                        canPlace = true;
                        break;
                    }
                    prev = obs;
                }
                // Check gap from last obstacle to x
                if (!canPlace && x - prev >= sz) {
                    canPlace = true;
                }
                results.add(canPlace);
            }
        }
        return results;
    }
}
```

> - **Time Complexity:** O(n^2) in the worst case. A type 2 query scans every obstacle at or before x, and there can be O(n) of them. Insertions into the ordered structure cost at most O(n) each.
> - **Space Complexity:** O(n) for the obstacle positions.

The bottleneck is the linear scan in each type 2 query. The next approach keeps every gap in a segment tree, so the maximum gap in [0, x] comes from a single logarithmic-time range query instead of a scan.

<h1 id="approach-2-segment-tree-sorted-set-optimal">
  Approach 2: Segment Tree + Sorted Set (Optimal)
</h1>

<h3 id="intuition">Intuition</h3>

Build a segment tree indexed by position on the number line. At each obstacle position, store the gap from that obstacle back to its predecessor, so every gap lives at its right endpoint. Inserting an obstacle at position p splits one gap, and the sorted set identifies which one: find the neighbors `prev` and `next` of p. The old gap `next - prev`, stored at `next`, becomes two gaps: `p - prev` stored at p, and `next - p` stored at `next`. Two point updates record the change.

A type 2 query becomes a range max query over positions [0, x], which returns the largest gap among the obstacles in that prefix. The trailing gap is `x - last`, where `last` is the largest obstacle position at or before x, found in the sorted set. The answer is true when either value reaches sz.

> Each gap is stored at its right endpoint, the obstacle that closes it. A range max over positions [0, x] therefore counts a gap only when its right endpoint is at most x, which means the entire gap lies inside [0, x]. A gap that straddles x is excluded from the query, and its usable part, from the last obstacle at or before x up to x, is exactly the trailing gap computed separately. So max(range max, trailing gap) is the longest free stretch available inside [0, x].

<h3 id="algorithm">Algorithm</h3>

1. Compute the maximum position that appears in any query.
2. Initialize a segment tree over the position range [0, maxPos] supporting point updates and range max queries.
3. Initialize a sorted set with obstacle at position 0.
4. For each query:

```java
class Solution {
    int[] tree;

    public List<Boolean> getResults(int[][] queries) {
        // Find max position to size the segment tree
        int maxPos = 0;
        for (int[] q : queries) {
            maxPos = Math.max(maxPos, q[1]);
        }
        maxPos += 2;

        tree = new int[4 * maxPos];
        TreeSet<Integer> obstacles = new TreeSet<>();
        obstacles.add(0);
        List<Boolean> results = new ArrayList<>();

        for (int[] query : queries) {
            if (query[0] == 1) {
                // Type 1: place obstacle at query[1]
                int p = query[1];
                Integer prev = obstacles.lower(p);
                Integer next = obstacles.higher(p);
                obstacles.add(p);
                update(1, 0, maxPos - 1, p, p - (prev != null ? prev : 0));
                if (next != null) {
                    update(1, 0, maxPos - 1, next, next - p);
                }
            } else {
                // Type 2: check if block of size query[2] fits in [0, query[1]]
                int x = query[1];
                int sz = query[2];
                int maxGap = queryMax(1, 0, maxPos - 1, 0, x);
                Integer last = obstacles.floor(x);
                int trailing = x - (last != null ? last : 0);
                results.add(Math.max(maxGap, trailing) >= sz);
            }
        }
        return results;
    }

    void update(int node, int start, int end, int idx, int val) {
        if (start == end) {
            tree[node] = val;
            return;
        }
        int mid = (start + end) / 2;
        if (idx <= mid) update(2 * node, start, mid, idx, val);
        else update(2 * node + 1, mid + 1, end, idx, val);
        tree[node] = Math.max(tree[2 * node], tree[2 * node + 1]);
    }

    int queryMax(int node, int start, int end, int l, int r) {
        if (r < start || end < l) return 0;
        if (l <= start && end <= r) return tree[node];
        int mid = (start + end) / 2;
        return Math.max(queryMax(2 * node, start, mid, l, r),
                       queryMax(2 * node + 1, mid + 1, end, l, r));
    }
}
```

```python
class Solution:
    def getResults(self, queries: list[list[int]]) -> list[bool]:
        from sortedcontainers import SortedList

        max_pos = 0
        for q in queries:
            max_pos = max(max_pos, q[1])
        max_pos += 2

        tree = [0] * (4 * max_pos)

        def update(node, start, end, idx, val):
            if start == end:
                tree[node] = val
                return
            mid = (start + end) // 2
            if idx <= mid:
                update(2 * node, start, mid, idx, val)
            else:
                update(2 * node + 1, mid + 1, end, idx, val)
            tree[node] = max(tree[2 * node], tree[2 * node + 1])

        def query_max(node, start, end, l, r):
            if r < start or end < l:
                return 0
            if l <= start and end <= r:
                return tree[node]
            mid = (start + end) // 2
            return max(query_max(2 * node, start, mid, l, r),
                      query_max(2 * node + 1, mid + 1, end, l, r))

        obstacles = SortedList([0])
        results = []

        for query in queries:
            if query[0] == 1:
                # Type 1: place obstacle at query[1]
                p = query[1]
                idx = obstacles.bisect_left(p)
                prev_obs = obstacles[idx - 1] if idx > 0 else 0
                next_obs = obstacles[idx] if idx < len(obstacles) else None
                obstacles.add(p)
                update(1, 0, max_pos - 1, p, p - prev_obs)
                if next_obs is not None:
                    update(1, 0, max_pos - 1, next_obs, next_obs - p)
            else:
                # Type 2: check block placement
                x, sz = query[1], query[2]
                max_gap = query_max(1, 0, max_pos - 1, 0, x)
                idx = obstacles.bisect_right(x) - 1
                last_obs = obstacles[idx] if idx >= 0 else 0
                trailing = x - last_obs
                results.append(max(max_gap, trailing) >= sz)

        return results
```

```cpp
    vector<bool> getResults(vector<vector<int>>& queries) {

        for (auto& q : queries) {
            maxPos = max(maxPos, q[1]);
        }
        maxPos += 2;

        tree.assign(4 * maxPos, 0);

                int p = query[1];
                auto it = obstacles.insert(p).first;
                int prevVal = (it != obstacles.begin()) ? *prev(it) : 0;
                auto nxt = next(it);
                update(1, 0, maxPos - 1, p, p - prevVal);
                if (nxt != obstacles.end()) {
                    update(1, 0, maxPos - 1, *nxt, *nxt - p);
                }
            } else {
                int x = query[1], sz = query[2];
                int maxGap = queryMax(1, 0, maxPos - 1, 0, x);
                auto it = obstacles.upper_bound(x);
                --it;
                int trailing = x - *it;
                results.push_back(max(maxGap, trailing) >= sz);
            }
        }
        return results;
    }
```

```csharp
public class Solution {
    int[] tree;

    public IList<bool> GetResults(int[][] queries) {
        int maxPos = 0;
        foreach (var q in queries) {
            maxPos = Math.Max(maxPos, q[1]);
        }
        maxPos += 2;

        tree = new int[4 * maxPos];
        SortedSet<int> obstacles = new SortedSet<int> { 0 };
        List<bool> results = new List<bool>();

        foreach (var query in queries) {
            if (query[0] == 1) {
                int p = query[1];
                // Position 0 is always present, so the view below p is never empty
                int prev = obstacles.GetViewBetween(0, p - 1).Max;
                // Min of an empty view is default(int) = 0; obstacles are >= 1, so 0 means no successor
                int next = obstacles.GetViewBetween(p + 1, int.MaxValue).Min;
                obstacles.Add(p);
                Update(1, 0, maxPos - 1, p, p - prev);
                if (next != 0) {
                    Update(1, 0, maxPos - 1, next, next - p);
                }
            } else {
                int x = query[1], sz = query[2];
                int maxGap = QueryMax(1, 0, maxPos - 1, 0, x);
                int last = obstacles.GetViewBetween(0, x).Max;
                int trailing = x - last;
                results.Add(Math.Max(maxGap, trailing) >= sz);
            }
        }
        return results;
    }

    void Update(int node, int start, int end, int idx, int val) {
        if (start == end) { tree[node] = val; return; }
        int mid = (start + end) / 2;
        if (idx <= mid) Update(2 * node, start, mid, idx, val);
        else Update(2 * node + 1, mid + 1, end, idx, val);
        tree[node] = Math.Max(tree[2 * node], tree[2 * node + 1]);
    }

    int QueryMax(int node, int start, int end, int l, int r) {
        if (r < start || end < l) return 0;
        if (l <= start && end <= r) return tree[node];
        int mid = (start + end) / 2;
```

```go
func getResults(queries [][]int) []bool {
    maxPos := 0
    for _, q := range queries {
        if q[1] > maxPos {
            maxPos = q[1]
        }
    }
    maxPos += 2

    tree := make([]int, 4*maxPos)

    var update func(node, start, end, idx, val int)
    update = func(node, start, end, idx, val int) {
        if start == end {
            tree[node] = val
            return
        }
        mid := (start + end) / 2
        if idx <= mid {
            update(2*node, start, mid, idx, val)
        } else {
            update(2*node+1, mid+1, end, idx, val)
        }
        if tree[2*node] > tree[2*node+1] {
            tree[node] = tree[2*node]
        } else {
            tree[node] = tree[2*node+1]
        }
    }

    var queryMax func(node, start, end, l, r int) int
    queryMax = func(node, start, end, l, r int) int {
        if r < start || end < l {
            return 0
        }
        if l <= start && end <= r {
            return tree[node]
        }
        mid := (start + end) / 2
        left := queryMax(2*node, start, mid, l, r)
        right := queryMax(2*node+1, mid+1, end, l, r)
        if left > right {
            return left
        }
        return right
    }

    obstacles := []int{0}

    findIdx := func(val int) int {
        lo, hi := 0, len(obstacles)
        for lo < hi {
            mid := (lo + hi) / 2
            if obstacles[mid] < val {
                lo = mid + 1
            } else {
                hi = mid
            }
        }
        return lo
    }

    insertObs := func(val int) {
        idx := findIdx(val)
        obstacles = append(obstacles, 0)
        copy(obstacles[idx+1:], obstacles[idx:])
        obstacles[idx] = val
    }

    results := []bool{}

    for _, query := range queries {
        if query[0] == 1 {
            p := query[1]
            idx := findIdx(p)
            prevObs := 0
            if idx > 0 {
                prevObs = obstacles[idx-1]
            }
            nextObs := -1
            if idx < len(obstacles) {
                nextObs = obstacles[idx]
            }
            insertObs(p)
            update(1, 0, maxPos-1, p, p-prevObs)
            if nextObs != -1 {
                update(1, 0, maxPos-1, nextObs, nextObs-p)
            }
        } else {
            x, sz := query[1], query[2]
            maxGap := queryMax(1, 0, maxPos-1, 0, x)
            idx := findIdx(x+1) - 1
            lastObs := obstacles[idx]
            trailing := x - lastObs
            if trailing > maxGap {
                maxGap = trailing
            }
            results = append(results, maxGap >= sz)
        }
    }
    return results
}
```

```rust
use std::cmp::max;
use std::collections::BTreeSet;

impl Solution {
    pub fn get_results(queries: Vec<Vec<i32>>) -> Vec<bool> {
        // Find max position to size the segment tree
        let mut max_pos = 0usize;
        for q in &queries {
            max_pos = max(max_pos, q[1] as usize);
        }
        max_pos += 2;

        let mut tree = vec![0i32; 4 * max_pos];
        let mut obstacles: BTreeSet<i32> = BTreeSet::new();
        obstacles.insert(0);
        let mut results: Vec<bool> = Vec::new();

        for query in queries {
            if query[0] == 1 {
                // Type 1: place obstacle at query[1]
                let p = query[1];
                let prev = obstacles.range(..p).next_back().copied().unwrap_or(0);
                let next = obstacles.range((p + 1)..).next().copied();
                obstacles.insert(p);
                update(&mut tree, 1, 0, max_pos - 1, p as usize, p - prev);
                if let Some(nxt) = next {
                    update(&mut tree, 1, 0, max_pos - 1, nxt as usize, nxt - p);
                }
            } else {
                // Type 2: check if block of size query[2] fits in [0, query[1]]
                let x = query[1] as usize;
                let sz = query[2];
                let max_gap = query_max(&tree, 1, 0, max_pos - 1, 0, x);
                let last = obstacles.range(..=query[1]).next_back().copied().unwrap_or(0);
                let trailing = query[1] - last;
                results.push(max(max_gap, trailing) >= sz);
            }
        }
        results
    }
}

fn update(tree: &mut Vec<i32>, node: usize, start: usize, end: usize, idx: usize, val: i32) {
    if start == end {
        tree[node] = val;
        return;
    }
    let mid = (start + end) / 2;
    if idx <= mid {
        update(tree, 2 * node, start, mid, idx, val);
    } else {
        update(tree, 2 * node + 1, mid + 1, end, idx, val);
    }
    tree[node] = max(tree[2 * node], tree[2 * node + 1]);
}

fn query_max(tree: &Vec<i32>, node: usize, start: usize, end: usize, l: usize, r: usize) -> i32 {
    if r < start || end < l {
        return 0;
    }
    if l <= start && end <= r {
        return tree[node];
    }
    let mid = (start + end) / 2;
    max(
        query_max(tree, 2 * node, start, mid, l, r),
        query_max(tree, 2 * node + 1, mid + 1, end, l, r),
    )
}
```

```javascript
var getResults = function (queries) {
  let maxPos = 0;
  for (const q of queries) {
    maxPos = Math.max(maxPos, q[1]);
  }
  maxPos += 2;

  const tree = new Array(4 * maxPos).fill(0);

  const update = (node, start, end, idx, val) => {
    if (start === end) {
      tree[node] = val;
      return;
    }
    const mid = (start + end) >> 1;
    if (idx <= mid) update(2 * node, start, mid, idx, val);
    else update(2 * node + 1, mid + 1, end, idx, val);
    tree[node] = Math.max(tree[2 * node], tree[2 * node + 1]);
  };

  const queryMax = (node, start, end, l, r) => {
    if (r < start || end < l) return 0;
    if (l <= start && end <= r) return tree[node];
    const mid = (start + end) >> 1;
    return Math.max(
      queryMax(2 * node, start, mid, l, r),
      queryMax(2 * node + 1, mid + 1, end, l, r),
    );
  };

  const obstacles = [0];

  const bisectLeft = (arr, val) => {
    let lo = 0,
      hi = arr.length;
    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      if (arr[mid] < val) lo = mid + 1;
      else hi = mid;
    }
    return lo;
  };

  const results = [];

  for (const query of queries) {
    if (query[0] === 1) {
      const p = query[1];
      const idx = bisectLeft(obstacles, p);
      const prev = idx > 0 ? obstacles[idx - 1] : 0;
      const next = idx < obstacles.length ? obstacles[idx] : -1;
      obstacles.splice(idx, 0, p);
      update(1, 0, maxPos - 1, p, p - prev);
      if (next !== -1) {
        update(1, 0, maxPos - 1, next, next - p);
      }
    } else {
      const x = query[1],
        sz = query[2];
      const maxGap = queryMax(1, 0, maxPos - 1, 0, x);
      const idx = bisectLeft(obstacles, x + 1) - 1;
      const trailing = x - obstacles[idx];
      results.push(Math.max(maxGap, trailing) >= sz);
    }
  }
  return results;
};
```

> - **Time Complexity:** O(n log M), where n is the number of queries and M is the maximum position (up to 5 \* 10^4). A type 1 query does two segment tree point updates at O(log M) each, plus an ordered-set insert. A type 2 query does one range max query at O(log M) plus a predecessor lookup.
> - **Space Complexity:** O(M + n). The segment tree uses O(M) space and the obstacle set uses O(n).
