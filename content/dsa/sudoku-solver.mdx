<LessonCard>

Write a program to solve a Sudoku puzzle by filling the empty cells.

A sudoku solution must satisfy **all of the following rules**:

- Each of the digits `1-9` must occur exactly once in each row.
- Each of the digits `1-9` must occur exactly once in each column.
- Each of the digits `1-9` must occur exactly once in each of the 9 `3 x 3` sub-boxes of the grid.

The `'.'` character indicates empty cells.

\***\*Example 1:\*\***

- **Input:** `board = [["5","3",".",".","7",".",".",".","."],["6",".",".","1","9","5",".",".","."],[".","9","8",".",".",".",".","6","."],["8",".",".",".","6",".",".",".","3"],["4",".",".","8",".","3",".",".","1"],["7",".",".",".","2",".",".",".","6"],[".","6",".",".",".",".","2","8","."],[".",".",".","4","1","9",".",".","5"],[".",".",".",".","8",".",".","7","9"]]`

- **Output:** `[["5","3","4","6","7","8","9","1","2"],["6","7","2","1","9","5","3","4","8"],["1","9","8","3","4","2","5","6","7"],["8","5","9","7","6","1","4","2","3"],["4","2","6","8","5","3","7","9","1"],["7","1","3","9","2","4","8","5","6"],["9","6","1","5","3","7","2","8","4"],["2","8","7","4","1","9","6","3","5"],["3","4","5","2","8","6","1","7","9"]]`

\***\*Constraints:\*\***

- `board.length == 9`
- `board[i].length == 9`
- `board[i][j]` is a digit or `'.'`.
- It is **guaranteed** that the input board has only one solution.

Classic backtracking solves this directly. Find the first empty cell, try placing digits 1 through 9, and for each digit check whether it violates any Sudoku constraint. If the digit is valid, place it and recursively try to fill the next empty cell. If we get stuck (no digit works for some cell), backtrack by removing the last digit we placed and trying the next option.

<h1 id="understanding-the-problem">Understanding the Problem</h1>

We are given a 9x9 Sudoku board with some cells already filled and others marked with `'.'`. Our job is to fill every empty cell with a digit from 1 to 9 such that no digit repeats in any row, any column, or any of the nine 3x3 sub-boxes. The board is modified in-place, so we don't return anything.

This is a constraint satisfaction problem. At each empty cell we have up to 9 choices, and many of them are eliminated by the row, column, and box constraints. The solution is to place a digit, move on to the next empty cell, and if we reach a dead end where no digit is valid, undo the choice and try the next digit. This is backtracking.

The constraints are what make the search tractable. A single placement eliminates possibilities in its row, its column, and its box at the same time, which prunes large parts of the search space before we ever explore them.

<h3 id="key-constraints">Key Constraints:</h3>

- `board.length == 9` and `board[i].length == 9` → The board is always exactly 9x9. This is a fixed, small size, so even exponential approaches are feasible as long as we prune aggressively.
- `board[i][j]` is a digit or `'.'` → We only need to fill cells containing `'.'`. Pre-filled cells are guaranteed to be valid.
- The input board has only one solution → We can stop as soon as we find the first valid completion. No need to enumerate all solutions.

<h1 id="approach-1-brute-force-backtracking">
  Approach 1: Brute Force Backtracking
</h1>

<h3 id="intuition">Intuition</h3>

Classic backtracking solves this directly. Find the first empty cell, try placing digits 1 through 9, and for each digit check whether it violates any Sudoku constraint. If the digit is valid, place it and recursively try to fill the next empty cell. If we get stuck (no digit works for some cell), backtrack by removing the last digit we placed and trying the next option.

The validity check scans the row for a duplicate, scans the column for a duplicate, and scans the 3x3 box for a duplicate. This is correct but does redundant work, since we re-scan the same row, column, and box for every digit we try.

<h3 id="algorithm">Algorithm</h3>

1. Scan the board to find the first cell containing `'.'`.
2. If no empty cell exists, the board is solved. Return true.
3. For each digit from '1' to '9':
4. If no digit from 1 to 9 works, return false (triggers backtracking in the caller).

```java
class Solution {
    public void solveSudoku(char[][] board) {
        solve(board);
    }

    private boolean solve(char[][] board) {
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] == '.') {
                    for (char c = '1'; c <= '9'; c++) {
                        if (isValid(board, i, j, c)) {
                            board[i][j] = c;
                            if (solve(board)) return true;
                            board[i][j] = '.';
                        }
                    }
                    return false; // No valid digit found, trigger backtrack
                }
            }
        }
        return true; // All cells filled
    }

    private boolean isValid(char[][] board, int row, int col, char c) {
        for (int i = 0; i < 9; i++) {
            // Check row
            if (board[row][i] == c) return false;
            // Check column
            if (board[i][col] == c) return false;
            // Check 3x3 box
            int boxRow = 3 * (row / 3) + i / 3;
            int boxCol = 3 * (col / 3) + i % 3;
            if (board[boxRow][boxCol] == c) return false;
        }
        return true;
    }
}
```

> - **Time Complexity:** O(9^E) where E is the number of empty cells. In the worst case, for each empty cell we try all 9 digits. The validity check itself takes O(9) per call since we scan the row, column, and box.
> - **Space Complexity:** O(E) for the recursion stack. The maximum recursion depth equals the number of empty cells, which is at most 81.

Every digit we try costs a scan of 27 cells for the validity check. The next approach removes that cost by tracking which digits are already used in each row, column, and box, turning each validity check into a constant-time lookup.

<h1 id="approach-2-backtracking-with-hash-set-constraint-tracking">
  Approach 2: Backtracking with Hash Set Constraint Tracking
</h1>

<h3 id="intuition">Intuition</h3>

The brute force re-scans the board for every validity check. Instead, before solving, precompute three collections of sets. `rows[i]` stores the digits already present in row i. `cols[j]` stores the digits in column j. `boxes[k]` stores the digits in box k, where the box index for cell (r, c) is `(r / 3) * 3 + (c / 3)`.

To check if digit d is valid at position (r, c), we do three set lookups: is d in `rows[r]`, in `cols[c]`, or in `boxes[boxIndex]`? Each lookup is O(1). When we place a digit, we add it to all three sets. When we backtrack, we remove it from all three.

> The three sets stay consistent with the board because every placement adds the digit to all three sets and every backtrack removes it from all three. So a lookup in the sets gives the same answer as a full scan of the row, column, and box would, in O(1) instead of O(27). A placement is valid exactly when the digit is absent from all three sets, which matches the three Sudoku rules.

<h3 id="algorithm">Algorithm</h3>

1. Initialize three arrays of sets: `rows[9]`, `cols[9]`, `boxes[9]`.
2. Scan the board. For each pre-filled digit at (r, c), add it to `rows[r]`, `cols[c]`, and `boxes[(r/3)*3 + c/3]`.
3. Call the recursive backtracking function starting from cell (0, 0).

```java
class Solution {
    private boolean[][] rows = new boolean[9][10];
    private boolean[][] cols = new boolean[9][10];
    private boolean[][] boxes = new boolean[9][10];

    public void solveSudoku(char[][] board) {
        // Initialize constraint tracking from pre-filled cells
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] != '.') {
                    int num = board[i][j] - '0';
                    int boxIdx = (i / 3) * 3 + j / 3;
                    rows[i][num] = true;
                    cols[j][num] = true;
                    boxes[boxIdx][num] = true;
                }
            }
        }
        solve(board, 0, 0);
    }

    private boolean solve(char[][] board, int row, int col) {
        // Find the next empty cell
        while (row < 9 && board[row][col] != '.') {
            col++;
            if (col == 9) { col = 0; row++; }
        }
        if (row == 9) return true; // All cells filled

        int boxIdx = (row / 3) * 3 + col / 3;
        for (int num = 1; num <= 9; num++) {
            if (!rows[row][num] && !cols[col][num] && !boxes[boxIdx][num]) {
                // Place the digit
                board[row][col] = (char) ('0' + num);
                rows[row][num] = true;
                cols[col][num] = true;
                boxes[boxIdx][num] = true;

                if (solve(board, row, col)) return true;

                // Backtrack
                board[row][col] = '.';
                rows[row][num] = false;
                cols[col][num] = false;
                boxes[boxIdx][num] = false;
            }
        }
        return false;
    }
}
```

```python
class Solution:
    def solveSudoku(self, board: list[list[str]]) -> None:
        rows = [set() for _ in range(9)]
        cols = [set() for _ in range(9)]
        boxes = [set() for _ in range(9)]

        # Initialize constraint tracking from pre-filled cells
        for i in range(9):
            for j in range(9):
                if board[i][j] != '.':
                    num = board[i][j]
                    box_idx = (i // 3) * 3 + j // 3
                    rows[i].add(num)
                    cols[j].add(num)
                    boxes[box_idx].add(num)

        def solve(r: int, c: int) -> bool:
            # Find the next empty cell
            while r < 9 and board[r][c] != '.':
                c += 1
                if c == 9:
                    c = 0
                    r += 1
            if r == 9:
                return True  # All cells filled

            box_idx = (r // 3) * 3 + c // 3
            for num in '123456789':
                if num not in rows[r] and num not in cols[c] and num not in boxes[box_idx]:
                    # Place the digit
                    board[r][c] = num
                    rows[r].add(num)
                    cols[c].add(num)
                    boxes[box_idx].add(num)

                    if solve(r, c):
                        return True

                    # Backtrack
                    board[r][c] = '.'
                    rows[r].remove(num)
                    cols[c].remove(num)
                    boxes[box_idx].remove(num)

            return False

        solve(0, 0)
```

> - **Time Complexity:** O(9^E) where E is the number of empty cells. The worst-case branching factor is still 9 per empty cell, but the O(1) validity check means we prune invalid branches much faster. In practice, standard puzzles solve in microseconds.
> - **Space Complexity:** O(1). The constraint arrays use 270 booleans (constant). The recursion stack is at most 81 deep. Since the board is fixed at 9x9, all space is O(1).

We still process empty cells in board order. But some cells have only one valid option while others have five or six. The next approach always fills the most constrained cell first, which cuts the number of branches the recursion has to explore.

<h1 id="approach-3-backtracking-with-bitmask-constraints-and-mrv-heuristic">
  Approach 3: Backtracking with Bitmask Constraints and MRV Heuristic
</h1>

<h3 id="intuition">Intuition</h3>

The previous approach tracked constraints with boolean arrays. Bitmasks make the same checks tighter. For each row, column, and box we store a 9-bit integer where bit i being set means digit (i+1) is already used. To find the available digits for a cell, OR the three bitmasks together and invert the low 9 bits: every remaining set bit is a candidate.

The larger gain comes from the Minimum Remaining Values (MRV) heuristic from constraint satisfaction. Instead of filling empty cells left to right, always pick the empty cell with the fewest valid candidates. A cell with one candidate causes no branching, since there is only one digit to try. Choosing the most constrained cell at each step minimizes the branching factor near the top of the recursion tree, where a wide branch is most expensive.

<h3 id="algorithm">Algorithm</h3>

1. Initialize bitmask arrays: `rowMask[9]`, `colMask[9]`, `boxMask[9]`, each starting at 0.
2. Scan the board. For each pre-filled digit d at (r, c), set bit (d-1) in the corresponding masks.
3. Collect all empty cell positions into a list.

```java
class Solution {
    private int[] rowMask = new int[9];
    private int[] colMask = new int[9];
    private int[] boxMask = new int[9];

    public void solveSudoku(char[][] board) {
        List<int[]> emptyCells = new ArrayList<>();

        // Initialize bitmasks and collect empty cells
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] == '.') {
                    emptyCells.add(new int[]{i, j});
                } else {
                    int bit = 1 << (board[i][j] - '1');
                    rowMask[i] |= bit;
                    colMask[j] |= bit;
                    boxMask[(i / 3) * 3 + j / 3] |= bit;
                }
            }
        }
        solve(board, emptyCells);
    }

    private boolean solve(char[][] board, List<int[]> emptyCells) {
        if (emptyCells.isEmpty()) return true;

        // MRV: find the cell with fewest candidates
        int minCount = 10, bestIdx = 0;
        for (int i = 0; i < emptyCells.size(); i++) {
            int r = emptyCells.get(i)[0], c = emptyCells.get(i)[1];
            int used = rowMask[r] | colMask[c] | boxMask[(r / 3) * 3 + c / 3];
            int count = Integer.bitCount(~used & 0x1FF);
            if (count < minCount) {
                minCount = count;
                bestIdx = i;
            }
        }

        int[] cell = emptyCells.get(bestIdx);
        int r = cell[0], c = cell[1];
        int boxIdx = (r / 3) * 3 + c / 3;
        int available = ~(rowMask[r] | colMask[c] | boxMask[boxIdx]) & 0x1FF;

        // Remove this cell from the list (swap with last for O(1))
        emptyCells.set(bestIdx, emptyCells.get(emptyCells.size() - 1));
        emptyCells.remove(emptyCells.size() - 1);

        // Try each available digit
        while (available != 0) {
            int bit = available & (-available); // Lowest set bit
            int digit = Integer.numberOfTrailingZeros(bit) + 1;

            board[r][c] = (char) ('0' + digit);
            rowMask[r] |= bit;
            colMask[c] |= bit;
            boxMask[boxIdx] |= bit;

            if (solve(board, emptyCells)) return true;

            // Backtrack
            board[r][c] = '.';
            rowMask[r] ^= bit;
            colMask[c] ^= bit;
            boxMask[boxIdx] ^= bit;

            available &= available - 1; // Clear lowest set bit
        }

        // Restore cell to the list
        emptyCells.add(cell);
        return false;
    }
```

```typescript
  const rowMask = new Array(9).fill(0);
  const colMask = new Array(9).fill(0);
  const boxMask = new Array(9).fill(0);
  const emptyCells: [number, number][] = [];

  // Initialize bitmasks and collect empty cells
  for (let i = 0; i < 9; i++) {
    for (let j = 0; j < 9; j++) {
      if (board[i][j] === ".") {
        emptyCells.push([i, j]);
      } else {
        const bit = 1 << (Number(board[i][j]) - 1);
        rowMask[i] |= bit;
        colMask[j] |= bit;
        boxMask[Math.floor(i / 3) * 3 + Math.floor(j / 3)] |= bit;
      }
    }
  }

  function bitCount(n: number): number {
    let count = 0;
    while (n) {
      count++;
      n &= n - 1;
    }
    return count;
  }

  function trailingZeros(n: number): number {
    let count = 0;
    while ((n & 1) === 0) {
      count++;
      n >>= 1;
    }
    return count;
  }

  function solve(): boolean {
    if (emptyCells.length === 0) return true;

    // MRV: find the cell with fewest candidates
    let minCount = 10,
      bestIdx = 0;
    for (let i = 0; i < emptyCells.length; i++) {
      const [r, c] = emptyCells[i];
      const used =
        rowMask[r] |
        colMask[c] |
        boxMask[Math.floor(r / 3) * 3 + Math.floor(c / 3)];
      const count = bitCount(~used & 0x1ff);
      if (count < minCount) {
        minCount = count;
        bestIdx = i;
      }
    }

    const [r, c] = emptyCells[bestIdx];
    const boxIdx = Math.floor(r / 3) * 3 + Math.floor(c / 3);
    let available = ~(rowMask[r] | colMask[c] | boxMask[boxIdx]) & 0x1ff;

    // Remove this cell (swap with last)
    const cell = emptyCells[bestIdx];
    emptyCells[bestIdx] = emptyCells[emptyCells.length - 1];
    emptyCells.pop();

    while (available) {
      const bit = available & -available; // Lowest set bit
      const digit = trailingZeros(bit) + 1;

      board[r][c] = String(digit);
      rowMask[r] |= bit;
      colMask[c] |= bit;
      boxMask[boxIdx] |= bit;

      if (solve()) return true;

      // Backtrack
      board[r][c] = ".";
      rowMask[r] ^= bit;
      colMask[c] ^= bit;
      boxMask[boxIdx] ^= bit;

      available &= available - 1; // Clear lowest set bit
    }

    emptyCells.push(cell);
    return false;
  }

  solve();
}
```

> - **Time Complexity:** O(9^E) worst case, but dramatically better in practice. MRV reduces the effective branching factor. For standard Sudoku puzzles, the algorithm typically explores only a handful of nodes.
> - **Space Complexity:** O(E) for the empty cells list and recursion stack. The bitmask arrays use 27 integers (constant).
