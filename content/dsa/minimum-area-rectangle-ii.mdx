<LessonCard>

You are given an array of points in the X-Y plane `points` where `points[i] = [xi, yi]`.

Return the minimum area of any rectangle formed from these points, with sides **not necessarily parallel** to the X and Y axes. If there is not any such rectangle, return `0`.

Answers within `10^-5` of the actual answer will be accepted.

\***\*Example 1:\*\***

- **Input:** `points = [[1,2],[2,1],[1,0],[0,1]]`

- **Output:** `2.00000`

\***\*Example 2:\*\***

- **Input:** `points = [[0,1],[2,1],[1,1],[1,0],[2,0]]`

- **Output:** `1.00000`

\***\*Example 3:\*\***

- **Input:** `points = [[0,3],[1,2],[3,1],[1,3],[2,1]]`

- **Output:** `0`

\***\*Constraints:\*\***

- `1 <= points.length <= 50`
- `points[i].length == 2`
- `0 <= xi, yi <= 4 * 10^4`
- All the given points are **unique**.

Treat one of the three chosen points, A, as the corner holding the right angle. Then the vectors AB and AC must be perpendicular, which the dot product detects: AB dot AC = 0 means the angle at A is 90 degrees. Given that right angle, the opposite corner is fixed at D = B + C - A, because in a rectangle the diagonal from A to D is the sum of the two adjacent sides.

This problem is a step up from the classic "Minimum Area Rectangle" (LeetCode #939) where rectangles had to be axis-aligned. Here, the rectangle can be rotated at any angle. That changes the problem fundamentally, because we can no longer look for pairs of points that share an x-coordinate or a y-coordinate.

A rectangle is four points where opposite sides are equal and parallel and all four angles are 90 degrees. In coordinate geometry, this implies a property that the efficient solution relies on: the two diagonals of a rectangle bisect each other (they share the same midpoint) and have equal length.

- `1 <= points.length <= 50` → With n at most 50, even an O(n^4) brute force stays under 6.25 million operations, so it runs in time. The O(n^3) and O(n^2) approaches below leave plenty of headroom.
- `0 <= xi, yi <= 4 * 10^4` → Coordinates are non-negative integers. This means we can use them as hash keys without worrying about floating-point issues in point lookups.
- `All points are unique` → No need to handle duplicate points.

Pick any three points and figure out where the fourth corner of the rectangle would have to be. If that fourth point exists in the set, the four points form a rectangle.

<h3 id="algorithm">Algorithm</h3>

1. Store all points in a hash set for O(1) lookup.
2. For every point A, and for every pair of other points (B, C):
3. Return the minimum area found, or 0 if no rectangle exists.

```java
class Solution {
    public double minAreaFreeRect(int[][] points) {
        int n = points.length;
        Set<Long> pointSet = new HashSet<>();
        for (int[] p : points) {
            pointSet.add(encode(p[0], p[1]));
        }

        double minArea = Double.MAX_VALUE;
        boolean found = false;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (i == j) continue;
                for (int k = j + 1; k < n; k++) {
                    if (k == i) continue;
                    // A = points[i], B = points[j], C = points[k]
                    int abx = points[j][0] - points[i][0];
                    int aby = points[j][1] - points[i][1];
                    int acx = points[k][0] - points[i][0];
                    int acy = points[k][1] - points[i][1];

                    // Check perpendicularity: dot product = 0
                    if (abx * acx + aby * acy != 0) continue;

                    // Fourth point D = B + C - A
                    int dx = points[j][0] + points[k][0] - points[i][0];
                    int dy = points[j][1] + points[k][1] - points[i][1];

                    if (pointSet.contains(encode(dx, dy))) {
                        double area = Math.sqrt((long) abx * abx + (long) aby * aby)
                                    * Math.sqrt((long) acx * acx + (long) acy * acy);
                        if (area > 0) {
                            found = true;
                            minArea = Math.min(minArea, area);
                        }
                    }
                }
            }
        }
        return found ? minArea : 0.0;
    }

    private long encode(int x, int y) {
        return (long) x * 40001 + y;
    }
}
```

```python
class Solution:
    def minAreaFreeRect(self, points: list[list[int]]) -> float:
        point_set = set(map(tuple, points))
        n = len(points)
        min_area = float('inf')
        found = False

        for i in range(n):
            ax, ay = points[i]
            for j in range(n):
                if j == i:
                    continue
                bx, by = points[j]
                for k in range(j + 1, n):
                    if k == i:
                        continue
                    cx, cy = points[k]

                    # Vectors AB and AC
                    abx, aby = bx - ax, by - ay
                    acx, acy = cx - ax, cy - ay

                    if abx * acx + aby * acy != 0:
                        continue

                    # Fourth point D = B + C - A
                    dx, dy = bx + cx - ax, by + cy - ay

                    if (dx, dy) in point_set:
                        area = (abx * abx + aby * aby) ** 0.5 * (acx * acx + acy * acy) ** 0.5
                        if area > 0:
                            found = True
                            min_area = min(min_area, area)

        return min_area if found else 0.0
```

> - **Time Complexity:** O(n^3). We iterate over all points as the right-angle vertex (n choices), then all pairs of other points (roughly n^2 pairs). The hash set lookup for the fourth point is O(1).
> - **Space Complexity:** O(n). The hash set storing all points takes O(n) space.

For each of the n points, this checks all O(n^2) pairs of remaining points to test for a right angle at that vertex. Most of those triples fail the perpendicularity check, so much of the work is spent on combinations that can never form a rectangle.

The next approach avoids triples entirely. Instead of testing whether three points happen to form a right angle, it groups pairs of points by a property that two diagonals of the same rectangle must share.

<h1 id="approach-2-diagonal-grouping-with-hash-map">
  Approach 2: Diagonal Grouping with Hash Map
</h1>

<h3 id="intuition">Intuition</h3>

The two diagonals of a rectangle bisect each other and have equal length, so they share both a midpoint and a length. Take every pair of points, treat that pair as a potential diagonal, and record its midpoint and length. Any two pairs that land in the same (midpoint, length) group are two diagonals that meet at a common center with equal length, which is exactly the condition for their four endpoints to form a rectangle.

> Two segments whose endpoints share a common midpoint and have equal length are guaranteed to be the diagonals of a rectangle. The shared midpoint forces the four endpoints to be symmetric about a single center, and equal diagonal length is the property that distinguishes a rectangle from a general parallelogram. So no pair within a group ever produces a non-rectangle, and grouping by (midpoint, length) cannot miss a rectangle either, since both of its diagonals necessarily produce the same key.

<h3 id="algorithm">Algorithm</h3>

1. For every pair of points (P1, P2), compute the midpoint sum and diagonal length squared.
2. Group all pairs by the key (midpoint_x_sum, midpoint_y_sum, dist_squared).
3. For each group with at least 2 pairs, check every combination. Each combination gives 4 points forming a rectangle.
4. Compute the area using the cross product of the side vectors.
5. Return the minimum area, or 0 if no rectangle is found.

```java
class Solution {
    public double minAreaFreeRect(int[][] points) {
        int n = points.length;
        Map<Long, List<int[]>> groups = new HashMap<>();

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int mx = points[i][0] + points[j][0];
                int my = points[i][1] + points[j][1];
                int dx = points[i][0] - points[j][0];
                int dy = points[i][1] - points[j][1];
                long distSq = (long) dx * dx + (long) dy * dy;

                long key = (long) mx * 80003L * 80003L + (long) my * 80003L + distSq;
                groups.computeIfAbsent(key, k -> new ArrayList<>()).add(new int[]{i, j});
            }
        }

        double minArea = Double.MAX_VALUE;
        boolean found = false;

        for (List<int[]> pairs : groups.values()) {
            for (int a = 0; a < pairs.size(); a++) {
                for (int b = a + 1; b < pairs.size(); b++) {
                    int i = pairs.get(a)[0], j = pairs.get(a)[1];
                    int k = pairs.get(b)[0];
                    double side1x = points[k][0] - points[i][0];
                    double side1y = points[k][1] - points[i][1];
                    double side2x = points[j][0] - points[i][0];
                    double side2y = points[j][1] - points[i][1];
                    double area = Math.abs(side1x * side2y - side1y * side2x);
                    if (area > 0) {
                        found = true;
                        minArea = Math.min(minArea, area);
                    }
                }
            }
        }
        return found ? minArea : 0.0;
    }
}
```

```go
func minAreaFreeRect(points [][]int) float64 {
    n := len(points)
    type key struct {
        mx, my int
        distSq int64
    }
    groups := make(map[key][][2]int)

    for i := 0; i < n; i++ {
        for j := i + 1; j < n; j++ {
            mx := points[i][0] + points[j][0]
            my := points[i][1] + points[j][1]
            dx := int64(points[i][0] - points[j][0])
            dy := int64(points[i][1] - points[j][1])
            distSq := dx*dx + dy*dy

            k := key{mx, my, distSq}
            groups[k] = append(groups[k], [2]int{i, j})
        }
    }

    minArea := math.MaxFloat64
    found := false

    for _, pairs := range groups {
        for a := 0; a < len(pairs); a++ {
```

```rust
        for i in 0..n {
            for j in i + 1..n {
                let mx = points[i][0] + points[j][0];
                let my = points[i][1] + points[j][1];
                let dx = (points[i][0] - points[j][0]) as i64;
                let dy = (points[i][1] - points[j][1]) as i64;
                let dist_sq = dx * dx + dy * dy;

                let key = (mx, my, dist_sq);
                groups.entry(key).or_insert_with(Vec::new).push((i, j));
            }
        }

        let mut min_area = f64::MAX;
        let mut found = false;

        for pairs in groups.values() {
            for a in 0..pairs.len() {
                for b in a + 1..pairs.len() {
                    let i = pairs[a].0;
                    let j = pairs[a].1;
                    let k = pairs[b].0;
                    let s1x = (points[k][0] - points[i][0]) as f64;
                    let s1y = (points[k][1] - points[i][1]) as f64;
                    let s2x = (points[j][0] - points[i][0]) as f64;
                    let s2y = (points[j][1] - points[i][1]) as f64;
                    let area = (s1x * s2y - s1y * s2x).abs();
                    if area > 0.0 {
                        found = true;
                        if area < min_area {
                            min_area = area;
                        }
                    }
                }
            }
        }

        if found { min_area } else { 0.0 }
    }
}
```

```typescript
function minAreaFreeRect(points: number[][]): number {
  const n = points.length;
  const groups = new Map<string, number[][]>();

  for (let i = 0; i < n; i++) {
    for (let j = i + 1; j < n; j++) {
      const mx = points[i][0] + points[j][0];
      const my = points[i][1] + points[j][1];
      const dx = points[i][0] - points[j][0];
      const dy = points[i][1] - points[j][1];
      const distSq = dx * dx + dy * dy;

      const key = `${mx},${my},${distSq}`;
      if (!groups.has(key)) groups.set(key, []);
      groups.get(key)!.push([i, j]);
    }
  }

  let minArea = Infinity;
  let found = false;

  for (const pairs of groups.values()) {
    for (let a = 0; a < pairs.length; a++) {
      for (let b = a + 1; b < pairs.length; b++) {
        const i = pairs[a][0],
          j = pairs[a][1];
        const k = pairs[b][0];
        const s1x = points[k][0] - points[i][0];
        const s1y = points[k][1] - points[i][1];
        const s2x = points[j][0] - points[i][0];
        const s2y = points[j][1] - points[i][1];
        const area = Math.abs(s1x * s2y - s1y * s2x);
        if (area > 0) {
          found = true;
          minArea = Math.min(minArea, area);
        }
      }
    }
  }
  return found ? minArea : 0.0;
}
```

> - **Time Complexity:** O(n^2 + R) where R is the total number of rectangle candidates. Building groups takes O(n^2). Within each group of size g, we check C(g, 2) pairs.
> - **Space Complexity:** O(n^2). We store all O(n^2) pairs in the hash map groups.
