<LessonCard>

You are given the `root` of a binary tree with `n` nodes. Each node is uniquely assigned a value from `1` to `n`. You are also given an integer `startValue` representing the value of the start node `s`, and a different integer `destValue` representing the value of the destination node `t`.

Find the **shortest path** between the node `s` and the node `t`. Generate step-by-step directions of such path as a string consisting of only the **uppercase** letters `'L'`, `'R'`, and `'U'`. Each letter indicates a specific direction:

- `'L'` means to go from a node to its **left child** node.
- `'R'` means to go from a node to its **right child** node.
- `'U'` means to go from a node to its **parent** node.

Return the step-by-step directions of the shortest path from node `s` to node `t`.

\***\*Example 1:\*\***

**Input:** `root = [5,1,2,3,null,6,4]`, `startValue = 3`, `destValue = 6`

**Output:** `"UURL"`

The shortest path is: 3 -> 1 -> 5 -> 2 -> 6.

\***\*Example 2:\*\***

**Input:** `root = [2,1]`, `startValue = 2`, `destValue = 1`

**Output:** `"L"`

The shortest path is: 2 -> 1.

\***\*Constraints:\*\***

- `The number of nodes in the tree is n.`
- `2 <= n <= 10^5`
- `1 <= Node.val <= n`
- `All the values in the tree are unique.`
- `1 <= startValue, destValue <= n`
- `startValue != destValue`

We have a binary tree and two node values. We need to find directions to walk from the start node to the destination node. In a binary tree, you can only move to children (left or right) or back up to a parent. So the path between any two nodes must go up from the start to some ancestor, then down to the destination.

That ancestor is the **Lowest Common Ancestor (LCA)** of the two nodes. Any path from start to destination in a binary tree must pass through the LCA, because the LCA is the deepest node that sits above both of them. The path from start to LCA is all 'U' moves (going up), and the path from LCA to destination is 'L' and 'R' moves (going down).

There is no need to build an explicit graph and run BFS. We can find the LCA and construct the path directly using DFS.

- `2 <= n <= 10^5` → We need O(n) time. A quadratic approach that repeatedly scans the tree would be too slow.
- `All values are unique` → We can identify nodes by their values without ambiguity, so matching a node to `startValue` or `destValue` is exact.
- `1 <= Node.val <= n` → Values are dense integers, so an array indexed by value can replace a hash map if memory matters.

<h3 id="intuition">Intuition</h3>

In a general graph, the shortest path between two nodes comes from BFS. A binary tree is a graph, with one missing piece: nodes point to their children but not to their parents. Add parent pointers and the problem becomes ordinary BFS. First traverse the tree to record each node's parent, then run BFS from the start node, treating left child, right child, and parent as the three neighbors of every node.

During BFS, we track the direction taken to reach each node ('L', 'R', or 'U') along with the node we came from. When BFS reaches the destination, we walk that trail backward to rebuild the path.

This converts the tree into an undirected graph and runs a full BFS, which costs more memory than the later approaches. It is a useful baseline because the correctness comes directly from the BFS shortest-path guarantee rather than any tree-specific reasoning.

<h3 id="algorithm">Algorithm</h3>

1. Traverse the tree (DFS or BFS) and store the parent of every node in a hash map. Also locate the actual start node reference.
2. Run BFS from the start node. At each step, try three neighbors: left child (direction 'L'), right child (direction 'R'), and parent (direction 'U').
3. Use a visited set to avoid revisiting nodes.
4. When BFS reaches the destination node, reconstruct the path using the stored directions.

<h3 id="example-walkthrough">Example Walkthrough</h3>

**Input:**

First, the parent map records each node's parent: `1→5`, `2→5`, `3→1`, `6→2`, `4→2`, and `5→null`. BFS then starts from node 3.

The `visited` map stores, for each node reached, the node we came from and the direction taken. It begins as `{3: (start, none)}`.

- Pop 3. Its children are 3.left (which is null) and no right child, so only its parent 1 is unvisited. Record `visited[1] = (3, 'U')` and enqueue 1.
- Pop 1. Its left child 3 is already visited and it has no right child, so visit its parent 5. Record `visited[5] = (1, 'U')` and enqueue 5.
- Pop 5. Its left child 1 is visited, its right child 2 is new, and it has no parent. Record `visited[2] = (5, 'R')` and enqueue 2.
- Pop 2. Its left child 6 and right child 4 are both new, and its parent 5 is visited. Record `visited[6] = (2, 'L')` and `visited[4] = (2, 'R')`, enqueue both.
- Pop 6. This is the destination.

Now reconstruct by following the trail backward from 6: `6` came from 2 via `'L'`, `2` came from 5 via `'R'`, `5` came from 1 via `'U'`, `1` came from 3 via `'U'`, and 3 is the start. Collected in reverse order this is "LRUU", so reversing gives "UURL".

```java
class Solution {
    public String getDirections(TreeNode root, int startValue, int destValue) {
        Map<Integer, TreeNode> parentMap = new HashMap<>();
        TreeNode[] startNode = new TreeNode[1];
        buildParentMap(root, null, parentMap, startValue, startNode);

        Queue<TreeNode> queue = new LinkedList<>();
        Map<Integer, int[]> visited = new HashMap<>();
        queue.offer(startNode[0]);
        visited.put(startValue, new int[]{-1, -1});

        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();

            if (node.val == destValue) {
                StringBuilder path = new StringBuilder();
                int current = destValue;
                while (visited.get(current)[0] != -1) {
                    path.append((char) visited.get(current)[1]);
                    current = visited.get(current)[0];
                }
                return path.reverse().toString();
            }

            if (node.left != null && !visited.containsKey(node.left.val)) {
                visited.put(node.left.val, new int[]{node.val, 'L'});
                queue.offer(node.left);
            }
            if (node.right != null && !visited.containsKey(node.right.val)) {
                visited.put(node.right.val, new int[]{node.val, 'R'});
                queue.offer(node.right);
            }
            TreeNode parent = parentMap.get(node.val);
            if (parent != null && !visited.containsKey(parent.val)) {
                visited.put(parent.val, new int[]{node.val, 'U'});
                queue.offer(parent);
            }
        }

        return "";
    }

    private void buildParentMap(TreeNode node, TreeNode parent,
            Map<Integer, TreeNode> parentMap, int startValue, TreeNode[] startNode) {
        if (node == null) return;
        if (node.val == startValue) startNode[0] = node;
        parentMap.put(node.val, parent);
        buildParentMap(node.left, node, parentMap, startValue, startNode);
        buildParentMap(node.right, node, parentMap, startValue, startNode);
    }
}
```

```cpp
        unordered_map<int, TreeNode*> parentMap;
        TreeNode* startNode = nullptr;
        buildParentMap(root, nullptr, parentMap, startValue, startNode);

            q.pop();

            if (node->val == destValue) {
                string path;
                int current = destValue;
                while (visited[current].first != -1) {
                    path += visited[current].second;
                    current = visited[current].first;
                }
                reverse(path.begin(), path.end());
                return path;
            }

            if (node->left && visited.find(node->left->val) == visited.end()) {
                visited[node->left->val] = {node->val, 'L'};
                q.push(node->left);
```

```go
func getDirections(root *TreeNode, startValue int, destValue int) string {
    parentMap := make(map[int]*TreeNode)
    var startNode *TreeNode

    var buildParentMap func(node, parent *TreeNode)
    buildParentMap = func(node, parent *TreeNode) {
        if node == nil {
            return
        }
        if node.Val == startValue {
            startNode = node
        }
        parentMap[node.Val] = parent
        buildParentMap(node.Left, node)
        buildParentMap(node.Right, node)
    }
    buildParentMap(root, nil)

    type entry struct {
        parentVal int
        dir       byte
    }
    queue := []*TreeNode{startNode}
    visited := map[int]entry{startValue: {-1, ' '}}

    for len(queue) > 0 {
        node := queue[0]
        queue = queue[1:]

        if node.Val == destValue {
            path := []byte{}
            current := destValue
            for visited[current].parentVal != -1 {
                path = append(path, visited[current].dir)
                current = visited[current].parentVal
            }
            for i, j := 0, len(path)-1; i < j; i, j = i+1, j-1 {
                path[i], path[j] = path[j], path[i]
            }
            return string(path)
        }

        if node.Left != nil {
            if _, ok := visited[node.Left.Val]; !ok {
                visited[node.Left.Val] = entry{node.Val, 'L'}
                queue = append(queue, node.Left)
            }
        }
        if node.Right != nil {
            if _, ok := visited[node.Right.Val]; !ok {
                visited[node.Right.Val] = entry{node.Val, 'R'}
                queue = append(queue, node.Right)
            }
        }
        if parent, ok := parentMap[node.Val]; ok && parent != nil {
            if _, ok := visited[parent.Val]; !ok {
                visited[parent.Val] = entry{node.Val, 'U'}
                queue = append(queue, parent)
            }
        }
    }

    return ""
}
```

```rust
use std::cell::RefCell;
use std::collections::{HashMap, VecDeque};
use std::rc::Rc;

type Node = Rc<RefCell<TreeNode>>;

impl Solution {
    pub fn get_directions(root: Option<Node>, start_value: i32, dest_value: i32) -> String {
        // Map each node value to its node and to its parent's value (-1 for the root).
        let mut nodes: HashMap<i32, Node> = HashMap::new();
        let mut parent_val: HashMap<i32, i32> = HashMap::new();
        Self::index_tree(root, -1, &mut nodes, &mut parent_val);

        // BFS from the start node. visited maps a node value to (came_from_value, direction).
        let mut visited: HashMap<i32, (i32, char)> = HashMap::new();
        let mut queue: VecDeque<i32> = VecDeque::new();
        visited.insert(start_value, (-1, ' '));
        queue.push_back(start_value);

        while let Some(val) = queue.pop_front() {
            if val == dest_value {
                let mut path: Vec<char> = Vec::new();
                let mut current = dest_value;
                while visited[&current].0 != -1 {
                    let (from, dir) = visited[&current];
                    path.push(dir);
                    current = from;
                }
                path.reverse();
                return path.into_iter().collect();
            }

            let node = nodes[&val].clone();
            let node_ref = node.borrow();
            if let Some(left) = node_ref.left.as_ref() {
                let lv = left.borrow().val;
                if !visited.contains_key(&lv) {
                    visited.insert(lv, (val, 'L'));
                    queue.push_back(lv);
                }
            }
            if let Some(right) = node_ref.right.as_ref() {
                let rv = right.borrow().val;
                if !visited.contains_key(&rv) {
                    visited.insert(rv, (val, 'R'));
                    queue.push_back(rv);
                }
            }
            let pv = parent_val[&val];
            if pv != -1 && !visited.contains_key(&pv) {
                visited.insert(pv, (val, 'U'));
                queue.push_back(pv);
            }
        }

        String::new()
    }

    fn index_tree(
        node: Option<Node>,
        parent: i32,
        nodes: &mut HashMap<i32, Node>,
        parent_val: &mut HashMap<i32, i32>,
    ) {
        if let Some(n) = node {
            let val = n.borrow().val;
            parent_val.insert(val, parent);
            nodes.insert(val, n.clone());
            let (left, right) = {
                let b = n.borrow();
                (b.left.clone(), b.right.clone())
            };
            Self::index_tree(left, val, nodes, parent_val);
            Self::index_tree(right, val, nodes, parent_val);
        }
    }
}
```

> - **Time Complexity:** O(n). Building the parent map visits every node once. BFS visits every node at most once. Path reconstruction is at most O(n). Total: O(n).
> - **Space Complexity:** O(n). The parent map, BFS queue, and visited map each store up to n entries.

BFS requires three auxiliary structures: a parent map, a visited map, and a queue. The next approach drops all of them by working with root-to-node paths instead.

<h1 id="approach-2-root-to-node-paths-with-common-prefix-removal">
  Approach 2: Root-to-Node Paths with Common Prefix Removal
</h1>

<h3 id="intuition">Intuition</h3>

The path from start to destination always goes through the Lowest Common Ancestor (LCA). The path from the root to start and the path from the root to destination share a common prefix: the portion from the root down to the LCA. After the LCA, the two paths diverge.

This gives the algorithm: find both root-to-node paths, strip their common prefix, replace the remaining start path with 'U' moves (going up to the LCA), and append the remaining destination path (going down from the LCA). The LCA itself is never computed as a node; it is the point where the prefixes stop matching, so the prefix length alone is enough.

<h3 id="algorithm">Algorithm</h3>

1. Use DFS to find the path from root to the start node, recording 'L' or 'R' at each step.
2. Use DFS to find the path from root to the destination node, same way.
3. Find the length of the common prefix between the two paths.
4. Build the result: repeat 'U' for the remaining length of the start path, then append the remaining portion of the destination path.

<h3 id="code">Code</h3>

```java
class Solution {
    public String getDirections(TreeNode root, int startValue, int destValue) {
        StringBuilder pathToStart = new StringBuilder();
        StringBuilder pathToDest = new StringBuilder();
        findPath(root, startValue, pathToStart);
        findPath(root, destValue, pathToDest);

        int commonLength = 0;
        while (commonLength < pathToStart.length() && commonLength < pathToDest.length()
                && pathToStart.charAt(commonLength) == pathToDest.charAt(commonLength)) {
            commonLength++;
        }

        StringBuilder result = new StringBuilder();
        for (int i = 0; i < pathToStart.length() - commonLength; i++) {
            result.append('U');
        }
        result.append(pathToDest.substring(commonLength));

        return result.toString();
    }

    private boolean findPath(TreeNode node, int target, StringBuilder path) {
        if (node == null) return false;
        if (node.val == target) return true;

        path.append('L');
        if (findPath(node.left, target, path)) return true;
        path.deleteCharAt(path.length() - 1);

        path.append('R');
        if (findPath(node.right, target, path)) return true;
        path.deleteCharAt(path.length() - 1);

        return false;
    }
}
```

```python
class Solution:
    def getDirections(self, root: Optional[TreeNode], startValue: int, destValue: int) -> str:
        path_to_start = []
        path_to_dest = []
        self.find_path(root, startValue, path_to_start)
        self.find_path(root, destValue, path_to_dest)

        common_length = 0
        while (common_length < len(path_to_start) and common_length < len(path_to_dest)
                and path_to_start[common_length] == path_to_dest[common_length]):
            common_length += 1

        ups = 'U' * (len(path_to_start) - common_length)
        downs = ''.join(path_to_dest[common_length:])
        return ups + downs

    def find_path(self, node, target, path):
        if not node:
            return False
        if node.val == target:
            return True

        path.append('L')
        if self.find_path(node.left, target, path):
            return True
        path.pop()

        path.append('R')
        if self.find_path(node.right, target, path):
            return True
        path.pop()

        return False
```

```csharp
                && pathToStart[commonLength] == pathToDest[commonLength]) {
            commonLength++;
        }

        var result = new StringBuilder();
        for (int i = 0; i < pathToStart.Length - commonLength; i++) {
            result.Append('U');
        }
        result.Append(pathToDest.ToString().Substring(commonLength));
        return result.ToString();
    }

    private bool FindPath(TreeNode node, int target, StringBuilder path) {
        if (node == null) return false;
        if (node.val == target) return true;

        path.Append('L');
        if (FindPath(node.left, target, path)) return true;
        path.Length--;

        path.Append('R');
        if (FindPath(node.right, target, path)) return true;
        path.Length--;

        return false;
    }
}
```

> - **Time Complexity:** O(n). Each DFS visits at most n nodes. The common prefix comparison and result building are each at most O(n). Total: O(n).

This approach builds full paths from the root, then discards the common prefix as wasted work. The next approach finds the LCA first and builds each path starting from it, so nothing is thrown away.

<h1 id="approach-3-lca-then-build-paths">Approach 3: LCA Then Build Paths</h1>

<h3 id="intuition">Intuition</h3>

This approach computes the LCA as an actual node first, then builds paths from the LCA to each target. Finding the LCA of two nodes in a binary tree is a standard recursion: if the current node is one of the targets, return it; otherwise search both subtrees; if both subtrees return non-null, the targets lie on opposite sides, so the current node is the LCA.

With the LCA in hand, one DFS from it to the start node gives the depth (the number of 'U' moves), and one DFS from it to the destination node gives the 'L'/'R' directions. The problem splits cleanly into two named subproblems: find the LCA, then build paths from it.

<h3 id="algorithm">Algorithm</h3>

1. Find the LCA of `startValue` and `destValue` using the standard recursive LCA algorithm.
2. DFS from the LCA to find the path to `startValue`. We only need the depth (number of steps), since all moves going up are 'U'.
3. DFS from the LCA to find the path to `destValue`, recording 'L' and 'R' at each step.
4. Build the result: repeat 'U' for the depth to start, then append the direction path to destination.
