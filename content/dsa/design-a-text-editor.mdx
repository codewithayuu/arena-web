<LessonCard>

Design a text editor with a cursor that can do the following:

- **Add** text to where the cursor is.
- **Delete** text from where the cursor is (simulating the backspace key).
- **Move** the cursor either left or right.

When deleting text, only characters to the left of the cursor will be deleted. The cursor will also remain within the actual text and cannot be moved beyond it. More formally, we have that `0 <= cursor.position <= currentText.length` always holds.

Implement the `TextEditor` class:

- `TextEditor()` Initializes the object with empty text.
- `void addText(String text)` Appends `text` to where the cursor is. The cursor ends to the right of `text`.
- `int deleteText(int k)` Deletes `k` characters to the left of the cursor. Returns the number of characters actually deleted.
- `String cursorLeft(int k)` Moves the cursor to the left `k` times. Returns the last `min(10, len)` characters to the left of the cursor, where `len` is the number of characters to the left of the cursor.
- `String cursorRight(int k)` Moves the cursor to the right `k` times. Returns the last `min(10, len)` characters to the left of the cursor, where `len` is the number of characters to the left of the cursor.

**Example 1:**

- **Input:** `operations = ["TextEditor", "addText", "deleteText", "addText", "cursorRight", "cursorLeft", "deleteText", "cursorLeft", "cursorRight"]`

- **Input:** `args = [[], ["leetcode"], [4], ["practice"], [3], [8], [10], [2], [6]]`

- **Output:** `[null, null, 4, null, "etpractice", "leet", 4, "", "practi"]`

**Constraints:**

- `1 <= text.length, k <= 40`
- `text` consists of lowercase English letters.
- At most `2 * 10^4` calls in total will be made to `addText`, `deleteText`, `cursorLeft`, and `cursorRight`.

We need to simulate a text editor where all operations happen relative to a cursor position. The cursor splits the text into two halves: everything to its left and everything to its right. Every operation either modifies characters near the cursor or moves the cursor itself.

All operations are local to the cursor. `addText` inserts at the cursor, `deleteText` removes characters immediately to its left, and `cursorLeft` and `cursorRight` shift its position. Nothing ever reads or modifies characters far from the cursor. This locality drives the optimal solution. The question becomes: what data structure supports efficient insertion, deletion, and access right next to one moving position?

- `1 <= text.length, k <= 40` -> Each individual operation involves at most 40 characters, so per-character work within one operation is cheap.
- At most `2 * 10^4` total calls -> The text can grow to about 8 \* 10^5 characters. An O(n) per operation approach still passes at this size, but an approach that touches only characters near the cursor costs O(k) per operation, effectively constant since k &lt;= 40.
- `text` consists of lowercase English letters -> Single-byte characters with no case or encoding edge cases.

<h1 id="approach-1-string-with-cursor-index">
  Approach 1: String with Cursor Index
</h1>

<h3 id="intuition">Intuition</h3>

Store the entire text as a single string and maintain an integer `cursor` that tracks the cursor position. Every operation manipulates the string around this cursor index. `addText` inserts at the cursor position, `deleteText` removes characters before the cursor, and `cursorLeft` and `cursorRight` adjust the integer.

This is simple and correct, but inserting into or deleting from the middle of a string costs O(n), where n is the total text length, because every character after the edit point shifts. For this problem's constraints that is acceptable.

<h3 id="algorithm">Algorithm</h3>

1. Maintain a string `text` and an integer `cursor` initialized to 0.
2. `addText(s)`: Insert `s` at position `cursor` in the string. Move `cursor` forward by `s.length`.
3. `deleteText(k)`: Compute `toDelete = min(k, cursor)`. Remove `toDelete` characters ending at `cursor`. Move `cursor` back by `toDelete`. Return `toDelete`.
4. `cursorLeft(k)`: Move `cursor` left by `min(k, cursor)`. Return the last `min(10, cursor)` characters to the left of the cursor.
5. `cursorRight(k)`: Move `cursor` right by `min(k, text.length - cursor)`. Return the last `min(10, cursor)` characters to its left.

```java
class TextEditor {
    StringBuilder text;
    int cursor;

    public TextEditor() {
        text = new StringBuilder();
        cursor = 0;
    }

    public void addText(String s) {
        text.insert(cursor, s);
        cursor += s.length();
    }

    public int deleteText(int k) {
        int toDelete = Math.min(k, cursor);
        text.delete(cursor - toDelete, cursor);
        cursor -= toDelete;
        return toDelete;
    }

    public String cursorLeft(int k) {
        cursor = Math.max(0, cursor - k);
        int start = Math.max(0, cursor - 10);
        return text.substring(start, cursor);
    }

    public String cursorRight(int k) {
        cursor = Math.min(text.length(), cursor + k);
        int start = Math.max(0, cursor - 10);
        return text.substring(start, cursor);
    }
}
```

```go
type TextEditor struct {
    text   []byte
    cursor int

func Constructor() TextEditor {
    return TextEditor{text: []byte{}, cursor: 0}
}

func (t *TextEditor) AddText(s string) {
    // Insert s at cursor position
    newText := make([]byte, len(t.text)+len(s))
    copy(newText, t.text[:t.cursor])
    copy(newText[t.cursor:], []byte(s))
    copy(newText[t.cursor+len(s):], t.text[t.cursor:])
    t.text = newText
    t.cursor += len(s)
}

func (t *TextEditor) DeleteText(k int) int {
    toDelete := k
    if toDelete > t.cursor {
        toDelete = t.cursor
    }
    // Remove toDelete characters before cursor
    t.text = append(t.text[:t.cursor-toDelete], t.text[t.cursor:]...)
    t.cursor -= toDelete
    return toDelete
}

func (t *TextEditor) CursorLeft(k int) string {
    if k > t.cursor {
        t.cursor = 0
    } else {
        t.cursor -= k
    }
    start := t.cursor - 10
    if start < 0 {
        start = 0
    }
    return string(t.text[start:t.cursor])
}

func (t *TextEditor) CursorRight(k int) string {
    t.cursor += k
    if t.cursor > len(t.text) {
        t.cursor = len(t.text)
    }
    start := t.cursor - 10
    if start < 0 {
        start = 0
    }
    return string(t.text[start:t.cursor])
}
```

> - **Time Complexity:** O(n) per `addText` and `deleteText` call, where n is the total length of the text, because inserting into or deleting from the middle of a string/array requires shifting elements. O(1) for `cursorLeft` and `cursorRight`.
> - **Space Complexity:** O(n) total for storing the text.

Every insert and delete here shifts characters that are nowhere near the cursor. The next approach splits the text at the cursor so that every modification happens at the end of a structure, where it costs O(1).

<h1 id="approach-2-two-stacks-optimal">Approach 2: Two Stacks (Optimal)</h1>

<h3 id="intuition">Intuition</h3>

The cursor divides the text into two parts: everything to its left and everything to its right. Store the left part in one stack and the right part in another, and every operation becomes an operation on the top of a stack, which is O(1) per character.

The left stack keeps the character closest to the cursor on top. The right stack does the same. The cursor sits between the two stack tops.

- `addText`: Push each character onto the left stack. They land right at the cursor.
- `deleteText`: Pop from the left stack. This removes the characters immediately to the left of the cursor.
- `cursorLeft`: Pop from the left stack and push onto the right stack. The character that was immediately left of the cursor is now immediately right of it.
- `cursorRight`: Pop from the right stack and push onto the left stack. The character that was immediately right of the cursor is now immediately left of it.

Every operation touches only the tops of the stacks, so there is no shifting, slicing, or reallocation of distant characters.

> Real editors use the same idea. The two stacks are a variant of the gap buffer used by editors such as Emacs: text is stored with a gap at the cursor position, so local edits write into the gap and never move distant characters. Moving the cursor moves the gap one character at a time, exactly like transferring characters between the two stacks.

<h3 id="algorithm">Algorithm</h3>

1. Initialize two stacks: `left` and `right`. `left` holds characters to the left of the cursor (top = closest to cursor). `right` holds characters to the right (top = closest to cursor).
2. `addText(s)`: Push each character of `s` onto `left`.
3. `deleteText(k)`: Pop `min(k, left.size)` characters from `left`. Return the count popped.
4. `cursorLeft(k)`: Pop `min(k, left.size)` characters from `left`, pushing each onto `right`. Then return the last `min(10, left.size)` characters from `left` (peek from the top down).
5. `cursorRight(k)`: Pop `min(k, right.size)` characters from `right`, pushing each onto `left`. Return the last `min(10, left.size)` characters from `left`, assembled in their original order.

```java
class TextEditor {
    Deque<Character> left;
    Deque<Character> right;

    public TextEditor() {
        left = new ArrayDeque<>();
        right = new ArrayDeque<>();
    }

    public void addText(String text) {
        // Push each character onto the left stack
        for (char ch : text.toCharArray()) {
            left.push(ch);
        }
    }

    public int deleteText(int k) {
        int deleted = 0;
        // Pop up to k characters from the left stack
        while (deleted < k && !left.isEmpty()) {
            left.pop();
            deleted++;
        }
        return deleted;
    }

    public String cursorLeft(int k) {
        // Move k characters from left stack to right stack
        int moves = 0;
        while (moves < k && !left.isEmpty()) {
            right.push(left.pop());
            moves++;
        }
        return getLeftText();
    }

    public String cursorRight(int k) {
        // Move k characters from right stack to left stack
        int moves = 0;
        while (moves < k && !right.isEmpty()) {
            left.push(right.pop());
            moves++;
        }
        return getLeftText();
    }

    private String getLeftText() {
        // Return last min(10, left.size) characters to the left of cursor
        int count = Math.min(10, left.size());
        char[] chars = new char[count];
        // Pop characters, they come out in reverse order
        for (int i = count - 1; i >= 0; i--) {
            chars[i] = left.pop();
        }
        // Push them back onto the left stack
        for (char ch : chars) {
            left.push(ch);
        }
        return new String(chars);
    }
}
```

```python
class TextEditor:
    def __init__(self):
        self.left = []   # characters to the left of cursor
        self.right = []  # characters to the right of cursor

    def addText(self, text: str) -> None:
        # Push each character onto the left stack
        for ch in text:
            self.left.append(ch)

    def deleteText(self, k: int) -> int:
        deleted = 0
        # Pop up to k characters from the left stack
        while deleted < k and self.left:
            self.left.pop()
            deleted += 1
        return deleted

    def cursorLeft(self, k: int) -> str:
        # Move k characters from left to right
        moves = 0
        while moves < k and self.left:
            self.right.append(self.left.pop())
            moves += 1
        return self._get_left_text()

    def cursorRight(self, k: int) -> str:
        # Move k characters from right to left
        moves = 0
        while moves < k and self.right:
            self.left.append(self.right.pop())
            moves += 1
        return self._get_left_text()

    def _get_left_text(self) -> str:
        # Return last min(10, len) characters to the left of cursor
        count = min(10, len(self.left))
        return ''.join(self.left[-count:]) if count > 0 else ''
```

```csharp
public class TextEditor {
    List<char> left;
    List<char> right;

    public TextEditor() {
        left = new List<char>();
        right = new List<char>();
    }

    public void AddText(string text) {
        // Push each character onto the left stack
        foreach (char ch in text) {
            left.Add(ch);
        }
    }

    public int DeleteText(int k) {
        int deleted = 0;
        // Pop up to k characters from the left stack
        while (deleted < k && left.Count > 0) {
            left.RemoveAt(left.Count - 1);
            deleted++;
        }
        return deleted;
    }

    public string CursorLeft(int k) {
        // Move k characters from left to right
        int moves = 0;
        while (moves < k && left.Count > 0) {
            right.Add(left[left.Count - 1]);
            left.RemoveAt(left.Count - 1);
            moves++;
        }
        return GetLeftText();
    }

    public string CursorRight(int k) {
        // Move k characters from right to left
        int moves = 0;
        while (moves < k && right.Count > 0) {
            left.Add(right[right.Count - 1]);
            right.RemoveAt(right.Count - 1);
            moves++;
        }
        return GetLeftText();
    }

        int count = Math.Min(10, left.Count);
        int start = left.Count - count;
        char[] chars = new char[count];
        for (int i = 0; i < count; i++) {
            chars[i] = left[start + i];
        }
        return new string(chars);
    }
```

```rust
struct TextEditor {
    left: Vec<char>,
    right: Vec<char>,
}

impl TextEditor {
    fn new() -> Self {
        Self {
            left: Vec::new(),
            right: Vec::new(),
        }
    }

    fn add_text(&mut self, text: String) {
        // Push each character onto the left stack
        for ch in text.chars() {
            self.left.push(ch);
        }
    }

    fn delete_text(&mut self, k: i32) -> i32 {
        let mut deleted = 0;
        // Pop up to k characters from the left stack
        while deleted < k && !self.left.is_empty() {
            self.left.pop();
            deleted += 1;
        }
        deleted
    }

    fn cursor_left(&mut self, k: i32) -> String {
        // Move k characters from left to right
        let mut moves = 0;
        while moves < k && !self.left.is_empty() {
            self.right.push(self.left.pop().unwrap());
            moves += 1;
        }
        self.get_left_text()
    }

    fn cursor_right(&mut self, k: i32) -> String {
        // Move k characters from right to left
        let mut moves = 0;
        while moves < k && !self.right.is_empty() {
            self.left.push(self.right.pop().unwrap());
            moves += 1;
        }
        self.get_left_text()
    }

    fn get_left_text(&self) -> String {
        // Return last min(10, left.size) characters to the left of cursor
        let count = self.left.len().min(10);
        self.left[self.left.len().saturating_sub(count)..]
            .iter()
            .collect()
    }
}
```

```typescript
    this.left = [];
    this.right = [];
  }

  addText(text: string): void {
    // Push each character onto the left stack
    for (const ch of text) {
      this.left.push(ch);
    }
  }

  deleteText(k: number): number {
    let deleted = 0;
    // Pop up to k characters from the left stack
    while (deleted < k && this.left.length > 0) {
      this.left.pop();
      deleted++;
    }
    return deleted;
  }

  cursorLeft(k: number): string {
    // Move k characters from left to right
    let moves = 0;
    while (moves < k && this.left.length > 0) {
      this.right.push(this.left.pop()!);
      moves++;
    }
    return this.getLeftText();
  }

  cursorRight(k: number): string {
    // Move k characters from right to left
    let moves = 0;
    while (moves < k && this.right.length > 0) {
      this.left.push(this.right.pop()!);
      moves++;
    }
    return this.getLeftText();
  }

  private getLeftText(): string {
    const count = Math.min(10, this.left.length);
    return this.left.slice(this.left.length - count).join("");
  }
}
```

> - **Time Complexity:** O(k) per operation, where k is the parameter passed to the method (at most 40). `addText` is O(len(text)), `deleteText` is O(k), `cursorLeft` and `cursorRight` are O(k). Since k &lt;= 40, every operation is effectively O(1).
> - **Space Complexity:** O(n) total, where n is the total number of characters in the text. The two stacks together hold all characters.

A doubly linked list with a pointer to the cursor node achieves the same O(k) bounds and is the other common implementation. The two stacks produce the same behavior with less pointer bookkeeping and contiguous memory, since each stack is an array.
