<LessonCard>

You are given an array `points` containing the coordinates of points on a 2D plane, sorted by the x-values, where `points[i] = [xi, yi]`. You are also given an integer `k`.

Return the maximum value of the equation `yi + yj + |xi - xj|` where `|xi - xj| <= k` and `1 <= i < j <= points.length`.

It is guaranteed that there exists at least one pair of points that satisfies the constraint `|xi - xj| <= k`.

\***\*Example 1:\*\***

- **Input:** `points = [[1,3],[2,0],[5,10],[6,-10]]`

- **Input:** `k = 1`

- **Output:** `4`

**Explanation:** The first two points satisfy the condition `|xi - xj| <= 1` and the equation gives `3 + 0 + |1 - 2| = 4`. The points `[5,10]` and `[6,-10]` also satisfy the condition but give `10 + -10 + |5 - 6| = 1`.

\***\*Example 2:\*\***

- **Input:** `points = [[0,0],[3,0],[9,2]]`

- **Input:** `k = 3`

- **Output:** `3`

**Explanation:** Only the first two points have an x-difference of at most 3. The equation gives `0 + 0 + |0 - 3| = 3`.

\***\*Constraints:\*\***

- `2 <= points.length <= 10^5`
- `points[i].length == 2`
- `-10^8 <= xi, yi <= 10^8`
- `0 <= k <= 2 * 10^8`
- `xi < xj` for all `1 <= i < j <= points.length`
- `xi` form a strictly increasing sequence.

We have points on a 2D plane, sorted by their x-coordinates, and we need to find a pair of points (i, j) where j > i that maximizes `yi + yj + |xi - xj|`, subject to the constraint that the x-coordinates are at most `k` apart.

Since the points are sorted by x-coordinate and `i < j`, we know `xj >= xi`, so `|xi - xj| = xj - xi`. The equation simplifies to:

`yi + yj + xj - xi = (yi - xi) + (yj + xj)`

This decomposition drives every approach below. For a fixed point j, the value `(yj + xj)` is a constant. So we need the point i (before j, within distance k) that maximizes `(yi - xi)`. The problem reduces to: for each j, find the maximum `(yi - xi)` among all valid previous points i where `xj - xi <= k`. That is a sliding window maximum problem.

- `points.length <= 10^5`. With up to 100,000 points, an O(n^2) brute force checking all pairs is on the order of 10^10 operations and times out. The target is O(n log n) or O(n).
- `-10^8 <= xi, yi <= 10^8`. The largest possible equation value is `yi + yj + (xj - xi)`, bounded by `10^8 + 10^8 + (10^8 - (-10^8)) = 4 * 10^8`, which fits in a signed 32-bit integer (max ~2.1 \* 10^9). So `int` is safe; no `long` is required.
- Points are already sorted by x-coordinate. We do not need to sort, and we can process points left to right, treating earlier points as candidates for the "i" in our pair.
- `0 <= k <= 2 * 10^8`. With k large enough to span the full x-range, every earlier point can be a valid candidate, so the window can hold all n points at once.

<h1 id="approach-1-brute-force">Approach 1: Brute Force</h1>

<h3 id="intuition">Intuition</h3>

Check every valid pair of points. For each pair (i, j) where j > i and `xj - xi <= k`, compute the equation value and track the maximum.

Since the points are sorted by x-coordinate, once the x-difference exceeds k, all earlier points exceed it too (x is strictly increasing). So for each j, we scan backwards from j-1 and stop at the first point whose distance exceeds k.

<h3 id="algorithm">Algorithm</h3>

1. Initialize `result` to negative infinity.
2. For each point j from 1 to n-1:
3. Return `result`.

<h3 id="example-walkthrough">Example Walkthrough</h3>

**Input:**

With k = 1, for each j we scan backwards and stop once the x-distance exceeds 1:

- j=1 (point [2,0]): i=0 has x-distance 2-1=1 ≤ 1. value = 3 + 0 + (2-1) = **4**. result = 4.
- j=2 (point [5,10]): i=1 has x-distance 5-2=3 > 1, so we stop immediately. No valid pair.
- j=3 (point [6,-10]): i=2 has x-distance 6-5=1 ≤ 1. value = 10 + (-10) + (6-5) = **1**. result stays 4.

The maximum across all pairs is 4.

**Output:**

<h3 id="code">Code</h3>

```java
class Solution {
    public int findMaxValueOfEquation(int[][] points, int k) {
        int n = points.length;
        int result = Integer.MIN_VALUE;

        for (int j = 1; j < n; j++) {
            for (int i = j - 1; i >= 0; i--) {
                // Since points are sorted by x, once distance exceeds k, stop
                if (points[j][0] - points[i][0] > k) break;
                int value = points[i][1] + points[j][1] + points[j][0] - points[i][0];
                result = Math.max(result, value);
            }
        }

        return result;
    }
}
```

> - **Time Complexity:** O(n^2). In the worst case (when k is large enough that all points are within distance k of each other), the inner loop runs O(n) times for each outer iteration, giving O(n^2) total.
> - **Space Complexity:** O(1). We only use a few variables to track the result.

This recomputes the scan from scratch for every j. Since the equation decomposes into `(yi - xi) + (yj + xj)`, each j only needs the maximum `(yi - xi)` within its window. The next two approaches maintain that running maximum instead of rescanning.

<h1 id="approach-2-priority-queue-max-heap">
  Approach 2: Priority Queue (Max-Heap)
</h1>

<h3 id="intuition">Intuition</h3>

For each point j, we want the maximum `(yi - xi)` among all points i where `xj - xi <= k`. A max-heap keyed on `(yi - xi)` keeps that maximum at the top. We push `(yi - xi, xi)` for each point. When processing point j, we pop entries whose x-coordinate is too far from xj (distance > k), then read the top.

Expired entries can sit anywhere inside the heap, and a heap cannot remove an arbitrary interior element in O(log n). The fix is lazy deletion: an expired entry is removed only if it surfaces at the top. While it stays buried, it cannot be the maximum and never affects the answer, so leaving it in place is safe.

<h3 id="algorithm">Algorithm</h3>

1. Initialize a max-heap (priority queue) and `result` to negative infinity.
2. For each point j from 0 to n-1:
3. Return `result`.

<h3 id="example-walkthrough">Example Walkthrough</h3>

<h3 id="code">Code</h3>

```java
class Solution {
    public int findMaxValueOfEquation(int[][] points, int k) {
        // Max-heap storing [yi - xi, xi]
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> b[0] - a[0]);
        int result = Integer.MIN_VALUE;

        for (int[] point : points) {
            int xj = point[0], yj = point[1];

            // Remove entries that are too far from current point
            while (!heap.isEmpty() && xj - heap.peek()[1] > k) {
                heap.poll();
            }

            // If heap has valid candidates, compute equation value
            if (!heap.isEmpty()) {
                result = Math.max(result, heap.peek()[0] + yj + xj);
            }

            // Add current point as a candidate for future points
            heap.offer(new int[]{yj - xj, xj});
        }

        return result;
    }
}
```

```csharp
public class Solution {
    public int FindMaxValueOfEquation(int[][] points, int k) {
        // Max-heap on (yi - xi): enqueue with priority -(yi - xi) so the
        // largest value dequeues first under the default ascending order
        PriorityQueue<int[], int> heap = new PriorityQueue<int[], int>();
        int result = int.MinValue;

        foreach (var point in points) {
            int xj = point[0], yj = point[1];

            // Remove entries that are too far from current point
            while (heap.Count > 0) {
                heap.TryPeek(out int[] top, out int _);
                if (xj - top[1] > k) heap.Dequeue();
                else break;
            }

            // If heap has valid candidates, compute equation value
            if (heap.Count > 0) {
                heap.TryPeek(out int[] best, out int _);
                result = Math.Max(result, best[0] + yj + xj);
            }

            // Add current point as a candidate for future points
            int val = yj - xj;
            heap.Enqueue(new int[]{val, xj}, -val);
        }

        return result;
    }
}
```

```go
    h := &maxHeap{}
    heap.Init(h)
    result := -1 << 31

    for _, point := range points {
```

```rust
    pub fn find_max_value_of_equation(points: Vec<Vec<i32>>, k: i32) -> i32 {

        for point in points.iter() {
            let xj = point[0];

            if let Some(&(best, _)) = heap.peek() {
                result = result.max(best + yj + xj);
            }

            // Add current point as a candidate for future points
            heap.push((yj - xj, xj));
        }

        result
    }
}
```

```javascript
var findMaxValueOfEquation = function (points, k) {
  // Simple max-heap using array with manual sift operations
  const heap = [];
  let result = -Infinity;

  const swap = (i, j) => {
    [heap[i], heap[j]] = [heap[j], heap[i]];
  };
  const siftUp = (i) => {
    while (i > 0) {
      const parent = (i - 1) >> 1;
      if (heap[parent][0] >= heap[i][0]) break;
      swap(parent, i);
      i = parent;
    }
  };
  const siftDown = (i) => {
    const n = heap.length;
    while (2 * i + 1 < n) {
      let j = 2 * i + 1;
      if (j + 1 < n && heap[j + 1][0] > heap[j][0]) j++;
      if (heap[i][0] >= heap[j][0]) break;
      swap(i, j);
      i = j;
    }
  };
  const push = (val) => {
    heap.push(val);
    siftUp(heap.length - 1);
  };
  const pop = () => {
    swap(0, heap.length - 1);
    const val = heap.pop();
    if (heap.length) siftDown(0);
    return val;
  };

  for (const [xj, yj] of points) {
    // Remove entries that are too far from current point
    while (heap.length > 0 && xj - heap[0][1] > k) {
      pop();
    }

    // If heap has valid candidates, compute equation value
    if (heap.length > 0) {
      result = Math.max(result, heap[0][0] + yj + xj);
    }

    // Add current point as a candidate for future points
    push([yj - xj, xj]);
  }

  return result;
};
```

> - **Time Complexity:** O(n log n). Each point is pushed onto the heap once (O(log n)) and popped at most once (O(log n)). So across all n points, we do O(n log n) work.
> - **Space Complexity:** O(n). The heap can hold up to n entries.

The heap maintains a full ordering of all elements, but only the maximum is ever read. The next approach drops the ordering and keeps only the candidates that could still become the maximum, which brings the work down to O(n).

<h1 id="approach-3-monotonic-deque-optimal">
  Approach 3: Monotonic Deque (Optimal)
</h1>

<h3 id="intuition">Intuition</h3>

A monotonic deque (decreasing) holds candidate points in decreasing order of `(yi - xi)`, so the front is always the current maximum. Each point enters and leaves the deque at most once, which makes every operation O(1) amortized and the whole algorithm O(n).

Two removals keep the invariant. From the front, drop points whose x-distance to the current point exceeds k, since they have left the window. From the back, drop points whose `(yi - xi)` is less than or equal to the new point's value, since they are dominated (explained below). The remaining points stay sorted by `(yi - xi)` from front to back.

> The deque relies on a dominance property. Take two candidate points A and B where A was added before B, so A has the smaller x-coordinate. If `(yA - xA) <= (yB - xB)`, then B is at least as good as A for every future point j: (1) B has a higher or equal `(yi - xi)` value, giving an equal or better equation result, and (2) B has the larger x-coordinate, so it stays inside the window at least as long as A. A loses on both dimensions, so discarding A never removes the true optimum.

<h3 id="algorithm">Algorithm</h3>

1. Initialize a deque and `result` to negative infinity.
2. For each point j from 0 to n-1:
3. Return `result`.

```java
class Solution {
    public int findMaxValueOfEquation(int[][] points, int k) {
        // Deque stores [yi - xi, xi] in decreasing order of yi - xi
        Deque<int[]> deque = new ArrayDeque<>();
        int result = Integer.MIN_VALUE;

        for (int[] point : points) {
            int xj = point[0], yj = point[1];

            // Remove expired entries from front
            while (!deque.isEmpty() && xj - deque.peekFirst()[1] > k) {
                deque.pollFirst();
            }

            // Best candidate is at the front
            if (!deque.isEmpty()) {
                result = Math.max(result, deque.peekFirst()[0] + yj + xj);
            }

            // Remove dominated entries from back
            int val = yj - xj;
            while (!deque.isEmpty() && deque.peekLast()[0] <= val) {
                deque.pollLast();
            }
            deque.offerLast(new int[]{val, xj});
        }

        return result;
    }
}
```

```go
    // Deque stores [yi - xi, xi] in decreasing order of yi - xi
    type entry struct{ val, x int }
    deque := []entry{}
    result := -1 << 31

    for _, point := range points {
        xj, yj := point[0], point[1]

        // Remove expired entries from front
        for len(deque) > 0 && xj-deque[0].x > k {
            deque = deque[1:]
        }

        // Best candidate is at the front
        if len(deque) > 0 {
            v := deque[0].val + yj + xj
            if v > result {
                result = v
            }
        }

        // Remove dominated entries from back
        val := yj - xj
        for len(deque) > 0 && deque[len(deque)-1].val <= val {
            deque = deque[:len(deque)-1]
        }
        deque = append(deque, entry{val, xj})
    }

    return result
}
```

```rust
use std::collections::VecDeque;

pub struct Solution;

impl Solution {
    pub fn find_max_value_of_equation(points: Vec<Vec<i32>>, k: i32) -> i32 {
        // Deque stores [yi - xi, xi] in decreasing order of yi - xi
        let mut deque: VecDeque<(i32, i32)> = VecDeque::new();
        let mut result = i32::MIN;

        for point in points.iter() {
            let xj = point[0];
            let yj = point[1];

            // Remove expired entries from front
            while let Some(&(_, x)) = deque.front() {
                if xj - x > k {
                    deque.pop_front();
                } else {
                    break;
                }
            }

            // Best candidate is at the front
            if let Some(&(val, _)) = deque.front() {
                result = result.max(val + yj + xj);
            }

            // Remove dominated entries from back
            let val = yj - xj;
            while let Some(&(back_val, _)) = deque.back() {
                if back_val <= val {
                    deque.pop_back();
                } else {
                    break;
                }
            }
            deque.push_back((val, xj));
        }

        result
    }
}
```


> - **Time Complexity:** O(n). Each point is pushed to the deque once and popped at most once. All deque operations (push/pop from either end) are O(1). The total work across all iterations is O(n).
> - **Space Complexity:** O(n). The deque can hold at most n entries in the worst case.
