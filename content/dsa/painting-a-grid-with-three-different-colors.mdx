<LessonCard>

You are given two integers `m` and `n`. Consider an `m x n` grid where each cell is initially white. You can paint each cell red, green, or blue. All cells must be painted.

Return the number of ways to color the grid with no two adjacent cells having the same color. Since the answer can be very large, return it modulo `10^9 + 7`.

Two cells are considered adjacent if they share a vertical or horizontal edge.

\***\*Example 1:\*\***

- **Input:** `m = 1`

- **Input:** `n = 1`

- **Output:** `3`

\***\*Example 2:\*\***

- **Input:** `m = 1`

- **Input:** `n = 2`

- **Output:** `6`

\***\*Example 3:\*\***

- **Input:** `m = 5`

- **Input:** `n = 5`

- **Output:** `580986`

\***\*Constraints:\*\***

- `1 <= m <= 5`
- `1 <= n <= 1000`

We have a grid with `m` rows and `n` columns. Each cell gets one of 3 colors, and no two cells that share an edge can have the same color. We need to count every valid coloring.

The dimensions are asymmetric: `m` is at most 5 while `n` can be up to 1000. That asymmetry drives the solution. If both dimensions were large, the problem would be intractable. With at most 5 rows, we can enumerate every valid way to color a single column, determine which column colorings can sit next to each other, and run a column-by-column DP.

Instead of painting individual cells, we paint one entire column at a time. A "column state" is a tuple of m colors like (R, G, B, R, G). A column state is valid if no two vertically adjacent cells in it share a color. Two column states are compatible if, for every row, the colors in that row differ between the two columns. The answer is the number of sequences of n compatible column states.

- `1 <= m <= 5`. The number of ways to assign 3 colors to m cells is 3^m, at most 3^5 = 243. After filtering for vertical adjacency the count of valid column states is even smaller: 3, 6, 12, 24, 48 for m = 1 through 5.
- `1 <= n <= 1000`. The approach must scale linearly or at most quadratically in n. With S valid column states (S at most 48), an O(n \* S^2) DP is feasible.

<h1 id="approach-1-backtracking-cell-by-cell">
  Approach 1: Backtracking (Cell by Cell)
</h1>

<h3 id="intuition">Intuition</h3>

Paint each cell one at a time in row-major order. For each cell, try all 3 colors and skip a color if it matches the cell above or to the left. When all m\*n cells are colored, one valid coloring has been counted.

This is pure backtracking. It is correct, but the branching factor is roughly 2 at each cell (of 3 colors, at least 1 is blocked by the cell above or to the left), giving roughly 2^(m\*n) total work. For m=5, n=1000 that is on the order of 2^5000, far beyond what is computable. The value of this version is that it defines exactly what we are counting before we optimize it.

<h3 id="algorithm">Algorithm</h3>

1. Traverse cells in row-major order (left to right, top to bottom).
2. For each cell, try colors 0, 1, and 2.
3. If the color matches the cell directly above (same column, previous row), skip it.
4. If the color matches the cell directly to the left (same row, previous column), skip it.
5. If we have colored all cells, increment the answer.
6. Return the total count modulo 10^9 + 7.

```java
class Solution {
    int MOD = 1_000_000_007;

    public int colorTheGrid(int m, int n) {
        int[][] grid = new int[m][n];
        for (int[] row : grid) Arrays.fill(row, -1);
        return backtrack(grid, m, n, 0, 0);
    }

    private int backtrack(int[][] grid, int m, int n, int r, int c) {
        // All cells colored
        if (c == n) return 1;

        // Move to next column when current column is done
        int nextR = r + 1, nextC = c;
        if (nextR == m) { nextR = 0; nextC = c + 1; }

        int count = 0;
        for (int color = 0; color < 3; color++) {
            // Check cell above
            if (r > 0 && grid[r - 1][c] == color) continue;
            // Check cell to the left
            if (c > 0 && grid[r][c - 1] == color) continue;

            grid[r][c] = color;
            count = (count + backtrack(grid, m, n, nextR, nextC)) % MOD;
            grid[r][c] = -1;
        }
        return count;
    }
}
```

> - **Time Complexity:** O(3^(m*n)). At each cell we try up to 3 colors. With m*n cells, the worst case is 3^(m\*n). In practice pruning reduces this, but it is still exponential.
> - **Space Complexity:** O(m _ n). We store the grid and the recursion stack depth is m _ n.

The backtracking explores every complete coloring. The key redundancy: once a column is fully colored, the colorings of all later columns depend only on that column's colors, not on how the earlier columns were filled. The next approach exploits this by tracking entire column states and counting transitions between them.

<h1 id="approach-2-column-state-dp">Approach 2: Column-State DP</h1>

<h3 id="intuition">Intuition</h3>

Since m is at most 5, the number of valid colorings of a single column is small. Each cell can be one of 3 colors, and vertically adjacent cells must differ. Enumerate all valid column colorings, determine which pairs are compatible (no two cells in the same row share a color), and run a DP column by column.

A "column state" is a tuple of m colors. For m = 2, there are 6 valid states: (0,1), (0,2), (1,0), (1,2), (2,0), (2,1). For m = 5, there are 48. These counts are small enough that storing a DP value per state and iterating over compatible pairs is cheap.

> The horizontal constraint only relates a column to its immediate neighbor, so the set of colorings allowed for column `c+1` depends only on the colors in column `c`. The grid history before column `c` does not constrain column `c+1`. Summing `dp[prev]` over every state compatible with `s` therefore counts each valid prefix exactly once, with no double counting and no omissions.
>
> The state space is bounded by 3 \* 2^(m-1): the first cell has 3 choices and each cell below has 2 (any color except the one above). For m = 5 that is 48 states, which keeps the DP small regardless of n.

<h3 id="algorithm">Algorithm</h3>

1. Generate all valid column states. A column state is a tuple of m values from {0, 1, 2} where no two adjacent values are the same. Use DFS/backtracking to build these.
2. For every pair of valid column states, check if they are compatible: for each row, the colors must differ between the two columns.
3. Build a compatibility adjacency list: for each state s, store the list of states that can follow s.
4. Initialize DP: for the first column, each valid state has count 1.
5. For each subsequent column (2 through n), for each valid state s, sum up `dp[prev]` for all states `prev` compatible with s. This becomes the new `dp[s]`.
6. The answer is the sum of all `dp[s]` after processing n columns, taken modulo 10^9 + 7.

```java
class Solution {
    public int colorTheGrid(int m, int n) {
        int MOD = 1_000_000_007;

        // Generate all valid column states
        List<int[]> states = new ArrayList<>();
        generateStates(m, new int[m], 0, states);

        int sz = states.size();

        // Build compatibility list
        List<List<Integer>> compatible = new ArrayList<>();
        for (int i = 0; i < sz; i++) {
            compatible.add(new ArrayList<>());
            for (int j = 0; j < sz; j++) {
                if (areCompatible(states.get(i), states.get(j), m)) {
                    compatible.get(i).add(j);
                }
            }
        }

        // DP: dp[i] = number of ways to reach state i at current column
        long[] dp = new long[sz];
        Arrays.fill(dp, 1); // First column: each valid state has 1 way

        for (int col = 1; col < n; col++) {
            long[] newDp = new long[sz];
            for (int s = 0; s < sz; s++) {
                for (int prev : compatible.get(s)) {
                    newDp[s] = (newDp[s] + dp[prev]) % MOD;
                }
            }
            dp = newDp;
        }

        long answer = 0;
        for (long val : dp) {
            answer = (answer + val) % MOD;
        }
        return (int) answer;
    }

    // Generate all column states with no two adjacent rows the same
    private void generateStates(int m, int[] state, int row, List<int[]> states) {
        if (row == m) {
            states.add(state.clone());
            return;
        }
        for (int color = 0; color < 3; color++) {
            if (row > 0 && state[row - 1] == color) continue;
            state[row] = color;
            generateStates(m, state, row + 1, states);
        }
    }

    // Check if two column states can be adjacent (differ at every row)
    private boolean areCompatible(int[] a, int[] b, int m) {
        for (int i = 0; i < m; i++) {
            if (a[i] == b[i]) return false;
        }
        return true;
    }
}
```

```python
class Solution:
    def colorTheGrid(self, m: int, n: int) -> int:
        MOD = 10**9 + 7

        # Generate all valid column states
        states = []
        def generate(row, state):
            if row == m:
                states.append(tuple(state))
                return
            for color in range(3):
                if row > 0 and state[row - 1] == color:
                    continue
                state.append(color)
                generate(row + 1, state)
                state.pop()

        generate(0, [])
        sz = len(states)

        # Build compatibility list
        compatible = [[] for _ in range(sz)]
        for i in range(sz):
            for j in range(sz):
                if all(states[i][r] != states[j][r] for r in range(m)):
                    compatible[i].append(j)

        # DP column by column
        dp = [1] * sz  # First column: each state has 1 way

        for col in range(1, n):
            new_dp = [0] * sz
            for s in range(sz):
                for prev in compatible[s]:
                    new_dp[s] = (new_dp[s] + dp[prev]) % MOD
            dp = new_dp

        return sum(dp) % MOD
```

```typescript
  const MOD = 1e9 + 7;

  // Generate all valid column states
  const states: number[][] = [];
  const generate = (row: number, state: number[]): void => {
    if (row === m) {
      states.push([...state]);
      return;
    }
    for (let color = 0; color < 3; color++) {
      if (row > 0 && state[row - 1] === color) continue;
      state[row] = color;
      generate(row + 1, state);
    }
  };
  generate(0, new Array(m));

  const sz = states.length;

  // Build compatibility list
  const compatible: number[][] = Array.from({ length: sz }, () => []);
  for (let i = 0; i < sz; i++) {
    for (let j = 0; j < sz; j++) {
      let ok = true;
      for (let r = 0; r < m; r++) {
        if (states[i][r] === states[j][r]) {
          ok = false;
          break;
        }
      }
      if (ok) compatible[i].push(j);
    }
  }

  // DP column by column
  let dp = new Array(sz).fill(1);

  for (let col = 1; col < n; col++) {
    const newDp = new Array(sz).fill(0);
    for (let s = 0; s < sz; s++) {
      for (const prev of compatible[s]) {
        newDp[s] = (newDp[s] + dp[prev]) % MOD;
      }
    }
    dp = newDp;
  }

  let answer = 0;
  for (const val of dp) answer = (answer + val) % MOD;
  return answer;
}
```

> - **Time Complexity:** O(n _ S^2 + S^2 _ m). Generating S valid states takes O(S _ m). Building the compatibility list takes O(S^2 _ m). The DP runs in O(n \* S^2). For m = 5, S = 48, so the DP does about 2.3 million operations for n = 1000.
> - **Space Complexity:** O(S^2 + S). The compatibility list stores at most S^2 entries. The DP arrays use O(S) space. With S = 48, this is negligible.

Each DP step applies the same linear transformation: the new state vector is the transition matrix times the old one. Because every step is identical, the n-1 applications can be collapsed into a single matrix power computed with O(log n) multiplications.

<h1 id="approach-3-matrix-exponentiation">Approach 3: Matrix Exponentiation</h1>

<h3 id="intuition">Intuition</h3>

The column-state DP from Approach 2 is a linear recurrence. At each column, the new DP vector equals the transition matrix T times the old DP vector. After n-1 transitions, the result is T^(n-1) times the initial vector.

Matrix exponentiation computes T^(n-1) in O(S^3 _ log n) time using repeated squaring. With S at most 48, S^3 is about 110,000, and multiplied by log2(1000) which is about 10, the total is roughly 1.1 million operations. For these constraints that is comparable to Approach 2, but the matrix approach is the one that survives if n grows to, say, 10^18, where the O(n _ S^2) DP would not.

The same technique applies to any problem that counts paths of length n in a fixed graph.

<h3 id="algorithm">Algorithm</h3>

1. Generate all S valid column states and build the S x S transition matrix T where T[i][j] = 1 if state j can follow state i (compatible), and 0 otherwise.
2. Start with an initial vector v of size S where every entry is 1 (each valid state is equally reachable in column 1).
3. Compute T^(n-1) using matrix exponentiation (repeated squaring). All arithmetic is modulo 10^9 + 7.
4. Multiply T^(n-1) by v to get the final DP vector.
5. The answer is the sum of all entries in the resulting vector, modulo 10^9 + 7.

```java
    public int colorTheGrid(int m, int n) {

                    T[i][j] = 1;
                }
            }

        long[][] result = matPow(T, n - 1, sz);

        // Multiply result by initial vector (all 1s) and sum
        long answer = 0;
        for (int i = 0; i < sz; i++) {
            for (int j = 0; j < sz; j++) {
                answer = (answer + result[i][j]) % MOD;
            }
        }
        return (int) answer;
    }

    private long[][] matMul(long[][] A, long[][] B, int sz) {
        long[][] C = new long[sz][sz];
        for (int i = 0; i < sz; i++) {
            for (int k = 0; k < sz; k++) {
                if (A[i][k] == 0) continue;
                for (int j = 0; j < sz; j++) {
                    C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD;
                }
            }
        }
        return C;
    }

            M = matMul(M, M, sz);
            p >>= 1;
```

```rust
impl Solution {
    pub fn color_the_grid(m: i32, n: i32) -> i32 {
        const MOD: i64 = 1_000_000_007;
        let m = m as usize;
        let n = n as i64;

        // Generate valid column states
        let mut states: Vec<Vec<i32>> = Vec::new();
        let mut state = vec![0; m];
        Self::generate_states(m, &mut state, 0, &mut states);
        let sz = states.len();

        // Build transition matrix
        let mut t = vec![vec![0i64; sz]; sz];
        for i in 0..sz {
            for j in 0..sz {
                if Self::are_compatible(&states[i], &states[j], m) {
                    t[i][j] = 1;
                }
            }
        }

        // Matrix exponentiation: T^(n-1)
        let result = Self::mat_pow(t, n - 1, sz, MOD);

        // Multiply result by initial vector (all 1s) and sum
        let mut answer: i64 = 0;
        for i in 0..sz {
            for j in 0..sz {
                answer = (answer + result[i][j]) % MOD;
            }
        }
        answer as i32
    }

    fn mat_mul(a: &Vec<Vec<i64>>, b: &Vec<Vec<i64>>, sz: usize, modulo: i64) -> Vec<Vec<i64>> {
        let mut c = vec![vec![0i64; sz]; sz];
        for i in 0..sz {
            for k in 0..sz {
                if a[i][k] == 0 {
                    continue;
                }
                for j in 0..sz {
                    c[i][j] = (c[i][j] + a[i][k] * b[k][j]) % modulo;
                }
            }
        }
        c
    }

    fn mat_pow(mut mtx: Vec<Vec<i64>>, mut p: i64, sz: usize, modulo: i64) -> Vec<Vec<i64>> {
        // Identity matrix
        let mut result = vec![vec![0i64; sz]; sz];
        for i in 0..sz {
            result[i][i] = 1;
        }

        while p > 0 {
            if p & 1 == 1 {
                result = Self::mat_mul(&result, &mtx, sz, modulo);
            }
            mtx = Self::mat_mul(&mtx, &mtx, sz, modulo);
            p >>= 1;
        }
        result
    }

        if row == m {
            states.push(state.clone());
            return;

            if row > 0 && state[row - 1] == c {
                continue;
            }
            state[row] = c;
            Self::generate_states(m, state, row + 1, states);
        }
    }

        for i in 0..m {
            if a[i] == b[i] {
                return false;
            }
        }
        true
```
