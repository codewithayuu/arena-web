<LessonCard>

You are given a 2D integer array `intervals`, where `intervals[i] = [left_i, right_i]` describes the `i`th interval starting at `left_i` and ending at `right_i` (inclusive). The size of an interval is defined as the number of integers it contains, or more formally `right_i - left_i + 1`.

You are also given an integer array `queries`. The answer to the `j`th query is the size of the smallest interval `i` such that `left_i <= queries[j] <= right_i`. If no such interval exists, the answer is `-1`.

Return an array containing the answers to the queries.

**Example 1:**

- **Input:** `intervals = [[1,4],[2,4],[3,6],[4,4]]`

- **Input:** `queries = [2,3,4,5]`

- **Output:** `[3,3,1,4]`

**Example 2:**

- **Input:** `intervals = [[2,3],[2,5],[1,8],[20,25]]`

- **Input:** `queries = [2,19,5,22]`

- **Output:** `[2,-1,4,6]`

**Constraints:**

- `1 <= intervals.length <= 10^5`
- `1 <= queries.length <= 10^5`
- `intervals[i].length == 2`
- `1 <= left_i <= right_i <= 10^7`
- `1 <= queries[j] <= 10^7`

We have a set of intervals on the number line, and for each query point, we need to find the smallest interval that contains that point. "Contains" means the point falls between the interval's left and right endpoints (inclusive), and "smallest" means the interval with the minimum size (right - left + 1).

The challenge is efficiency. With up to 100,000 intervals and 100,000 queries, checking every interval for every query is too slow. Sorting both the intervals and the queries lets us process everything in a single left-to-right sweep instead of solving each query independently.

- `1 <= intervals.length <= 10^5` → With n up to 100,000 intervals, O(n^2) is 10^10 operations, far too slow. We need O(n log n) or better per dimension.
- `1 <= queries.length <= 10^5` → Same scale as intervals. The combined work must stay near O((n + q) log(n + q)).
- `1 <= left_i <= right_i <= 10^7` → Large value range rules out direct indexing over the number line. We must work with event points, not with every possible integer.

For each query, scan every interval and check if it contains the query point. Among all intervals that do, pick the one with the smallest size. This gives a correct baseline to optimize from.

1. Create a result array of size `queries.length`.
2. For each query `q` at index `j`:
3. Return `result`.

```java
class Solution {
    public int[] minInterval(int[][] intervals, int[] queries) {
        int[] result = new int[queries.length];

        for (int j = 0; j < queries.length; j++) {
            int minSize = Integer.MAX_VALUE;
            for (int[] interval : intervals) {
                // Check if query falls within this interval
                if (interval[0] <= queries[j] && queries[j] <= interval[1]) {
                    int size = interval[1] - interval[0] + 1;
                    minSize = Math.min(minSize, size);
                }
            }
            result[j] = (minSize == Integer.MAX_VALUE) ? -1 : minSize;
        }

        return result;
    }
}
```

> - **Time Complexity:** O(n \* q). For each of the q queries, we scan all n intervals. With n and q both up to 10^5, this is 10^10 operations, which is far too slow.
> - **Space Complexity:** O(q). We only store the result array of size q.

For every query, we scan all n intervals from scratch, repeating work across queries. The next approach sorts both the intervals and the queries so that processing queries in increasing order lets us maintain a running set of active intervals instead of rescanning.

<h1 id="approach-2-sorting-min-heap-line-sweep">
  Approach 2: Sorting + Min-Heap (Line Sweep)
</h1>

<h3 id="intuition">Intuition</h3>

Sort the intervals by left endpoint and the queries by value, then sweep from left to right across the number line. For each query, add every interval whose left endpoint is at or before the query. These intervals start early enough to possibly contain the query. Some of them end before the query point, so those must be discarded.

We need the smallest valid interval at each step. A min-heap keyed by interval size provides it. We push candidate intervals onto the heap, pop any whose right endpoint is less than the current query, and the heap's top is the answer.

> Expired intervals are not removed eagerly. Before answering a query, we check the heap top: if its right endpoint is before the current query, it can never cover this query or any later one (queries only increase), so we pop it and check the next top. Popping the minimum-size interval is safe because a smaller interval that already expired would never have been a valid answer for a later query anyway. Each interval is pushed once and popped at most once, so the total heap work across the whole sweep is O(n log n).

<h3 id="algorithm">Algorithm</h3>

1. Sort `intervals` by left endpoint.
2. Create a list of `(query_value, original_index)` pairs and sort by `query_value`.
3. Initialize a min-heap keyed by interval size and a pointer `i = 0` into the sorted intervals.
4. For each query `(q, idx)` in sorted order:
5. Return `result`.

```java
class Solution {
    public int[] minInterval(int[][] intervals, int[] queries) {
        // Sort intervals by left endpoint
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

        // Pair each query with its original index, then sort by value
        int q = queries.length;
        int[][] sortedQueries = new int[q][2];
        for (int j = 0; j < q; j++) {
            sortedQueries[j] = new int[]{queries[j], j};
        }
        Arrays.sort(sortedQueries, (a, b) -> a[0] - b[0]);

        // Min-heap: (interval size, right endpoint)
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        int[] result = new int[q];
        int i = 0;

        for (int[] sq : sortedQueries) {
            int queryVal = sq[0];
            int idx = sq[1];

            // Push all intervals whose left endpoint <= query value
            while (i < intervals.length && intervals[i][0] <= queryVal) {
                int size = intervals[i][1] - intervals[i][0] + 1;
                heap.offer(new int[]{size, intervals[i][1]});
                i++;
            }

            // Remove expired intervals whose right endpoint < query value
            while (!heap.isEmpty() && heap.peek()[1] < queryVal) {
                heap.poll();
            }

            result[idx] = heap.isEmpty() ? -1 : heap.peek()[0];
        }

        return result;
    }
}
```

```go
func minInterval(intervals [][]int, queries []int) []int {
    // Sort intervals by left endpoint
    sort.Slice(intervals, func(i, j int) bool {
        return intervals[i][0] < intervals[j][0]
    })

    // Pair each query with its original index, then sort by value
    q := len(queries)
    sortedQueries := make([][2]int, q)
    for j := 0; j < q; j++ {
        sortedQueries[j] = [2]int{queries[j], j}
    }
    sort.Slice(sortedQueries, func(i, j int) bool {
        return sortedQueries[i][0] < sortedQueries[j][0]
    })

    // Min-heap: (interval size, right endpoint)
    h := &MinHeap{}
    heap.Init(h)
    result := make([]int, q)
    idx := 0

    for _, sq := range sortedQueries {
        queryVal, origIdx := sq[0], sq[1]

        // Push all intervals whose left endpoint <= query value
        for idx < len(intervals) && intervals[idx][0] <= queryVal {
            size := intervals[idx][1] - intervals[idx][0] + 1
            heap.Push(h, [2]int{size, intervals[idx][1]})
            idx++
        }

        // Remove expired intervals whose right endpoint < query value
        for h.Len() > 0 && (*h)[0][1] < queryVal {
            heap.Pop(h)
        }

        if h.Len() == 0 {
            result[origIdx] = -1
        } else {
            result[origIdx] = (*h)[0][0]
        }
    }

    return result
}

func (h MinHeap) Len() int            { return len(h) }
func (h MinHeap) Less(i, j int) bool  { return h[i][0] < h[j][0] }

    old := *h
    n := len(old)
```

```rust
use std::cmp::Reverse;
use std::collections::BinaryHeap;

pub struct Solution;

impl Solution {
    pub fn min_interval(intervals: Vec<Vec<i32>>, queries: Vec<i32>) -> Vec<i32> {
        // Sort intervals by left endpoint
        let mut intervals = intervals;
        intervals.sort_unstable_by_key(|v| v[0]);

        // Pair each query with its original index, then sort by value
        let q = queries.len();
        let mut sorted_queries: Vec<(i32, usize)> = queries
            .into_iter()
            .enumerate()
            .map(|(j, val)| (val, j))
            .collect();
        sorted_queries.sort_unstable_by_key(|&(val, _)| val);

        // Min-heap: (interval size, right endpoint)
        let mut heap: BinaryHeap<Reverse<(i32, i32)>> = BinaryHeap::new();
        let mut result = vec![-1; q];
        let mut i = 0;

        for (query_val, idx) in sorted_queries {
            // Push all intervals whose left endpoint <= query value
            while i < intervals.len() && intervals[i][0] <= query_val {
                let size = intervals[i][1] - intervals[i][0] + 1;
                heap.push(Reverse((size, intervals[i][1])));
                i += 1;
            }

            // Remove expired intervals whose right endpoint < query value
            while let Some(&Reverse((_, right))) = heap.peek() {
                if right < query_val {
                    heap.pop();
                } else {
                    break;
                }
            }

            result[idx] = heap.peek().map(|&Reverse((size, _))| size).unwrap_or(-1);
        }

        result
    }
}
```

```javascript
var minInterval = function (intervals, queries) {
  // Sort intervals by left endpoint
  intervals.sort((a, b) => a[0] - b[0]);

  // Pair each query with its original index, then sort by value
  var sortedQueries = queries.map((val, idx) => [val, idx]);
  sortedQueries.sort((a, b) => a[0] - b[0]);

  // Min-heap implementation using array
  var heap = [];
  var result = new Array(queries.length);
  var i = 0;

  function heapPush(item) {
    heap.push(item);
    var idx = heap.length - 1;
    while (idx > 0) {
      var parent = Math.floor((idx - 1) / 2);
      if (heap[parent][0] > heap[idx][0]) {
        var tmp = heap[parent];
        heap[parent] = heap[idx];
        heap[idx] = tmp;
        idx = parent;
      } else break;
    }
  }

  function heapPop() {
    var top = heap[0];
    var last = heap.pop();
    if (heap.length > 0) {
      heap[0] = last;
      var idx = 0;
      while (true) {
        var left = 2 * idx + 1,
          right = 2 * idx + 2,
          smallest = idx;
        if (left < heap.length && heap[left][0] < heap[smallest][0])
          smallest = left;
        if (right < heap.length && heap[right][0] < heap[smallest][0])
          smallest = right;
        if (smallest !== idx) {
          var tmp = heap[idx];
          heap[idx] = heap[smallest];
          heap[smallest] = tmp;
          idx = smallest;
        } else break;
      }
    }
    return top;
  }

  for (var s = 0; s < sortedQueries.length; s++) {
    var queryVal = sortedQueries[s][0];
    var idx = sortedQueries[s][1];

    while (i < intervals.length && intervals[i][0] <= queryVal) {
      var size = intervals[i][1] - intervals[i][0] + 1;
      heapPush([size, intervals[i][1]]);
      i++;
    }

    while (heap.length > 0 && heap[0][1] < queryVal) {
      heapPop();
    }

    result[idx] = heap.length === 0 ? -1 : heap[0][0];
  }

  return result;
};
```

```typescript
function minInterval(intervals: number[][], queries: number[]): number[] {
  // Sort intervals by left endpoint
  intervals.sort((a, b) => a[0] - b[0]);

  // Pair each query with its original index, then sort by value
  const sortedQueries: [number, number][] = queries.map((val, idx) => [
    val,
    idx,
  ]);
  sortedQueries.sort((a, b) => a[0] - b[0]);

  const heap: [number, number][] = [];
  const result: number[] = new Array(queries.length);
  let i = 0;

  function heapPush(item: [number, number]): void {
    heap.push(item);
    let idx = heap.length - 1;
    while (idx > 0) {
      const parent = Math.floor((idx - 1) / 2);
      if (heap[parent][0] > heap[idx][0]) {
        [heap[parent], heap[idx]] = [heap[idx], heap[parent]];
        idx = parent;
      } else break;
    }
  }

  function heapPop(): [number, number] {
    const top = heap[0];
    const last = heap.pop()!;
    if (heap.length > 0) {
      heap[0] = last;
      let idx = 0;
      while (true) {
        const left = 2 * idx + 1,
          right = 2 * idx + 2;
        let smallest = idx;
        if (left < heap.length && heap[left][0] < heap[smallest][0])
          smallest = left;
        if (right < heap.length && heap[right][0] < heap[smallest][0])
          smallest = right;
        if (smallest !== idx) {
          [heap[idx], heap[smallest]] = [heap[smallest], heap[idx]];
          idx = smallest;
        } else break;
      }
    }
    return top;
  }

  for (const [queryVal, idx] of sortedQueries) {
    while (i < intervals.length && intervals[i][0] <= queryVal) {
      const size = intervals[i][1] - intervals[i][0] + 1;
      heapPush([size, intervals[i][1]]);
      i++;
    }

    while (heap.length > 0 && heap[0][1] < queryVal) {
      heapPop();
    }

    result[idx] = heap.length === 0 ? -1 : heap[0][0];
  }

  return result;
}
```

> - **Time Complexity:** O((n + q) log n). Sorting intervals takes O(n log n). Sorting queries takes O(q log q). Each interval is pushed and popped from the heap at most once, and each heap operation is O(log n).
> - **Space Complexity:** O(n + q). The heap holds at most n intervals. The sorted queries array and result array each use O(q) space.

When queries contain many duplicates, this version repeats the heap peek-and-pop work for every copy of the same query value. The next approach computes the answer once per unique query value and reuses it.

<h1 id="approach-3-sorting-hash-map-optimal">
  Approach 3: Sorting + Hash Map (Optimal)
</h1>

<h3 id="intuition">Intuition</h3>

This approach uses the same sweep but processes each distinct query value only once. Instead of pairing every query with its original index and sorting those pairs, we extract the unique query values, compute the answer for each, and store it in a hash map keyed by query value. At the end, we look up each original query's answer.

The sweep logic is unchanged: sort intervals by left endpoint, process unique queries in sorted order, and use a min-heap to track the smallest active interval. The benefit appears when queries repeat: a query value that occurs many times drives only one round of heap operations rather than one per occurrence.

<h3 id="algorithm">Algorithm</h3>

1. Sort `intervals` by left endpoint.
2. Extract sorted unique query values.
3. Initialize a min-heap keyed by interval size and an interval pointer `i = 0`.
4. For each unique query value `q` in sorted order:
5. Build the result array by looking up each original query in `queryMap`.

<h3 id="code">Code</h3>

```java
class Solution {
    public int[] minInterval(int[][] intervals, int[] queries) {
        // Sort intervals by left endpoint
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

        // Get sorted unique query values
        int[] sortedUnique = Arrays.stream(queries).distinct().sorted().toArray();

        // Min-heap: (interval size, right endpoint)
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        Map<Integer, Integer> queryMap = new HashMap<>();
        int i = 0;

        for (int q : sortedUnique) {
            // Push all intervals whose left endpoint <= query value

            while (!heap.isEmpty() && heap.peek()[1] < q) {
                heap.poll();

            queryMap.put(q, heap.isEmpty() ? -1 : heap.peek()[0]);

        // Map results back to original query order
        int[] result = new int[queries.length];
        for (int j = 0; j < queries.length; j++) {
            result[j] = queryMap.get(queries[j]);
        }
        return result;
```

```go
func minInterval(intervals [][]int, queries []int) []int {
    // Sort intervals by left endpoint
    sort.Slice(intervals, func(i, j int) bool {
        return intervals[i][0] < intervals[j][0]
    })

    // Get sorted unique query values
    uniqueSet := make(map[int]bool)
    for _, q := range queries {
        uniqueSet[q] = true
    }
    sortedUnique := make([]int, 0, len(uniqueSet))
    for q := range uniqueSet {
        sortedUnique = append(sortedUnique, q)
    }
    sort.Ints(sortedUnique)

    // Min-heap: (interval size, right endpoint)
    h := &MinHeap{}
    heap.Init(h)
    queryMap := make(map[int]int)
    idx := 0

    for _, q := range sortedUnique {
        // Push all intervals whose left endpoint <= query value
        for idx < len(intervals) && intervals[idx][0] <= q {
            size := intervals[idx][1] - intervals[idx][0] + 1
            heap.Push(h, [2]int{size, intervals[idx][1]})
            idx++
        }

        // Remove expired intervals whose right endpoint < query value
        for h.Len() > 0 && (*h)[0][1] < q {
            heap.Pop(h)
        }

        if h.Len() == 0 {
            queryMap[q] = -1
        } else {
            queryMap[q] = (*h)[0][0]
        }
    }

    // Map results back to original query order
    result := make([]int, len(queries))
    for j, q := range queries {
        result[j] = queryMap[q]
    }
    return result
}
```

```rust
impl Solution {
    pub fn min_interval(mut intervals: Vec<Vec<i32>>, queries: Vec<i32>) -> Vec<i32> {
        // Sort intervals by left endpoint
        intervals.sort_unstable_by_key(|v| v[0]);

        // Get sorted unique query values
        let mut sorted_unique = queries.clone();
        sorted_unique.sort_unstable();
        sorted_unique.dedup();

        // Min-heap: (interval size, right endpoint)
        let mut heap: BinaryHeap<Reverse<(i32, i32)>> = BinaryHeap::new();
        let mut query_map: HashMap<i32, i32> = HashMap::new();
        let mut i = 0usize;

        for q in sorted_unique {
            // Push all intervals whose left endpoint <= query value
            while i < intervals.len() && intervals[i][0] <= q {
                let size = intervals[i][1] - intervals[i][0] + 1;
                heap.push(Reverse((size, intervals[i][1])));
                i += 1;
            }

            // Remove expired intervals whose right endpoint < query value
            while let Some(&Reverse((_, r))) = heap.peek() {
                if r < q {
                    heap.pop();
                } else {
                    break;
                }
            }

            query_map.insert(q, heap.peek().map_or(-1, |x| (x.0).0));
        }

        // Map results back to original query order
        queries
            .into_iter()
            .map(|q| *query_map.get(&q).unwrap())
            .collect()
    }
}
```

```javascript
var minInterval = function (intervals, queries) {
  // Sort intervals by left endpoint
  intervals.sort((a, b) => a[0] - b[0]);

  // Get sorted unique query values
  var uniqueSet = new Set(queries);
  var sortedUnique = Array.from(uniqueSet).sort((a, b) => a - b);

  var heap = [];
  function heapPush(item) {
    heap.push(item);
    var idx = heap.length - 1;
    while (idx > 0) {
      var parent = Math.floor((idx - 1) / 2);
      if (heap[parent][0] > heap[idx][0]) {
        var tmp = heap[parent];
        heap[parent] = heap[idx];
        heap[idx] = tmp;
        idx = parent;
      } else break;
    }
  }
  function heapPop() {
    var top = heap[0];
    var last = heap.pop();
    if (heap.length > 0) {
      heap[0] = last;
      var idx = 0;
      while (true) {
        var left = 2 * idx + 1,
          right = 2 * idx + 2,
          smallest = idx;
        if (left < heap.length && heap[left][0] < heap[smallest][0])
          smallest = left;
        if (right < heap.length && heap[right][0] < heap[smallest][0])
          smallest = right;
        if (smallest !== idx) {
          var tmp = heap[idx];
          heap[idx] = heap[smallest];
          heap[smallest] = tmp;
          idx = smallest;
        } else break;
      }
    }
    return top;
  }

  var queryMap = new Map();
  var i = 0;

  for (var s = 0; s < sortedUnique.length; s++) {
    var q = sortedUnique[s];
    while (i < intervals.length && intervals[i][0] <= q) {
```

```typescript
    while (idx > 0) {

      if (heap[parent][0] > heap[idx][0]) {
        [heap[parent], heap[idx]] = [heap[idx], heap[parent]];
        idx = parent;
      } else break;
    }

          idx = smallest;
        } else break;
```
