<LessonCard>

A Range Module is a module that tracks ranges of numbers. Design a data structure to track the ranges represented as **half-open intervals** and query about them.

A **half-open interval** `[left, right)` denotes all the real numbers `x` where `left <= x < right`.

Implement the `RangeModule` class:

- `RangeModule()` Initializes the object of the data structure.
- `void addRange(int left, int right)` Adds the half-open interval `[left, right)`, tracking every real number in that interval. Adding an interval that partially overlaps with currently tracked numbers should add any numbers in the interval `[left, right)` that are not already tracked.
- `boolean queryRange(int left, int right)` Returns `true` if every real number in the interval `[left, right)` is currently being tracked, and `false` otherwise.
- `void removeRange(int left, int right)` Stops tracking every real number currently being tracked in the half-open interval `[left, right)`.

**Example 1:**

- **Input:** `operations = ["RangeModule", "addRange", "removeRange", "queryRange", "queryRange", "queryRange"]`

- **Input:** `arguments = [[], [10, 20], [14, 16], [10, 14], [13, 15], [16, 20]]`

- **Output:** `[null, null, null, true, false, true]`

**Explanation:**

- `rangeModule.addRange(10, 20);`: Tracks [10, 20)
- `rangeModule.removeRange(14, 16);`: Now tracks [10, 14) and [16, 20)
- `rangeModule.queryRange(10, 14);`: Returns true, every number in [10, 14) is tracked
- `rangeModule.queryRange(13, 15);`: Returns false, 14 is not tracked
- `rangeModule.queryRange(16, 20);`: Returns true, every number in [16, 20) is tracked

**Constraints:**

- `1 <= left < right <= 10^9`
- At most `10^4` calls will be made to `addRange`, `queryRange`, and `removeRange`.

Maintain a list of non-overlapping intervals sorted by start position. For each operation, scan the list to find which intervals overlap the given range, then merge, split, or check as needed.

<h1 id="understanding-the-problem">Understanding the Problem</h1>

We need to maintain a dynamic collection of non-overlapping intervals and support three operations: adding a range (merging it with any overlapping intervals), removing a range (splitting intervals if necessary), and querying whether a range is fully covered.

The difficult part is handling the merging and splitting correctly. When we add `[10, 20)` and then remove `[14, 16)`, our collection becomes `{[10, 14), [16, 20)}`. If we then add `[13, 18)`, we need to merge it with the existing pieces to get `{[10, 20)}` again.

The value range goes up to 10^9, so we can't use a boolean array indexed by value: a billion-entry array is too large. We need to store intervals and detect overlap without touching every integer in a range. The number of operations is at most 10^4, which leaves room for approaches that are O(n) per operation, as long as they stay correct under merging and splitting.

<h3 id="key-constraints">Key Constraints:</h3>

- `1 <= left < right <= 10^9`: the coordinate space is too large to index directly, so we store intervals rather than individual values.
- At most `10^4` calls: with n = 10^4 operations, an O(n) per-operation approach does about 10^8 total work, which runs in time. An O(log n) per-operation approach has plenty of margin.

<h1 id="approach-1-brute-force-with-sorted-list">
  Approach 1: Brute Force with Sorted List
</h1>

<h3 id="intuition">Intuition</h3>

Maintain a list of non-overlapping intervals sorted by start position. For each operation, scan the list to find which intervals overlap the given range, then merge, split, or check as needed.

The invariant is that the intervals are always sorted by start and never overlap. As long as `addRange` and `removeRange` rebuild the list to preserve that property, `queryRange` can decide coverage by finding a single interval that contains the query: if any interval starts at or before `left` and ends at or after `right`, the range is fully tracked. No two intervals can ever combine to cover a range, because a gap between them means some value is untracked.

<h3 id="algorithm">Algorithm</h3>

For `addRange(left, right)`:

1. Scan through all intervals. For each interval `[a, b)` that overlaps with `[left, right)` (i.e., `a < right && b > left`), extend `left` to `min(left, a)` and `right` to `max(right, b)`.
2. Remove all overlapping intervals from the list.
3. Insert the merged interval `[left, right)` at the correct sorted position.

For `queryRange(left, right)`:

1. Scan through all intervals. If any interval `[a, b)` satisfies `a <= left && b >= right`, the query range is fully covered. Return `true`.
2. If no single interval covers the entire range, return `false`.

For `removeRange(left, right)`:

1. Build a new list. For each existing interval `[a, b)`: if it doesn't overlap, keep it. If it does overlap, add `[a, left)` if `a < left`, and `[right, b)` if `b > right`.
2. Replace the old list with the new one.

```java
class RangeModule {
    List<int[]> intervals;

    public RangeModule() {
        intervals = new ArrayList<>();
    }

    public void addRange(int left, int right) {
        List<int[]> result = new ArrayList<>();
        boolean inserted = false;

        for (int[] interval : intervals) {
            if (interval[1] < left) {
                // Current interval ends before new range starts
                result.add(interval);
            } else if (interval[0] > right) {
                // Current interval starts after new range ends
                if (!inserted) {
                    result.add(new int[]{left, right});
                    inserted = true;
                }
                result.add(interval);
            } else {
                // Overlap: merge by extending the new range
                left = Math.min(left, interval[0]);
                right = Math.max(right, interval[1]);
            }
        }

        if (!inserted) {
            result.add(new int[]{left, right});
        }
        intervals = result;
    }

    public boolean queryRange(int left, int right) {
        for (int[] interval : intervals) {
            if (interval[0] <= left && interval[1] >= right) {
                return true;
            }
        }
        return false;
    }

    public void removeRange(int left, int right) {
        List<int[]> result = new ArrayList<>();

        for (int[] interval : intervals) {
            if (interval[1] <= left || interval[0] >= right) {
                // No overlap, keep the interval
                result.add(interval);
            } else {
                // Overlap: keep the non-removed portions
                if (interval[0] < left) {
                    result.add(new int[]{interval[0], left});
                }
                if (interval[1] > right) {
                    result.add(new int[]{right, interval[1]});
                }
            }
        }
        intervals = result;
    }
}
```

> - **Time Complexity:** O(n) per operation. Each operation scans through all existing intervals once. In the worst case, after k operations, there could be up to k intervals.
> - **Space Complexity:** O(n). We store the list of non-overlapping intervals. In the worst case, alternating add and remove calls could create up to n/2 intervals.

This approach scans every interval on every operation. Since the intervals are sorted, binary search can jump directly to the relevant ones instead of starting from the front.

<h1 id="approach-2-treemap-sorted-map-with-binary-search">
  Approach 2: TreeMap (Sorted Map with Binary Search)
</h1>

<h3 id="intuition">Intuition</h3>

The intervals are already sorted and non-overlapping, so a linear scan repeats work that binary search avoids. A TreeMap (or equivalent sorted map) keyed by interval start lets us jump directly to the interval that matters in O(log n).

For a range `[left, right)`, the only interval that can overlap its left edge is the one whose start is the largest value at or before `left`. A TreeMap's `floorKey` operation returns exactly that key in O(log n), which replaces the front-to-back scan of the brute force.

> `queryRange` checks only one interval, the one returned by `floorKey(left)`, and that is sufficient. Any interval that starts after `left` cannot cover `left` itself. The single interval starting at or before `left` is the only candidate, so if its end reaches `right` the range is covered, and if not, no other interval can fill the gap because the stored intervals never overlap.

<h3 id="algorithm">Algorithm</h3>

For `addRange(left, right)`:

1. Use `floorKey(left)` to find the interval starting at or before `left`. If its end >= left, it overlaps, so extend `left` to `min(left, its start)`.
2. Use `floorKey(right)` to find the interval starting at or before `right`. If its end > left, extend `right` to `max(right, its end)`.
3. Remove all entries from the map whose keys fall in `[left, right)`.
4. Insert the merged interval with key `left` and value `right`.

For `queryRange(left, right)`:

1. Use `floorKey(left)` to find the interval starting at or before `left`.
2. If such an interval exists and its end >= `right`, return `true`. Otherwise, return `false`.

For `removeRange(left, right)`:

1. Save portions of overlapping intervals that extend beyond the removal range.
2. Remove all entries whose keys fall in `[left, right)`.
3. Reinsert the preserved portions.

```java
class RangeModule {
    TreeMap<Integer, Integer> map;

    public RangeModule() {
        map = new TreeMap<>();
    }

    public void addRange(int left, int right) {
        // Check if an interval starting at or before 'left' extends into our range
        Integer start = map.floorKey(left);
        if (start != null && map.get(start) >= left) {
            left = start;
        }
        // Check if an interval starting at or before 'right' extends past our range
        Integer end = map.floorKey(right);
        if (end != null && map.get(end) > left) {
            right = Math.max(right, map.get(end));
        }
        // Remove all intervals that are fully covered by [left, right)
        map.subMap(left, right).clear();
        map.put(left, right);
    }

    public boolean queryRange(int left, int right) {
        Integer start = map.floorKey(left);
        return start != null && map.get(start) >= right;
    }

    public void removeRange(int left, int right) {
        // Check if an interval starting at or before 'left' needs its left portion saved
        Integer start = map.floorKey(left);
        if (start != null && map.get(start) > left) {
            int originalEnd = map.get(start);
            map.put(start, left);  // Keep the left portion [start, left)
            if (originalEnd > right) {
                map.put(right, originalEnd);  // Keep the right portion [right, originalEnd)
            }
        }
        // Check if an interval starting at or before 'right' needs its right portion saved
        Integer end = map.floorKey(right);
        if (end != null && end >= left && map.get(end) > right) {
            map.put(right, map.get(end));  // Keep [right, end_value)
        }
        // Remove all intervals fully within [left, right)
        map.subMap(left, right).clear();
    }
}
```

```python
from sortedcontainers import SortedDict

class RangeModule:
    def __init__(self):
        self.map = SortedDict()

    def addRange(self, left: int, right: int) -> None:
        # Find intervals that overlap with [left, right)
        idx = self.map.bisect_right(left)
        if idx > 0:
            prev_start = self.map.keys()[idx - 1]
            if self.map[prev_start] >= left:
                left = prev_start

        idx = self.map.bisect_right(right)
        if idx > 0:
            prev_start = self.map.keys()[idx - 1]
            if self.map[prev_start] > left:
                right = max(right, self.map[prev_start])

        # Remove all overlapping intervals
        keys_to_remove = list(self.map.irange(left, right, (True, False)))
        for key in keys_to_remove:
            del self.map[key]

        self.map[left] = right

    def queryRange(self, left: int, right: int) -> bool:
        idx = self.map.bisect_right(left)
        if idx == 0:
            return False
        prev_start = self.map.keys()[idx - 1]
        return self.map[prev_start] >= right

    def removeRange(self, left: int, right: int) -> None:
        # Save portions that extend beyond the removal range
        idx = self.map.bisect_right(left)
        if idx > 0:
            prev_start = self.map.keys()[idx - 1]
            prev_end = self.map[prev_start]
            if prev_end > left:
                self.map[prev_start] = left  # Keep [prev_start, left)
                if prev_end > right:
                    self.map[right] = prev_end  # Keep [right, prev_end)

        idx = self.map.bisect_right(right)
        if idx > 0:
            prev_start = self.map.keys()[idx - 1]
            if prev_start >= left and self.map[prev_start] > right:
                self.map[right] = self.map[prev_start]

        # Remove all intervals starting in [left, right)
        keys_to_remove = list(self.map.irange(left, right, (True, False)))
        for key in keys_to_remove:
            del self.map[key]
```

```cpp
class RangeModule {
    map<int, int> intervals; // start -> end

public:
    RangeModule() {}

    void addRange(int left, int right) {
        // Find all overlapping intervals and merge
        auto it = intervals.upper_bound(left);
        if (it != intervals.begin()) {
            --it;
            if (it->second >= left) {
                left = it->first;
            } else {
                ++it;
            }
        }
        // Extend right to cover all overlapping intervals
        while (it != intervals.end() && it->first <= right) {
            right = max(right, it->second);
            it = intervals.erase(it);
        }
        intervals[left] = right;
    }

    bool queryRange(int left, int right) {
        auto it = intervals.upper_bound(left);
        if (it == intervals.begin()) return false;
        --it;
        return it->second >= right;
    }

    void removeRange(int left, int right) {
        auto it = intervals.upper_bound(left);
        if (it != intervals.begin()) {
            --it;
            if (it->second > left) {
                int origStart = it->first;
                int origEnd = it->second;
                if (origEnd > right) {
                    intervals[right] = origEnd; // Keep [right, origEnd)
                }
                if (origStart < left) {
                    it->second = left; // Keep [origStart, left)
                    ++it;
                } else {
                    // origStart == left: this interval is fully inside [left, right)
                    it = intervals.erase(it);
                }
            } else {
                ++it;
            }
        }
        // Remove intervals starting in [left, right) and handle the last one
        while (it != intervals.end() && it->first < right) {
            if (it->second > right) {
                intervals[right] = it->second; // Keep [right, it->second)
                it = intervals.erase(it);
                break;
            }
            it = intervals.erase(it);
        }
    }
};
```

```csharp
public class RangeModule {
    SortedDictionary<int, int> map;

    public RangeModule() {
        map = new SortedDictionary<int, int>();
    }

    public void AddRange(int left, int right) {
        // Find and merge overlapping intervals
        var toRemove = new List<int>();

        foreach (var kvp in map) {
            if (kvp.Key > right) break;
            if (kvp.Value < left) continue;
            // Overlapping interval
            left = Math.Min(left, kvp.Key);
            right = Math.Max(right, kvp.Value);
            toRemove.Add(kvp.Key);
        }

        foreach (var key in toRemove) {
            map.Remove(key);
        }
        map[left] = right;
    }

    public bool QueryRange(int left, int right) {
        // Find the interval that could contain [left, right)
        foreach (var kvp in map) {
            if (kvp.Key > left) return false;
            if (kvp.Key <= left && kvp.Value >= right) return true;
        }
        return false;
    }

    public void RemoveRange(int left, int right) {
        var toRemove = new List<int>();
        var toAdd = new List<int[]>();

        foreach (var kvp in map) {
            if (kvp.Key >= right) break;
            if (kvp.Value <= left) continue;
            // Overlapping interval
            toRemove.Add(kvp.Key);
            if (kvp.Key < left) toAdd.Add(new int[]{kvp.Key, left});
            if (kvp.Value > right) toAdd.Add(new int[]{right, kvp.Value});
        }

        foreach (var key in toRemove) map.Remove(key);
        foreach (var interval in toAdd) map[interval[0]] = interval[1];
    }
```

```go
                left = rm.starts[i]
            }
            if rm.ends[i] > right {
                right = rm.ends[i]
            }
        }
    }

    if !inserted {
        newStarts = append(newStarts, left)
        newEnds = append(newEnds, right)

    rm.ends = newEnds
```

```rust
use std::collections::BTreeMap;

struct RangeModule {
    map: BTreeMap<i32, i32>,
}

impl RangeModule {
    fn new() -> Self {
        RangeModule {
            map: BTreeMap::new(),
        }
    }

    fn add_range(&mut self, mut left: i32, mut right: i32) {
        // Check if an interval starting at or before 'left' extends into our range
        if let Some((&start, &end)) = self.map.range(..=left).next_back() {
            if end >= left {
                left = start;
            }
        }
        // Check if an interval starting at or before 'right' extends past our range
        if let Some((&start, &end)) = self.map.range(..=right).next_back() {
            if end > left {
                right = right.max(end);
            }
        }
        // Remove all intervals that are fully covered by [left, right)
        let keys: Vec<i32> = self
            .map
            .range(left..right)
            .map(|(&k, _)| k)
            .collect();
        for k in keys {
            self.map.remove(&k);
        }
        self.map.insert(left, right);
    }

    fn query_range(&self, left: i32, right: i32) -> bool {
        if let Some((_, &end)) = self.map.range(..=left).next_back() {
            end >= right
        } else {
            false
        }
    }

    fn remove_range(&mut self, left: i32, right: i32) {
        // Check if an interval starting at or before 'left' needs its left portion saved
        if let Some((&start, &end)) = self.map.range(..=left).next_back() {
            if end > left {
                let original_end = end;
                self.map.insert(start, left); // Keep the left portion [start, left)
                if original_end > right {
                    self.map.insert(right, original_end); // Keep the right portion [right, originalEnd)
                }
            }
        }
        // Check if an interval starting at or before 'right' needs its right portion saved
        if let Some((&start, &end)) = self.map.range(..=right).next_back() {
            if start >= left && end > right {
                self.map.insert(right, end); // Keep [right, end_value)
            }
        }
        // Remove all intervals fully within [left, right)
        let keys: Vec<i32> = self
            .map
            .range(left..right)
            .map(|(&k, _)| k)
            .collect();
        for k in keys {
            self.map.remove(&k);
        }
    }
}
```

> - **Time Complexity:** O(n) per addRange/removeRange in the worst case, O(log n) per queryRange. The query uses a single floorKey call which is O(log n). Add and remove need O(log n) to find the position but O(k) to remove k overlapping intervals.
> - **Space Complexity:** O(n). We store at most n non-overlapping intervals, where n is the number of addRange calls.

The TreeMap gives O(log n) queries, but add and remove can still cost O(n) when a single call merges or splits many intervals. A segment tree bounds every operation by the depth of the tree instead.

<h1 id="approach-3-segment-tree-with-lazy-propagation">
  Approach 3: Segment Tree with Lazy Propagation
</h1>

<h3 id="intuition">Intuition</h3>

A segment tree supports range updates and range queries in O(log n). The obstacle here is that the value range goes up to 10^9, so building a full tree over every coordinate upfront would allocate billions of nodes. A **dynamic segment tree** (also called an implicit segment tree) avoids that by creating a node only when an operation first touches its subrange.

The tree covers `[1, 10^9)`. Each node represents a subrange and stores whether that entire subrange is tracked. An update marks a range as tracked or untracked and uses lazy propagation to defer pushing the change to children until a later operation visits them. A query reports whether every part of the query range is tracked.

Each operation visits at most O(log C) nodes, where C = 10^9 is the size of the coordinate space. Since log2(10^9) is about 30, an operation touches at most around 30 levels regardless of how many intervals exist.

<h3 id="algorithm">Algorithm</h3>

1. Create a dynamic segment tree with root covering `[1, 10^9)`.
2. Each node stores: `tracked` (whether the entire range is fully tracked), `lazy` (a pending update: 1 = mark as tracked, -1 = mark as untracked, 0 = no pending), and `left`/`right` child pointers (created on demand).
3. For `addRange(left, right)`: do a range update marking `[left, right)` as tracked.
4. For `removeRange(left, right)`: do a range update marking `[left, right)` as untracked.
5. For `queryRange(left, right)`: do a range query checking if the entire `[left, right)` is tracked.

```java
    private boolean tracked;

    private static final int LO = 1;
    private static final int HI = 1_000_000_001;
    private RangeModule root;

        root = new RangeModule(true);
    }

        tracked = false;
        lazy = 0;
    }

    private void pushDown() {
        if (leftChild == null) leftChild = new RangeModule(true);
        if (rightChild == null) rightChild = new RangeModule(true);

        if (lazy != 0) {
            leftChild.tracked = (lazy == 1);
            leftChild.lazy = lazy;
            rightChild.tracked = (lazy == 1);
            rightChild.lazy = lazy;
            lazy = 0;
        }
    }

    private void update(RangeModule node, int lo, int hi, int left, int right, boolean val) {
        if (left >= hi || right <= lo) return; // No overlap
        if (left <= lo && hi <= right) {
            // Full overlap
            node.tracked = val;
            node.lazy = val ? 1 : -1;
            return;

        int mid = lo + (hi - lo) / 2;
```

```rust
            Self::update(lc, lo, mid, left, right, val);
        }
        if let Some(rc) = node.right.as_mut() {
            Self::update(rc, mid, hi, left, right, val);
        }
        node.tracked = node.left.as_ref().unwrap().tracked && node.right.as_ref().unwrap().tracked;
    }

    fn query(node: &mut Node, lo: i32, hi: i32, left: i32, right: i32) -> bool {
        if left >= hi || right <= lo {
            return true; // Out of range, doesn't affect result
        }
        if left <= lo && hi <= right {
            return node.tracked;
        }
        Self::push_down(node);
        let mid = lo + (hi - lo) / 2;
        let left_ok = Self::query(node.left.as_mut().unwrap(), lo, mid, left, right);
        let right_ok = Self::query(node.right.as_mut().unwrap(), mid, hi, left, right);
        left_ok && right_ok
    }

    pub fn add_range(&mut self, left: i32, right: i32) {
        Self::update(&mut self.root, Self::LO, Self::HI, left, right, true);
    }

    pub fn query_range(&mut self, left: i32, right: i32) -> bool {
        Self::query(&mut self.root, Self::LO, Self::HI, left, right)
    }

    pub fn remove_range(&mut self, left: i32, right: i32) {
        Self::update(&mut self.root, Self::LO, Self::HI, left, right, false);
    }
}
```

```typescript
class SegNode {
  tracked: boolean = false;
  lazy: number = 0;
  left: SegNode | null = null;
  right: SegNode | null = null;
}

class RangeModule {
  private root: SegNode;
  private readonly LO = 1;
  private readonly HI = 1_000_000_001;

  constructor() {
    this.root = new SegNode();
  }

  private pushDown(node: SegNode): void {
    if (!node.left) node.left = new SegNode();
    if (!node.right) node.right = new SegNode();
    if (node.lazy !== 0) {
      node.left.tracked = node.lazy === 1;
      node.left.lazy = node.lazy;
      node.right.tracked = node.lazy === 1;
      node.right.lazy = node.lazy;
      node.lazy = 0;
    }
  }

  private update(
    node: SegNode,
    lo: number,
    hi: number,
    left: number,
    right: number,
    val: boolean,
  ): void {
    if (left >= hi || right <= lo) return;
    if (left <= lo && hi <= right) {
      node.tracked = val;
      node.lazy = val ? 1 : -1;
      return;
    }
    this.pushDown(node);
    const mid = lo + Math.floor((hi - lo) / 2);
    this.update(node.left!, lo, mid, left, right, val);
    this.update(node.right!, mid, hi, left, right, val);
    node.tracked = node.left!.tracked && node.right!.tracked;
  }

  private query(
    node: SegNode | null,
    lo: number,
    hi: number,
    left: number,
    right: number,
  ): boolean {
    if (left >= hi || right <= lo) return true;
    if (!node) return false;
    if (left <= lo && hi <= right) return node.tracked;
    this.pushDown(node);
    const mid = lo + Math.floor((hi - lo) / 2);
    return (
      this.query(node.left, lo, mid, left, right) &&
      this.query(node.right, mid, hi, left, right)
    );
  }

  addRange(left: number, right: number): void {
    this.update(this.root, this.LO, this.HI, left, right, true);
  }

  queryRange(left: number, right: number): boolean {
    return this.query(this.root, this.LO, this.HI, left, right);
  }

  removeRange(left: number, right: number): void {
    this.update(this.root, this.LO, this.HI, left, right, false);
  }
}
```

> - **Time Complexity:** O(log C) per operation, where C = 10^9 is the value range. Each operation traverses at most O(log C) levels of the segment tree. Since log2(10^9) is about 30, this is effectively constant per operation.
> - **Space Complexity:** O(Q \* log C), where Q is the number of operations. Each operation creates at most O(log C) new nodes. For Q = 10^4 and log C = 30, that's about 300,000 nodes.
