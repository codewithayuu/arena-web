<LessonCard>

Design a search autocomplete system for a search engine. Users may input a sentence (at least one word and end with a special character `'#'`). You are given a `String[]` `sentences` and an `int[]` `times` where `sentences[i]` is a previously typed sentence and `times[i]` is the corresponding number of times the sentence was typed. For each input character except `'#'`, return the top 3 historical hot sentences that have the same prefix as the part of the sentence already typed.

Here are the specific rules:

- The hot degree for a sentence is defined as the number of times a user typed the exactly same sentence before.
- The returned top 3 hot sentences should be sorted by hot degree (descending). If several sentences have the same hot degree, use ASCII-code order (ascending).
- If less than 3 hot sentences exist that share the given prefix, return as many as you can.
- When the input is a special character `'#'`, it means the sentence ends, and in this case, you need to add the sentence to the historical data and return an empty list.

Implement the `AutocompleteSystem` class:

- `AutocompleteSystem(String[] sentences, int[] times)` Initializes the data structure with historical sentences and their counts.
- `List<String> input(char c)` This indicates that the user typed the character `c`. Returns the top 3 historical hot sentences that have the same prefix as the sentence being typed.

**Example 1:**

**Input:** `sentences = ["i love you","island","iroman","i love leetcode"]`, `times = [5,3,2,2]`, `inputs = ["i"," ","a","#"]`

**Output:** `[["i love you","island","i love leetcode"],["i love you","i love leetcode"],[],[]]`

**Constraints:**

- `n == sentences.length`
- `n == times.length`
- `1 <= n <= 100`
- `1 <= sentences[i].length <= 100`
- `1 <= times[i] <= 50`
- `sentences[i]` consists of lowercase English letters and spaces `' '`.
- Each sentence in `sentences` is unique.
- At most `5000` calls will be made to `input`.
- `c` is a lowercase English letter, a hash `'#'`, or a space `' '`.

We need to build something that behaves like a search bar. As the user types characters one by one, the system suggests the top 3 most-typed sentences that match what has been typed so far. When the user finishes typing (signaled by `#`), the system records that sentence.

Two concerns combine here: prefix matching and ranking. We need to find all sentences sharing a prefix, then pick the top 3 by frequency (with ties broken alphabetically), and we have to do this on every keystroke.

Prefix matching points to a Trie (prefix tree), which is built for exactly this kind of lookup. The ranking component adds the harder part, because a Trie on its own only records which strings exist, not which ones are most frequent. So the design question is how to combine prefix matching with efficient top-k retrieval.

- `n <= 100` sentences, each up to 100 characters long. The initial data set is small, so even a brute-force construction is feasible.
- Up to `5000` calls to `input`, and each call should be fast. A Trie reduces the per-call cost compared to scanning every sentence.
- Characters are lowercase letters and spaces, so a Trie node needs 27 children (26 letters plus space), not 26.

Keep a HashMap mapping each sentence to its frequency count. Every time the user types a character, append it to the current prefix. Then scan through all sentences, filter those starting with the current prefix, sort them by frequency (descending) then alphabetically (ascending), and return the top 3.

This is simple but does redundant work. Every keystroke triggers a full scan and sort of all sentences. It stays within the given constraints but does not scale.

```java
class AutocompleteSystem {
    Map<String, Integer> counts;
    StringBuilder prefix;

    public AutocompleteSystem(String[] sentences, int[] times) {
        counts = new HashMap<>();
        prefix = new StringBuilder();
        for (int i = 0; i < sentences.length; i++) {
            counts.put(sentences[i], times[i]);
        }
    }

    public List<String> input(char c) {
        if (c == '#') {
            String sentence = prefix.toString();
            counts.put(sentence, counts.getOrDefault(sentence, 0) + 1);
            prefix = new StringBuilder();
            return new ArrayList<>();
        }

        prefix.append(c);
        String currentPrefix = prefix.toString();

        // Filter sentences matching the prefix
        List<String> matches = new ArrayList<>();
        for (String sentence : counts.keySet()) {
            if (sentence.startsWith(currentPrefix)) {
                matches.add(sentence);
            }
        }

        // Sort by count descending, then alphabetically ascending
        matches.sort((a, b) -> {
            int countDiff = counts.get(b) - counts.get(a);
            if (countDiff != 0) return countDiff;
            return a.compareTo(b);
        });

        // Return top 3
        List<String> result = new ArrayList<>();
        for (int i = 0; i < Math.min(3, matches.size()); i++) {
            result.add(matches.get(i));
        }
        return result;
    }
}
```

```rust
use std::collections::HashMap;

struct AutocompleteSystem {
    counts: HashMap<String, i32>,
    prefix: String,
}

impl AutocompleteSystem {
    fn new(sentences: Vec<String>, times: Vec<i32>) -> Self {
        let mut counts = HashMap::new();
        let prefix = String::new();
        for i in 0..sentences.len() {
            counts.insert(sentences[i].clone(), times[i]);
        }
        Self { counts, prefix }
    }

    fn input(&mut self, c: char) -> Vec<String> {
        if c == '#' {
            let sentence = self.prefix.clone();
            *self.counts.entry(sentence).or_insert(0) += 1;
            self.prefix.clear();
            return Vec::new();
        }

        self.prefix.push(c);
        let current_prefix = self.prefix.clone();

        // Filter sentences matching the prefix
        let mut matches: Vec<String> = Vec::new();
        for sentence in self.counts.keys() {
            if sentence.starts_with(&current_prefix) {
                matches.push(sentence.clone());
            }
        }

        // Sort by count descending, then alphabetically ascending
        matches.sort_by(|a, b| {
            let count_diff = self.counts[b].cmp(&self.counts[a]);
            if count_diff != std::cmp::Ordering::Equal {
                return count_diff;
            }
            a.cmp(b)
        });

        // Return top 3
        if matches.len() > 3 {
            matches.truncate(3);
        }
        matches
    }
}
```

> - **Time Complexity:** O(n \* l + n log n) per `input` call, where n is the total number of sentences and l is the average sentence length. We scan all n sentences and check if each starts with the prefix, then sort the matching subset.
> - **Space Complexity:** O(n \* l). We store all sentences and their counts in the HashMap.

On every keystroke we scan every sentence and re-sort. The candidate set only shrinks as the prefix grows, yet we re-filter from scratch each time. The next approach organizes the sentences so we can jump directly to the node for the current prefix and look at only the matching ones.

<h1 id="approach-2-trie-with-dfs-collection">
  Approach 2: Trie with DFS Collection
</h1>

<h3 id="intuition">Intuition</h3>

A Trie organizes strings by their characters, so all sentences sharing a prefix live in the same subtree. We insert every sentence into the Trie, storing the sentence's frequency at its terminal node. When the user types a character, we move to the node for the current prefix, run a DFS to collect all sentences in that subtree, sort them by frequency, and return the top 3.

Compared to the HashMap approach, we never look at sentences outside the current subtree. We also keep a pointer into the Trie that advances one level deeper per keystroke, so reaching the prefix node costs one edge traversal instead of a full string comparison against everything.

<h3 id="algorithm">Algorithm</h3>

1. Build a Trie from all initial sentences. Each node has children for 'a'-'z' and space (' '). Terminal nodes store the sentence string and its count.
2. Maintain a current node pointer (starts at root) and a prefix string.
3. On `input(c)`:

```java
class AutocompleteSystem {
    int[][] children;
    int[] counts;
    String[] sentences;
    int nodeCount;
    int currentNode;
    StringBuilder prefix;

    public AutocompleteSystem(String[] sentences, int[] times) {
        int maxNodes = 600000;
        children = new int[maxNodes][27];
        counts = new int[maxNodes];
        this.sentences = new String[maxNodes];
        nodeCount = 1;
        prefix = new StringBuilder();
        currentNode = 0;

        for (int[] row : children) Arrays.fill(row, -1);

        for (int i = 0; i < sentences.length; i++) {
            insert(sentences[i], times[i]);
        }
    }

    private int charIndex(char c) {
        return c == ' ' ? 26 : c - 'a';
    }

    private void insert(String sentence, int count) {
        int node = 0;
        for (char c : sentence.toCharArray()) {
            int idx = charIndex(c);
            if (children[node][idx] == -1) {
                children[node][idx] = nodeCount++;
                Arrays.fill(children[children[node][idx]], -1);
            }
            node = children[node][idx];
        }
        counts[node] += count;
        sentences[node] = sentence;
    }

    private void dfs(int node, List<int[]> results) {
        if (sentences[node] != null) {
            results.add(new int[]{node, counts[node]});
        }
        for (int i = 0; i < 27; i++) {
            if (children[node][i] != -1) {
                dfs(children[node][i], results);
            }
        }
    }

    public List<String> input(char c) {
        if (c == '#') {
            String sentence = prefix.toString();
            insert(sentence, 1);
            prefix = new StringBuilder();
            currentNode = 0;
            return new ArrayList<>();
        }

        prefix.append(c);
        int idx = charIndex(c);

        if (currentNode == -1 || children[currentNode][idx] == -1) {
            currentNode = -1;
            return new ArrayList<>();
        }

        currentNode = children[currentNode][idx];

        // DFS to collect all sentences from this subtree
        List<int[]> results = new ArrayList<>();
        dfs(currentNode, results);

        // Sort by count descending, then sentence alphabetically
        results.sort((a, b) -> {
            if (a[1] != b[1]) return b[1] - a[1];
            return sentences[a[0]].compareTo(sentences[b[0]]);
        });

        List<String> output = new ArrayList<>();
        for (int i = 0; i < Math.min(3, results.size()); i++) {
            output.add(sentences[results.get(i)[0]]);
        }
        return output;
    }
}
```

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.sentence = None
        self.count = 0

class AutocompleteSystem:
    def __init__(self, sentences: list[str], times: list[int]):
        self.root = TrieNode()
        self.current = self.root
        self.prefix = []

        for i in range(len(sentences)):
            self._insert(sentences[i], times[i])

    def _insert(self, sentence: str, count: int) -> None:
        node = self.root
        for c in sentence:
            if c not in node.children:
                node.children[c] = TrieNode()
            node = node.children[c]
        node.count += count
        node.sentence = sentence

    def _dfs(self, node: TrieNode, results: list) -> None:
        if node.sentence is not None:
            results.append((-node.count, node.sentence))
        for child in node.children.values():
            self._dfs(child, results)

    def input(self, c: str) -> list[str]:
        if c == '#':
            sentence = ''.join(self.prefix)
            self._insert(sentence, 1)
            self.prefix = []
            self.current = self.root
            return []

        self.prefix.append(c)

        if self.current is None or c not in self.current.children:
            self.current = None
            return []

        self.current = self.current.children[c]

        # DFS to collect all sentences from this subtree
        results = []
        self._dfs(self.current, results)

        # Sort by count descending (negated), then alphabetically
        results.sort()

        return [sentence for _, sentence in results[:3]]
```

```cpp
struct TrieNode {
    unordered_map<char, TrieNode*> children;
    string sentence;
    int count = 0;
};

class AutocompleteSystem {
    TrieNode* root;
    TrieNode* current;
    string prefix;

    void insert(const string& sentence, int count) {
        TrieNode* node = root;
        for (char c : sentence) {
            if (node->children.find(c) == node->children.end()) {
                node->children[c] = new TrieNode();
            }
            node = node->children[c];
        }
        node->count += count;
        node->sentence = sentence;
    }

    void dfs(TrieNode* node, vector<pair<int, string>>& results) {
        if (!node->sentence.empty()) {
            results.push_back({-node->count, node->sentence});
        }
        for (auto& [ch, child] : node->children) {
            dfs(child, results);
        }
    }

public:
    AutocompleteSystem(vector<string>& sentences, vector<int>& times) {
        root = new TrieNode();
        current = root;
        for (int i = 0; i < sentences.size(); i++) {
            insert(sentences[i], times[i]);
        }
    }

    vector<string> input(char c) {
        if (c == '#') {
            insert(prefix, 1);
            prefix.clear();
            current = root;
            return {};
        }

        prefix += c;

        if (current == nullptr || current->children.find(c) == current->children.end()) {
            current = nullptr;
            return {};
        }

        current = current->children[c];

        vector<pair<int, string>> results;
        dfs(current, results);

        sort(results.begin(), results.end());

        vector<string> output;
        for (int i = 0; i < min(3, (int)results.size()); i++) {
            output.push_back(results[i].second);
        }
        return output;
    }
};
```

```csharp
public class AutocompleteSystem {
    class TrieNode {
        public Dictionary<char, TrieNode> Children = new Dictionary<char, TrieNode>();
        public string Sentence;
        public int Count;
    }

    TrieNode root;
    TrieNode current;
    StringBuilder prefix;

    public AutocompleteSystem(string[] sentences, int[] times) {
        root = new TrieNode();
        current = root;
        prefix = new StringBuilder();
        for (int i = 0; i < sentences.Length; i++) {
            Insert(sentences[i], times[i]);
        }
    }

    void Insert(string sentence, int count) {
        var node = root;
        foreach (char c in sentence) {
            if (!node.Children.ContainsKey(c))
                node.Children[c] = new TrieNode();
            node = node.Children[c];
        }
        node.Count += count;
        node.Sentence = sentence;
    }

    void Dfs(TrieNode node, List<(int count, string sentence)> results) {
        if (node.Sentence != null) {
            results.Add((-node.Count, node.Sentence));
        }
        foreach (var child in node.Children.Values) {
            Dfs(child, results);
        }
    }

    public IList<string> Input(char c) {
        if (c == '#') {
            Insert(prefix.ToString(), 1);
            prefix.Clear();
            current = root;
            return new List<string>();
        }

        prefix.Append(c);

        if (current == null || !current.Children.ContainsKey(c)) {
            current = null;
            return new List<string>();
        }

        current = current.Children[c];

        var results = new List<(int count, string sentence)>();
        Dfs(current, results);

        results.Sort();

        var output = new List<string>();
        for (int i = 0; i < Math.Min(3, results.Count); i++) {
            output.Add(results[i].sentence);
        }
        return output;
    }
}
```

```go
type TrieNode struct {
    children map[byte]*TrieNode
    sentence string
    count    int
}

type AutocompleteSystem struct {
    root    *TrieNode
    current *TrieNode
    prefix  []byte
}

func Constructor(sentences []string, times []int) AutocompleteSystem {
    root := &TrieNode{children: make(map[byte]*TrieNode)}
    sys := AutocompleteSystem{root: root, current: root}
    for i := 0; i < len(sentences); i++ {
        sys.insert(sentences[i], times[i])
    }
    return sys
}

func (as *AutocompleteSystem) insert(sentence string, count int) {
    node := as.root
    for i := 0; i < len(sentence); i++ {
        c := sentence[i]
        if node.children[c] == nil {
            node.children[c] = &TrieNode{children: make(map[byte]*TrieNode)}
        }
        node = node.children[c]
    }
    node.count += count
    node.sentence = sentence
}

func (as *AutocompleteSystem) dfs(node *TrieNode, results *[][2]interface{}) {
    if node.sentence != "" {
        *results = append(*results, [2]interface{}{-node.count, node.sentence})
    }
    for _, child := range node.children {
        as.dfs(child, results)
    }
}

func (as *AutocompleteSystem) Input(c byte) []string {
    if c == '#' {
        as.insert(string(as.prefix), 1)
        as.prefix = nil
        as.current = as.root
        return []string{}
    }

    as.prefix = append(as.prefix, c)

    if as.current == nil || as.current.children[c] == nil {
        as.current = nil
        return []string{}
    }

    as.current = as.current.children[c]

    var results [][2]interface{}
    as.dfs(as.current, &results)

    sort.Slice(results, func(i, j int) bool {
        ci := results[i][0].(int)
        cj := results[j][0].(int)
        if ci != cj {
            return ci < cj
        }
        return results[i][1].(string) < results[j][1].(string)
    })

    output := []string{}
    for i := 0; i < len(results) && i < 3; i++ {
        output = append(output, results[i][1].(string))
    }
    return output
}
```

```rust
struct TrieNode {

impl TrieNode {
    fn new() -> Self {
        Self {
            children: vec![None; 27],
            sentence: None,
            count: 0,
        }
    }
}

pub struct AutocompleteSystem {
    nodes: Vec<TrieNode>,
    current: Option<usize>,
    prefix: String,
}

impl AutocompleteSystem {
    pub fn new(sentences: Vec<String>, times: Vec<i32>) -> Self {
        let mut system = Self {
            nodes: vec![TrieNode::new()],
            current: Some(0),
            prefix: String::new(),
        };

        for i in 0..sentences.len() {
            system.insert(&sentences[i], times[i]);
        }

        system
    }

    fn char_index(c: char) -> usize {
        if c == ' ' {
            26
        } else {
            (c as u8 - b'a') as usize
        }
    }

    fn insert(&mut self, sentence: &str, count: i32) {
        let mut node = 0;
        for c in sentence.chars() {
            let idx = Self::char_index(c);
            if self.nodes[node].children[idx].is_none() {
                self.nodes[node].children[idx] = Some(self.nodes.len());
                self.nodes.push(TrieNode::new());
            }
            node = self.nodes[node].children[idx].unwrap();
        }
        self.nodes[node].count += count;
        self.nodes[node].sentence = Some(sentence.to_string());
    }

    fn dfs(&self, node: usize, results: &mut Vec<(i32, String)>) {
        if let Some(sentence) = &self.nodes[node].sentence {
            results.push((-self.nodes[node].count, sentence.clone()));
        }
        for i in 0..27 {
            if let Some(child) = self.nodes[node].children[i] {
                self.dfs(child, results);
            }
        }
    }

    pub fn input(&mut self, c: char) -> Vec<String> {
        if c == '#' {
            let sentence = self.prefix.clone();
            self.insert(&sentence, 1);
            self.prefix.clear();
            self.current = Some(0);
            return Vec::new();
        }

        self.prefix.push(c);

        if self.current.is_none() {
            return Vec::new();
        }

        let node = self.current.unwrap();
        let idx = Self::char_index(c);

        if self.nodes[node].children[idx].is_none() {
            self.current = None;
            return Vec::new();
        }

        self.current = self.nodes[node].children[idx];

        // DFS to collect all sentences from this subtree
        let mut results: Vec<(i32, String)> = Vec::new();
        self.dfs(self.current.unwrap(), &mut results);

        // Sort by count descending, then sentence alphabetically
        results.sort_by(|a, b| {
            if a.0 != b.0 {
                a.0.cmp(&b.0)
            } else {
                a.1.cmp(&b.1)
            }
        });

        let mut output = Vec::new();
        for i in 0..results.len().min(3) {
            output.push(results[i].1.clone());
        }
        output
    }
}
```

> - **Time Complexity:** O(total_chars) for construction. O(subtree_size + k log k) per `input` call, where subtree_size is the number of nodes beneath the current prefix and k is the number of matching sentences. In the worst case (single-character prefix), this is similar to brute force.
> - **Space Complexity:** O(total_chars). The Trie stores one node per character across all sentences.

The DFS still visits the entire subtree on every keystroke, and we sort all matches only to return 3 of them. The next approach stores the top 3 sentences at each node ahead of time, so a query reads the answer directly without any DFS or sorting.

<h1 id="approach-3-trie-with-pre-stored-top-3-results-optimal">
  Approach 3: Trie with Pre-stored Top-3 Results (Optimal)
</h1>

<h3 id="intuition">Intuition</h3>

Instead of collecting and sorting at query time, pre-compute the top 3 sentences at every node during insertion. Each Trie node maintains a sorted list of at most 3 sentences that share the prefix leading to that node.

When the user types a character, we move to the next node and return its stored list directly. There is no DFS, no sorting, and no collecting at query time.

The trade-off is more expensive insertion. Inserting or updating a sentence walks its entire Trie path and updates the top-3 list at every node on the way. Each update sorts at most 4 elements (the existing 3 plus the new candidate), and the path is at most the sentence length, so the insertion cost stays small.

> A node's top-3 list must hold the three best sentences in its entire subtree, not only the sentences whose path passes through it directly. Every sentence that lives in a subtree shares the prefix of that subtree's root, so its full insertion path includes that root. Because insertion updates the list at every node along the path, each ancestor of a sentence sees that sentence as a candidate. The per-node list therefore considers exactly the sentences below it, and keeping the best 3 at each step is safe: a sentence dropped from a node's list ranks below 3 others that are also in the subtree, so it can never belong in that node's answer.

<h3 id="algorithm">Algorithm</h3>

1. Build a Trie where each node stores a list of at most 3 sentences (the top 3 by frequency, then alphabetically).
2. During insertion, walk the path for the sentence. At each node, add the sentence to the top-3 list, re-sort, and trim to 3.
3. Maintain a current node pointer and prefix string.

```java
class AutocompleteSystem {
    Map<String, Integer> counts;
    Object[] children;
    List<String>[] top3;
    int nodeCount;
    int currentNode;
    StringBuilder prefix;

    @SuppressWarnings("unchecked")
    public AutocompleteSystem(String[] sentences, int[] times) {
        int maxNodes = 600000;
        counts = new HashMap<>();
        children = new Object[maxNodes];
        top3 = new List[maxNodes];
        nodeCount = 1;
        currentNode = 0;
        prefix = new StringBuilder();

        // Initialize root
        children[0] = new int[27];
        Arrays.fill((int[]) children[0], -1);
        top3[0] = new ArrayList<>();

        for (int i = 0; i < sentences.length; i++) {
            counts.put(sentences[i], times[i]);
            insertIntoTrie(sentences[i]);
        }
    }

    private int charIndex(char c) {
        return c == ' ' ? 26 : c - 'a';
    }

    private void insertIntoTrie(String sentence) {
        int node = 0;
        updateTop3(node, sentence);
        for (char c : sentence.toCharArray()) {
            int idx = charIndex(c);
            int[] ch = (int[]) children[node];
            if (ch[idx] == -1) {
                ch[idx] = nodeCount;
                children[nodeCount] = new int[27];
                Arrays.fill((int[]) children[nodeCount], -1);
                top3[nodeCount] = new ArrayList<>();
                nodeCount++;
            }
            node = ch[idx];
            updateTop3(node, sentence);
        }
    }

    private void updateTop3(int node, String sentence) {
        List<String> list = top3[node];
        list.remove(sentence);
        list.add(sentence);
        list.sort((a, b) -> {
            int countDiff = counts.get(b) - counts.get(a);
            if (countDiff != 0) return countDiff;
            return a.compareTo(b);
        });
        while (list.size() > 3) {
            list.remove(list.size() - 1);
        }
    }

    public List<String> input(char c) {
        if (c == '#') {
            String sentence = prefix.toString();
            counts.put(sentence, counts.getOrDefault(sentence, 0) + 1);
            insertIntoTrie(sentence);
            prefix = new StringBuilder();
            currentNode = 0;
            return new ArrayList<>();
        }

        prefix.append(c);
        int idx = charIndex(c);

        if (currentNode == -1) {
            return new ArrayList<>();
        }

        int[] ch = (int[]) children[currentNode];
        if (ch[idx] == -1) {
            currentNode = -1;
            return new ArrayList<>();
        }

        currentNode = ch[idx];
        return new ArrayList<>(top3[currentNode]);
    }
}
```

```go
func (as *AutocompleteSystem) updateTop3(node *TrieNode, sentence string) {
    filtered := node.top3[:0]
    for _, s := range node.top3 {
        if s != sentence {
            filtered = append(filtered, s)
        }
    }
    node.top3 = append(filtered, sentence)

    sort.Slice(node.top3, func(i, j int) bool {
        ci := as.counts[node.top3[i]]
        cj := as.counts[node.top3[j]]
        if ci != cj {
            return ci > cj
        }
        return node.top3[i] < node.top3[j]
    })

    if len(node.top3) > 3 {
        node.top3 = node.top3[:3]
    }
}

    node := as.root
    as.updateTop3(node, sentence)
    for i := 0; i < len(sentence); i++ {
        c := sentence[i]
        if node.children[c] == nil {
            node.children[c] = &TrieNode{children: make(map[byte]*TrieNode)}
        }
        node = node.children[c]
        as.updateTop3(node, sentence)
    }
}
```

```rust
use std::cmp::Ordering;
use std::collections::HashMap;

struct TrieNode {
    children: [Option<usize>; 27],
    top3: Vec<String>,
}

impl TrieNode {
    fn new() -> Self {
        Self {
            children: [None; 27],
            top3: Vec::new(),
        }
    }
}

pub struct AutocompleteSystem {
    nodes: Vec<TrieNode>,
    current: Option<usize>,
    prefix: String,
    counts: HashMap<String, i32>,
}

impl AutocompleteSystem {
    pub fn new(sentences: Vec<String>, times: Vec<i32>) -> Self {
        let mut sys = Self {
            nodes: vec![TrieNode::new()],
            current: Some(0),
            prefix: String::new(),
            counts: HashMap::new(),
        };

        for i in 0..sentences.len() {
            sys.counts.insert(sentences[i].clone(), times[i]);
            sys.insert_into_trie(&sentences[i]);
        }

        sys
    }

    fn char_index(c: char) -> usize {
        if c == ' ' {
            26
        } else {
            (c as u8 - b'a') as usize
        }
    }

    fn update_top3(&mut self, node: usize, sentence: &str) {
        // Take the list out so we can sort it without borrowing self twice.
        let mut list = std::mem::take(&mut self.nodes[node].top3);
        list.retain(|s| s != sentence);
        list.push(sentence.to_string());
        list.sort_by(|a, b| {
            let count_a = *self.counts.get(a).unwrap_or(&0);
            let count_b = *self.counts.get(b).unwrap_or(&0);
            match count_b.cmp(&count_a) {
                Ordering::Equal => a.cmp(b),
                ord => ord,
            }
        });
        list.truncate(3);
        self.nodes[node].top3 = list;
    }

    fn insert_into_trie(&mut self, sentence: &str) {
        let mut node = 0;
        self.update_top3(node, sentence);
        for c in sentence.chars() {
            let idx = Self::char_index(c);
            if self.nodes[node].children[idx].is_none() {
                self.nodes[node].children[idx] = Some(self.nodes.len());
                self.nodes.push(TrieNode::new());
            }
            node = self.nodes[node].children[idx].unwrap();
            self.update_top3(node, sentence);
        }
    }

    pub fn input(&mut self, c: char) -> Vec<String> {
        if c == '#' {
            let sentence = self.prefix.clone();
            *self.counts.entry(sentence.clone()).or_insert(0) += 1;
            self.insert_into_trie(&sentence);
            self.prefix.clear();
            self.current = Some(0);
            return Vec::new();
        }

        self.prefix.push(c);
        let idx = Self::char_index(c);

        let node = match self.current {
            Some(n) => n,
            None => return Vec::new(),
        };

        match self.nodes[node].children[idx] {
            Some(child) => {
                self.current = Some(child);
                self.nodes[child].top3.clone()
            }
            None => {
                self.current = None;
                Vec::new()
            }
        }
    }
}
```

> - **Time Complexity:** O(total_chars) for construction. O(1) per `input(c)` when c is not '#'. O(sentence_length) per `input('#')` for inserting and updating top-3 along the path. Since k=3 is constant, sorting at each node is O(1).
> - **Space Complexity:** O(total_chars). Each Trie node stores up to 3 sentence string references. The Trie itself has one node per character across all sentences.
