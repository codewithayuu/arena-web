<LessonCard>

Design a data structure to store the strings' count with the ability to return the strings with minimum and maximum counts.

Implement the `AllOne` class:

- `AllOne()` Initializes the object of the data structure.
- `inc(String key)` Increments the count of the string `key` by 1. If `key` does not exist in the data structure, insert it with count 1.
- `dec(String key)` Decrements the count of the string `key` by 1. If the count of `key` becomes 0, remove it from the data structure. It is guaranteed that `key` exists in the data structure before the decrement.
- `getMaxKey()` Returns one of the keys with the maximal count. If no element exists, return an empty string `""`.
- `getMinKey()` Returns one of the keys with the minimal count. If no element exists, return an empty string `""`.

**Note** that each function must run in `O(1)` average time complexity.

**Example 1:**

- **Input:** `operations = ["AllOne","inc","inc","getMaxKey","getMinKey","inc","getMaxKey","getMinKey"]`

- **Input:** `values = [[],["hello"],["hello"],[],[],["leet"],[],[]]`

- **Output:** `[null,null,null,"hello","hello",null,"hello","leet"]`

**Constraints:**

- `1 <= key.length <= 10`
- `key` consists of lowercase English letters.
- It is guaranteed that for each call to `dec`, `key` is existing in the data structure.
- At most `5 * 10^4` calls will be made to `inc`, `dec`, `getMaxKey`, and `getMinKey`.

We need to build a data structure that tracks how many times each string has been incremented and, at any moment, can return a string with the highest count and one with the lowest, all in O(1) time.

A hash map covers the count updates: incrementing and decrementing are constant-time map operations. Finding the min and max in O(1) is the hard part. A heap gives O(log n) insert and delete. A balanced tree needs O(log n) for rebalancing. Neither meets the requirement.

Full sorting is unnecessary, though. Only the minimum and maximum matter, and a count changes by exactly 1 per operation. When a key's count goes from c to c+1, the key moves to the neighboring position in count order; nothing else shifts. That property is what makes O(1) possible.

- `At most 5 * 10^4 calls` -- The cost that matters is per call. The problem requires O(1) average time per operation, which rules out heaps and balanced trees at O(log n).
- `key consists of lowercase English letters` -- Keys are regular strings, no special handling needed.
- `dec is only called on existing keys` -- We don't need to handle decrementing a non-existent key.

Store each key's count in a hash map. Incrementing and decrementing are O(1) map updates. For `getMaxKey` and `getMinKey`, scan all entries and return the key with the highest or lowest count.

This is correct, but every `getMaxKey` or `getMinKey` call costs O(n), which violates the O(1) requirement. It still serves as a baseline: the map already answers count updates in O(1), so the min/max query is the only operation left to fix.

<h3 id="algorithm">Algorithm</h3>

1. Maintain a hash map `counts` that maps each key to its integer count.
2. For `inc(key)`: increment `counts[key]` by 1. If the key doesn't exist, set it to 1.
3. For `dec(key)`: decrement `counts[key]` by 1. If it reaches 0, remove the key.
4. For `getMaxKey()`: iterate through all entries in the map and return the key with the highest count. Return `""` if the map is empty.
5. For `getMinKey()`: iterate through all entries and return the key with the lowest count. Return `""` if the map is empty.

```java
class AllOne {
    Map<String, Integer> counts;

    public AllOne() {
        counts = new HashMap<>();
    }

    public void inc(String key) {
        counts.put(key, counts.getOrDefault(key, 0) + 1);
    }

    public void dec(String key) {
        int newCount = counts.get(key) - 1;
        if (newCount == 0) {
            counts.remove(key);
        } else {
            counts.put(key, newCount);
        }
    }

    public String getMaxKey() {
        if (counts.isEmpty()) return "";
        String maxKey = "";
        int maxCount = 0;
        for (Map.Entry<String, Integer> entry : counts.entrySet()) {
            if (entry.getValue() > maxCount) {
                maxCount = entry.getValue();
                maxKey = entry.getKey();
            }
        }
        return maxKey;
    }

    public String getMinKey() {
        if (counts.isEmpty()) return "";
        String minKey = "";
        int minCount = Integer.MAX_VALUE;
        for (Map.Entry<String, Integer> entry : counts.entrySet()) {
            if (entry.getValue() < minCount) {
                minCount = entry.getValue();
                minKey = entry.getKey();
            }
        }
        return minKey;
    }
}
```

> - **Time Complexity:** O(1) for `inc` and `dec`, O(n) for `getMaxKey` and `getMinKey`. Hash map operations are O(1), but finding min/max requires scanning all n keys.
> - **Space Complexity:** O(n). One hash map entry per unique key.

Every call to `getMaxKey` or `getMinKey` scans the entire hash map, recomputing the answer from scratch even though the last `inc` or `dec` changed one key's count by 1. The next approach keeps keys grouped by count in sorted order, so the current min and max always sit at the two ends of a list.

<h1 id="approach-2-doubly-linked-list-of-count-buckets-optimal">
  Approach 2: Doubly-Linked List of Count Buckets (Optimal)
</h1>

<h3 id="intuition">Intuition</h3>

A count moves from c to c+1 or from c to c-1, never anywhere else. A fully sorted structure is overkill; a key only ever needs to move between adjacent "count buckets."

The structure is a doubly-linked list where each node represents one count value and holds the set of keys that currently have that count. The list stays sorted by count, smallest at the head and largest at the tail. `getMinKey` reads the node next to the head, `getMaxKey` reads the node next to the tail, both O(1).

Incrementing a key from count c to c+1 removes it from bucket c and adds it to bucket c+1. If bucket c+1 does not exist, we create a new node right after bucket c, an O(1) insertion in a doubly-linked list. If bucket c becomes empty after the removal, we splice that node out, also O(1).

A hash map from each key to its bucket node locates the key's current bucket without searching. Every operation is then a hash map lookup plus an O(1) list splice plus an O(1) set update.

> The list stays sorted by count even though no operation ever compares more than two neighbors. Assume the list is sorted before an operation. When a key moves from bucket c to c+1 and no c+1 bucket exists, the node after bucket c holds a count greater than c (sorted order) and not equal to c+1 (the code checked), so it is at least c+2. Inserting the new c+1 bucket directly after bucket c therefore preserves the order. The symmetric argument covers `dec`, which inserts a c-1 bucket directly before bucket c. The sentinels (count 0 at the head, infinity at the tail) guarantee every real bucket has a neighbor on both sides, so the same insertion logic works at the ends of the list.

1. Create a doubly-linked list with sentinel head and tail nodes (count 0 and infinity). This avoids null checks.
2. Maintain a hash map `keyToNode` that maps each key to its current bucket node in the linked list.

5. For `getMaxKey()`: return any key from the node right before the tail sentinel.

```java
class AllOne {
    // Each node holds a count and all keys with that count
    class Node {
        int count;
        Set<String> keys;
        Node prev, next;
        Node(int count) {
            this.count = count;
            this.keys = new LinkedHashSet<>();
        }
    }

    Node head, tail;
    Map<String, Node> keyToNode;

    public AllOne() {
        // Sentinel nodes to avoid null checks
        head = new Node(0);
        tail = new Node(Integer.MAX_VALUE);
        head.next = tail;
        tail.prev = head;
        keyToNode = new HashMap<>();
    }

    // Insert a new node right after the given node
    private Node insertAfter(Node prevNode, int count) {
        Node newNode = new Node(count);
        newNode.prev = prevNode;
        newNode.next = prevNode.next;
        prevNode.next.prev = newNode;
        prevNode.next = newNode;
        return newNode;
    }

    // Remove a node from the linked list
    private void removeNode(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    public void inc(String key) {
        if (!keyToNode.containsKey(key)) {
            // New key, needs to go into count-1 bucket
            Node firstNode = head.next;
            if (firstNode.count != 1) {
                firstNode = insertAfter(head, 1);
            }
            firstNode.keys.add(key);
            keyToNode.put(key, firstNode);
        } else {
            // Existing key, move from count c to count c+1
            Node curr = keyToNode.get(key);
            int newCount = curr.count + 1;
            Node nextNode = curr.next;
            if (nextNode.count != newCount) {
                nextNode = insertAfter(curr, newCount);
            }
            nextNode.keys.add(key);
            keyToNode.put(key, nextNode);
            // Remove from old bucket
            curr.keys.remove(key);
            if (curr.keys.isEmpty()) {
                removeNode(curr);
            }
        }
    }

    public void dec(String key) {
        Node curr = keyToNode.get(key);
        int newCount = curr.count - 1;

        if (newCount == 0) {
            // Remove the key entirely
            keyToNode.remove(key);
        } else {
            // Move to count c-1 bucket
            Node prevNode = curr.prev;
            if (prevNode.count != newCount) {
                prevNode = insertAfter(curr.prev, newCount);
            }
            prevNode.keys.add(key);
            keyToNode.put(key, prevNode);
        }

        // Remove from old bucket
        curr.keys.remove(key);
        if (curr.keys.isEmpty()) {
            removeNode(curr);
        }
    }

    public String getMaxKey() {
        if (tail.prev == head) return "";
        return tail.prev.keys.iterator().next();
    }

    public String getMinKey() {
        if (head.next == tail) return "";
        return head.next.keys.iterator().next();
    }
}
```

```python
class Node:
    def __init__(self, count):
        self.count = count
        self.keys = set()
        self.prev = None
        self.next = None

class AllOne:
    def __init__(self):
        # Sentinel nodes to avoid null checks
        self.head = Node(0)
        self.tail = Node(float('inf'))
        self.head.next = self.tail
        self.tail.prev = self.head
        self.key_to_node = {}

    def _insert_after(self, prev_node, count):
        # Insert a new node right after prev_node
        new_node = Node(count)
        new_node.prev = prev_node
        new_node.next = prev_node.next
        prev_node.next.prev = new_node
        prev_node.next = new_node
        return new_node

    def _remove_node(self, node):
        # Remove a node from the linked list
        node.prev.next = node.next
        node.next.prev = node.prev

    def inc(self, key: str) -> None:
        if key not in self.key_to_node:
            # New key, needs to go into count-1 bucket
            first_node = self.head.next
            if first_node.count != 1:
                first_node = self._insert_after(self.head, 1)
            first_node.keys.add(key)
            self.key_to_node[key] = first_node
        else:
            # Existing key, move from count c to count c+1
            curr = self.key_to_node[key]
            new_count = curr.count + 1
            next_node = curr.next
            if next_node.count != new_count:
                next_node = self._insert_after(curr, new_count)
            next_node.keys.add(key)
            self.key_to_node[key] = next_node
            # Remove from old bucket
            curr.keys.remove(key)
            if not curr.keys:
                self._remove_node(curr)

    def dec(self, key: str) -> None:
        curr = self.key_to_node[key]
        new_count = curr.count - 1

        if new_count == 0:
            # Remove the key entirely
            del self.key_to_node[key]
        else:
            # Move to count c-1 bucket
            prev_node = curr.prev
            if prev_node.count != new_count:
                prev_node = self._insert_after(curr.prev, new_count)
            prev_node.keys.add(key)
            self.key_to_node[key] = prev_node

        # Remove from old bucket
        curr.keys.remove(key)
        if not curr.keys:
            self._remove_node(curr)

    def getMaxKey(self) -> str:
        if self.tail.prev == self.head:
            return ""
        return next(iter(self.tail.prev.keys))

    def getMinKey(self) -> str:
        if self.head.next == self.tail:
            return ""
        return next(iter(self.head.next.keys))
```

```cpp
    struct Node {

        Node* prev;
        Node* next;

    Node* tail;

        Node* newNode = new Node(count);
        newNode->prev = prevNode;
        newNode->next = prevNode->next;
        prevNode->next->prev = newNode;
        prevNode->next = newNode;
        return newNode;
    }

    // Remove a node from the linked list
    void removeNode(Node* node) {
        node->prev->next = node->next;
        node->next->prev = node->prev;
        delete node;
    }

public:
    AllOne() {
        // Sentinel nodes to avoid null checks
        head = new Node(0);
        tail = new Node(INT_MAX);
        head->next = tail;
        tail->prev = head;
    }

    void inc(string key) {
        if (keyToNode.find(key) == keyToNode.end()) {
```

```csharp
            if (firstNode.Count != 1) {
                firstNode = InsertAfter(head, 1);
            }
            firstNode.Keys.Add(key);
            keyToNode[key] = firstNode;
        } else {
            // Existing key, move from count c to count c+1
            Node curr = keyToNode[key];
            int newCount = curr.Count + 1;
            Node nextNode = curr.Next;
            if (nextNode.Count != newCount) {
                nextNode = InsertAfter(curr, newCount);
            }
            nextNode.Keys.Add(key);
            keyToNode[key] = nextNode;
            // Remove from old bucket
            curr.Keys.Remove(key);
            if (curr.Keys.Count == 0) {
                RemoveNode(curr);
            }
        }
    }

    public void Dec(string key) {
        Node curr = keyToNode[key];
        int newCount = curr.Count - 1;

        if (newCount == 0) {
            // Remove the key entirely
            keyToNode.Remove(key);
        } else {
            // Move to count c-1 bucket
            Node prevNode = curr.Prev;
            if (prevNode.Count != newCount) {
                prevNode = InsertAfter(curr.Prev, newCount);
            }
            prevNode.Keys.Add(key);
            keyToNode[key] = prevNode;
        }

        // Remove from old bucket
        curr.Keys.Remove(key);
        if (curr.Keys.Count == 0) {
            RemoveNode(curr);
        }
    }

    public string GetMaxKey() {
        if (tail.Prev == head) return "";
        var enumerator = tail.Prev.Keys.GetEnumerator();
        enumerator.MoveNext();
        return enumerator.Current;
    }

    public string GetMinKey() {
        if (head.Next == tail) return "";
        var enumerator = head.Next.Keys.GetEnumerator();
        enumerator.MoveNext();
        return enumerator.Current;
    }
}
```

```rust
use std::collections::{HashMap, HashSet};

struct Node {
    count: i32,
    keys: HashSet<String>,
    prev: *mut Node,
    next: *mut Node,
}

pub struct AllOne {
    head: *mut Node,
    tail: *mut Node,
    key_to_node: HashMap<String, *mut Node>,
}

impl AllOne {
    pub fn new() -> Self {
        // Sentinel nodes to avoid null checks
        let head = Box::into_raw(Box::new(Node {
            count: 0,
            keys: HashSet::new(),
            prev: std::ptr::null_mut(),
            next: std::ptr::null_mut(),
        }));
        let tail = Box::into_raw(Box::new(Node {
            count: i32::MAX,
            keys: HashSet::new(),
            prev: head,
            next: std::ptr::null_mut(),
        }));
        unsafe {
            (*head).next = tail;
        }
        Self {
            head,
            tail,
            key_to_node: HashMap::new(),
        }
    }

    // Insert a new node right after the given node
    unsafe fn insert_after(&mut self, prev_node: *mut Node, count: i32) -> *mut Node {
        let new_node = Box::into_raw(Box::new(Node {
            count,
            keys: HashSet::new(),
            prev: prev_node,
            next: (*prev_node).next,
        }));
        (*(*prev_node).next).prev = new_node;
        (*prev_node).next = new_node;
        new_node
    }

    // Remove a node from the linked list
    unsafe fn remove_node(&mut self, node: *mut Node) {
        (*(*node).prev).next = (*node).next;
        (*(*node).next).prev = (*node).prev;
        drop(Box::from_raw(node));
    }

    pub fn inc(&mut self, key: String) {
        if !self.key_to_node.contains_key(&key) {
            // New key, needs to go into count-1 bucket
            unsafe {
                let mut first_node = (*self.head).next;
                if (*first_node).count != 1 {
                    first_node = self.insert_after(self.head, 1);
                }
                (*first_node).keys.insert(key.clone());
                self.key_to_node.insert(key, first_node);
            }
        } else {
            // Existing key, move from count c to count c+1
            unsafe {
                let curr = *self.key_to_node.get(&key).unwrap();
                let new_count = (*curr).count + 1;
                let mut next_node = (*curr).next;
                if (*next_node).count != new_count {
                    next_node = self.insert_after(curr, new_count);
                }
                (*next_node).keys.insert(key.clone());
                self.key_to_node.insert(key.clone(), next_node);
                // Remove from old bucket
                (*curr).keys.remove(&key);
                if (*curr).keys.is_empty() {
                    self.remove_node(curr);
                }
            }
        }
    }

    pub fn dec(&mut self, key: String) {
        unsafe {
            let curr = *self.key_to_node.get(&key).unwrap();
            let new_count = (*curr).count - 1;

            if new_count == 0 {
                // Remove the key entirely
                self.key_to_node.remove(&key);
            } else {
                // Move to count c-1 bucket
                let mut prev_node = (*curr).prev;
                if (*prev_node).count != new_count {
                    prev_node = self.insert_after((*curr).prev, new_count);
                }
                (*prev_node).keys.insert(key.clone());
                self.key_to_node.insert(key.clone(), prev_node);
            }

            // Remove from old bucket
            (*curr).keys.remove(&key);
            if (*curr).keys.is_empty() {
                self.remove_node(curr);
            }
        }
    }

    pub fn get_max_key(&self) -> String {
        unsafe {
            if (*self.tail).prev == self.head {
                return String::new();
            }
            (*(*self.tail).prev).keys.iter().next().unwrap().clone()
        }
    }

    pub fn get_min_key(&self) -> String {
        unsafe {
            if (*self.head).next == self.tail {
                return String::new();
            }
            (*(*self.head).next).keys.iter().next().unwrap().clone()
        }
    }
}

impl Drop for AllOne {
    fn drop(&mut self) {
        unsafe {
            let mut curr = (*self.head).next;
            while curr != self.tail {
                let next = (*curr).next;
                drop(Box::from_raw(curr));
                curr = next;
            }
            drop(Box::from_raw(self.head));
            drop(Box::from_raw(self.tail));
        }
    }
}
```

```typescript
class ListNode {
  count: number;
  keys: Set<string>;
  prev: ListNode | null;
  next: ListNode | null;
  constructor(count: number) {
    this.count = count;
    this.keys = new Set();
    this.prev = null;
    this.next = null;
  }
}

class AllOne {
  head: ListNode;
  tail: ListNode;
  keyToNode: Map<string, ListNode>;

  constructor() {
    // Sentinel nodes to avoid null checks
    this.head = new ListNode(0);
    this.tail = new ListNode(Infinity);
    this.head.next = this.tail;
    this.tail.prev = this.head;
    this.keyToNode = new Map();
  }

  // Insert a new node right after prevNode
  private insertAfter(prevNode: ListNode, count: number): ListNode {
    const newNode = new ListNode(count);
    newNode.prev = prevNode;
    newNode.next = prevNode.next;
    prevNode.next!.prev = newNode;
    prevNode.next = newNode;
    return newNode;
  }

  // Remove a node from the linked list
  private removeNode(node: ListNode): void {
    node.prev!.next = node.next;
    node.next!.prev = node.prev;
  }

  inc(key: string): void {
    if (!this.keyToNode.has(key)) {
      // New key, needs to go into count-1 bucket
      let firstNode = this.head.next!;
      if (firstNode.count !== 1) {
        firstNode = this.insertAfter(this.head, 1);
      }
      firstNode.keys.add(key);
      this.keyToNode.set(key, firstNode);
    } else {
      // Existing key, move from count c to count c+1
      const curr = this.keyToNode.get(key)!;
      const newCount = curr.count + 1;
      let nextNode = curr.next!;
      if (nextNode.count !== newCount) {
        nextNode = this.insertAfter(curr, newCount);
      }
      nextNode.keys.add(key);
      this.keyToNode.set(key, nextNode);
      // Remove from old bucket
      curr.keys.delete(key);
      if (curr.keys.size === 0) {
        this.removeNode(curr);
      }
    }
  }

  dec(key: string): void {
    const curr = this.keyToNode.get(key)!;
    const newCount = curr.count - 1;

    if (newCount === 0) {
      // Remove the key entirely
      this.keyToNode.delete(key);
    } else {
      // Move to count c-1 bucket
      let prevNode = curr.prev!;
      if (prevNode.count !== newCount) {
        prevNode = this.insertAfter(curr.prev!, newCount);
      }
      prevNode.keys.add(key);
      this.keyToNode.set(key, prevNode);
    }

    // Remove from old bucket
    curr.keys.delete(key);
    if (curr.keys.size === 0) {
      this.removeNode(curr);
    }
  }

  getMaxKey(): string {
    if (this.tail.prev === this.head) return "";
    return this.tail.prev!.keys.values().next().value;
  }

  getMinKey(): string {
    if (this.head.next === this.tail) return "";
    return this.head.next!.keys.values().next().value;
  }
}
```

> - **Time Complexity:** O(1) for all operations. `inc` and `dec` each do a hash map lookup O(1), linked list insert/delete O(1), and set add/remove O(1). `getMaxKey` accesses tail.prev and gets any element from its set, O(1). `getMinKey` accesses head.next similarly, O(1).
> - **Space Complexity:** O(n), where n is the number of unique keys. The hash map stores n entries. The linked list has at most n nodes (one per distinct count value). Each key appears in exactly one bucket's set.
