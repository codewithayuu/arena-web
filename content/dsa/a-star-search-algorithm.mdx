<LessonCard>

A\* is widely used in GPS navigation, game pathfinding, and robotics motion planning, anywhere a single shortest path needs to be computed quickly between a known start and a known goal.

<h2 id="what-is-a-search">What Is A* Search?</h2>

A\* (pronounced "A-star") is a **best-first search algorithm** that finds the shortest path between a start node and a goal node. It combines two pieces of information for each node:

- **g(n):** The actual cost from the start node to node n (what we have already paid)
- **h(n):** A heuristic estimate of the cost from node n to the goal (what we expect to pay)

The algorithm uses their sum:

**f(n) = g(n) + h(n)**

At every step, A\* picks the node with the lowest f(n) value. This favors nodes that are both cheap to reach (low g) and close to the goal (low h). The result is a search that gravitates toward the destination instead of spreading in all directions.

The diagram below compares the two approaches for a path from node S to node G. Dijkstra explores uniformly, while A\* focuses toward the goal.

Dijkstra expands many nodes it does not need. A\* uses the heuristic to skip unpromising directions and reach the goal faster, while still guaranteeing the optimal path as long as the heuristic is admissible (never overestimates the true cost to the goal).

<h2 id="the-key-insight-heuristics">The Key Insight: Heuristics</h2>

The heuristic h(n) is what differentiates A\* from Dijkstra. A poorly chosen heuristic can produce incorrect results or no speedup at all, so two properties matter: admissibility and consistency.

<h3 id="admissibility">Admissibility</h3>

A heuristic is **admissible** if it never overestimates the true cost to reach the goal.

The heuristic can be optimistic (underestimate) or exactly right, but it must never say "it will cost 10" when the real cost is 5. Overestimating can cause A\* to skip the optimal path in favor of a suboptimal one that looked cheaper.

Why does admissibility guarantee optimality? Because if h(n) never overestimates, then f(n) = g(n) + h(n) never overestimates the total cost through n. So the first time A* reaches the goal, it is guaranteed to have found the cheapest path. If h overestimated somewhere, A* might have avoided a node on the true shortest path, thinking it was too expensive.

<h3 id="consistency-monotonicity">Consistency (Monotonicity)</h3>

A heuristic is **consistent** if for every node n and every neighbor n' reached via edge cost c(n, n'):

**h(n) &lt;= c(n, n') + h(n')**

This is the triangle inequality. It means the estimated cost from n should not exceed the cost of stepping to a neighbor plus the estimate from that neighbor. Consistency is a stronger condition than admissibility. Every consistent heuristic is admissible, but not every admissible heuristic is consistent.

Why does consistency matter? With a consistent heuristic, once A* expands (closes) a node, it has already found the shortest path to that node. You never need to re-open a closed node. This simplifies the implementation and makes A* more efficient.

<h2 id="how-a-works">How A* Works</h2>

The algorithm maintains two collections:

- **Open set:** Nodes discovered but not yet fully explored. Implemented as a priority queue sorted by f(n), so the most promising node is always pulled next.
- **Closed set:** Nodes that have been fully explored. We have already found the shortest path to these nodes and processed all their neighbors.

Here is the step-by-step process:

1. Add the start node to the open set with g = 0 and h = heuristic(start, goal).
2. While the open set is not empty:
3. If the open set is empty and we never reached the goal, no path exists.

**Path reconstruction** works by keeping a `parent` map. Every time we update a node's best path, we record which node we came from. Once we reach the goal, we follow parent pointers backward from goal to start to get the full path.

- Neighbors: (0,0) closed, (0,2), (1,1) is obstacle
- (0,2): g=2, h=|0-3|+|2-3|=4, f=6
- Open: &#123;(1,0) f=6, (0,2) f=6&#125;
- Closed: &#123;(0,0), (0,1)&#125;

**Step 3:** Expand (1,0), f=6

- Neighbors: (0,0) closed, (2,0)
- (2,0): g=2, h=|2-3|+|0-3|=4, f=6
- Open: &#123;(0,2) f=6, (2,0) f=6&#125;
- Closed: &#123;(0,0), (0,1), (1,0)&#125;

**Step 4:** Expand (0,2), f=6

- Neighbors: (0,1) closed, (0,3), (1,2)
- (0,3): g=3, h=|0-3|+|3-3|=3, f=6
- (1,2): g=3, h=|1-3|+|2-3|=3, f=6
- Open: &#123;(2,0) f=6, (0,3) f=6, (1,2) f=6&#125;
- Closed: &#123;(0,0), (0,1), (1,0), (0,2)&#125;

**Step 5:** Expand (0,3), f=6

- Neighbors: (0,2) closed, (1,3)
- (1,3): g=4, h=|1-3|+|3-3|=2, f=6
- Open: &#123;(2,0) f=6, (1,2) f=6, (1,3) f=6&#125;

**Step 6:** Expand (1,2), f=6

- Neighbors: (0,2) closed, (2,2)
- (2,2): g=4, h=|2-3|+|2-3|=2, f=6

**Step 7:** Expand (1,3), f=6

- Neighbors: (0,3) closed, (2,3)
- (2,3): g=5, h=|2-3|+|3-3|=1, f=6

**Step 8:** Expand (2,2), f=6

- Neighbors: (1,2) closed, (2,3) already has g=5 (same), (3,2)
- (3,2): g=5, h=|3-3|+|2-3|=1, f=6

**Step 9:** Expand (2,3), f=6

- Neighbor: (3,3) is the goal!
- (3,3): g=6, h=0, f=6
- Goal reached.

**Path:** (0,0) -> (0,1) -> (0,2) -> (0,3) -> (1,3) -> (2,3) -> (3,3), cost = 6.

Every expanded node had f=6 because the optimal path length equals the Manhattan distance from start to goal (the obstacles do not lengthen the path here, since a route around them has the same length). When obstacles force a detour, f values increase, and A\* focuses on the nodes with lower f.

<h2 id="implementation">Implementation</h2>

Here is a complete implementation of A\* for a weighted graph using an adjacency list. The graph has nodes identified by integers, and edges have associated costs.

```java
import java.util.*;

public class AStar {

    static class Edge {
        int to;
        double cost;

        Edge(int to, double cost) {
            this.to = to;
            this.cost = cost;
        }
    }

    static class Node implements Comparable<Node> {
        int id;
        double f; // g + h

        Node(int id, double f) {
            this.id = id;
            this.f = f;
        }

        public int compareTo(Node other) {
            return Double.compare(this.f, other.f);
        }
    }

    /**
     * Runs A* search from start to goal.
     * heuristic[i] = estimated cost from node i to goal.
     * Returns the shortest path as a list of node IDs, or empty list if no path.
     */
    public static List<Integer> aStarSearch(
            List<List<Edge>> graph, int start, int goal, double[] heuristic) {

        int n = graph.size();
        double[] gScore = new double[n];
        Arrays.fill(gScore, Double.MAX_VALUE);
        gScore[start] = 0;

        int[] parent = new int[n];
        Arrays.fill(parent, -1);

        boolean[] closed = new boolean[n];

        PriorityQueue<Node> openSet = new PriorityQueue<>();
        openSet.add(new Node(start, heuristic[start]));

        while (!openSet.isEmpty()) {
            Node current = openSet.poll();

            if (current.id == goal) {
                return reconstructPath(parent, goal);
            }

            if (closed[current.id]) {
                continue; // Already processed with a better path
            }
            closed[current.id] = true;

            for (Edge edge : graph.get(current.id)) {
                if (closed[edge.to]) {
                    continue;
                }

                double tentativeG = gScore[current.id] + edge.cost;

                if (tentativeG < gScore[edge.to]) {
                    gScore[edge.to] = tentativeG;
                    parent[edge.to] = current.id;
                    double f = tentativeG + heuristic[edge.to];
                    openSet.add(new Node(edge.to, f));
                }
            }
        }

        return Collections.emptyList(); // No path found
    }

    private static List<Integer> reconstructPath(int[] parent, int goal) {
        List<Integer> path = new ArrayList<>();
        for (int node = goal; node != -1; node = parent[node]) {
            path.add(node);
        }
        Collections.reverse(path);
        return path;
    }
}
```

```python
import heapq
from typing import List, Tuple

def a_star_search(
    graph: List[List[Tuple[int, float]]],
    start: int,
    goal: int,
    heuristic: List[float]
) -> List[int]:
    """
    Runs A* search from start to goal.
    graph[u] = list of (v, cost) edges from node u.
    heuristic[i] = estimated cost from node i to goal.
    Returns the shortest path as a list of node IDs, or empty list if no path.
    """
    n = len(graph)
    g_score = [float('inf')] * n
    g_score[start] = 0

    parent = [-1] * n
    closed = [False] * n

    # Priority queue entries: (f, node_id)
    open_set: List[Tuple[float, int]] = []
    heapq.heappush(open_set, (heuristic[start], start))

    while open_set:
        f, current = heapq.heappop(open_set)

        if current == goal:
            return _reconstruct_path(parent, goal)

        if closed[current]:
            continue  # Already processed with a better path
        closed[current] = True

        for neighbor, cost in graph[current]:
            if closed[neighbor]:
                continue

            tentative_g = g_score[current] + cost

            if tentative_g < g_score[neighbor]:
                g_score[neighbor] = tentative_g
                parent[neighbor] = current
                f = tentative_g + heuristic[neighbor]
                heapq.heappush(open_set, (f, neighbor))

    return []  # No path found

def _reconstruct_path(parent: List[int], goal: int) -> List[int]:
    path = []
    node = goal
    while node != -1:
        path.append(node)
        node = parent[node]
    path.reverse()
    return path
```

```go
package main

import (
	"container/heap"
	"math"
)

type Edge struct {
	To   int
	Cost float64
}

type Node struct {
	ID int
	F  float64 // g + h
}

type MinHeap []Node

func (h MinHeap) Len() int            { return len(h) }
func (h MinHeap) Less(i, j int) bool   { return h[i].F < h[j].F }
func (h MinHeap) Swap(i, j int)        { h[i], h[j] = h[j], h[i] }
func (h *MinHeap) Push(x interface{})  { *h = append(*h, x.(Node)) }
func (h *MinHeap) Pop() interface{} {
	old := *h
	n := len(old)
	x := old[n-1]
	*h = old[:n-1]
	return x
}

// AStarSearch runs A* from start to goal.
// heuristic[i] = estimated cost from node i to goal.
// Returns the shortest path as a slice of node IDs, or nil if no path.
func AStarSearch(graph [][]Edge, start, goal int, heuristic []float64) []int {
	n := len(graph)
	gScore := make([]float64, n)
	for i := range gScore {
		gScore[i] = math.MaxFloat64
	}
	gScore[start] = 0

	parent := make([]int, n)
	for i := range parent {
		parent[i] = -1
	}

	closed := make([]bool, n)

	openSet := &MinHeap{}
	heap.Init(openSet)
	heap.Push(openSet, Node{ID: start, F: heuristic[start]})

	for openSet.Len() > 0 {
		current := heap.Pop(openSet).(Node)

		if current.ID == goal {
			return reconstructPath(parent, goal)
		}

		if closed[current.ID] {
			continue // Already processed with a better path
		}
		closed[current.ID] = true

		for _, edge := range graph[current.ID] {
			if closed[edge.To] {
				continue
			}

			tentativeG := gScore[current.ID] + edge.Cost

			if tentativeG < gScore[edge.To] {
				gScore[edge.To] = tentativeG
				parent[edge.To] = current.ID
				f := tentativeG + heuristic[edge.To]
				heap.Push(openSet, Node{ID: edge.To, F: f})
			}
		}
	}

	return nil // No path found
}

func reconstructPath(parent []int, goal int) []int {
	var path []int
	for node := goal; node != -1; node = parent[node] {
		path = append(path, node)
	}
	// Reverse
	for i, j := 0, len(path)-1; i < j; i, j = i+1, j-1 {
		path[i], path[j] = path[j], path[i]
	}
	return path
}
```

```rust
            .then_with(|| other.id.cmp(&self.id))
```

```javascript
class MinHeap {
  constructor() {
    this.data = [];
  }

  push(node) {
    this.data.push(node);
    this._bubbleUp(this.data.length - 1);
  }

  pop() {
    const top = this.data[0];
    const last = this.data.pop();
    if (this.data.length > 0) {
      this.data[0] = last;
      this._sinkDown(0);
    }
    return top;
  }

  get size() {
    return this.data.length;
  }

  _bubbleUp(i) {
    while (i > 0) {
      const parent = (i - 1) >> 1;
      if (this.data[i].f >= this.data[parent].f) break;
      [this.data[i], this.data[parent]] = [this.data[parent], this.data[i]];
      i = parent;
    }
  }

  _sinkDown(i) {
    const n = this.data.length;
    while (true) {
      let smallest = i;
      const left = 2 * i + 1;
      const right = 2 * i + 2;
      if (left < n && this.data[left].f < this.data[smallest].f)
        smallest = left;
      if (right < n && this.data[right].f < this.data[smallest].f)
        smallest = right;
      if (smallest === i) break;
      [this.data[i], this.data[smallest]] = [this.data[smallest], this.data[i]];
      i = smallest;
    }
  }
}

  gScore[start] = 0;

  const parent = new Array(n).fill(-1);
  const closed = new Array(n).fill(false);

      return reconstructPath(parent, goal);
    }

      continue; // Already processed with a better path
    }
    closed[current.id] = true;

    for (const edge of graph[current.id]) {

        gScore[edge.to] = tentativeG;
        parent[edge.to] = current.id;
        const f = tentativeG + heuristic[edge.to];
        openSet.push({ id: edge.to, f });
      }
    }
  }

  return []; // No path found
}

  const path = [];
```

```typescript
interface Edge {

  cost: number;

interface HeapNode {
  id: number;
  f: number;
}

class MinHeap {
  private data: HeapNode[] = [];

  push(node: HeapNode): void {
    this.data.push(node);
    this.bubbleUp(this.data.length - 1);
  }

  pop(): HeapNode {
    const top = this.data[0];
    const last = this.data.pop()!;
    if (this.data.length > 0) {
      this.data[0] = last;
      this.sinkDown(0);
    }
    return top;
  }

  get size(): number {
    return this.data.length;
  }

  private bubbleUp(i: number): void {
    while (i > 0) {
      const parent = (i - 1) >> 1;
      if (this.data[i].f >= this.data[parent].f) break;
      [this.data[i], this.data[parent]] = [this.data[parent], this.data[i]];
      i = parent;
    }
  }

  private sinkDown(i: number): void {
    const n = this.data.length;
    while (true) {
      let smallest = i;
      const left = 2 * i + 1;
      const right = 2 * i + 2;
      if (left < n && this.data[left].f < this.data[smallest].f)
        smallest = left;
      if (right < n && this.data[right].f < this.data[smallest].f)
        smallest = right;
      if (smallest === i) break;
      [this.data[i], this.data[smallest]] = [this.data[smallest], this.data[i]];
      i = smallest;
    }
  }
}

/**
 * Runs A* search from start to goal.
 * graph[u] = array of Edge from node u.
 * heuristic[i] = estimated cost from node i to goal.
 * Returns the shortest path as an array of node IDs, or empty array if no path.
 */
function aStarSearch(
  graph: Edge[][],
  start: number,
  goal: number,
  heuristic: number[],
): number[] {
  const n = graph.length;
  const gScore: number[] = new Array(n).fill(Infinity);
  gScore[start] = 0;

  const parent: number[] = new Array(n).fill(-1);
  const closed: boolean[] = new Array(n).fill(false);

  const openSet = new MinHeap();
  openSet.push({ id: start, f: heuristic[start] });

  while (openSet.size > 0) {
    const current = openSet.pop();

    if (current.id === goal) {
      return reconstructPath(parent, goal);
    }

    if (closed[current.id]) {
      continue; // Already processed with a better path
    }
    closed[current.id] = true;

    for (const edge of graph[current.id]) {
      if (closed[edge.to]) {
        continue;
      }

      const tentativeG = gScore[current.id] + edge.cost;

      if (tentativeG < gScore[edge.to]) {
        gScore[edge.to] = tentativeG;
        parent[edge.to] = current.id;
        const f = tentativeG + heuristic[edge.to];
        openSet.push({ id: edge.to, f });
      }
    }
  }

  return []; // No path found
}

function reconstructPath(parent: number[], goal: number): number[] {
  const path: number[] = [];
  for (let node = goal; node !== -1; node = parent[node]) {
    path.push(node);
  }
  path.reverse();
  return path;
}
```

- We use a **lazy deletion** approach for the priority queue. Instead of updating priorities (which most standard priority queues do not support efficiently), we add a new entry with the updated f value. When we poll a node that is already closed, we skip it. This is simpler than maintaining a decrease-key operation on the queue.
- The `closed` array (or set) serves as our closed set. Once a node is marked closed, we never process it again (valid because we assume a consistent heuristic).
- Path reconstruction walks backward from the goal using the `parent` array.

<h2 id="a-vs-dijkstra">A* vs Dijkstra</h2>

Dijkstra's algorithm is A\* with h(n) = 0 for every node. Without a heuristic, f(n) = g(n), so Dijkstra always expands the node with the lowest actual cost from the source. It explores in concentric "rings" of increasing distance, which is correct but wasteful when you have a specific destination.

<h2 id="complexity-analysis">Complexity Analysis</h2>

<h3 id="time-complexity">Time Complexity</h3>

The worst case is O((V + E) log V) with a binary-heap priority queue, the same bound as Dijkstra, since A* with h(n) = 0 reduces to Dijkstra. A more precise characterization is that the running time depends on the quality of the heuristic. The number of nodes A* expands can be exponential in the worst case, but it stays far smaller with an accurate, admissible heuristic, which is why A\* usually explores many fewer nodes than Dijkstra on the same graph.

<h3 id="space-complexity">Space Complexity</h3>

A* needs O(V) space to store the g, f, and parent information for each node, plus the open and closed sets. The main practical limitation of A* is memory, because the open set can hold a large fraction of the graph's nodes before the goal is reached.

<h2 id="key-takeaways">Key Takeaways</h2>

- A\* is a best-first search that always expands the frontier node with the lowest f(n) = g(n) + h(n), where g(n) is the actual cost from the start and h(n) is a heuristic estimate of the remaining cost to the goal.
- A* generalizes Dijkstra's algorithm, which is the special case where h(n) = 0; the heuristic is what steers A* toward the goal instead of expanding uniformly in all directions.
- A\* returns the optimal path when the heuristic is admissible, meaning it never overestimates the true cost to the goal.
- When the heuristic is consistent, satisfying h(n) &lt;= c(n, n') + h(n') for every edge, A\* never needs to reopen a closed node because it has already found the shortest path to each node when it closes it.
- On 2D grids, Manhattan distance fits 4-directional movement and Euclidean distance fits any-angle movement, and both stay admissible for their respective movement types.
- A\* has a worst-case time complexity of O((V + E) log V), the same as Dijkstra, but a good heuristic usually makes it explore far fewer nodes in practice.
