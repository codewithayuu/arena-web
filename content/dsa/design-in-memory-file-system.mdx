<LessonCard>

Design a data structure that simulates an in-memory file system.

Implement the `FileSystem` class:

- `FileSystem()` Initializes the object of the system.
- `List<String> ls(String path)` If `path` is a file path, returns a list that only contains this file's name. If `path` is a directory path, returns the list of file and directory names in this directory. The answer should be in **lexicographic order**.
- `void mkdir(String path)` Makes a new directory according to the given path. The given directory path does not exist. If the middle directories in the path do not exist, you should create them as well.
- `void addContentToFile(String filePath, String content)` If `filePath` does not exist, creates that file containing given `content`. If `filePath` already exists, appends the given `content` to original content.
- `String readContentFromFile(String filePath)` Returns the content in the file at `filePath`.

\***\*Example 1:\*\***

- **Input:** `operations = ["FileSystem", "ls", "mkdir", "addContentToFile", "ls", "readContentFromFile"]`

- **Input:** `arguments = [[], ["/"], ["/a/b/c"], ["/a/b/c/d", "hello"], ["/"], ["/a/b/c/d"]]`

- **Output:** `[null, [], null, null, ["a"], "hello"]`

**Explanation:**

- `FileSystem fileSystem = new FileSystem();`
- `fileSystem.ls("/");` // return []
- `fileSystem.mkdir("/a/b/c");`
- `fileSystem.addContentToFile("/a/b/c/d", "hello");`
- `fileSystem.ls("/");` // return ["a"]
- `fileSystem.readContentFromFile("/a/b/c/d");` // return "hello"

\***\*Constraints:\*\***

- `1 <= path.length, filePath.length <= 200`
- `1 <= content.length <= 30`
- At most `300` calls will be made to `ls`, `mkdir`, `addContentToFile`, and `readContentFromFile`.
- `path`, `filePath`, and `content` only consist of English letters, digits, `/`, `.`, and spaces.
- All the paths are valid (i.e., they follow the described format).

We need to build a file system that supports four operations: listing directory contents, creating directories, writing to files, and reading files. The file system is hierarchical, like a real one. Paths like `/a/b/c` indicate a nested structure where `c` is inside `b`, which is inside `a`, which is inside the root `/`.

One detail matters for the design: `ls` behaves differently depending on whether the path points to a file or a directory. If it points to a file, we return only the file name (not the full path). If it points to a directory, we return all its children sorted lexicographically.

The main design decision is which data structure represents this hierarchy. Paths are sequences of names separated by `/`, and we traverse them one component at a time, so a tree where each node represents a directory or file fits the structure directly.

- `1 <= path.length <= 200`: paths are short, so the cost of splitting a path is negligible per call.
- At most `300` calls: the total number of nodes stays small, so memory is not a concern and we can sort children on every `ls`.
- Paths contain only letters, digits, `/`, `.`, and spaces: there are no special characters to escape and no `.` or `..` relative-path components to resolve.

<h1 id="approach-1-hash-map-of-full-paths">
  Approach 1: Hash Map of Full Paths
</h1>

<h3 id="intuition">Intuition</h3>

Store everything in two hash maps. One maps a directory path to a set of its children names, and another maps a file path to its content string.

When we `mkdir("/a/b/c")`, we add `"a"` to the children of `"/"`, add `"b"` to the children of `"/a"`, and add `"c"` to the children of `"/a/b"`. When we `ls("/a")`, we look up `"/a"` in the directory map and return its children sorted.

The downside is that the keys are full path strings, so every operation rebuilds intermediate path prefixes (`/`, `/a`, `/a/b`) by string concatenation, and deep paths store the same prefixes repeatedly across keys.

<h3 id="algorithm">Algorithm</h3>

1. Initialize two hash maps: `dirContents` (maps directory path to a sorted set of child names) and `fileContents` (maps file path to its content string).
2. For `ls(path)`: Check if `path` is a file (exists in `fileContents`). If yes, return only the file name. Otherwise, return the sorted set of children from `dirContents`.
3. For `mkdir(path)`: Split the path by `/`. For each prefix, add the next component as a child of that prefix in `dirContents`.
4. For `addContentToFile(filePath, content)`: Create parent directories. Add the file name to the parent's children. Append `content` to `fileContents[filePath]`.
5. For `readContentFromFile(filePath)`: Return `fileContents[filePath]`.

```java
class FileSystem {
    // Maps directory path to sorted set of child names
    Map<String, TreeSet<String>> dirContents;
    // Maps file path to file content
    Map<String, StringBuilder> fileContents;

    public FileSystem() {
        dirContents = new HashMap<>();
        fileContents = new HashMap<>();
        dirContents.put("/", new TreeSet<>());
    }

    public List<String> ls(String path) {
        // If path is a file, return just the file name
        if (fileContents.containsKey(path)) {
            String[] parts = path.split("/");
            return Collections.singletonList(parts[parts.length - 1]);
        }
        // Otherwise return sorted directory contents
        TreeSet<String> contents = dirContents.getOrDefault(path, new TreeSet<>());
        return new ArrayList<>(contents);
    }

    public void mkdir(String path) {
        String[] parts = path.split("/");
        StringBuilder current = new StringBuilder();
        for (int i = 1; i < parts.length; i++) {
            String parent = current.length() == 0 ? "/" : current.toString();
            current.append("/").append(parts[i]);
            // Ensure parent directory knows about this child
            dirContents.computeIfAbsent(parent, k -> new TreeSet<>()).add(parts[i]);
            // Ensure this directory exists in the map
            dirContents.computeIfAbsent(current.toString(), k -> new TreeSet<>());
        }
    }

    public void addContentToFile(String filePath, String content) {
        // Create parent directories
        String[] parts = filePath.split("/");
        StringBuilder parentPath = new StringBuilder();
        for (int i = 1; i < parts.length - 1; i++) {
            String parent = parentPath.length() == 0 ? "/" : parentPath.toString();
            parentPath.append("/").append(parts[i]);
            dirContents.computeIfAbsent(parent, k -> new TreeSet<>()).add(parts[i]);
            dirContents.computeIfAbsent(parentPath.toString(), k -> new TreeSet<>());
        }
        // Add file name to parent directory
        String parent = parentPath.length() == 0 ? "/" : parentPath.toString();
        dirContents.computeIfAbsent(parent, k -> new TreeSet<>()).add(parts[parts.length - 1]);
        // Append content to file
        fileContents.computeIfAbsent(filePath, k -> new StringBuilder()).append(content);
    }

    public String readContentFromFile(String filePath) {
        return fileContents.get(filePath).toString();
    }
}
```

```python
class FileSystem:
    def __init__(self):
        # Maps directory path to sorted set of child names
        self.dir_contents = {"/": set()}
        # Maps file path to file content
        self.file_contents = {}

    def ls(self, path: str) -> list[str]:
        # If path is a file, return just the file name
        if path in self.file_contents:
            return [path.split("/")[-1]]
        # Otherwise return sorted directory contents
        return sorted(self.dir_contents.get(path, set()))

    def mkdir(self, path: str) -> None:
        parts = path.split("/")
        current = ""
        for i in range(1, len(parts)):
            parent = "/" if not current else current
            current += "/" + parts[i]
            # Ensure parent knows about this child
            if parent not in self.dir_contents:
                self.dir_contents[parent] = set()
            self.dir_contents[parent].add(parts[i])
            # Ensure this directory exists
            if current not in self.dir_contents:
                self.dir_contents[current] = set()

    def addContentToFile(self, filePath: str, content: str) -> None:
        # Create parent directories
        parts = filePath.split("/")
        parent_path = ""
        for i in range(1, len(parts) - 1):
            parent = "/" if not parent_path else parent_path
            parent_path += "/" + parts[i]
            if parent not in self.dir_contents:
                self.dir_contents[parent] = set()
            self.dir_contents[parent].add(parts[i])
            if parent_path not in self.dir_contents:
                self.dir_contents[parent_path] = set()
        # Add file name to parent directory
        parent = "/" if not parent_path else parent_path
        if parent not in self.dir_contents:
            self.dir_contents[parent] = set()
        self.dir_contents[parent].add(parts[-1])
        # Append content to file
        if filePath not in self.file_contents:
            self.file_contents[filePath] = ""
        self.file_contents[filePath] += content

    def readContentFromFile(self, filePath: str) -> str:
```

```cpp
class FileSystem {
    // Maps directory path to sorted set of child names
    unordered_map<string, set<string>> dirContents;
    // Maps file path to file content
    unordered_map<string, string> fileContents;

    vector<string> splitPath(const string& path) {
        vector<string> parts;
        string part;
        for (int i = 1; i < path.size(); i++) {
            if (path[i] == '/') {
                if (!part.empty()) parts.push_back(part);
                part.clear();
            } else {
                part += path[i];
            }
        }
        if (!part.empty()) parts.push_back(part);
        return parts;
    }

public:
    FileSystem() {
        dirContents["/"] = {};
    }

    vector<string> ls(string path) {
        // If path is a file, return just the file name
        if (fileContents.count(path)) {
            vector<string> parts = splitPath(path);
            return {parts.back()};
        }
        // Otherwise return sorted directory contents
        return vector<string>(dirContents[path].begin(), dirContents[path].end());
    }

    void mkdir(string path) {
        vector<string> parts = splitPath(path);
        string current = "";
        for (const string& part : parts) {
            string parent = current.empty() ? "/" : current;
            current += "/" + part;
            dirContents[parent].insert(part);
            if (!dirContents.count(current)) dirContents[current] = {};
        }
    }

    void addContentToFile(string filePath, string content) {
        // Create parent directories
        vector<string> parts = splitPath(filePath);

            current += "/" + parts[i];

            if (!dirContents.count(current)) dirContents[current] = {};

        string parent = current.empty() ? "/" : current;
        dirContents[parent].insert(parts.back());
        // Append content
        fileContents[filePath] += content;
```

```go
    fs := FileSystem{
        dirContents:  make(map[string]map[string]bool),

func (fs *FileSystem) Ls(path string) []string {
    // If path is a file, return just the file name
    if _, ok := fs.fileContents[path]; ok {
        parts := strings.Split(path, "/")
        return []string{parts[len(parts)-1]}
    }
    // Otherwise return sorted directory contents
    children := fs.dirContents[path]
    result := make([]string, 0, len(children))
    for name := range children {
        result = append(result, name)
    }
    sort.Strings(result)
    return result
}

func (fs *FileSystem) Mkdir(path string) {
    parts := strings.Split(path, "/")
    current := ""
    for i := 1; i < len(parts); i++ {
        parent := current
        if parent == "" {
            parent = "/"
        }
        current += "/" + parts[i]
        if fs.dirContents[parent] == nil {
            fs.dirContents[parent] = make(map[string]bool)
        }
        fs.dirContents[parent][parts[i]] = true
        if fs.dirContents[current] == nil {
            fs.dirContents[current] = make(map[string]bool)
        }
    }
}
```

```rust
use std::collections::{BTreeSet, HashMap};

struct FileSystem {
    // Maps directory path to sorted set of child names
    dir_contents: HashMap<String, BTreeSet<String>>,
    // Maps file path to file content
    file_contents: HashMap<String, String>,
}

impl FileSystem {
    fn new() -> Self {
        let mut dir_contents = HashMap::new();
        dir_contents.insert("/".to_string(), BTreeSet::new());
        Self {
            dir_contents,
            file_contents: HashMap::new(),
        }
    }

    fn ls(&self, path: String) -> Vec<String> {
        // If path is a file, return just the file name
        if self.file_contents.contains_key(&path) {
            let parts: Vec<&str> = path.split('/').collect();
            return vec![parts[parts.len() - 1].to_string()];
        }
        // Otherwise return sorted directory contents
        self.dir_contents
            .get(&path)
            .cloned()
            .unwrap_or_default()
            .into_iter()
            .collect()
    }

    fn mkdir(&mut self, path: String) {
        let parts: Vec<&str> = path.split('/').collect();
        let mut current = String::new();
        for i in 1..parts.len() {
            let parent = if current.is_empty() {
                "/".to_string()
            } else {
                current.clone()
            };
            current.push('/');
            current.push_str(parts[i]);
            // Ensure parent directory knows about this child
            self.dir_contents
                .entry(parent)
                .or_insert_with(BTreeSet::new)
                .insert(parts[i].to_string());
            // Ensure this directory exists in the map
            self.dir_contents
                .entry(current.clone())
                .or_insert_with(BTreeSet::new);
        }
    }

    fn add_content_to_file(&mut self, file_path: String, content: String) {
        // Create parent directories
        let parts: Vec<&str> = file_path.split('/').collect();
        let mut parent_path = String::new();
        for i in 1..parts.len() - 1 {
            let parent = if parent_path.is_empty() {
                "/".to_string()
            } else {
                parent_path.clone()
            };
            parent_path.push('/');
            parent_path.push_str(parts[i]);
            self.dir_contents
                .entry(parent)
                .or_insert_with(BTreeSet::new)
                .insert(parts[i].to_string());
            self.dir_contents
                .entry(parent_path.clone())
                .or_insert_with(BTreeSet::new);
        }
        // Add file name to parent directory
        let parent = if parent_path.is_empty() {
            "/".to_string()
        } else {
            parent_path
        };
        self.dir_contents
            .entry(parent)
            .or_insert_with(BTreeSet::new)
            .insert(parts[parts.len() - 1].to_string());
        // Append content to file
        self.file_contents.entry(file_path).or_default().push_str(&content);
    }

    fn read_content_from_file(&self, file_path: String) -> String {
        self.file_contents.get(&file_path).unwrap().clone()
    }
}
```

```typescript
class FileSystem {
  private dirContents: Map<string, Set<string>>;
  private fileContents: Map<string, string>;

  constructor() {
    this.dirContents = new Map();
    this.fileContents = new Map();
    this.dirContents.set("/", new Set());
  }

  ls(path: string): string[] {
    // If path is a file, return just the file name
    if (this.fileContents.has(path)) {
      const parts = path.split("/");
      return [parts[parts.length - 1]];
    }
    // Otherwise return sorted directory contents
    const contents = this.dirContents.get(path) || new Set<string>();
    return [...contents].sort();
  }

  mkdir(path: string): void {
    const parts = path.split("/");
    let current = "";
    for (let i = 1; i < parts.length; i++) {
      const parent = current === "" ? "/" : current;
      current += "/" + parts[i];
      if (!this.dirContents.has(parent))
        this.dirContents.set(parent, new Set());
      this.dirContents.get(parent)!.add(parts[i]);
      if (!this.dirContents.has(current))
        this.dirContents.set(current, new Set());
    }
  }

  addContentToFile(filePath: string, content: string): void {
    const parts = filePath.split("/");
    let current = "";
    for (let i = 1; i < parts.length - 1; i++) {
      const parent = current === "" ? "/" : current;
      current += "/" + parts[i];
      if (!this.dirContents.has(parent))
        this.dirContents.set(parent, new Set());
      this.dirContents.get(parent)!.add(parts[i]);
      if (!this.dirContents.has(current))
        this.dirContents.set(current, new Set());
    }
    const parent = current === "" ? "/" : current;
    if (!this.dirContents.has(parent)) this.dirContents.set(parent, new Set());
    this.dirContents.get(parent)!.add(parts[parts.length - 1]);
    const existing = this.fileContents.get(filePath) || "";
    this.fileContents.set(filePath, existing + content);
  }

  readContentFromFile(filePath: string): string {
    return this.fileContents.get(filePath)!;
  }
}
```

> - **Time Complexity:** O(m + k log k) for `ls` where m is path length and k is the number of children (due to sorting). O(m) for `mkdir`, `addContentToFile`, and `readContentFromFile`, where m is the number of components in the path.
> - **Space Complexity:** O(n \* m) where n is the total number of files and directories, and m is the average path length. We store full path strings as keys, which is redundant since nested paths share prefixes.

This approach stores redundant full path strings as map keys. The next approach removes that redundancy by representing the file system as a tree, where moving from a parent to a child is following a pointer instead of building a new key.

<h1 id="approach-2-trie-file-system-tree">
  Approach 2: Trie (File System Tree)
</h1>

<h3 id="intuition">Intuition</h3>

A file system is a tree. The root directory `/` is the root node, and each subdirectory or file is a child node. Instead of flattening paths into hash map keys, we represent the file system as a tree where each node stores a map of its children (keyed by name) and an optional file content.

This is a Trie, except each level represents a path component rather than a single character. Given a path like `/a/b/c`, we start at the root, follow the edge labeled `"a"` to reach node `a`, then follow `"b"` to reach node `b`, then follow `"c"` to reach node `c`.

Navigating to any path is a walk down the tree, and `mkdir` creates the intermediate nodes it passes through. There is no string concatenation and no duplicate prefix storage, because each node holds only its own children.

To distinguish files from directories, each node has an optional `content` field. A node with non-null content is a file; otherwise it is a directory.

<h3 id="algorithm">Algorithm</h3>

1. Define a `TrieNode` class with a `children` map (name to child node) and a `content` string (null for directories).
2. Create a root node representing `/`.
3. For any path, split by `/` and traverse from root, following child pointers for each component.
4. `ls(path)`: Navigate to the node. If it's a file, return its name. Otherwise, return sorted keys of its children map.
5. `mkdir(path)`: Navigate the path, creating child nodes as needed.
6. `addContentToFile(filePath, content)`: Navigate to the node (creating nodes along the way), then append content.
7. `readContentFromFile(filePath)`: Navigate to the node and return its content.

```java
class FileSystem {
    // Each node represents a file or directory in the tree
    class TrieNode {
        Map<String, TrieNode> children;
        String content;  // null for directories, non-null for files

        TrieNode() {
            children = new HashMap<>();
            content = null;
        }
    }

    TrieNode root;

    public FileSystem() {
        root = new TrieNode();
    }

    // Navigate from root to the node at the given path
    private TrieNode navigate(String path) {
        TrieNode node = root;
        if (path.equals("/")) return node;
        String[] parts = path.split("/");
        for (int i = 1; i < parts.length; i++) {
            node = node.children.get(parts[i]);
        }
        return node;
    }

    // Navigate and create missing nodes along the way
    private TrieNode navigateAndCreate(String path) {
```

```cpp
class FileSystem {
    struct TrieNode {
        unordered_map<string, TrieNode*> children;
        string content;  // empty string means directory, non-empty means file
        bool isFile;

        TrieNode() : isFile(false) {}
    };

    TrieNode* root;

    // Split path into components (skip empty first element from leading /)
    vector<string> splitPath(const string& path) {
        vector<string> parts;
        string part;
        for (int i = 1; i < path.size(); i++) {
            if (path[i] == '/') {
                if (!part.empty()) parts.push_back(part);
                part.clear();
            } else {
                part += path[i];
            }
        }
        if (!part.empty()) parts.push_back(part);
        return parts;
    }

    // Navigate from root to the node at the given path
    TrieNode* navigate(const string& path) {
        TrieNode* node = root;
        vector<string> parts = splitPath(path);
        for (const string& p : parts) {
            node = node->children[p];
        }
        return node;
    }

    // Navigate and create missing nodes along the way
    TrieNode* navigateAndCreate(const string& path) {
        TrieNode* node = root;
        vector<string> parts = splitPath(path);
        for (const string& p : parts) {
            if (!node->children.count(p)) {
                node->children[p] = new TrieNode();
            }
            node = node->children[p];
        }
        return node;
    }

public:
    FileSystem() {
        root = new TrieNode();
    }

    vector<string> ls(string path) {
        TrieNode* node = navigate(path);
        // If it's a file, return just the file name
        if (node->isFile) {
            vector<string> parts = splitPath(path);
            return {parts.back()};
        }
        // Otherwise return sorted children names
        vector<string> result;
        for (auto& [name, child] : node->children) {
            result.push_back(name);
        }
        sort(result.begin(), result.end());
        return result;
    }

    void mkdir(string path) {
        navigateAndCreate(path);
    }

    void addContentToFile(string filePath, string content) {
        TrieNode* node = navigateAndCreate(filePath);
        node->isFile = true;
        node->content += content;
    }

    string readContentFromFile(string filePath) {
        return navigate(filePath)->content;
    }
};
```

```rust
        let mut node = &self.root;
        if path == "/" {
            return node;
        }
        let parts: Vec<&str> = path.split('/').collect();
        for i in 1..parts.len() {
            node = node.children.get(parts[i]).unwrap();

        if path == "/" {

        }
        let parts: Vec<&str> = path.split('/').collect();
        for i in 1..parts.len() {
            node = node
                .children
                .entry(parts[i].to_string())
                .or_insert_with(TrieNode::new);
        }
        node

            return vec![parts[parts.len() - 1].to_string()];
        }
        // Otherwise return sorted children names
        let mut result: Vec<String> = node.children.keys().cloned().collect();
        result.sort();
        result

        self.navigate_and_create(&path);

            node.content = Some(content);
```

```typescript
    let node = this.root;
    if (path === "/") return node;
    const parts = path.split("/");
    for (let i = 1; i < parts.length; i++) {
      node = node.children.get(parts[i])!;
    }
    return node;

    if (path === "/") return node;
    const parts = path.split("/");
    for (let i = 1; i < parts.length; i++) {
      if (!node.children.has(parts[i])) {
        node.children.set(parts[i], new TrieNode());

    // Otherwise return sorted children names
```

> - **Time Complexity:** O(m + k log k) for `ls` where m is the number of path components and k is the number of children (sorting). O(m) for `mkdir`, `addContentToFile`, and `readContentFromFile`. O(m + c) for `addContentToFile` when considering content length c.
> - **Space Complexity:** O(T + C) where T is the total number of nodes in the tree (directories + files) and C is the total content stored across all files. More space-efficient than Approach 1 because we don't store redundant full path strings as keys.
