<LessonCard>

You are given an integer array `nums`.

A subarray is called balanced if the number of distinct even numbers in the subarray is equal to the number of distinct odd numbers.

Return the length of the longest balanced subarray.

**Example 1:**

- **Input:** `nums = [2,5,4,3]`

- **Output:** `4`

**Example 2:**

- **Input:** `nums = [3,2,2,5,4]`

- **Output:** `5`

**Example 3:**

- **Input:** `nums = [1,2,3,2]`

- **Output:** `3`

**Constraints:**

- **1 &lt;= nums.length &lt;= 10\*\***5\*\*
- **1 &lt;= nums[i] &lt;= 10\*\***5\*\*

The load-bearing word is "distinct." If the problem counted every even and odd element, a prefix-sum or sliding window would handle it directly. Distinct values behave differently. Extending a window by one element changes the distinct-even count only when that value is new to the window. Shrinking from the left changes the count only when the removed element was the last copy of its value.

That makes the window state non-monotonic. A number can appear many times, yet it contributes once to the distinct count as long as at least one copy remains in the subarray.

The problem reduces to two sub-questions: how do we track whether a value still belongs to the current subarray, and how do we compare distinct-odd and distinct-even counts efficiently across all subarrays?

- `nums.length <= 10^5`. An O(n^2) scan over all subarrays is around 10^10 operations in the worst case, too slow. The final solution needs to be O(n log n) or better.
- Values are at most `10^5`, so a hash map keyed by value fits comfortably.
- The answer is the longest valid subarray, so we want to recover the best left endpoint for each right endpoint in a single sweep rather than re-examine ranges.

Pick every possible subarray, scan it, build one set of distinct even values and one set of distinct odd values, and compare their sizes. The longest subarray with equal sizes is the answer.

This is the baseline because it follows the definition directly. It also exposes the bottleneck: we rebuild the same distinct sets from scratch for heavily overlapping subarrays.

<h3 id="algorithm">Algorithm</h3>

1. Initialize `answer = 0`.
2. For every `l` from `0` to `n - 1`:
3. For every `r` from `l` to `n - 1`:
4. Create empty sets for distinct even and odd values.
5. Scan `k` from `l` to `r` and insert `nums[k]` into the appropriate set.
6. If the two set sizes are equal, update `answer`.
7. Return `answer`.

```java
class Solution {
    public int longestBalanced(int[] nums) {
        int n = nums.length;
        int answer = 0;

        for (int left = 0; left < n; left++) {
            for (int right = left; right < n; right++) {
                Set<Integer> evens = new HashSet<>();
                Set<Integer> odds = new HashSet<>();

                    } else {
                        odds.add(nums[k]);
                    }
                }

                if (evens.size() == odds.size()) {
                    answer = Math.max(answer, right - left + 1);
                }
            }
        }

        return answer;
    }
}
```

> - **Time Complexity:** O(n^3). There are O(n^2) subarrays, and each one is rescanned in O(n) time.
> - **Space Complexity:** O(n). In the worst case, the even and odd sets together can hold O(n) distinct values.

The inner rescan is pure waste. Fixing the left boundary and extending the right one element at a time lets us update the distinct sets incrementally instead of rebuilding them.

<h1 id="approach-2-incremental-distinct-sets">
  Approach 2: Incremental Distinct Sets
</h1>

<h3 id="intuition">Intuition</h3>

Fix `left` and grow `right` one step at a time. The window `[left..right + 1]` differs from `[left..right]` by a single new value, so we insert that value into the correct set in O(1) average time rather than rebuilding both sets. For a fixed `left`, the two sets always hold the distinct values inside the current window, because each step only adds and nothing leaves.

This removes the O(n) inner rescan and drops the running time from O(n^3) to O(n^2). It is still too slow at `n = 10^5`, because every (left, right) pair is examined.

<h3 id="algorithm">Algorithm</h3>

1. Initialize `answer = 0`.
2. For each `left` from `0` to `n - 1`:
3. Create empty even and odd sets.
4. Extend `right` from `left` to `n - 1`.
5. Insert `nums[right]` into the correct set.
6. If the set sizes are equal, update `answer`.
7. Return `answer`.

> - **Time Complexity:** O(n^2). We still enumerate all subarrays by choosing every pair (left, right).
> - **Space Complexity:** O(n). The two sets can still hold up to O(n) distinct values.

Distinct-set maintenance is now cheap, but we still process all O(n^2) subarrays. The next approach transforms the balance condition into a value that a single sweep over the right endpoint can match against, so the best left endpoint falls out of one query instead of an inner loop.

<h1 id="approach-3-optimal-segment-tree-last-occurrence">
  Approach 3: Optimal (Segment Tree + Last Occurrence)
</h1>

<h3 id="intuition">Intuition</h3>

The path to O(n log n) is to stop counting "how many distinct values are inside `[l..r]`" and reason about latest occurrences instead.

Fix a right endpoint `i`. For any value `x`, whether `x` belongs to the subarray `[l..i]` depends on one fact: is the latest occurrence of `x` at or after `l`? If yes, `x` appears somewhere in `[l..i]`. If no, every copy of `x` sits before `l`, so `x` is absent.

Assign each distinct value a contribution: `+1` if odd, `-1` if even. A subarray is balanced exactly when its distinct-odd and distinct-even counts are equal, which means the total contribution of its distinct values is `0`.

Let `last[x]` be the latest 1-based position of value `x`. Process positions left to right. After handling position `i`, define `tree[p]` as the total contribution of all distinct values whose latest occurrence is at or before `p`, and `now` as the total contribution of all distinct values seen so far (equivalently `tree[i]`). The values counted in `tree[p]` are precisely the ones whose only remaining copies lie in `[1..p]`, so they are absent from the subarray `(p + 1) .. i`. The contribution of the distinct values that do fall inside `(p + 1) .. i` is therefore `now - tree[p]`, and the subarray is balanced exactly when `tree[p] == now`.

For each right endpoint `i`, we want the earliest `p` with `tree[p] == now`, which maximizes the length `i - p`. When `x` arrives at position `i`, its latest occurrence moves: if it appeared before at `old`, remove its contribution from the suffix `[old, n]` and add the new contribution to `[i, n]`. Suffix range-add plus an earliest-position query is what a lazy segment tree handles in O(log n) per step.

> Two facts make the query valid. First, `tree[n]` accumulates every update, since every suffix add ends at `n`, so `tree[n] == now`. The target `now` is therefore always present somewhere, and a balanced cut always exists (at worst the empty range at `p = i`). Second, each tree node stores the `mn` and `mx` of its range, so `now` appears in a subtree only if `mn <= now <= mx` there. The query descends into the left child whenever the target falls in its range, so when both children contain `now` it still goes left. That returns the smallest position `p` with `tree[p] == now`, the earliest balanced cut, which maximizes `i - p`.

<h3 id="algorithm">Algorithm</h3>

1. Build a lazy segment tree on positions `[0, n]`, initialized to all zeros.
2. Keep a hash map `last` for the latest 1-based occurrence of each value.
3. Initialize `now = 0` and `answer = 0`.
4. For each position `i` from 1 through `n`:
   - Set `x = nums[i - 1]` and `det = +1` if `x` is odd, otherwise `-1`.
   - If `x` appeared before at `last[x]`, apply `modify(last[x], n, -det)` and subtract `det` from `now`.
   - Set `last[x] = i`, apply `modify(i, n, det)`, and add `det` to `now`.
   - Query the leftmost position `p` whose tree value equals `now`, then set `answer = max(answer, i - p)`.
5. Return `answer`.

```java
class Solution {
    private static class Node {
        int l;
        int r;
        int mn;
        int mx;
        int lazy;
    }

    private Node[] tr;

    private void build(int u, int l, int r) {
        tr[u] = new Node();
        tr[u].l = l;
        tr[u].r = r;
        tr[u].mn = 0;
        tr[u].mx = 0;
        tr[u].lazy = 0;

        if (l == r) {
            return;
        }

        int mid = (l + r) >> 1;
        build(u << 1, l, mid);
        build(u << 1 | 1, mid + 1, r);
    }

    private void apply(int u, int v) {
        tr[u].mn += v;
        tr[u].mx += v;
        tr[u].lazy += v;
    }

    private void pushup(int u) {
        tr[u].mn = Math.min(tr[u << 1].mn, tr[u << 1 | 1].mn);
        tr[u].mx = Math.max(tr[u << 1].mx, tr[u << 1 | 1].mx);
    }

    private void pushdown(int u) {
        if (tr[u].lazy != 0) {
            int v = tr[u].lazy;
            apply(u << 1, v);
            apply(u << 1 | 1, v);
            tr[u].lazy = 0;
        }
    }

    private void modify(int u, int l, int r, int v) {
        if (l <= tr[u].l && tr[u].r <= r) {
            apply(u, v);
            return;
        }

        pushdown(u);
        int mid = (tr[u].l + tr[u].r) >> 1;
        if (l <= mid) {
            modify(u << 1, l, r, v);
        }
        if (r > mid) {
            modify(u << 1 | 1, l, r, v);
        }
        pushup(u);
    }

    private int query(int u, int target) {
        if (tr[u].l == tr[u].r) {
            return tr[u].l;
        }

        pushdown(u);
        if (tr[u << 1].mn <= target && target <= tr[u << 1].mx) {
            return query(u << 1, target);
        }
        return query(u << 1 | 1, target);
    }

    public int longestBalanced(int[] nums) {
        int n = nums.length;
        tr = new Node[(n + 1) * 4];
        build(1, 0, n);

        Map<Integer, Integer> last = new HashMap<>();
        int now = 0;
        int answer = 0;

        for (int i = 1; i <= n; i++) {
            int x = nums[i - 1];
            int det = (x & 1) == 1 ? 1 : -1;

            if (last.containsKey(x)) {
                int old = last.get(x);
                modify(1, old, n, -det);
                now -= det;
            }

            last.put(x, i);
            modify(1, i, n, det);
            now += det;

            int p = query(1, now);
            answer = Math.max(answer, i - p);
        }

        return answer;
    }
}
```

```python
            pushup(u)

                return tr[u].l
            pushdown(u)
            if tr[u << 1].mn <= target <= tr[u << 1].mx:
                return query(u << 1, target)
            return query(u << 1 | 1, target)

        build(1, 0, n)

        last = {}
        now = 0
        answer = 0

        for i, x in enumerate(nums, start=1):
            det = 1 if x & 1 else -1

            if x in last:
                old = last[x]
                modify(1, old, n, -det)
                now -= det
```

```cpp
        tr[u].mn += v;
        tr[u].mx += v;
        tr[u].lazy += v;
```

```csharp
    private void PushUp(int u) {

            Apply(u << 1 | 1, v);
```

```go
type Node struct {
	l, r int
	mn   int
	mx   int
	lazy int
}

type SegmentTree struct {
	tr []Node
}

func newSegmentTree(n int) *SegmentTree {
	st := &SegmentTree{
		tr: make([]Node, (n+1)<<2),
	}
	st.build(1, 0, n)
	return st
}

func (st *SegmentTree) build(u, l, r int) {
	st.tr[u] = Node{l: l, r: r, mn: 0, mx: 0, lazy: 0}
	if l == r {
		return
	}
	mid := (l + r) >> 1
	st.build(u<<1, l, mid)
	st.build(u<<1|1, mid+1, r)
}

func (st *SegmentTree) apply(u, v int) {
	st.tr[u].mn += v
	st.tr[u].mx += v
	st.tr[u].lazy += v
}

func (st *SegmentTree) pushup(u int) {
	left, right := u<<1, u<<1|1
	if st.tr[left].mn < st.tr[right].mn {
		st.tr[u].mn = st.tr[left].mn
	} else {
		st.tr[u].mn = st.tr[right].mn
	}
	if st.tr[left].mx > st.tr[right].mx {
		st.tr[u].mx = st.tr[left].mx
	} else {
		st.tr[u].mx = st.tr[right].mx
	}
}

func (st *SegmentTree) pushdown(u int) {
	if st.tr[u].lazy != 0 {
		v := st.tr[u].lazy
		st.apply(u<<1, v)
		st.apply(u<<1|1, v)
		st.tr[u].lazy = 0
	}
}

func (st *SegmentTree) modify(u, l, r, v int) {
	if l <= st.tr[u].l && st.tr[u].r <= r {
		st.apply(u, v)
		return
	}
	st.pushdown(u)
	mid := (st.tr[u].l + st.tr[u].r) >> 1
	if l <= mid {
		st.modify(u<<1, l, r, v)
	}
	if r > mid {
		st.modify(u<<1|1, l, r, v)
	}
	st.pushup(u)
}

func (st *SegmentTree) query(u, target int) int {
	if st.tr[u].l == st.tr[u].r {
		return st.tr[u].l
	}
	st.pushdown(u)
	if st.tr[u<<1].mn <= target && target <= st.tr[u<<1].mx {
		return st.query(u<<1, target)
	}
	return st.query(u<<1|1, target)
}

func longestBalanced(nums []int) int {
	n := len(nums)
	st := newSegmentTree(n)
	last := map[int]int{}
	now := 0
	answer := 0

	for i := 1; i <= n; i++ {
		x := nums[i-1]
		det := -1
		if x&1 == 1 {
			det = 1
		}

		if old, ok := last[x]; ok {
			st.modify(1, old, n, -det)
			now -= det
		}

		last[x] = i
		st.modify(1, i, n, det)
		now += det

		p := st.query(1, now)
		if i-p > answer {
			answer = i - p
		}
	}

	return answer
}
```

```rust
use std::cmp::{max, min};
use std::collections::HashMap;

pub struct Solution;

#[derive(Clone, Default)]
struct Node {
    l: i32,
    r: i32,
    mn: i32,
    mx: i32,
    lazy: i32,
}

impl Solution {
    fn build(tr: &mut Vec<Node>, u: usize, l: i32, r: i32) {
        tr[u] = Node {
            l,
            r,
            mn: 0,
            mx: 0,
            lazy: 0,
        };

        if l == r {
            return;
        }

        let mid = (l + r) >> 1;
        Self::build(tr, u << 1, l, mid);
        Self::build(tr, u << 1 | 1, mid + 1, r);
    }

    fn apply(tr: &mut Vec<Node>, u: usize, v: i32) {
        tr[u].mn += v;
        tr[u].mx += v;
        tr[u].lazy += v;
    }

    fn pushup(tr: &mut Vec<Node>, u: usize) {
        tr[u].mn = min(tr[u << 1].mn, tr[u << 1 | 1].mn);
        tr[u].mx = max(tr[u << 1].mx, tr[u << 1 | 1].mx);
    }

    fn pushdown(tr: &mut Vec<Node>, u: usize) {
        if tr[u].lazy != 0 {
            let v = tr[u].lazy;
            Self::apply(tr, u << 1, v);
            Self::apply(tr, u << 1 | 1, v);
            tr[u].lazy = 0;
        }
    }

    fn modify(tr: &mut Vec<Node>, u: usize, l: i32, r: i32, v: i32) {
        if l <= tr[u].l && tr[u].r <= r {
            Self::apply(tr, u, v);
            return;
        }

        Self::pushdown(tr, u);
        let mid = (tr[u].l + tr[u].r) >> 1;
        if l <= mid {
            Self::modify(tr, u << 1, l, r, v);
        }
        if r > mid {
            Self::modify(tr, u << 1 | 1, l, r, v);
        }
        Self::pushup(tr, u);
    }

    fn query(tr: &mut Vec<Node>, u: usize, target: i32) -> i32 {
        if tr[u].l == tr[u].r {
            return tr[u].l;
        }

        Self::pushdown(tr, u);
        if tr[u << 1].mn <= target && target <= tr[u << 1].mx {
            return Self::query(tr, u << 1, target);
        }
        Self::query(tr, u << 1 | 1, target)
    }

    pub fn longest_balanced(nums: Vec<i32>) -> i32 {
        let n = nums.len() as i32;
        let mut tr = vec![Node::default(); ((n + 1) as usize) * 4];
        Self::build(&mut tr, 1, 0, n);

        let mut last: HashMap<i32, i32> = HashMap::new();
        let mut now = 0;
        let mut answer = 0;

        for i in 1..=n {
            let x = nums[(i - 1) as usize];
            let det = if (x & 1) == 1 { 1 } else { -1 };

            if let Some(&old) = last.get(&x) {
                Self::modify(&mut tr, 1, old, n, -det);
                now -= det;
            }

            last.insert(x, i);
            Self::modify(&mut tr, 1, i, n, det);
            now += det;

            let p = Self::query(&mut tr, 1, now);
            answer = max(answer, i - p);
        }

        answer
    }
}
```
