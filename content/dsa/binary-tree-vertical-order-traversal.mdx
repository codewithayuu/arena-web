<LessonCard>

Given the `root` of a binary tree, return the **vertical order traversal** of its nodes' values (i.e., from top to bottom, column by column).

If two nodes are in the same row and column, the order should be from **left to right**.

**Example 1:**

- **Input:** `root = [3,9,20,null,null,15,7]`

- **Output:** `[[9],[3,15],[20],[7]]`

**Example 2:**

- **Input:** `root = [3,9,8,4,0,1,7]`

- **Output:** `[[4],[9],[3,0,1],[8],[7]]`

**Example 3:**

- **Input:** `root = [3,9,8,4,0,1,7,null,null,null,2,5]`

- **Output:** `[[4],[9,5],[3,0,1],[8,2],[7]]`

**Constraints:**

- `The number of nodes in the tree is in the range [0, 100].`
- `-100 <= Node.val <= 100`

We're given a binary tree and need to return node values grouped by their vertical column. Place the tree on a grid with the root at column 0. Every left edge decreases the column by 1, and every right edge increases it by 1. Nodes that land in the same column form one group.

Within a column, nodes appear from top to bottom. If two nodes share both the same column and the same row, the one further to the left in the tree comes first. This tie-breaking rule is what makes BFS a good fit: BFS processes nodes level by level, left to right, which is the required order.

The main work is grouping nodes by column and returning the columns in left-to-right order.

- `0 <= number of nodes <= 100`: The tree can be empty (`root = null`), in which case the answer is an empty list. The small size means performance does not decide between the approaches below, though the algorithmic difference matters for larger inputs.
- `-100 <= Node.val <= 100`: Values can be negative. Column indices can also be negative (any node to the left of the root), so the grouping structure must accept negative keys.

Traverse the tree, assign a column index to every node, and group values by column. BFS processes nodes level by level, which gives the correct top-to-bottom ordering within each column, and within a level it visits nodes left to right, which satisfies the tie-breaking rule.

For each node, we store its value in a hash map keyed by column index. The root starts at column 0. When we visit a node at column `c`, its left child goes to column `c - 1` and its right child to column `c + 1`. After the traversal, we sort the hash map keys to arrange columns from leftmost to rightmost.

<h3 id="algorithm">Algorithm</h3>

1. If the root is null, return an empty list.
2. Create a hash map to store column index to list of node values.
3. Create a BFS queue. Enqueue the root with column index 0.
4. While the queue is not empty:
5. Sort the hash map keys.
6. For each key in sorted order, add the corresponding list to the result.
7. Return the result.

```java
class Solution {
    public List<List<Integer>> verticalOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        // Map from column index to list of node values
        Map<Integer, List<Integer>> columnMap = new HashMap<>();
        Queue<TreeNode> nodeQueue = new LinkedList<>();
        Queue<Integer> colQueue = new LinkedList<>();
        nodeQueue.offer(root);
        colQueue.offer(0);

        while (!nodeQueue.isEmpty()) {
            TreeNode node = nodeQueue.poll();
            int col = colQueue.poll();

            columnMap.computeIfAbsent(col, k -> new ArrayList<>()).add(node.val);

            if (node.left != null) {
                nodeQueue.offer(node.left);
                colQueue.offer(col - 1);
            }
            if (node.right != null) {
                nodeQueue.offer(node.right);
                colQueue.offer(col + 1);
            }
        }

        // Sort columns from left to right
        List<Integer> sortedKeys = new ArrayList<>(columnMap.keySet());
        Collections.sort(sortedKeys);

        for (int key : sortedKeys) {
            result.add(columnMap.get(key));
        }

        return result;
    }
}
```

```go
func verticalOrder(root *TreeNode) [][]int {
    if root == nil {
        return [][]int{}
    }

    // Map from column index to list of node values
    columnMap := make(map[int][]int)
    type entry struct {
        node *TreeNode
        col  int
    }
    queue := []entry{{root, 0}}

    for len(queue) > 0 {
        front := queue[0]
        queue = queue[1:]

        columnMap[front.col] = append(columnMap[front.col], front.node.Val)

        if front.node.Left != nil {
            queue = append(queue, entry{front.node.Left, front.col - 1})
        }
        if front.node.Right != nil {
            queue = append(queue, entry{front.node.Right, front.col + 1})
        }
    }

    // Sort columns from left to right
    keys := make([]int, 0, len(columnMap))
    for k := range columnMap {
        keys = append(keys, k)
    }
    sort.Ints(keys)

    result := make([][]int, len(keys))
    for i, k := range keys {
        result[i] = columnMap[k]
    }
    return result
}
```

```rust
/**
 * Definition for a binary tree node.
 * pub struct TreeNode {
 *     pub val: i32,
 *     pub left: Option<Rc<RefCell<TreeNode>>>,
 *     pub right: Option<Rc<RefCell<TreeNode>>>,
 * }
 */

use std::cell::RefCell;
use std::rc::Rc;

impl Solution {
    pub fn vertical_order(root: Option<Rc<RefCell<TreeNode>>>) -> Vec<Vec<i32>> {
        if root.is_none() {
            return vec![];
        }

        // Map from column index to list of node values
        let mut column_map: HashMap<i32, Vec<i32>> = HashMap::new();
        let mut node_queue: VecDeque<Rc<RefCell<TreeNode>>> = VecDeque::new();
        let mut col_queue: VecDeque<i32> = VecDeque::new();

        node_queue.push_back(root.unwrap());
        col_queue.push_back(0);

        while let Some(node_rc) = node_queue.pop_front() {
            let col = col_queue.pop_front().unwrap();
            let node = node_rc.borrow();

            column_map.entry(col).or_insert_with(Vec::new).push(node.val);

            if let Some(left) = node.left.clone() {
                node_queue.push_back(left);
                col_queue.push_back(col - 1);
            }
            if let Some(right) = node.right.clone() {
                node_queue.push_back(right);
                col_queue.push_back(col + 1);
            }
        }

        // Sort columns from left to right
        let mut sorted_keys: Vec<i32> = column_map.keys().cloned().collect();
        sorted_keys.sort();

        let mut result = Vec::with_capacity(sorted_keys.len());
        for key in sorted_keys {
            result.push(column_map.remove(&key).unwrap());
        }

        result
    }
}
```

> - **Time Complexity:** O(n log n). The BFS traversal is O(n). Sorting the column keys is O(k log k) where k is the number of distinct columns. In the worst case (skewed tree), k = n, making the sort O(n log n).
> - **Space Complexity:** O(n). The hash map stores all n node values. The BFS queue holds nodes from at most two adjacent levels, which is O(n) for a complete tree (the widest level has about n/2 nodes).

The bottleneck is the sorting step: the traversal is O(n), and the key sort pushes the total to O(n log n). The next approach removes the sort by tracking the minimum and maximum column indices during the traversal.

<h1 id="approach-2-bfs-hashmap-minmax-column-tracking-optimal">
  Approach 2: BFS + HashMap + Min/Max Column Tracking (Optimal)
</h1>

<h3 id="intuition">Intuition</h3>

This builds on Approach 1 with one change. Instead of sorting column keys after the traversal, we track the minimum and maximum column indices as we go. When the BFS finishes, we iterate from `minCol` to `maxCol` and collect each column's list, which visits the columns in left-to-right order without a sort.

> The final loop reads every column from `minCol` to `maxCol` and assumes none of them is empty. This holds because each edge changes the column by exactly 1: the root-to-node path for a node at `minCol` passes through every column between 0 and `minCol`, and the same argument applies to `maxCol`. The occupied columns therefore form a contiguous range of integers.
>
> The per-column order comes from the BFS queue. Parents leave the queue in left-to-right order within a level, and each parent enqueues its left child before its right child, so every level enters the queue in left-to-right order. Each column's list receives nodes top to bottom, with same-row ties resolved left to right.

<h3 id="algorithm">Algorithm</h3>

1. If the root is null, return an empty list.
2. Create a hash map to store column index to list of node values.
3. Initialize `minCol = 0` and `maxCol = 0`.
4. Create a BFS queue. Enqueue the root with column index 0.
5. While the queue is not empty:
6. Iterate from `minCol` to `maxCol`. For each column, add the corresponding list to the result.
7. Return the result.

> - **Time Complexity:** O(n). We visit every node exactly once during BFS, doing O(1) work per node. Building the result iterates over at most n columns. Total: O(n).
> - **Space Complexity:** O(n). The hash map stores all n node values. The BFS queue holds nodes from at most two adjacent levels, which is O(n) for a complete tree (the widest level has about n/2 nodes).

Approach 2 is optimal at O(n). DFS can also solve the problem, but it needs extra bookkeeping because it does not visit nodes in level order.

<h1 id="approach-3-dfs-hashmap-sorting">Approach 3: DFS + HashMap + Sorting</h1>

<h3 id="intuition">Intuition</h3>

DFS goes deep before going wide, so values do not arrive in top-to-bottom order within a column. A node deep in the left subtree can be recorded before a shallower node in the same column from the right subtree.

The fix is to track each node's row (depth) in addition to its column and store `(row, value)` pairs in each column's list. After the traversal, sorting each column's list by row restores the top-to-bottom order. The same-row tie-break comes from the traversal order: pre-order DFS finishes the entire left subtree before entering the right subtree at every branch, so two nodes with equal row and column are appended in left-to-right order, and a stable sort by row preserves that order.

<h3 id="algorithm">Algorithm</h3>

1. If the root is null, return an empty list.
2. Create a hash map to store column index to list of `(row, value)` pairs.
3. Run DFS from the root with initial row 0 and column 0.
4. At each node, add `(row, node.val)` to the hash map for the current column.
5. Recursively visit the left child with `(row + 1, column - 1)` and the right child with `(row + 1, column + 1)`.
6. Sort the hash map keys to get column order.
7. For each column, sort the entries by row (stable sort preserves left-to-right order for same-row nodes).
8. Extract the values, dropping the rows, and add each column's list to the result.
9. Return the result.

```java
class Solution {
    public List<List<Integer>> verticalOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        // Map from column to list of (row, value) pairs
        Map<Integer, List<int[]>> columnMap = new HashMap<>();
        dfs(root, 0, 0, columnMap);

        // Sort columns from left to right
        List<Integer> sortedKeys = new ArrayList<>(columnMap.keySet());
        Collections.sort(sortedKeys);

        for (int col : sortedKeys) {
            List<int[]> entries = columnMap.get(col);
            // Stable sort by row preserves left-to-right for same row
            entries.sort((a, b) -> a[0] - b[0]);
            List<Integer> colValues = new ArrayList<>();
            for (int[] entry : entries) {
                colValues.add(entry[1]);
            }
            result.add(colValues);
        }

        return result;
    }

    private void dfs(TreeNode node, int row, int col,
                     Map<Integer, List<int[]>> columnMap) {
        if (node == null) return;

        columnMap.computeIfAbsent(col, k -> new ArrayList<>())
                 .add(new int[]{row, node.val});

        // Process left before right to maintain left-to-right order
        dfs(node.left, row + 1, col - 1, columnMap);
        dfs(node.right, row + 1, col + 1, columnMap);
    }
}
```

```cpp
class Solution {
public:
    vector<vector<int>> verticalOrder(TreeNode* root) {
        vector<vector<int>> result;
        if (!root) return result;

        // Map from column to list of (row, value) pairs
        map<int, vector<pair<int, int>>> columnMap;
        dfs(root, 0, 0, columnMap);

        // map is sorted by key in C++
        for (auto& [col, entries] : columnMap) {
            // Stable sort by row preserves left-to-right for same row
            stable_sort(entries.begin(), entries.end(),
                       [](const pair<int,int>& a, const pair<int,int>& b) {
                           return a.first < b.first;
                       });
            vector<int> colValues;
            for (auto& [row, val] : entries) {
                colValues.push_back(val);
            }
            result.push_back(colValues);
        }

        return result;
    }

             map<int, vector<pair<int, int>>>& columnMap) {
```

```csharp
public class Solution {
    public IList<IList<int>> VerticalOrder(TreeNode root) {
        IList<IList<int>> result = new List<IList<int>>();
        if (root == null) return result;

        // Map from column to list of (row, value) pairs
        Dictionary<int, List<(int row, int val)>> columnMap =
            new Dictionary<int, List<(int, int)>>();

        Dfs(root, 0, 0, columnMap);

        // Sort columns from left to right
        List<int> sortedKeys = new List<int>(columnMap.Keys);
        sortedKeys.Sort();

        foreach (int col in sortedKeys) {
            List<(int row, int val)> entries = columnMap[col];
            // List.Sort is not stable; OrderBy is, so same-row nodes
            // keep their left-to-right insertion order
            IList<int> colValues = new List<int>();
            foreach (var entry in entries.OrderBy(e => e.row)) {
                colValues.Add(entry.val);
            }
            result.Add(colValues);
        }

        return result;
    }

    private void Dfs(TreeNode node, int row, int col,
                     Dictionary<int, List<(int row, int val)>> columnMap) {
        if (node == null) return;

        if (!columnMap.ContainsKey(col))
            columnMap[col] = new List<(int, int)>();
        columnMap[col].Add((row, node.val));

        // Process left before right to maintain left-to-right order
        Dfs(node.left, row + 1, col - 1, columnMap);
        Dfs(node.right, row + 1, col + 1, columnMap);
    }
}
```

```go
func verticalOrder(root *TreeNode) [][]int {
    if root == nil {
        return [][]int{}
    }

    type entry struct {
        row, val int
    }
    columnMap := make(map[int][]entry)

    var dfs func(node *TreeNode, row, col int)
    dfs = func(node *TreeNode, row, col int) {
        if node == nil {
            return
        }
        columnMap[col] = append(columnMap[col], entry{row, node.Val})
        // Process left before right to maintain left-to-right order
        dfs(node.Left, row+1, col-1)
        dfs(node.Right, row+1, col+1)
    }

    dfs(root, 0, 0)

    // Sort columns from left to right
    keys := make([]int, 0, len(columnMap))
    for k := range columnMap {
        keys = append(keys, k)
    }
    sort.Ints(keys)

    result := make([][]int, len(keys))
    for i, col := range keys {
        entries := columnMap[col]
        // Stable sort by row preserves left-to-right for same row
        sort.SliceStable(entries, func(a, b int) bool {
            return entries[a].row < entries[b].row
        })
        vals := make([]int, len(entries))
        for j, e := range entries {
            vals[j] = e.val
        }
        result[i] = vals
    }
    return result
}
```

```rust
use std::collections::HashMap;

/**
 * Definition for a binary tree node.
 * pub struct TreeNode {
 *     pub val: i32,
 *     pub left: Option<Rc<RefCell<TreeNode>>>,
 *     pub right: Option<Rc<RefCell<TreeNode>>>,
 * }
 */

use std::cell::RefCell;
use std::rc::Rc;

type Node = Option<Rc<RefCell<TreeNode>>>;

impl Solution {
    pub fn vertical_order(root: Node) -> Vec<Vec<i32>> {
        if root.is_none() {
            return vec![];
        }

        // Map from column to list of (row, value) pairs
        let mut column_map: HashMap<i32, Vec<(i32, i32)>> = HashMap::new();
        Self::dfs(root, 0, 0, &mut column_map);

        // Sort columns from left to right
        let mut sorted_keys: Vec<i32> = column_map.keys().copied().collect();
        sorted_keys.sort();

        let mut result = Vec::new();
        for col in sorted_keys {
            let entries = column_map.get_mut(&col).unwrap();
            // Stable sort by row preserves left-to-right for same row
            entries.sort_by(|a, b| a.0.cmp(&b.0));
            let mut col_values = Vec::with_capacity(entries.len());
            for &(_, val) in entries.iter() {
                col_values.push(val);
            }
            result.push(col_values);
        }

        result
    }

    fn dfs(node: Node, row: i32, col: i32, column_map: &mut HashMap<i32, Vec<(i32, i32)>>) {
        if let Some(rc_node) = node {
            let node_ref = rc_node.borrow();
            column_map.entry(col).or_insert_with(Vec::new).push((row, node_ref.val));

            // Process left before right to maintain left-to-right order
            Self::dfs(node_ref.left.clone(), row + 1, col - 1, column_map);
            Self::dfs(node_ref.right.clone(), row + 1, col + 1, column_map);
        }
    }
}
```
