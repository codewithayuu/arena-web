<LessonCard>

Given a collection of candidate numbers (`candidates`) and a target number (`target`), find all unique combinations in `candidates` where the candidate numbers sum to `target`.

Each number in `candidates` may only be used **once** in the combination.

**Note:** The solution set must not contain duplicate combinations.

\***\*Example 1:\*\***

- **Input:** `candidates = [10,1,2,7,6,1,5]`

- **Input:** `target = 8`

- **Output:** `[[1,1,6],[1,2,5],[1,7],[2,6]]`

\***\*Example 2:\*\***

- **Input:** `candidates = [2,5,2,1,2]`

- **Input:** `target = 5`

- **Output:** `[[1,2,2],[5]]`

\***\*Constraints:\*\***

- `1 <= candidates.length <= 100`
- `1 <= candidates[i] <= 50`
- `1 <= target <= 30`

We're given an array of numbers that may contain duplicates, and we need to find all unique combinations that add up to a target sum. Each element in the array can be used at most once (based on its position), and we can't have duplicate combinations in the result.

Two requirements interact here. The search must explore subsets that sum to a target, and the input can contain duplicate values, so naive backtracking produces the same combination through different index paths. For example, with `candidates = [1, 1, 2]` and `target = 3`, picking the first 1 with 2 and picking the second 1 with 2 both give [1, 2], but the result should contain it once.

Sorting the array places equal values next to each other. That lets the backtracking skip a value it has already tried at the same decision level, which is enough to prevent duplicate combinations from being generated at all.

- `1 <= candidates.length <= 100` → With n up to 100, we can't enumerate all 2^100 subsets. But the target is at most 30, and each candidate is at least 1, so any valid combination has at most 30 elements. This keeps the recursion tree shallow.
- `1 <= candidates[i] <= 50` → All candidates are positive. This means the running sum only increases as we add elements, allowing us to prune when the sum exceeds the target.
- `1 <= target <= 30` → The small target limits the number of valid combinations. Even though the array can have 100 elements, we'll never go deeper than 30 levels in the recursion.

<h1 id="approach-1-brute-force-generate-all-then-deduplicate">
  Approach 1: Brute Force (Generate All, Then Deduplicate)
</h1>

<h3 id="intuition">Intuition</h3>

Ignore duplicates during generation and remove them afterward. Sort the array, generate every subset that sums to the target with standard include/exclude backtracking, and store each valid combination in a set so repeated combinations collapse into one entry.

Sorting matters even in this brute-force version. The recursion picks elements in index order, so on an unsorted array two index subsets with the same values can produce differently ordered lists ([7, 1] from one path, [1, 7] from another), and the set would treat them as distinct. Sorting first gives every combination a canonical order, so equal combinations compare equal.

The cost is wasted work: the search builds duplicate combinations in full, and the set immediately discards them.

<h3 id="algorithm">Algorithm</h3>

1. Sort the candidates array.
2. Use backtracking to explore all subsets: for each element, try including it and try skipping it.
3. When the remaining target reaches 0, add the current combination to a set (to catch duplicates).
4. When the remaining target goes negative, stop exploring that branch.
5. Convert the set of unique combinations into a list and return it.

<h3 id="code">Code</h3>

```java
class Solution {
    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        Arrays.sort(candidates);
        Set<List<Integer>> resultSet = new HashSet<>();
        backtrack(candidates, 0, target, new ArrayList<>(), resultSet);
        return new ArrayList<>(resultSet);
    }

    private void backtrack(int[] candidates, int index, int remaining, List<Integer> current, Set<List<Integer>> resultSet) {
        if (remaining == 0) {
            resultSet.add(new ArrayList<>(current));
            return;
        }
        if (index == candidates.length || remaining < 0) {
            return;
        }
        // Include candidates[index]
        current.add(candidates[index]);
        backtrack(candidates, index + 1, remaining - candidates[index], current, resultSet);
        current.remove(current.size() - 1);

        // Skip candidates[index]
        backtrack(candidates, index + 1, remaining, current, resultSet);
    }
}
```

<h1 id="approach-2-backtracking-with-sorting-and-duplicate-skipping">
  Approach 2: Backtracking with Sorting and Duplicate Skipping
</h1>

<h3 id="intuition">Intuition</h3>

Sort the array and apply one rule during backtracking: at any given decision level, once a value has been tried, skip every later occurrence of that same value.

After sorting, duplicates sit next to each other. Each call loops over candidates from its `start` index to the right, so when `i > start` and `candidates[i] == candidates[i-1]`, the value at index `i` was already tried at this level by the iteration at `i-1`, and the loop skips it.

> Uniqueness: when `candidates[i] == candidates[i-1]` and `i > start`, every combination that begins by picking `candidates[i]` at this level was already produced when `candidates[i-1]` was picked, because the candidates available after index `i` are a subset of those available after index `i-1`. Skipping `candidates[i]` removes only repeats.
>
> Completeness: the second copy of a value is still reachable as a deeper choice. With `[1, 1, 6]` and `target = 8`, the second `1` is skipped at the root level, but after picking the first `1` and recursing, the second `1` satisfies `i == start` at the next level and gets picked normally. [1, 1, 6] is still found, exactly once.

<h3 id="algorithm">Algorithm</h3>

1. Sort the candidates array.
2. Start a backtracking function with a start index, the remaining target, and the current combination.
3. If remaining equals 0, we found a valid combination. Add a copy to the result.
4. Loop from `start` to the end of the array. For each index `i`:
5. Return the result.

```java
class Solution {
    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        Arrays.sort(candidates);
        List<List<Integer>> result = new ArrayList<>();
        backtrack(candidates, 0, target, new ArrayList<>(), result);
        return result;
    }

    private void backtrack(int[] candidates, int start, int remaining, List<Integer> current, List<List<Integer>> result) {
        if (remaining == 0) {
            result.add(new ArrayList<>(current));
            return;
        }
        for (int i = start; i < candidates.length; i++) {
            // Prune: all subsequent candidates are larger, so stop here
            if (candidates[i] > remaining) break;
            // Skip duplicates at the same decision level
            if (i > start && candidates[i] == candidates[i - 1]) continue;

            current.add(candidates[i]);
            backtrack(candidates, i + 1, remaining - candidates[i], current, result);
            current.remove(current.size() - 1);
        }
    }
}
```

A different way to handle duplicates works at the level of values instead of indices.

<h1 id="approach-3-backtracking-with-frequency-counting">
  Approach 3: Backtracking with Frequency Counting
</h1>

<h3 id="intuition">Intuition</h3>

Count how many times each value appears, then backtrack over the unique values. For each unique value, decide how many copies to use (from 0 up to the available count), then move to the next unique value.

This reframes the problem from "which indices to pick" to "how many of each value to use," and no duplicate-skipping rule is needed because the search never sees the same value twice at one level. The deduplication argument is direct: two combinations produced by this search must differ in the copy count of at least one value, so they cannot be equal.

<h3 id="algorithm">Algorithm</h3>

1. Count the frequency of each candidate value (using a hash map or sorted map).
2. Convert the frequency map into a list of (value, count) pairs.
3. Start a backtracking function that iterates over these pairs. For each pair (value, count):
4. When the remaining target reaches 0, record the combination.

<h3 id="example-walkthrough">Example Walkthrough</h3>

<h3 id="code">Code</h3>

```java
class Solution {
    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        // Count frequency of each value
        Map<Integer, Integer> freqMap = new TreeMap<>();
        for (int c : candidates) {
            freqMap.put(c, freqMap.getOrDefault(c, 0) + 1);
        }
        // Convert to list of (value, count) pairs
        List<int[]> pairs = new ArrayList<>();
        for (Map.Entry<Integer, Integer> entry : freqMap.entrySet()) {
            pairs.add(new int[]{entry.getKey(), entry.getValue()});
        }

        List<List<Integer>> result = new ArrayList<>();
        backtrack(pairs, 0, target, new ArrayList<>(), result);
        return result;
    }

    private void backtrack(List<int[]> pairs, int index, int remaining, List<Integer> current, List<List<Integer>> result) {
        if (remaining == 0) {
            result.add(new ArrayList<>(current));
            return;
        }
        if (index == pairs.size()) return;

        int value = pairs.get(index)[0];
        int count = pairs.get(index)[1];

        // Try using 0 to count copies of this value
        for (int copies = 0; copies <= count; copies++) {
            if (value * copies > remaining) break;

            // Add 'copies' copies of value to current
            for (int j = 0; j < copies; j++) {
                current.add(value);
            }
            backtrack(pairs, index + 1, remaining - value * copies, current, result);
            // Remove the copies we added
            for (int j = 0; j < copies; j++) {
                current.remove(current.size() - 1);
            }
        }
    }
}
```

```cpp
    vector<vector<int>> combinationSum2(vector<int>& candidates, int target) {
        // Count frequency of each value
        map<int, int> freqMap;
        for (int c : candidates) {
            freqMap[c]++;
        }
        // Convert to list of (value, count) pairs
        vector<pair<int, int>> pairs(freqMap.begin(), freqMap.end());

        vector<vector<int>> result;
        vector<int> current;
        backtrack(pairs, 0, target, current, result);
        return result;
    }

private:
    void backtrack(vector<pair<int, int>>& pairs, int index, int remaining, vector<int>& current, vector<vector<int>>& result) {
        if (remaining == 0) {
            result.push_back(current);
            return;

        if (index == (int)pairs.size()) return;

        int value = pairs[index].first;
        int count = pairs[index].second;

                current.push_back(value);
            }
            backtrack(pairs, index + 1, remaining - value * copies, current, result);
```

```csharp
            if (freqMap.ContainsKey(c)) freqMap[c]++;
            else freqMap[c] = 1;
        }
        // Convert to list of (value, count) pairs
        List<int[]> pairs = new List<int[]>();
        foreach (var entry in freqMap) {
            pairs.Add(new int[] { entry.Key, entry.Value });
        }

        IList<IList<int>> result = new List<IList<int>>();
        Backtrack(pairs, 0, target, new List<int>(), result);
        return result;
    }

    private void Backtrack(List<int[]> pairs, int index, int remaining, List<int> current, IList<IList<int>> result) {
        if (remaining == 0) {
            result.Add(new List<int>(current));
            return;
        }
        if (index == pairs.Count) return;

        int value = pairs[index][0];
        int count = pairs[index][1];

        // Try using 0 to count copies of this value
        for (int copies = 0; copies <= count; copies++) {
            if (value * copies > remaining) break;

            for (int j = 0; j < copies; j++) {
                current.Add(value);
            }
            Backtrack(pairs, index + 1, remaining - value * copies, current, result);
            for (int j = 0; j < copies; j++) {
                current.RemoveAt(current.Count - 1);
            }
        }
    }
}
```

```go
func combinationSum2(candidates []int, target int) [][]int {
    // Count frequency of each value
    freqMap := map[int]int{}
    for _, c := range candidates {
        freqMap[c]++
    }
    // Convert to sorted list of (value, count) pairs
    keys := []int{}
    for k := range freqMap {
        keys = append(keys, k)
    }
    sort.Ints(keys)
    pairs := [][2]int{}
    for _, k := range keys {
        pairs = append(pairs, [2]int{k, freqMap[k]})
    }

    result := [][]int{}
    var backtrack func(index, remaining int, current []int)
    backtrack = func(index, remaining int, current []int) {
        if remaining == 0 {
            combo := make([]int, len(current))
            copy(combo, current)
            result = append(result, combo)
            return
        }
        if index == len(pairs) {
            return
        }
        value := pairs[index][0]
        count := pairs[index][1]

        // Try using 0 to count copies of this value
        for copies := 0; copies <= count; copies++ {
            if value*copies > remaining {
                break
            }
            added := make([]int, len(current))
            copy(added, current)
            for j := 0; j < copies; j++ {
                added = append(added, value)
            }
            backtrack(index+1, remaining-value*copies, added)
        }
    }
    backtrack(0, target, []int{})
    return result
}
```

```rust
use std::collections::BTreeMap;

impl Solution {
    pub fn combination_sum2(candidates: Vec<i32>, target: i32) -> Vec<Vec<i32>> {
        // Count frequency of each value
        let mut freq_map: BTreeMap<i32, i32> = BTreeMap::new();
        for c in candidates {
            *freq_map.entry(c).or_insert(0) += 1;
        }
        // Convert to list of (value, count) pairs
        let pairs: Vec<(i32, i32)> = freq_map.into_iter().collect();

        let mut result: Vec<Vec<i32>> = Vec::new();
        let mut current: Vec<i32> = Vec::new();
        Self::backtrack(&pairs, 0, target, &mut current, &mut result);
        result
    }

    fn backtrack(
        pairs: &Vec<(i32, i32)>,
        index: usize,
        remaining: i32,
        current: &mut Vec<i32>,
        result: &mut Vec<Vec<i32>>,
    ) {
        if remaining == 0 {
            result.push(current.clone());
            return;
        }
        if index == pairs.len() {
            return;
        }

        let (value, count) = pairs[index];

        // Try using 0 to count copies of this value
        for copies in 0..=count {
            if value * copies > remaining {
                break;
            }

            // Add 'copies' copies of value to current
            for _ in 0..copies {
                current.push(value);
            }
            Self::backtrack(pairs, index + 1, remaining - value * copies, current, result);
            // Remove the copies we added
            for _ in 0..copies {
                current.pop();
            }
        }
    }
}
```

> - **Time Complexity:** O(2^n \* k). The number of leaves in the search is the product of (count + 1) over all unique values, and since count + 1 &lt;= 2^count, this product is at most 2^n (with equality when all candidates are distinct). Each recorded combination of length up to k costs O(k) to copy. The more duplicates the input has, the further the product falls below 2^n, which is where this approach saves work over Approach 1.
> - **Space Complexity:** O(target + m). The recursion depth is bounded by m (number of unique values). The frequency map takes O(m) space. The current combination takes O(target) space at most.
