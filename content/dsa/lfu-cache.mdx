<LessonCard>

Design and implement a data structure for a Least Frequently Used (LFU) cache.

Implement the `LFUCache` class:

- `LFUCache(int capacity)` Initializes the object with the `capacity` of the data structure.
- `int get(int key)` Gets the value of the `key` if the `key` exists in the cache. Otherwise, returns `-1`.
- `void put(int key, int value)` Update the value of the `key` if present, or inserts the `key` if not already present. When the cache reaches its `capacity`, it should invalidate and remove the **least frequently used** key before inserting a new item. For this problem, when there is a **tie** (i.e., two or more keys with the same frequency), the **least recently used** key would be evicted.

To determine the least frequently used key, a **use counter** is maintained for each key in the cache. The key with the smallest **use counter** is the least frequently used key.

When a key is first inserted into the cache, its **use counter** is set to `1` (due to the `put` operation). The **use counter** for a key in the cache is incremented either a `get` or `put` operation is called on it.

The functions `get` and `put` must each run in `O(1)` average time complexity.

**Example 1:**

- **Input:** `operations = ["LFUCache","put","put","get","put","get","get","put","get","get","get"]`

- **Input:** `args = [[2],[1,1],[2,2],[1],[3,3],[2],[3],[4,4],[1],[3],[4]]`

- **Output:** `[null,null,null,1,null,-1,3,null,-1,3,4]`

**Constraints:**

- `1 <= capacity <= 10^4`
- `0 <= key <= 10^5`
- `0 <= value <= 10^9`
- At most `2 * 10^5` calls will be made to `get` and `put`.

<h1 id="understanding-the-problem">Understanding the Problem</h1>

We need to build a cache with a twist. Unlike LRU Cache (which evicts the least recently used item), LFU Cache tracks how many times each key has been accessed and evicts the one used the fewest times. When multiple keys share the same frequency, we break the tie using LRU ordering, evicting whichever was accessed least recently among them.

So there are two dimensions to manage: frequency counts and recency within each frequency. The challenge is doing this in O(1) time for both `get` and `put`. That rules out sorting, scanning, and log(n) data structures like heaps or balanced BSTs.

Two operations have to be fast: finding the minimum frequency, and within that frequency group, finding and removing the least recently used item. A combination of hash maps and linked lists handles both.

<h3 id="key-constraints">Key Constraints:</h3>

- `1 <= capacity <= 10^4`. The O(1) requirement is stated explicitly in the problem, so a small cache size is no excuse for a slower approach.
- `0 <= key <= 10^5`. Keys are non-negative integers, but a key array of size 10^5 wastes space when the cache holds far fewer entries, so a hash map is the general choice.
- At most `2 * 10^5` calls. With 200K operations, an O(n) per-operation approach reaches roughly 2 \* 10^9 basic steps in the worst case and times out. An O(log n) heap approach passes but does not meet the O(1) requirement.

<h1 id="approach-1-brute-force-linear-scan">
  Approach 1: Brute Force (Linear Scan)
</h1>

<h3 id="intuition">Intuition</h3>

Store everything in a single hash map and handle eviction by scanning. For each key, track its value, its frequency count, and the timestamp of its last access. When eviction is needed, scan all entries to find the one with the lowest frequency, breaking ties by oldest timestamp.

This does not meet the O(1) requirement, but it gets the eviction rule correct and sets up the optimization that follows.

<h3 id="algorithm">Algorithm</h3>

1. Maintain a hash map where each key maps to a triple: `(value, frequency, lastUsed)`.
2. Keep a global counter `time` that increments on every `get` or `put` call.
3. For `get(key)`: if key exists, increment its frequency, update its `lastUsed` to current `time`, and return its value. Otherwise return -1.
4. For `put(key, value)`: if key exists, update its value, increment frequency, update `lastUsed`. If key doesn't exist and cache is full, scan all entries to find the one with the minimum frequency (break ties by minimum `lastUsed`), remove it, then insert the new key with frequency=1.

```java
class LFUCache {
    int capacity;
    int time;
    // key -> [value, frequency, lastUsed]
    HashMap<Integer, int[]> map;

    public LFUCache(int capacity) {
        this.capacity = capacity;
        this.time = 0;
        this.map = new HashMap<>();
    }

    public int get(int key) {
        if (!map.containsKey(key)) return -1;
        int[] entry = map.get(key);
        entry[1]++; // increment frequency
        entry[2] = time++; // update last used time
        return entry[0];
    }

    public void put(int key, int value) {
        if (capacity == 0) return;
        if (map.containsKey(key)) {
            int[] entry = map.get(key);
            entry[0] = value;
            entry[1]++; // increment frequency
            entry[2] = time++; // update last used time
            return;
        }
        // Evict if at capacity
        if (map.size() == capacity) {
            int evictKey = -1;
            int minFreq = Integer.MAX_VALUE;
            int minTime = Integer.MAX_VALUE;
            // Scan all entries to find LFU (then LRU for ties)
            for (var e : map.entrySet()) {
                int[] info = e.getValue();
                if (info[1] < minFreq || (info[1] == minFreq && info[2] < minTime)) {
                    minFreq = info[1];
                    minTime = info[2];
                    evictKey = e.getKey();
                }
            }
            map.remove(evictKey);
        }
        map.put(key, new int[]{value, 1, time++});
    }
}
```

```rust
    time: i32,

        if !self.map.contains_key(&key) {

        let entry = self.map.get_mut(&key).unwrap();
        entry[1] += 1; // increment frequency
        entry[2] = self.time; // update last used time
        self.time += 1;
        entry[0]
    }

    fn put(&mut self, key: i32, value: i32) {
        if self.capacity == 0 {
            return;
        }
        if self.map.contains_key(&key) {
            let entry = self.map.get_mut(&key).unwrap();
            entry[0] = value;
            entry[1] += 1; // increment frequency
            entry[2] = self.time; // update last used time
            self.time += 1;

                    min_time = info[2];

                }

            self.map.remove(&evict_key);
```

> - **Time Complexity:** O(n) per `put` in the worst case, O(1) for `get`. The `put` operation scans all n entries in the cache when eviction is needed. The `get` is O(1): a hash map lookup plus a metadata update.
> - **Space Complexity:** O(capacity). We store at most `capacity` entries in the hash map, each with constant extra metadata.

The O(n) scan on every eviction is the bottleneck. A min-heap ordered by the eviction priority removes the need to scan, bringing eviction down to O(log n).

<h1 id="approach-2-heap-based-olog-n">Approach 2: Heap-Based (O(log n))</h1>

<h3 id="intuition">Intuition</h3>

Instead of scanning all entries to find the minimum, use a min-heap (priority queue) ordered by `(frequency, lastUsed)`. The top of the heap is always the eviction candidate, which brings eviction down from O(n) to O(log n).

The complication is updates. When `get` is called on a key, its frequency and last-used time change, but a binary heap cannot update an arbitrary element efficiently. The workaround is lazy deletion: push a fresh entry for the key on every change and leave the old entry in the heap. During eviction, pop entries and skip any whose `(frequency, lastUsed)` no longer matches what the hash map records for that key.

<h3 id="algorithm">Algorithm</h3>

1. Maintain a hash map `keyToEntry` mapping each key to `(value, frequency, lastUsed)`.
2. Maintain a min-heap ordered by `(frequency, lastUsed)`. Each heap entry stores `(frequency, lastUsed, key)`.
3. For `get(key)`: look up in hash map, increment frequency, update lastUsed, push a new entry into the heap (the old one becomes stale).
4. For `put(key, value)`: if key exists, update it like `get`. If not, evict if full. To evict, pop from the heap until we find an entry whose `(frequency, lastUsed)` matches the current state in the hash map (skip stale entries). Remove that key. Then insert the new key.

```java
class LFUCache {
    int capacity, time;
    HashMap<Integer, int[]> map; // key -> [value, freq, lastUsed]
    PriorityQueue<int[]> heap;   // [freq, lastUsed, key]

    public LFUCache(int capacity) {
        this.capacity = capacity;
        this.time = 0;
        this.map = new HashMap<>();
        // Min-heap ordered by (freq, lastUsed)
        this.heap = new PriorityQueue<>((a, b) ->
            a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);
    }

    public int get(int key) {
        if (!map.containsKey(key)) return -1;
        int[] entry = map.get(key);
        entry[1]++;
        entry[2] = time++;
        // Push updated entry; old one becomes stale
        heap.offer(new int[]{entry[1], entry[2], key});
        return entry[0];
    }

    public void put(int key, int value) {
        if (capacity == 0) return;
        if (map.containsKey(key)) {
            int[] entry = map.get(key);
            entry[0] = value;
            entry[1]++;
            entry[2] = time++;
            heap.offer(new int[]{entry[1], entry[2], key});
            return;
        }
        if (map.size() == capacity) {
            // Pop until we find a non-stale entry
            while (!heap.isEmpty()) {
                int[] top = heap.poll();
                int k = top[2];
                if (map.containsKey(k) && map.get(k)[1] == top[0] && map.get(k)[2] == top[1]) {
                    map.remove(k);
                    break;
                }
            }
        }
        map.put(key, new int[]{value, 1, time});
        heap.offer(new int[]{1, time, key});
        time++;
    }
}
```

```csharp
        var entry = map[key];
        entry[1]++;

            entry[1]++;
            entry[2] = time++;
            heap.Enqueue(new int[]{entry[1], entry[2], key}, (entry[1], entry[2]));

                    break;
                }
            }
        }
        map[key] = new int[]{value, 1, time};
        heap.Enqueue(new int[]{1, time, key}, (1, time));
        time++;
    }
```

```go
type entry struct {
    freq, lastUsed, key int
}
type minHeap []entry
func (h minHeap) Len() int { return len(h) }
func (h minHeap) Less(i, j int) bool {
    if h[i].freq != h[j].freq { return h[i].freq < h[j].freq }
    return h[i].lastUsed < h[j].lastUsed
}
func (h minHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }
func (h *minHeap) Push(x interface{}) { *h = append(*h, x.(entry)) }
func (h *minHeap) Pop() interface{} {
    old := *h; n := len(old); x := old[n-1]; *h = old[:n-1]; return x
}

type LFUCache struct {
    capacity, time int
    cache          map[int][3]int // key -> [value, freq, lastUsed]
    h              *minHeap
}

func Constructor(capacity int) LFUCache {
    h := &minHeap{}
    heap.Init(h)
    return LFUCache{capacity: capacity, cache: make(map[int][3]int), h: h}
}

func (c *LFUCache) Get(key int) int {
    e, ok := c.cache[key]
    if !ok { return -1 }
    e[1]++; e[2] = c.time; c.time++
    c.cache[key] = e
    heap.Push(c.h, entry{e[1], e[2], key})
    return e[0]
}

    if c.capacity == 0 { return }

        e[0] = value; e[1]++; e[2] = c.time; c.time++
        c.cache[key] = e
        heap.Push(c.h, entry{e[1], e[2], key})
        return
    }
    if len(c.cache) == c.capacity {
        for c.h.Len() > 0 {
            top := heap.Pop(c.h).(entry)
            if e, ok := c.cache[top.key]; ok && e[1] == top.freq && e[2] == top.lastUsed {
                delete(c.cache, top.key)
                break
            }
        }
    }
    c.cache[key] = [3]int{value, 1, c.time}
    heap.Push(c.h, entry{1, c.time, key})
    c.time++
}
```

```rust
    heap: BinaryHeap<Reverse<(i32, i32, i32)>>, // (freq, lastUsed, key)

    pub fn new(capacity: i32) -> Self {
        LFUCache {
            capacity: capacity as usize,
            time: 0,
            map: HashMap::new(),
            heap: BinaryHeap::new(),
        }
    }

        if !self.map.contains_key(&key) {
            return -1;
        }
        let entry = self.map.get_mut(&key).unwrap();
        entry[1] += 1;
        entry[2] = self.time;
        self.time += 1;
        // Push updated entry; old one becomes stale
        self.heap.push(Reverse((entry[1], entry[2], key)));
        entry[0]
    }

    pub fn put(&mut self, key: i32, value: i32) {
        if self.capacity == 0 {
            return;
        }
        if self.map.contains_key(&key) {
            let entry = self.map.get_mut(&key).unwrap();
            entry[0] = value;
            entry[1] += 1;
            entry[2] = self.time;
            self.time += 1;
            self.heap.push(Reverse((entry[1], entry[2], key)));
            return;
        }
        if self.map.len() == self.capacity {
            // Pop until we find a non-stale entry
            while let Some(Reverse((freq, last_used, k))) = self.heap.pop() {
                if let Some(entry) = self.map.get(&k) {
                    if entry[1] == freq && entry[2] == last_used {
                        self.map.remove(&k);
                        break;
                    }
                }
            }
        }
        self.map.insert(key, [value, 1, self.time]);
        self.heap.push(Reverse((1, self.time, key)));
        self.time += 1;
    }
```

```typescript
class LFUCache {
  private capacity: number;
  private time: number;
  private map: Map<number, number[]>; // key -> [value, freq, lastUsed]
  private heap: number[][]; // [[freq, lastUsed, key], ...]

  constructor(capacity: number) {
    this.capacity = capacity;
    this.time = 0;
    this.map = new Map();
    this.heap = [];
  }

  private compare(a: number[], b: number[]): number {
    return a[0] !== b[0] ? a[0] - b[0] : a[1] - b[1];
  }

  private heapPush(item: number[]): void {
    this.heap.push(item);
    let i = this.heap.length - 1;
    while (i > 0) {
      const parent = (i - 1) >> 1;
      if (this.compare(this.heap[i], this.heap[parent]) < 0) {
        [this.heap[i], this.heap[parent]] = [this.heap[parent], this.heap[i]];
        i = parent;
      } else break;
    }
  }

  private heapPop(): number[] {
    const top = this.heap[0];
    const last = this.heap.pop()!;
    if (this.heap.length > 0) {
      this.heap[0] = last;
      let i = 0;
      while (true) {
        let smallest = i,
          l = 2 * i + 1,
          r = 2 * i + 2;

          this.compare(this.heap[r], this.heap[smallest]) < 0

          smallest = r;
        if (smallest === i) break;
        [this.heap[i], this.heap[smallest]] = [
          this.heap[smallest],
          this.heap[i],
        ];
        i = smallest;
      }
    }
    return top;

    entry[2] = this.time++;

      entry[0] = value;
      entry[1]++;
      entry[2] = this.time++;
      this.heapPush([entry[1], entry[2], key]);
```

> - **Time Complexity:** O(log n) amortized per operation. Both `get` and `put` do a heap push (O(log n)). Eviction involves popping from the heap, also O(log n). Lazy deletion can cause extra pops, but amortized each entry is pushed and popped at most once per frequency change.
> - **Space Complexity:** O(n) where n is the number of operations. The heap can accumulate stale entries, growing to O(total operations) in the worst case. The hash map stays at O(capacity).

The heap gives O(log n) per operation, but the problem asks for O(1). Two facts about LFU make the heap unnecessary: frequencies only ever increase by 1, and only the minimum frequency is ever queried. Grouping keys by frequency and tracking the minimum directly turns every operation into O(1).

<h1 id="approach-3-optimal-hashmap-frequency-buckets-with-doubly-linked-lists">
  Approach 3: Optimal - HashMap + Frequency Buckets with Doubly Linked Lists
</h1>

<h3 id="intuition">Intuition</h3>

Because frequencies only increase by 1 and only the minimum is ever queried, no heap or sorted structure is needed.

Organize keys into frequency buckets. Bucket 1 holds all keys accessed once, bucket 2 holds keys accessed twice, and so on. Within each bucket, keys are ordered by recency using a doubly linked list: most recently used at the tail, least recently used at the head.

To evict, go to the bucket at `minFreq` and remove the head of its list (the least recently used key in the minimum-frequency group). That is O(1).

When a key's frequency increases from f to f+1, remove its node from bucket f's list and add it to bucket f+1's list. Both steps are O(1) because the hash map gives a direct pointer to the node, and a doubly linked list removes or inserts a known node in constant time.

The remaining question is how to keep `minFreq` correct without scanning. It changes in exactly two situations: inserting a brand new key resets it to 1, and emptying the bucket at `minFreq` during a promotion increments it by 1.

> The two-case update for `minFreq` is exhaustive. A promotion moves a node from bucket f to bucket f+1, so it can only ever empty bucket f, never any other bucket. If f was the minimum and is now empty, the smallest non-empty bucket must be f+1, because the promoted node landed there and no bucket between the old minimum and f+1 exists. If f was not the minimum, the minimum bucket still has its keys, so `minFreq` is unchanged. On insertion, the new key has frequency 1, which is the global minimum possible, so `minFreq` is 1. No other operation removes keys, so these two cases cover every change.

<h3 id="algorithm">Algorithm</h3>

1. Maintain three data structures:
2. For `get(key)`: if key doesn't exist, return -1. Otherwise, remove the node from its current frequency list, increment its frequency, add it to the new frequency's list. If the old frequency list is now empty and equals `minFreq`, increment `minFreq`. Return the value.
3. For `put(key, value)`: if capacity is 0, return. If key exists, update its value and call the same frequency-promotion logic as `get`. If key doesn't exist and cache is full, evict the head node from `freqToList[minFreq]`. Create a new node with frequency 1, add it to `freqToList[1]`, and set `minFreq = 1`.

```go
        c.promote(node)
        return
    }
    // Evict if at capacity
    if len(c.keyToNode) == c.capacity {
        minList := c.freqToList[c.minFreq]
        evicted := minList.removeHead()
        delete(c.keyToNode, evicted.key)
    }
    // Insert new node
    newNode := &Node{key: key, value: value, freq: 1}
    c.keyToNode[key] = newNode
    if _, ok := c.freqToList[1]; !ok {
        c.freqToList[1] = newDLinkedList()
    }
    c.freqToList[1].addToTail(newNode)
    c.minFreq = 1
}
```

```rust
use std::collections::HashMap;
use std::ptr::NonNull;

struct Node {
    key: i32,
    value: i32,
    freq: i32,
    prev: Option<NonNull<Node>>,
    next: Option<NonNull<Node>>,
}

struct DLinkedList {
    head: NonNull<Node>,
    tail: NonNull<Node>,
    size: usize,
}

impl DLinkedList {
    fn new() -> Self {
        let head = Box::new(Node {
            key: 0,
            value: 0,
            freq: 0,
            prev: None,
            next: None,
        });
        let tail = Box::new(Node {
            key: 0,
            value: 0,
            freq: 0,
            prev: None,
            next: None,
        });

        let head = unsafe { NonNull::new_unchecked(Box::into_raw(head)) };
        let tail = unsafe { NonNull::new_unchecked(Box::into_raw(tail)) };

        unsafe {
            (*head.as_ptr()).next = Some(tail);
            (*tail.as_ptr()).prev = Some(head);
        }

        Self { head, tail, size: 0 }
    }

    // Add node to tail (most recently used position)
    fn add_to_tail(&mut self, node: NonNull<Node>) {
        unsafe {
            let prev = (*self.tail.as_ptr()).prev.unwrap();
            (*node.as_ptr()).prev = Some(prev);
            (*node.as_ptr()).next = Some(self.tail);
            (*prev.as_ptr()).next = Some(node);
            (*self.tail.as_ptr()).prev = Some(node);
        }
        self.size += 1;
    }

    // Remove a specific node
    fn remove(&mut self, node: NonNull<Node>) {
        unsafe {
            let prev = (*node.as_ptr()).prev.unwrap();
            let next = (*node.as_ptr()).next.unwrap();
            (*prev.as_ptr()).next = Some(next);
            (*next.as_ptr()).prev = Some(prev);
            (*node.as_ptr()).prev = None;
            (*node.as_ptr()).next = None;
        }
        self.size -= 1;
    }

    // Remove and return the head node (least recently used)
    fn remove_head(&mut self) -> Option<NonNull<Node>> {
        if self.size == 0 {
            return None;
        }
        unsafe {
            let first = (*self.head.as_ptr()).next.unwrap();
            self.remove(first);
            Some(first)
        }
    }

    fn is_empty(&self) -> bool {
        self.size == 0
    }
}

impl Drop for DLinkedList {
    fn drop(&mut self) {
        unsafe {
            let _ = Box::from_raw(self.head.as_ptr());
            let _ = Box::from_raw(self.tail.as_ptr());
        }
    }
}

pub struct LFUCache {
    capacity: usize,
    min_freq: i32,
    key_to_node: HashMap<i32, NonNull<Node>>,
    freq_to_list: HashMap<i32, DLinkedList>,
}

impl LFUCache {
    pub fn new(capacity: i32) -> Self {
        Self {
            capacity: capacity as usize,
            min_freq: 0,
            key_to_node: HashMap::new(),
            freq_to_list: HashMap::new(),
        }
    }

    pub fn get(&mut self, key: i32) -> i32 {
        let node_ptr = match self.key_to_node.get(&key).copied() {
            Some(p) => p,
            None => return -1,
        };
        self.promote_node(node_ptr);
        unsafe { (*node_ptr.as_ptr()).value }
    }

    pub fn put(&mut self, key: i32, value: i32) {
        if self.capacity == 0 {
            return;
        }

        if let Some(node_ptr) = self.key_to_node.get(&key).copied() {
            unsafe {
                (*node_ptr.as_ptr()).value = value;
            }
            self.promote_node(node_ptr);
            return;
        }

        // Evict if at capacity
        if self.key_to_node.len() == self.capacity {
            let min_list = self.freq_to_list.get_mut(&self.min_freq).unwrap();
            let evicted = min_list.remove_head().unwrap();
            let evicted_key = unsafe { (*evicted.as_ptr()).key };
            self.key_to_node.remove(&evicted_key);
            unsafe {
                drop(Box::from_raw(evicted.as_ptr()));
            }
        }

        // Insert new node
        let new_node = Box::new(Node {
            key,
            value,
            freq: 1,
            prev: None,
            next: None,
        });
        let new_node_ptr = unsafe { NonNull::new_unchecked(Box::into_raw(new_node)) };
        self.key_to_node.insert(key, new_node_ptr);
        self.freq_to_list
            .entry(1)
            .or_insert_with(DLinkedList::new)
            .add_to_tail(new_node_ptr);
        self.min_freq = 1;
    }

    // Move node from current freq list to freq+1 list
    fn promote_node(&mut self, node: NonNull<Node>) {
        let old_freq = unsafe { (*node.as_ptr()).freq };
        {
            let old_list = self.freq_to_list.get_mut(&old_freq).unwrap();
            old_list.remove(node);
            // If old list is now empty and was the min freq, bump min_freq
            if old_list.is_empty() && self.min_freq == old_freq {
                self.min_freq += 1;
            }
        }

        unsafe {
            (*node.as_ptr()).freq += 1;
            let new_freq = (*node.as_ptr()).freq;
            self.freq_to_list
                .entry(new_freq)
                .or_insert_with(DLinkedList::new)
                .add_to_tail(node);
        }
    }
}

impl Drop for LFUCache {
    fn drop(&mut self) {
        for (_, ptr) in self.key_to_node.drain() {
            unsafe {
                drop(Box::from_raw(ptr.as_ptr()));
            }
        }
    }
}
```

```javascript
  node.next.prev = node.prev;
  this.size--;

  const first = this.head.next;

};

};
```

```typescript
class DLLNode {
  key: number;
  value: number;
  freq: number;
  prev: DLLNode | null;
  next: DLLNode | null;
  constructor(key: number, value: number) {
    this.key = key;
    this.value = value;
    this.freq = 1;
    this.prev = null;
    this.next = null;
  }
}

class DoublyLinkedList {
  head: DLLNode;
  tail: DLLNode;
  size: number;
  constructor() {
    this.head = new DLLNode(0, 0);
    this.tail = new DLLNode(0, 0);
    this.head.next = this.tail;
    this.tail.prev = this.head;
    this.size = 0;
  }
  addToTail(node: DLLNode): void {
    node.prev = this.tail.prev;
    node.next = this.tail;
    this.tail.prev!.next = node;
    this.tail.prev = node;
    this.size++;
  }
  remove(node: DLLNode): void {
    node.prev!.next = node.next;
    node.next!.prev = node.prev;
    this.size--;
  }
  removeHead(): DLLNode | null {
    if (this.size === 0) return null;
    const first = this.head.next!;
    this.remove(first);
    return first;
  }
  isEmpty(): boolean {
    return this.size === 0;
  }
}

class LFUCache {
  private capacity: number;
  private minFreq: number;
  private keyToNode: Map<number, DLLNode>;
  private freqToList: Map<number, DoublyLinkedList>;

  constructor(capacity: number) {
    this.capacity = capacity;
    this.minFreq = 0;
    this.keyToNode = new Map();
    this.freqToList = new Map();
  }

  private promote(node: DLLNode): void {
    const oldFreq = node.freq;
    const oldList = this.freqToList.get(oldFreq)!;
    oldList.remove(node);
    if (oldList.isEmpty() && this.minFreq === oldFreq) {
      this.minFreq++;
    }
    node.freq++;
    if (!this.freqToList.has(node.freq)) {
      this.freqToList.set(node.freq, new DoublyLinkedList());
    }
    this.freqToList.get(node.freq)!.addToTail(node);
  }

  get(key: number): number {
    if (!this.keyToNode.has(key)) return -1;
    const node = this.keyToNode.get(key)!;
    this.promote(node);
    return node.value;
  }

  put(key: number, value: number): void {
    if (this.capacity === 0) return;
    if (this.keyToNode.has(key)) {
      const node = this.keyToNode.get(key)!;
      node.value = value;
      this.promote(node);
      return;
    }
    // Evict if at capacity
    if (this.keyToNode.size === this.capacity) {
      const minList = this.freqToList.get(this.minFreq)!;
      const evicted = minList.removeHead()!;
      this.keyToNode.delete(evicted.key);
    }
    // Insert new node
    const newNode = new DLLNode(key, value);
    this.keyToNode.set(key, newNode);
    if (!this.freqToList.has(1)) {
      this.freqToList.set(1, new DoublyLinkedList());
    }
    this.freqToList.get(1)!.addToTail(newNode);
    this.minFreq = 1;
  }
}
```

> - **Time Complexity:** O(1) for both `get` and `put`. Hash map lookup is O(1), doubly linked list remove/add is O(1), and `minFreq` updates are O(1) since they only happen in two deterministic cases.
> - **Space Complexity:** O(capacity). We store at most `capacity` nodes across all frequency lists. The `keyToNode` map has at most `capacity` entries. The `freqToList` map can have at most `capacity` entries (one per distinct frequency), but typically far fewer.
