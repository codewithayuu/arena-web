A `Point` class should support point-to-point `+` and `-` with coordinates added or subtracted component by component. Use `Point(3, 4)` as `first` and `Point(10, -2)` as `second`.

Implement `__add__` and `__sub__` so each operator returns a new `Point` when the other operand is also a `Point`, and returns `NotImplemented` for any other type. The existing `__repr__` method formats points as `Point(x, y)`.
