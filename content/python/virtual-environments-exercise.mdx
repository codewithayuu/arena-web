Build a short macOS/Linux virtual-environment setup checklist for the project `ecom-cli`. Use the venv folder `.venv`, install exactly `requests==2.32.3` and `rich==13.7.1`, and record installed versions in `requirements.txt`.

Use `python -m venv` to create the environment, `source` to activate it, `python -m pip install` to install both packages in the listed order, and shell redirection with `python -m pip freeze` to write the requirements file.
