Build a small module file named `pricing.py` and import it with `import pricing`. Inside the module, set `TAX_RATE` to `0.08` and define `cart_total(prices)` so it returns the subtotal plus 8% tax.

The main script uses the cart `[29.99, 14.99, 9.99]` and prints values through the module namespace as `pricing.cart_total(cart)` and `pricing.TAX_RATE`.
