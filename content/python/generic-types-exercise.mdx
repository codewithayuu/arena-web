Write a generic `first` helper that works for any list element type. Use the existing `TypeVar` named `T`, annotate `items` as `list[T]`, annotate the return type as `Optional[T]`, and return `None` for an empty list.

The program uses products named "Wireless Mouse" and "USB Cable", customer names "Alice" and "Bob", and an empty `list[int]`. The printed annotations should show that the same type variable flows from the input list to the optional return value.
