Calculate shopping cart totals from any number of positional price arguments. Define `cart_total` so it accepts `*prices` and returns the sum of all received prices.

The program prints totals for the prices `12.50`, `4.25`, and `3.25`; for the single price `9.99`; and for no prices. Each total is formatted with two digits after the decimal point.
