Demonstrate that a `with` statement looks up `__enter__` and `__exit__` on the manager's class, not on a single instance. The program assigns an instance attribute `cart.__enter__` that would print `instance __enter__ (ignored)`, but `with cart as value:` must use the class method instead.

Make the class `__enter__` print `class __enter__` and return `cart from class`. Make the class `__exit__` print `class __exit__` and return `False`.
