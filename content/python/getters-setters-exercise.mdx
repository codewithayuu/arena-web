A product named "Wireless Mouse" starts with price 29.99, then changes to 24.99 using the same `mouse.price = 24.99` syntax. Keep `name` as a plain public attribute.

Make `price` a property backed by `_price`. The setter must store valid values unchanged and reject negative values by raising `ValueError("price cannot be negative")`. Do not add Java-style `get_price()` or `set_price()` methods.
