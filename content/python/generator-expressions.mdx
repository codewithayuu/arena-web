<h1 id="the-syntax">The Syntax</h1>

A generator expression has the same shape as a list comprehension, except it uses parentheses instead of square brackets:

```python
prices = [29.99, 14.99, 9.99, 49.99, 19.99]

doubled = (price * 2 for price in prices)
print(doubled)
```

That's the whole syntactic difference from a list comprehension. Swap `[]` for `()` and the same expression now produces a generator object instead of a list. Nothing has run yet. No multiplication has happened. The expression just packaged up the recipe.

Compare it to the list-comprehension form:

```python
prices = [29.99, 14.99, 9.99, 49.99, 19.99]

doubled_list = [price * 2 for price in prices]
doubled_gen = (price * 2 for price in prices)

print(type(doubled_list))
print(type(doubled_gen))
```

The list comprehension allocates a full list eagerly. The generator expression returns a generator object that yields one value at a time when something asks for it. The two-character change from `[ ]` to `( )` flips the evaluation model from eager to lazy.

The general shape is:

```text
(expression for variable in iterable)
```

And with an optional `if` filter:

```text
(expression for variable in iterable if condition)
```
