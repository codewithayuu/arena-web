Create a curried `make_badge` function that takes exactly one argument per call: `label`, then `name`, then `points`. Each nested function should close over the values from earlier calls.

For the calls `make_badge("VIP")("Alice")(250)` and `make_badge("Staff")("Ben")(90)`, the final call should return a string formatted as `label: name (points pts)`.
