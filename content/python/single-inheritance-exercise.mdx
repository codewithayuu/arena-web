Create an `AdminUser` class that has exactly one parent, `User`, and no methods of its own. Use the class declaration `class AdminUser(User):` with a `pass` body so the constructor and `summary()` method come from `User`.

The program constructs one admin with user ID `2`, name `"Bob"`, and email `"bob@example.com"`, then prints the inherited summary and verifies that the admin is also a `User`.
