A `Product.code` attribute is controlled by `TraceAttribute`. Reading `product.code` should call `__get__`, print the owner class name `Product` in the message `__get__ for Product`, and return the string `descriptor value` to the caller.

Assigning the string `A-100` to `product.code` should call `__set__` and print `__set__ to A-100`.
