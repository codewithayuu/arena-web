<h1 id="overview">Overview</h1>

In this practice exercise, you'll apply the techniques learned in the **Functools Module** lesson. You'll implement memoization using `@lru_cache`, create reusable function variants using `partial`, and combine elements using `reduce`.

<h1 id="problem-1-memoized-fibonacci-with-cache-info">Problem 1: Memoized Fibonacci with Cache Info</h1>

Write a function `fib(n: int) -> int` that calculates the n-th Fibonacci number efficiently using `@lru_cache`. Verify the number of cache hits and misses using `fib.cache_info()`.

```python
from functools import lru_cache

@lru_cache(maxsize=128)
def fib(n: int) -> int:
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

# Test cases
print(fib(10))  # Output: 55
print(fib.cache_info())  # CacheInfo(hits=8, misses=11, maxsize=128, currsize=11)
```

<h1 id="problem-2-creating-specialized-functions-with-partial">Problem 2: Creating Specialized Functions with Partial</h1>

Use `functools.partial` to create a `base2_int` function that parses binary strings into base-10 integers without requiring the `base=2` argument on every invocation.

```python
from functools import partial

# Standard int takes (val, base=10)
base2_int = partial(int, base=2)

print(base2_int("1010"))  # Output: 10
print(base2_int("11111111"))  # Output: 255
```

<h1 id="problem-3-aggregating-data-with-reduce">Problem 3: Aggregating Data with Reduce</h1>

Given a list of transactions, use `functools.reduce` to calculate the net account balance starting from an initial balance of $100.

```python
from functools import reduce

transactions = [25, -10, 50, -35, 120]

net_balance = reduce(lambda acc, t: acc + t, transactions, 100)
print(f"Final Balance: ${net_balance}")  # Output: Final Balance: $250
```
