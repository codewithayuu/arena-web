<h1 id="aggregations">Aggregations</h1>

An aggregation reduces a column (or DataFrame) to a single number, or a small set of numbers. The basics are `sum`, `mean`, `min`, `max`, `count`, `median`, `std`. They're all methods on a Series or a DataFrame.

```python
import pandas as pd

orders = pd.DataFrame(
    {
        "order_id": [1001, 1002, 1003, 1004, 1005, 1006],
        "customer": ["Alice", "Bob", "Alice", "Carol", "Bob", "Alice"],
        "product": ["Mouse", "Keyboard", "Hub", "Keyboard", "Speaker", "Mouse"],
        "category": ["Electronics", "Electronics", "Cables", "Electronics", "Audio", "Electronics"],
        "quantity": [1, 2, 1, 1, 1, 3],
        "price": [29.99, 89.99, 24.50, 89.99, 49.99, 29.99],
    }
)
print(orders["price"].sum())
print(orders["price"].mean())
print(orders.shape[0], "orders")
```

`orders["price"].sum()` adds the price column and returns a single float. `mean()` is the average. `shape[0]` is the number of rows (the count). Calling these on the whole DataFrame returns a Series, one value per numeric column:

```python
print(orders[["quantity", "price"]].sum())
```

Each column got its own sum. Non-numeric columns (`customer`, `product`, `category`) would be ignored by `sum()` by default.
