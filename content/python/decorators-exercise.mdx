Create an `announce_call` decorator that wraps any function with two printed status messages. When `greet("Mina")` is called, the wrapper prints `About to call greet` before calling the original function and `Finished call to greet` after it returns.

The decorated `greet` function must still return the string `Hello, Mina!`, so the existing final `print(message)` call displays that returned value.
