<h1 id="the-three-selection-operators">The Three Selection Operators</h1>

Pandas has three ways to pull data out of a `DataFrame`: bracket selection on columns, `.loc[]` for label-based access, and `.iloc[]` for position-based access. They look similar but mean different things, and mixing them up is a common source of pandas bugs.

Start with a small product catalog:

```python
import pandas as pd

products = pd.DataFrame(
    {
        "name": ["Wireless Mouse", "Mechanical Keyboard", "USB-C Hub", "Webcam", "Speaker"],
        "category": ["Electronics", "Electronics", "Cables", "Electronics", "Audio"],
        "price": [29.99, 89.99, 24.50, 59.99, 49.99],
        "stock": [42, 15, 7, 22, 30],
    },
    index=["P001", "P002", "P003", "P004", "P005"],
)
print(products)
```

The index is the product ID (`P001` through `P005`), not the default `RangeIndex` of `0, 1, 2, ...`. The columns are `name`, `category`, `price`, `stock`.

<h3 id="column-selection-with-dfcol">Column Selection with df[col]</h3>

`df["price"]` returns a single column as a `Series`. `df[["price", "stock"]]` (note the double brackets) returns a new `DataFrame` with just those columns. The double-bracket form is a list of column names, which is how pandas decides "give me a DataFrame, not a Series."
