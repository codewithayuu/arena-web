Build and import a tiny regular package named `ecommerce`. The program creates `ecommerce/__init__.py`, `ecommerce/cart.py`, and `ecommerce/products.py` in a temporary project directory.

Use `from ecommerce.cart import add_item, cart_total` and `from ecommerce.products import PRICES` where the placeholders are shown. The cart must add 2 `"Wireless Mouse"` items and 1 `"USB Cable"` item, then total them using prices 29.99 and 9.99 from the package.
