Run an async greeting from a regular script. The coroutine `make_greeting` should pause once with `asyncio.sleep(0)`, then return the string built from the name `"Ada"` as `"Hello, Ada!"`.

`main` should await `make_greeting("Ada")` and print the returned string. Use `asyncio.run(main())` as the entry point.
